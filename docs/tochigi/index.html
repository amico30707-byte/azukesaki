医療的ケア児支援センター

栃木県医療的ケア児等支援センターくくるん

医療的ケアの必要なお子様・ご家族・支援者から相談を受け、地域の関係機関と連携する窓口です。公式ページに相談フォームと問い合わせ先の案内があります。

出典：https://www.cfa.go.jp/assets/contents/node/basic_page/field_ref_resources/5218c3a3-610e-4925-8596-a9116889756f/b536f355/20260617_policies_shougaijishien_care-ji-shien_21.pdf　確認日：2026年3月

  • 栃木県の短期入所・障害児のあずけ先まとめ栃木県で、重い障害や医療的ケアのあるお子様をあずけられる短期入所・日中一時支援の探し方をまとめました。相談の窓口や受給者証の申しこみ先、見学のポイントもやさしく説明します。
  • 宇都宮市の短期入所・日中一時支援・移動支援宇都宮市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。通学通所支援や医療的ケア児在宅レスパイト事業も、やさしく説明します。
  • 栃木市の短期入所・日中一時支援・移動支援栃木市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。急な病気のときなどに助けを受けやすくする「くらしだいじネット」や、市独自の重度障がい児支援手当も、やさしく説明します。
  • 小山市の短期入所・日中一時支援・移動支援小山市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。電話で24時間相談できる「小山市障がい児者基幹相談支援センター」や、家でのお風呂がむずかしい方のための訪問入浴サービスも、やさしく説明します。
  • 那須塩原市の短期入所・日中一時支援・移動支援那須塩原市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。お子様を受け入れる短期入所の事業所や、急なときに受け入れる「地域生活支援拠点」、医療的ケアのあるお子様が使える栃木県の在宅レスパイト事業も、やさしく説明します。
  • 足利市の短期入所・日中一時支援・移動支援足利市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。前もって登録しておいた方を短期入所で受け入れる「あっしーネット緊急時支援事業」や、小学校に入る前のお子様の通所の料金の助成も、やさしく説明します。
