医療的ケア児支援センター

鹿児島県医療的ケア児等支援センター

出典：https://www.cfa.go.jp/assets/contents/node/basic_page/field_ref_resources/5218c3a3-610e-4925-8596-a9116889756f/b536f355/20260617_policies_shougaijishien_care-ji-shien_21.pdf　確認日：2026年3月

まとめの記事

  • 鹿児島県の短期入所・障害児のあずけ先まとめ鹿児島県で、重い障害や医療的ケアのあるお子様をあずけられる短期入所・日中一時支援の探し方をまとめました。相談の窓口や受給者証の申しこみ先、見学のポイントもやさしく説明します。
  • 鹿児島市の短期入所・日中一時支援・移動支援鹿児島市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。日帰りショートステイや重症児の訪問看護の助成も、やさしく説明します。
  • 鹿屋市の短期入所・日中一時支援・移動支援鹿屋市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。手帳がなくても使える場合がある日中一時支援や、児童発達支援・放課後等デイサービスなどの利用者負担の免除も、やさしく説明します。
  • 霧島市の短期入所・日中一時支援・移動支援霧島市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。お子様の相談先や事業所をまとめた「きりしま発達支援ガイドブック」や、市独自の「霧島市福祉手当」も、やさしく説明します。
  • 薩摩川内市の短期入所・日中一時支援・移動支援薩摩川内市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。市内で医療型の短期入所をしている済生会川内病院や、医療的ケアのあるお子様のための訪問看護師による見守りも、やさしく説明します。
