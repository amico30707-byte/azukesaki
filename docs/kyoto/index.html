医療的ケア児支援センター

京都府医療的ケア児等支援センターことのわ

医療的ケアや重症心身障害のあるお子様とご家族の相談を受け、情報提供や関係機関の案内を行います。専用電話は075-414-5120。受付は平日9時〜16時（祝日・年末年始を除く）。京都府庁1号館4階の障害者支援課内です。この案内は施設の空きや個別の受け入れを示すものではありません。

出典：https://www.cfa.go.jp/assets/contents/node/basic_page/field_ref_resources/5218c3a3-610e-4925-8596-a9116889756f/b536f355/20260617_policies_shougaijishien_care-ji-shien_21.pdf　確認日：2026年3月

公式の相談先・案内

  • 京都市の障害福祉サービス事業所一覧
    京都市の事業所を探す公式の入口です。お子様の年齢と利用条件は別途ご確認ください。　確認日：2026年9月25日

まとめの記事

  • 京都府の短期入所・障害児のあずけ先まとめ京都府で、重い障害や医療的ケアのあるお子様をあずけられる短期入所・日中一時支援の探し方をまとめました。相談の窓口や受給者証の申しこみ先、見学のポイントもやさしく説明します。
  • 京都市の日中一時支援・移動支援京都市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。ほほえみネットや医療的ケアのコーディネーターも、やさしく説明します。
  • 宇治市の日中一時支援・移動支援宇治市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。お子様の料金が低くなる区分や、宇治支援学校の空き教室での日中一時支援も、やさしく説明します。
  • 舞鶴市の日中一時支援・移動支援舞鶴市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。18歳以下のお子様が泊まれる「京都府立舞鶴こども療育センター」や、放課後や長い休みにあずかる「就学児童等タイムケア事業」も、やさしく説明します。
