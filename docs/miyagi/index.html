医療的ケア児支援センター

宮城県医療的ケア児等相談支援センターちるふぁ

医療的ケアのあるお子様とご家族、関係者の相談を、電話・メール・来所・訪問で受ける窓口です。電話は022-346-7835、電話相談は月〜金曜（祝日を除く）9時〜16時30分です。

出典：https://www.cfa.go.jp/assets/contents/node/basic_page/field_ref_resources/5218c3a3-610e-4925-8596-a9116889756f/b536f355/20260617_policies_shougaijishien_care-ji-shien_21.pdf　確認日：2026年3月

まとめの記事

  • 宮城県の短期入所・障害児のあずけ先まとめ宮城県で、重い障害や医療的ケアのあるお子様をあずけられる短期入所・日中一時支援の探し方をまとめました。相談の窓口や受給者証の申しこみ先、見学のポイントもやさしく説明します。
  • 仙台市の短期入所・日中一時支援・移動支援仙台市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。日中ショートステイの申しこみ方や医療的ケアの相談先も、やさしく説明します。
  • 石巻市の短期入所・日中一時支援・移動支援石巻市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。重い心身の障害のあるお子様が市外の短期入所を使うときに、ガソリン代や付きそいの費用を助ける市の制度や、石巻市・女川町の基幹相談支援センター「くるみ」も、やさしく説明します。
  • 大崎市の短期入所・日中一時支援・移動支援大崎市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。市民税がかからない世帯や生活保護の世帯は料金がかからない移動支援や、大崎市民病院の医療型短期入所も、やさしく説明します。
