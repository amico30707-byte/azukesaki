医療的ケア児支援センター

いしかわ医療的ケア児支援センターこのこの

医療的ケアの必要なお子様、ご家族、支援者から相談を受ける窓口です。平日9〜17時、電話とメールの相談を公式ページで確認しました。

出典：https://www.cfa.go.jp/assets/contents/node/basic_page/field_ref_resources/5218c3a3-610e-4925-8596-a9116889756f/b536f355/20260617_policies_shougaijishien_care-ji-shien_21.pdf　確認日：2026-03

まとめの記事

  • 石川県の短期入所・障害児のあずけ先まとめ石川県で、重い障害や医療的ケアのあるお子様をあずけられる短期入所・日中一時支援の探し方をまとめました。相談の窓口や受給者証の申しこみ先、見学のポイントもやさしく説明します。
  • 金沢市の日中一時支援・移動支援金沢市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。看護職員が付きそう外出支援や料金が無料になるしくみも、やさしく説明します。
