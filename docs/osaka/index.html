  • 大阪市 移動支援・日中一時支援

    大阪市

    外出の付きそい日中のあずかり

    対象：移動支援は、外出の支援が必要な重度の盲ろう、知的、精神、重度の全身性の障害があるお子様も対象です。日中一時支援は、市内在住の身体・知的・精神の障害があるお子様や難病等のある方が対象です。

    社会生活上必要な外出や余暇・社会参加を支える移動支援と、ご家族の就労や休息のため登録事業所で日中を過ごす日中一時支援です。利用目的と場所が異なります。

    くわしく（大阪市 移動支援・日中一時支援）
