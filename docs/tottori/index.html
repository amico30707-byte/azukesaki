医療的ケア児支援センター

鳥取県医療的ケア児等支援センター

県内を東部・中部・西部の3つの相談窓口で支えています。電話は平日9〜16時30分。メール・相談フォーム・FAXはいつでも送れます。

出典：https://www.cfa.go.jp/assets/contents/node/basic_page/field_ref_resources/5218c3a3-610e-4925-8596-a9116889756f/b536f355/20260617_policies_shougaijishien_care-ji-shien_21.pdf　確認日：2026年3月

まとめの記事

  • 鳥取県の短期入所・障害児のあずけ先まとめ鳥取県で、重い障害や医療的ケアのあるお子様をあずけられる短期入所・日中一時支援の探し方をまとめました。相談の窓口や受給者証の申しこみ先、見学のポイントもやさしく説明します。
  • 鳥取市の短期入所・日中一時支援・移動支援鳥取市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。市に登録している日中一時支援の事業所や、お子様の移動支援の決まりも、やさしく説明します。
  • 米子市の短期入所・日中一時支援・移動支援米子市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。医療的ケアのあるお子様も短期入所を相談できる鳥取県立総合療育センターや、県の一時預かりの場所も、やさしく説明します。
