医療的ケア児支援センター

熊本県医療的ケア児支援センター

熊本県内の医療的ケア児や重症心身障害児の在宅生活を支える相談・連携窓口です。ご家族向けの相談電話は平日9〜12時・13〜17時と公式ページで案内されています。

出典：https://www.cfa.go.jp/assets/contents/node/basic_page/field_ref_resources/5218c3a3-610e-4925-8596-a9116889756f/b536f355/20260617_policies_shougaijishien_care-ji-shien_21.pdf　確認日：2026-03

まとめの記事

  • 熊本県の短期入所・障害児のあずけ先まとめ熊本県で、重い障害や医療的ケアのあるお子様をあずけられる短期入所・日中一時支援の探し方をまとめました。相談の窓口や受給者証の申しこみ先、見学のポイントもやさしく説明します。
  • 熊本市の日中一時支援・移動支援熊本市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。医療型短期入所をふやす取り組みや相談先も、やさしく説明します。
  • 八代市の日中一時支援・移動支援八代市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。小学1年生から高校3年生のお子様が放課後や夏休みなどに使える「障がい児タイムケア」や、「日中短期入所」も、やさしく説明します。
