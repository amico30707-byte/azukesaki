医療的ケア児支援センター

島根県医療的ケア児支援センターどんぐり

県内の医療的ケアが必要なお子様とご家族を対象に、相談と関係機関の調整を行います。電話は070-1263-2225、平日9時〜16時です。フォーム・メールの案内もあります。

出典：https://www.cfa.go.jp/assets/contents/node/basic_page/field_ref_resources/5218c3a3-610e-4925-8596-a9116889756f/b536f355/20260617_policies_shougaijishien_care-ji-shien_21.pdf　確認日：2026-03

まとめの記事

  • 島根県の短期入所・障害児のあずけ先まとめ島根県で、重い障害や医療的ケアのあるお子様をあずけられる短期入所・日中一時支援の探し方をまとめました。相談の窓口や受給者証の申しこみ先、見学のポイントもやさしく説明します。
