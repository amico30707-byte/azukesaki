あずけ先の種類と使い方

短期入所と日中一時支援の違い・ヘルパーとの使い分け

更新日：2026年11月9日

  • ひと目でわかるちがい
  • 短期入所：お泊まりもできるあずけ先
  • 日中一時支援：日中だけのあずけ先
  • 居宅介護：家に来てもらう
  • 移動支援：外出に付きそってもらう
  • どれを使えばいい？

はじめに

「あずけたい」と思って調べると、むずかしい言葉がたくさん出てきます。短期入所、日中一時支援、居宅介護、移動支援。名前が似ていて、ちがいが分かりにくいですよね。

この記事では、「どこで」「どのくらいの時間」「何をしてもらえるか」で、ちがいを整理します。

ひと目でわかるちがい

名前 どこで 時間 こんなときに 申しこみ先
短期入所（ショートステイ） 施設や病院 日帰り〜数日のお泊まり ご家族の休息、冠婚葬祭、病気、きょうだいの行事 市区町村（国の制度）
日中一時支援 施設 日中の数時間（お泊まりなし） 放課後や休みの日、ご家族の仕事や休息 市区町村（市区町村ごとの制度）
居宅介護（ホームヘルプ） ご自宅 決まった時間 食事・おふろ・トイレのお手伝い、通院の付きそい 市区町村（国の制度）
移動支援（外出の付きそい） 外出先 外出の間 買い物、余暇、行事などのお出かけ 市区町村（市区町村ごとの制度）

短期入所：お泊まりもできるあずけ先

施設や病院にお子様をあずけて、日帰りや数日のお泊まりをするしくみです。医療的ケアが必要なお子様は、病院などの「医療型」を使うことが多いです。

初めて使うまでに、受給者証の手続き、事前の診察、見学、体験の利用などが必要なところが多いです。使いたい日の何か月も前から、じゅんびを始めておくと安心です。

日中一時支援：日中だけのあずけ先

日中の数時間だけ、施設で過ごすしくみです。お泊まりはしません。市区町村ごとの制度なので、名前や使える時間、対象のお子様が地域によってちがいます。

「日帰りショートステイ」「タイムケア」など、別の名前でよばれていることもあります。

居宅介護：家に来てもらう

ヘルパーさんがご自宅に来て、食事やおふろ、トイレなどを手伝ってくれます。いつもの家で過ごせるので、場所が変わると落ち着かないお子様にも合いやすいです。

お子様の場合は、多くの市区町村で、お父様・お母様の病気やお仕事など、お世話がむずかしい事情があるときに使えます。使える時間は市区町村が決めます。また、ご家族が家にいることを条件にしている事業所もあります。

移動支援：外出に付きそってもらう

お出かけのときに、ヘルパーさんが付きそってくれるしくみです。市区町村ごとの制度で、通学や通所など毎日続く外出には使えないことが多いです。

小さいお子様は対象外のこともあるので、市区町村の窓口でご確認ください。

どれを使えばいい？

  • 1日以上、ご家族がお世話できない日がある → 短期入所
  • 数時間だけ、あずけたい → 日中一時支援
  • 家でのお世話を手伝ってほしい → 居宅介護
  • お出かけを手伝ってほしい → 移動支援

いくつかを組み合わせて使うご家族も多いです。どれも、まずはお住まいの市区町村の窓口か、相談支援事業所に相談するところから始まります。

※制度の名前、対象、使える時間は、市区町村によってちがいます。くわしくはお住まいの窓口でご確認ください。

お住まいの地域のあずけ先をさがす →都道府県や、お子様に必要なケアからさがせます

あわせて読みたい

  • 医療型短期入所とは？福祉型との違いと使い方医療型短期入所は、医療的ケアのあるお子様が病院などでお泊まりできる短期入所です。福祉型とのちがい、どんなときに使うか、はじめて使うまでの流れと知っておきたいことを説明します。
  • 日中一時支援と放課後等デイサービスの違い日中一時支援と放課後等デイサービスは、どちらも日中にお子様をあずけられる支援です。目的、使える時間、費用、申しこみ先のちがいと、組み合わせて使う方法を説明します。
  • 障害児のヘルパーが見つからないときにできる7つのこと受給者証にヘルパーの時間があるのに、来てくれる事業所が見つからない。そんなときに試したい7つのことをまとめました。探し方の工夫や、ほかの支援との組み合わせ方を説明します。
  • 短期入所の費用はいくら？障害児の利用料のしくみ短期入所の利用料は、原則1割負担で、ひと月の上限があります。上限額の決まり方、食費などの実費、日中一時支援との費用のちがいなど、お金のしくみをやさしく説明します。
