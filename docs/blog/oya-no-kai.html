障害児の親の会・ピアサポートとは？同じ立場のご家族とつながる方法

はじめに

「この気持ちを、わかってくれる人がまわりにいない」。重い障害や医療的ケアのあるお子様を育てていると、そう感じる日があるとおもいます。病院や役所の人は親身になってくれても、毎日の小さなこまりごとまでは話しにくいものです。

そんなときに支えになるのが、同じ立場のご家族とのつながりです。この記事では、親の会やピアサポートとは何か、どこでさがせるか、はじめて参加するときのコツをまとめました。

親の会・ピアサポートとは

親の会は、障害や病気のあるお子様を育てるご家族が集まる会です。ピアサポートは、「同じ経験をした人どうしの支え合い」という意味です。「ピア」は「仲間」という意味の英語です。

親の会では、たとえば次のようなことをしています。

  • 集まって話をする会（おしゃべり会、交流会）
  • 学校やあずけ先、制度についての勉強会
  • 行事やレクリエーション
  • 国や自治体に、こまっていることを伝える活動

制度の情報だけでなく、くらしのくふうを知ることができるのも、親の会のよいところです。

こんなときに、つながりが助けになる

同じ立場のご家族の話は、とくに次のような「変わり目」に役立ちます。

時期 聞いてみたいこと
診断や退院のすぐあと 家でのケアのくふう、はじめに使ったサービス
小学校に入る前 学校のえらび方、付きそいのこと（「就学相談とは？」）
長いお休みの前 夏休みや春休みのあずけ先の使い方
高校を卒業する前 卒業後の通い先や、くらしの場の見学のこと
親なきあとをかんがえはじめたとき お金やくらしのじゅんびの進め方（「親なきあとの準備は何から？」）

窓口で聞く制度の話と、じっさいに使ったご家族の話を合わせると、自分の家に合う形が見えやすくなります。ただし、地域や年度できまりが変わることもあるので、最後は窓口でたしかめましょう。

どんな会があるか

全国に、都道府県ごとの支部や会がある団体があります。都道府県がのせている団体一覧（静岡県、新潟県、島根県など）には、たとえば次のような会が出ています。

会の名前 どんなご家族の会か
重症心身障害児（者）を守る会 重い知的障害と重い体の障害があるお子様のご家族
手をつなぐ育成会 知的障害のある方のご家族
自閉症協会 自閉症のある方のご家族
肢体不自由児者父母の会連合会 体の障害のあるお子様のご家族
全国心臓病の子どもを守る会（各県の支部） 心臓病のあるお子様のご家族
日本ダウン症協会（各県の支部） ダウン症のある方のご家族
難聴児を持つ親の会 耳のきこえにくいお子様のご家族

一覧には、てんかん、筋ジストロフィー、遷延性意識障害（いしきがもどりにくい状態が長く続いている）など、病気や状態ごとの会ものっています。お子様の障害や病気がいくつもあるときは、いちばん気になることに近い会からさがしてみるとよいでしょう。

このほかに、医療的ケアのあるお子様のご家族の会がある県もあります。たとえば島根県の一覧には「医療的ケア家族会しまね」がのっています。病気の名前ごとの会や、市町村の小さな会もあります。

会の名前やある・なしは、都道府県によってちがいます。お住まいの地域にどんな会があるかは、次のさがし方でたしかめてください。

さがし方

  1. 都道府県のホームページで「障害者団体」「家族会」と調べる。団体の一覧をのせている都道府県がある（新潟県は2026年4月、島根県は2026年7月の一覧を公開）
  2. 市区町村の障害福祉の窓口で、地域の親の会を聞く
  3. 相談支援専門員に聞く（「相談支援事業所とは？」）
  4. 医療的ケアのあるお子様は、都道府県の医療的ケア児支援センターに聞く（「医療的ケア児支援センター一覧」）
  5. 主治医や病院の相談室、通っている事業所の職員に聞く

窓口では、「同じような障害のお子様のご家族と話したい」と、そのまま伝えてかまいません。

小児慢性特定疾病のお子様は、自立支援事業も

小児慢性特定疾病（国が決めた子どもの長い病気）の医療費助成を受けているお子様のご家族は、「小児慢性特定疾病児童等自立支援事業」の相談も使えます。都道府県、政令市、中核市などが行っている事業です。

国の事業として行われた調査の報告では、この相談のなかで、ピアカウンセリング（同じ経験をした人が相談にのること）を行っている自治体があると紹介されています。相談にのる人は、同じような病気のお子様を育てた経験のある方や、患者会・家族会の方が多いとされています。また、お子様どうしやご家族どうしが交流する「相互交流支援」を行っている自治体もあります。

お住まいの地域で何をしているかは、医療費助成の窓口（保健所など）でご確認ください。医療費の助成のしくみは「子どもの医療費の助成のちがい」にまとめています。

国も「ご家族どうしの支え合い」を進めます

2026年7月に、医療的ケア児支援法を改正する法律が成立しました。2027年4月1日からはじまる新しいしくみでは、相談の体制づくりの1つとして、国や自治体が、ご本人やご家族どうしの交流の活動などを支える取り組みをすることが書かれています（「医療的ケア児支援法の改正で何が変わる？」）。これから、センターや市区町村で、交流の場が少しずつふえていくかもしれません。

はじめて参加するとき

  • まずは、話を聞くだけのつもりで参加してみる
  • オンラインの会や、少人数の会からはじめてみる
  • 会員にならなくても参加できる集まりがあるか、会費や役わり（係の仕事など）があるかを先に聞いておく
  • お子様をつれて行けるか、会場が車いすで入れるかをたしかめる
  • 1回行って合わないと感じたら、ほかの会をさがしてもよい

会によって、ふんいきはさまざまです。「ここなら話せそう」とおもえる場所を、ゆっくりみつけてください。

気をつけたいこと

  • ほかのご家庭の話は、そのご家庭のばあいのことです。お子様のケアや薬のことは、かならず主治医に相談してください
  • 聞いた話を、ほかの場所で名前つきで話さないようにしましょう
  • SNSやオンラインの集まりでは、お子様の顔写真や、住所や学校がわかる情報をのせすぎないようにしましょう
  • お金がかかる物や、特別な治療をすすめられたときは、すぐに決めずに、主治医や窓口に相談しましょう

きょうだいや、つかれたときの相談先も

きょうだい児（障害のあるお子様の兄弟姉妹）が集まる会もあります。きょうだいの気持ちは「きょうだい児の気持ちとサポート」でまとめています。

親の会に行く元気もないほどつかれているときは、まず休むことがたいせつです。相談先は「障害児の子育てに疲れたとき、相談できる場所」にまとめています。

さいごに

同じ立場のご家族とのつながりは、すぐに何かを解決してくれるものではないかもしれません。でも、「ひとりではない」と感じられることは、長く子育てを続けるうえで大きな力になります。親の会で、あずけ先の生の情報をおしえてもらえることもあります。

あずけさき手帖では、お住まいの地域のあずけ先をさがせます。お住まいの市区町村のページもあわせてご覧ください。

※ここであげた会は一例で、あずけさき手帖がすすめるものではありません。会の活動や連絡先は変わることがあります。くわしくは都道府県や市区町村の窓口でご確認ください。
