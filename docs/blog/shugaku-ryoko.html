医療的ケア児の修学旅行・宿泊行事｜付きそい・看護師・準備の順番

公開日：2026年11月12日

はじめに

修学旅行や宿泊学習は、お子様にとって、友だちといっしょにすごす特別な思い出になる行事です。でも、医療的ケアのあるお子様のお父様・お母様からは、「親が付きそわないと参加できないと言われた」「夜のケアはだれがしてくれるの？」という声も聞かれます。

この記事では、文部科学省の通知や資料でわかった国の考え方と、学校と話し合うときの順番をまとめました。学校の医療的ケアや付きそいのきほんは、「就学相談とは？医療的ケアのある子の学校・訪問教育・付きそい」にまとめています。

国の考え方：付きそいは「本当に必要なときだけ」

文部科学省は、学校での医療的ケアについて話し合った会議のまとめを、通知で学校などに伝えています（平成30年6月20日の「中間まとめ」、平成31年3月20日の「最終まとめ」）。中間まとめの通知には、次のように書かれています。

  • 保護者の付きそいの協力をもらうことは、お子様の自立のためにも、「真に必要と考えられる場合に限るよう努めるべき」
  • やむをえず協力をたのむときも、ほかの方法をよく考えたうえで、その理由やこれからの見通しを、ていねいに説明する

最終まとめをしょうかいした東京都の会議の資料（令和元年7月）でも、同じ考え方がまとめられていて、校外学習（宿泊学習をふくむ）での医療的ケアも取り上げられています。

さらに、2026年に成立した医療的ケア児支援法の改正では、保護者の付きそいがなくても、授業に出たり、修学旅行などの行事に参加したりするための支援を受けられるように、学校などがすることの例に「介護の職員をおくこと」がくわえられました（2027年4月から。くわしくは「医療的ケア児支援法の改正で何が変わる？」）。

文部科学省の資料に書かれていること（令和8年）

文部科学省の「令和7年度 学校における医療的ケアに関する実態調査結果」（令和8年7月公表）の参考資料には、宿泊をともなう行事について、次のようなことがのっています。

文部科学省「小学校等における医療的ケア実施支援資料」（令和8年7月に一部改訂）

  • 今回の改訂で、学校で働く看護師などを、宿泊をともなう校外活動に同行させるときに、自治体がすることを、新しく整理した
  • お子様の様子によって、医師に参加してよいかを確かめる
  • 必要に応じて、日程に合わせた看護師などへの指示を、医師からあらためて受ける
  • 学校の外や夜に考えられる対応や、緊急のときの対応を、保護者だけでなく医師にも確かめる
  • お子様の情報と緊急のときの対応を、引率するすべての先生で共有する

文部科学省「学校における医療的ケア実施ガイドライン【ひな形】」

自治体が自分たちのガイドラインをつくるときの「ひな形（見本）」です。修学旅行などの宿泊をともなう校外学習について、次のことを書くようにとされています。

  • 病気や医療的ケアの内容で、参加できるかどうかや、保護者の付きそいを「画一的に」決めない
  • 主治医などのほか、お子様とご家族の気持ちを大切にして、一人ひとり決める
  • 夜もふくめた、そのときだけの医療的ケアの体制をつくる方法を考える
  • ふだん学校の看護師がしていない夜の医療的ケアがいることがあるので、学校・主治医・保護者などで話し合い、協力する

つまり、国の資料では、「医療的ケアがあるから参加できない」「必ず親が付きそう」と決めつけるのではなく、一人ひとり話し合って決める方向をしめしています。ただし、看護師の人数や、夜の体制は、学校や自治体によってちがいます。お住まいの都道府県・市区町村でご確認ください。

話し合いの順番

  1. 行事の日程がわかったら、早めに担任の先生に「参加したい」と伝える
  2. 主治医に、参加してよいか、旅行先でとくに気をつけることを聞く
  3. 学校と、だれが医療的ケアをするか（学校の看護師が同行するか）、夜のケアをどうするかを話し合う
  4. 宿泊先の設備（電源、部屋、ベッド、おふろ）や、近くの病院を確かめてもらう
  5. 緊急のときの連絡の流れを、学校・主治医・ご家族で決める
  6. 必要なら、事前に下見や、短い時間の外出で練習する

医療と学校のあいだに入ってくれる人として、医療的ケア児等コーディネーターに相談できる地域もあります（「医療的ケア児等コーディネーターとは？」）。

学校に聞いておきたいこと

  • 学校の看護師は同行するか。何人で、夜もいるか
  • 夜の吸引や体位を変えること、注入などは、だれがするか
  • 付きそいをたのまれたときは、その理由と、どの時間だけか
  • 医療機器の電源や、予備のバッテリーはどうするか（「医療的ケア児の災害・停電へのそなえ」）
  • 移動のバスや新幹線などで、ケアをどこでするか
  • 宿泊先の近くの、受け入れてくれる病院はどこか
  • 体調が悪くなったとき、どこで帰るか、だれがむかえに行くか

付きそいをたのまれたときは

話し合いのうえで、どうしても付きそいがいることもあります。そのときは、次のことを確かめておきましょう。

  • 付きそう時間は、夜だけか、ずっとか
  • 部屋はお子様といっしょか、べつか（友だちとすごす時間をまもれるか）
  • 費用（交通費、宿泊費）をだれが出すか
  • お父様・お母様のかわりに、ほかの家族が付きそえるか

付きそいの費用や、看護師の同行の費用のあつかいは、自治体や学校によってちがいます。お住まいの市区町村・学校でご確認ください。

また、お父様・お母様が付きそうあいだ、家にいるきょうだいのお世話も考えておく必要があります（「障害児のきょうだいの行事の日、預け先はどうする？」）。病院での付きそいのつらさについては「医療的ケア児の付き添い入院がつらいとき」にまとめています。

持っていくものと、伝えるメモ

  • お薬と、お薬手帳
  • 医療的ケアの物品と、予備
  • 医療機器と、予備のバッテリー
  • ケアの手順や、夜の様子、体調が悪いときのサインを書いたメモ
  • 主治医の連絡先と、緊急のときの連絡先

ケアの手順や、ふだんの様子をまとめたサポートブックがあると、看護師や先生に伝えやすくなります（「サポートブックの作り方」）。

行事の前から、できること

修学旅行は、学年が上がってから急に決まるわけではありません。早めにできることもあります。

  • 学校の看護師や先生に、ふだんのケアのようすを見てもらう機会をふやす
  • 日帰りの校外学習で、学校の外でのケアの流れをためしておく
  • 短期入所などで、家族以外の人とお泊まりする経験をしておく
  • 夜のケアの手順を、だれが見てもわかるように紙にまとめておく

家族以外の人とすごすお泊まりになれていると、お子様もご家族も、行事のときに少し安心できます。医療的ケアのあるお子様の短期入所については「医療的ケア児の預け先は？」にまとめています。

よくある質問

  • 付きそいをことわったら、参加できなくなりますか？ →国の考え方では、付きそいは本当に必要なときにかぎり、たのむときも理由や見通しを説明することになっています。まずは「どうしたら付きそいなしで参加できるか」を、学校といっしょに考えてもらってください。話し合いがむずかしいときは、教育委員会に相談する方法もあります。

  • 看護師の同行は、だれが決めますか？ →学校や、学校をもうけている自治体（教育委員会など）が体制を決めます。お住まいの教育委員会でご確認ください。

さいごに

修学旅行や宿泊学習は、お子様にとって大切な成長の機会です。国も、付きそいがなくても行事に参加できる方向をしめしています。あきらめる前に、主治医と学校に「どうしたら参加できるか」を相談してみてください。

あずけさき手帖では、医療的ケアに対応した短期入所などを、地域からさがせます。行事にむけて、家族以外の人とお泊まりする練習をしたいときにも、お役立てください。

※付きそいや看護師の同行のしかたは、学校・自治体・年度によって変わります。くわしくは学校やお住まいの教育委員会でご確認ください。

あわせて読みたい

  • 就学相談とは？医療的ケアのある子の学校・訪問教育・付きそい小学校に入る前の「就学相談」の流れと、医療的ケアのあるお子様の学校の選び方をまとめました。特別支援学校、訪問教育、学校の看護師、保護者の付きそいの実態まで、国の資料をもとにやさしく説明します。
  • 医療的ケア児の付き添い入院がつらいとき｜休む方法と使える支援お子様の入院に、お父様・お母様が付き添う「付き添い入院」。ねむれない、食事がとれない、きょうだいが心配。国の資料でわかった付き添いのきまりや、病院の環境をよくする国の事業、休むためにできることの順番をまとめました。
  • 医療的ケア児支援法の改正で何が変わる？2027年4月からのこと2026年7月に医療的ケア児支援法を改正する法律が成立し、2027年4月1日から新しいしくみが始まります。18歳をすぎた方や重症心身障害のある大人の方への対象の広がり、支援センター、学校・保育の付きそい、あずけ先にかかわる変化をまとめました。
  • 医療的ケア児等コーディネーターとは？何をしてくれる人か・どこにいるか医療的ケア児等コーディネーターは、医療・福祉・教育などの支えをつないでくれる人です。どんなことを相談できるか、相談支援専門員とのちがい、どこにいるか、つながり方をやさしくまとめました。
  • サポートブックの作り方・あずけ先に伝わる書き方サポートブックは、お子様のことをあずけ先に伝えるための手帳です。何を書けばよいか、伝わりやすい書き方、更新のタイミングまで、はじめて作るお父様・お母様向けにまとめました。
  • 障害児のきょうだいの行事の日、預け先はどうする？運動会や発表会など、きょうだいの行事の日に障害のあるお子様をあずける方法をまとめました。使えるあずけ先、早めの予約のコツ、はじめての利用で気をつけたいことを説明します。
  • 医療的ケア児の預け先は？吸引や経管栄養があっても使える場所たんの吸引や経管栄養など、医療的ケアのあるお子様のあずけ先をまとめました。使える場所の種類、まず相談したい窓口、問い合わせで伝えること、はじめて使うまでの流れを説明します。
  • 医療的ケア児の災害・停電へのそなえ・今日からできること人工呼吸器や吸引器を使うお子様にとって、災害や停電へのそなえは大切です。電源の確保、避難先の考え方、ふだんから用意しておきたい物を、今日からできる順にまとめました。
