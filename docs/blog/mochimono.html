はじめに

はじめてのお泊まりは、お子様にとっても、お父様・お母様にとっても、大きな一歩です。「ちゃんと眠れるかな」「泣いていないかな」と、心配でいっぱいになりますよね。

この記事では、はじめてのお泊まりの前にしておきたいことと、持ち物をまとめました。持ち物は施設によってちがうので、必ず施設の案内もあわせてご確認ください。

お泊まりの前にしておきたいこと

  • 見学や日帰りの体験で、場所と職員に少し慣れておく
  • サポートブックを用意して、施設に渡しておく
  • お子様に、写真や絵を使って「お泊まりに行く」ことを前もって伝える
  • 寝る前の習慣（お気に入りの音楽、決まった順番など）を、施設に伝えておく
  • 当日の体調が悪いときの連絡方法を確かめておく

当日のこと

  • 朝の体調（熱、食事、排せつ、ねむり）をメモして渡す
  • お別れは、短く、明るく。長く名残をおしむと、お子様が不安になることもあります
  • 迎えに行ったら、施設での様子を聞いて、次に向けたメモを残す

ショートステイは何歳から使える？

国の案内では、短期入所（ショートステイ）を使えるお子様は、「必要な支援の度合いに応じた区分で、区分1以上」とされています。「何歳から」という年齢の下限は、国の案内には書かれていません。区分は、受給者証の申しこみのときに、市区町村がお子様の様子を聞いて決めます（くわしくは「受給者証とは？障害児の取り方と流れをやさしく解説」）。

ただし、実際に何歳から受け入れてくれるかは、施設ごとにちがいます。お子様の年齢や体の状態、医療的ケアの内容によって、受け入れられるかどうかが変わることもあります。重い障害や医療的ケアのあるお子様は、病院などで行う医療型短期入所が選択肢になることもあります（「医療型短期入所とは？福祉型との違いと使い方」）。

見学や問い合わせのときに、「何歳から受け入れていますか」「はじめての利用の前に、体験や診察はありますか」と聞いておくと安心です。

出典：厚生労働省「障害福祉サービスについて」

1か月に何日使える？

1か月に何日使えるかは、市区町村がご家庭の事情を聞いて決めます。決まった日数は、受給者証に書かれています。受給者証の日数をこえて使った分は全額自分ではらうことになる、と案内している施設もあります。

また、国のきまりでは、短期入所を使う日数は「年間180日をこえないようにする」ことになっています（特に必要とみとめられる場合をのぞきます）。

さらに、「1回は3泊4日まで」のように、1回に泊まれる日数を施設ごとに決めていることもあります。

日数が足りないときは、ふやす申しこみができることがあります。くわしくは「受給者証の日数を増やしたいとき」をご覧ください。

出典：名古屋市「短期入所の年間利用日数の適正化について」、国立病院機構 柳井医療センター「短期入所のご案内」

お父様・お母様へ

はじめてのお泊まりの夜は、きっと落ち着かないと思います。でも、その時間は、どうかご自分のために使ってください。ぐっすり眠ること。それも、お泊まりの大切な目的です。

お住まいの地域のあずけ先をさがす →都道府県や、お子様に必要なケアからさがせます

あわせて読みたい

  • 短期入所（ショートステイ）の見学ポイント10こ・聞いておきたいこと短期入所やショートステイの見学で、見ておきたい10のことをまとめました。聞きにくいことの聞き方や、見学のあとに書いて残しておくと安心なことも、お父様・お母様向けに説明します。
  • サポートブックの作り方・あずけ先に伝わる書き方サポートブックは、お子様のことをあずけ先に伝えるための手帳です。何を書けばよいか、伝わりやすい書き方、更新のタイミングまで、はじめて作るお父様・お母様向けにまとめました。
  • 医療型短期入所とは？福祉型との違いと使い方医療型短期入所は、医療的ケアのあるお子様が病院などでお泊まりできる短期入所です。福祉型とのちがい、どんなときに使うか、はじめて使うまでの流れと知っておきたいことを説明します。
