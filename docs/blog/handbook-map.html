お子様の状態別

あなたの市の「医療的ケア児ハンドブック・支援マップ」はどこ？

公開日：2026年11月12日

はじめに

医療的ケアのあるお子様が家でくらすには、病院、訪問看護、福祉のサービス、手当、学校など、たくさんのしくみがかかわります。窓口もばらばらで、「何がつかえるのか、ぜんたいが見えない」と感じるお父様・お母様は多いと思います。

そこで、県や市の中には、医療的ケアのあるお子様とご家族のために、使えるしくみや相談先を1冊にまとめた冊子を作っているところがあります。名前は「ハンドブック」「ガイドブック」「しおり」「支援マップ」など、さまざまです。

この記事では、あずけさき手帖でたしかめた県・市の冊子を一覧にし、お住まいの市の冊子のさがし方と、上手な使い方をまとめました。

冊子には、どんなことがのっている？

冊子によってちがいますが、たとえばつぎのようなことがのっています。

  • 医療的ケアとは何か、どんな法律があるか
  • お子様のねんれいごとに、使えるサービスの見通し
  • 手帳や手当、医療費の助成
  • 訪問看護、ヘルパー、短期入所、相談支援の事業所
  • 医療的ケア児等コーディネーター（医療と福祉をつなぐ人）や相談窓口
  • 災害のときのそなえ

窓口で1つずつ聞いて回るまえに、まず冊子をひらくと、ぜんたいの地図が手に入ります。

県・市の冊子の例（あずけさき手帖でたしかめたもの）

地域 冊子の名前 作られた時期 おもにのっていること
栃木県 医療的ケアが必要なお子さんと家族のための支援ガイドブック栃木県 令和7年3月発行（情報は2024年12月時点） 家に帰るまでの流れ、先輩家族の声、短期入所を使うまでの流れ、福祉用具や住まいをととのえる支援、災害対策、市町などの相談窓口の一覧
松山市 医療的ケア児支援のしおり 2026年度版 保育園・幼稚園や学校での医療的ケア、学校で訪問看護を使ったときの補助、非常用電源を買うときの助成
西条市 医療的ケア児支援のしおり 2025年度版（令和7年4月） 医療的ケア児等コーディネーターのいる相談支援事業所、短期入所を使うときの受給者証、停電にそなえる電源の助成

このほか、江戸川区は、相談先などをホームページの「えどがわ医療的ケア児ガイド」（令和8年10月更新）にまとめています。

市の冊子のくわしいなかみは、それぞれの市の記事（松山市・西条市・福山市・厚木市・土浦市・摂津市・江戸川区）をご覧ください。

作られた時期を、かならず見てください

冊子は、作られたときの情報で書かれています。土浦市や摂津市のように、作られてから何年かたっているものもあります。そのあいだに、事業所がふえたりへったり、制度の金額やじょうけんが変わったりしていることがあります。

  • 表紙やさいごのページで、「〇年〇月」「〇年度版」をたしかめる
  • 事業所の一覧は、「今も受けいれているか」を電話で聞いてから動く
  • 金額やじょうけんは、市区町村の窓口でたしかめなおす

冊子は「ぜんたいを知るための地図」、窓口は「いまの答えを聞くところ」と考えると、使いやすくなります。

お住まいの市の冊子のさがし方

  1. インターネットで「（市区町村の名前） 医療的ケア児 ハンドブック」「（市区町村の名前） 医療的ケア児 ガイドブック」「（市区町村の名前） 医療的ケア児 しおり」と調べる。「支援マップ」「社会資源」でも調べてみる
  2. 市区町村のホームページの障害福祉や子育てのページで、「医療的ケア児」のページをさがす
  3. 市にないときは、都道府県のホームページや、都道府県の医療的ケア児支援センターのページを見る。栃木県のように、県が作っていることもあります（「医療的ケア児支援センター一覧」）
  4. 見つからないときは、市区町村の障害福祉の窓口や保健センターで「医療的ケアのある子どものための冊子はありますか」と聞く
  5. 相談支援専門員や、医療的ケア児等コーディネーターにも聞いてみる（「相談支援事業所とは？」「医療的ケア児等コーディネーターとは？」）

市によっては、冊子という名前ではなく、「障害福祉のしおり」や「福祉ガイドブック」の中に、医療的ケアのページが入っていることもあります。冊子がない市でも、窓口でおなじことを聞けば教えてもらえます。

冊子にのっていないことも、たくさんあります

冊子は、たくさんのしくみをまとめた便利なものですが、つぎのようなことは、のっていないことが多いです。

  • いまの空き状況（短期入所などが、いつ使えるか）
  • その事業所が、お子様とおなじケアのお子様を受け入れたことがあるか
  • 市の外にある病院や施設のこと

こうしたことは、相談支援専門員や医療的ケア児等コーディネーターに聞くのが近道です。医療的ケアのあるお子様が使えるあずけ先の種類は「医療的ケア児の預け先は？」、家に来てくれる看護師のことは「小児の訪問看護とは？」にまとめています。空きの調べ方は「重心・医療的ケアのショートステイの「空き」の調べ方」にまとめています。

また、県の冊子と市の冊子の両方があるときは、どちらも見てみてください。県の冊子は、県の支援センターや大きな病院のこと、市の冊子は、市のサービスや近くの事業所のことが、くわしく書かれていることがあります。

よくある困りごと

  • 市のホームページで、どこにあるかわからない →ホームページの中の検索に「医療的ケア」と入れてみてください。障害福祉のページではなく、子育てや保健のページにのっていることもあります。

  • 紙の冊子がほしい →窓口で、紙でもらえるか聞いてみてください。ページ数が多い冊子は、PDFで見るより、紙のほうが書きこみやすいこともあります。

  • 冊子の内容が古いようだ →あたらしい版がないか、窓口でたずねてみましょう。作りなおしの予定を教えてもらえることもあります。

冊子を手に入れたら、こう使う

  • 使っているしくみに丸、まだ使っていないしくみに印をつける
  • 気になるところに付せんをはって、窓口や相談支援専門員との話し合いに持っていく
  • ねんれいごとの見通しのページで、つぎの1〜2年に何がありそうかを見ておく（「年齢ごとのじゅんび地図」）
  • 災害のページがあれば、そのページだけでも先にやっておく（「医療的ケア児の災害・停電へのそなえ」）

NICUや病院から家に帰るまえのご家族は、退院のまえに冊子を手に入れておくと、病院や訪問看護の人との話がすすめやすくなります（「NICUから家に帰る前にしておく、あずけ先のじゅんび」）。

さいごに

冊子は、たくさんのしくみをいっぺんに知ることができる、心づよいどうぐです。ただし、作られた時期によっては内容が古くなっていることもあるので、さいごはかならず窓口でたしかめてください。

あずけさき手帖では、短期入所や日中一時支援など、医療的ケアにたいおうしたあずけ先を地域からさがせます。お住まいの市区町村のページもあわせてご覧ください。

※冊子の内容や、のっている事業所、制度のじょうけんは、年度や市区町村によって変わります。くわしくはお住まいの窓口でご確認ください。

あわせて読みたい

  • 医療的ケア児支援センター一覧・47都道府県の相談窓口医療的ケア児支援センターは、医療的ケアのあるお子様とご家族の相談窓口です。47都道府県のセンター一覧、相談できること、連絡のしかた、あずけ先さがしでの使い方をまとめました。
  • 医療的ケア児等コーディネーターとは？何をしてくれる人か・どこにいるか医療的ケア児等コーディネーターは、医療・福祉・教育などの支えをつないでくれる人です。どんなことを相談できるか、相談支援専門員とのちがい、どこにいるか、つながり方をやさしくまとめました。
  • 医療的ケア児の預け先は？吸引や経管栄養があっても使える場所たんの吸引や経管栄養など、医療的ケアのあるお子様のあずけ先をまとめました。使える場所の種類、まず相談したい窓口、問い合わせで伝えること、はじめて使うまでの流れを説明します。
  • 相談支援事業所とは？障害児の探し方と選び方相談支援事業所は、受給者証のための計画づくりや、あずけ先さがしを手伝ってくれる場所です。費用、自分で計画を作る方法、見つけ方、選ぶときに見ることをやさしく説明します。
  • NICUから家に帰る前にしておく、あずけ先のじゅんびNICUなどから、医療的ケアのある赤ちゃんと家に帰る前に、あずけ先や休むためのじゅんびとして、しておきたいことをまとめました。退院前の話しあいで聞くこと、相談の窓口、受給者証や医療費の手つづき、短期入所の登録を、順番にそって説明します。
  • 障害児の預け先はいつから？年齢ごとのじゅんび地図障害のあるお子様のあずけ先は、困ってから探すと間に合わないことがあります。0歳から18歳まで、年齢ごとにしておきたいじゅんびを、ひとつの地図のようにまとめました。
  • 医療的ケア児の災害・停電へのそなえ・今日からできること人工呼吸器や吸引器を使うお子様にとって、災害や停電へのそなえは大切です。電源の確保、避難先の考え方、ふだんから用意しておきたい物を、今日からできる順にまとめました。
  • 小児の訪問看護とは？回数・費用と在宅レスパイト小児の訪問看護で自宅に来てもらえるケアをまとめました。医療保険で使える回数や時間、費用と医療費の助成、ご家族が休むための在宅レスパイト事業、ステーションの選び方を説明します。
