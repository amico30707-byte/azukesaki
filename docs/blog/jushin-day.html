重症心身障害児の児童発達支援・放課後等デイサービス（重心型）とは？ちがい・さがし方

はじめに

「ねたきりで、たんの吸引もあるうちの子を、うけ入れてくれる通い先はあるのかな」。重い障害のあるお子様を育てるお父様・お母様から、よく聞く心配です。

お子様が通う場所には、小学校に入る前の「児童発達支援」と、学校に通うお子様の「放課後等デイサービス」があります。そのなかに、重い障害のあるお子様をおもにうけ入れる事業所があり、「重心型（じゅうしんがた）」とよばれることがあります。

この記事では、2つのサービスのちがい、重心型の事業所のとくちょう、さがす順番を、やさしくまとめました。「重症心身障害」という言葉の意味は、「重症心身障害児とは？医療的ケア児との違い」でくわしく書いています。

児童発達支援と放課後等デイサービスのちがい

どちらも、児童福祉法という国の法律で決められたサービスです。全国で、だいたい同じしくみで行われています。

児童発達支援 放課後等デイサービス
使うお子様 おもに小学校に入る前のお子様 学校（幼稚園と大学をのぞく）に通っているお子様
使う時間 平日の日中など 学校がおわったあと、土曜日や長いお休みの日
していること 毎日の生活の動きの練習、集団になれる練習など 生活の力をのばす練習、まわりの人との交流など
使える期間 小学校に入るまで 学校に通っているあいだ。ひつようとみとめられれば、20歳になるまで使えることがある

小学校に入るときに、児童発達支援から放課後等デイサービスに切りかわります。受給者証（サービスを使うための証明書）の中身も変わるので、入学の前の年の秋ごろから、相談支援専門員や市区町村の窓口と話しておくと安心です（「受給者証とは？障害児の取り方と流れをやさしく解説」）。

放課後等デイサービスと、市区町村の日中一時支援のちがいは、「日中一時支援と放課後等デイサービスの違い」をご覧ください。

「重心型」の事業所とは

国の基準では、「おもに重症心身障害のお子様を通わせる事業所」には、次の人をそれぞれ1人以上おくことになっています。児童発達支援でも、放課後等デイサービスでも同じです。

  • 嘱託医（その事業所とけいやくしている医師）
  • 看護職員（看護師など）
  • 児童指導員または保育士
  • 機能訓練担当職員（理学療法士など、体の動きの練習を見る人）
  • 児童発達支援管理責任者（お子様ごとの支援の計画をつくる人）

じっさいに、いつ、だれが何人いるかは事業所によってちがうので、見学のときに聞いてみてください。

また、国の基準をもとにした都道府県の条例（たとえば京都府）では、事業所の定員は、ふつうは10人以上です。でも、重心型の事業所は5人以上でもよいとされています。そのため、重心型は少人数の事業所が多いのが、とくちょうです。

児童発達支援センターとのちがい

小学校に入る前のお子様の通い先には、「児童発達支援センター」という名前のところもあります。以前は、センターに「福祉型」と「医療型（体の障害のあるお子様が対象）」の2つがありました。2024年4月からは法律が変わり、この2つが1つにまとめられました。あわせて、センターが地域の障害のあるお子様の支援の中心になる役わりも、はっきり決められました。

「近くに重心型の事業所がない」というときは、地域のセンターに相談してみるのも1つの方法です。

ふつうの事業所でも、うけ入れてくれることがある

重心型でなくても、看護師がいて、医療的ケアのあるお子様をうけ入れている事業所もあります。歩けるお子様や、ほかのお子様と遊ぶのが好きなお子様には、そちらが合うこともあります。

  • 重心型：少人数で、ねたきりのお子様や体の動きがとてもすくないお子様にあわせたすごし方が多い
  • 看護師がいるふつうの事業所：歩ける医療的ケア児など、動きのあるお子様も多い

どちらがよいかは、お子様の体のようすと、ケアの中身によります。「重心型しかだめ」ときめつけず、両方の候補を相談支援専門員に聞いてみてください。医療的ケアのあるお子様のあずけ先全体は、「医療的ケア児の預け先は？」にまとめています。

送迎のこと

国の資料では、放課後等デイサービスのしくみの中に「学校と事業所のあいだの送迎」が入っています。じっさいに送迎があるか、どこまで来てくれるか、車に看護師がいっしょに乗るかは、事業所ごとにちがいます。

医療的ケアのあるお子様の送迎は、事業所の人手が足りず、「送迎はご家族で」と言われることもあります。そこで2024年4月からは、国の報酬（事業所に入るお金）のしくみが見直されました。重症心身障害のあるお子様や医療的ケアのあるお子様を送迎するとき、運転する人のほかに職員や看護師などが車に乗ると、ふつうより多く加算されるようになっています（杉並区の説明資料より）。

見学のときは、次のことをかならず聞いておきましょう。

  • 家まで、または学校まで送迎があるか
  • 車いすのまま乗れる車か
  • 車の中で吸引などがひつようなとき、看護師が乗るか
  • 送迎がない日や、ご家族が送るときの時間

学校から事業所までの送り迎えにこまったときは、「障害児の通学支援・送り迎えに使えるサービス」も読んでみてください。

さがす順番

  1. 相談支援専門員に「重心型、または看護師がいる事業所をさがしたい」と伝える（まだいない方は「相談支援事業所とは？」）
  2. 市区町村の障害福祉の窓口で、地域の事業所の一覧をもらう
  3. 主治医や病院の相談室にも、通っているお子様が多い事業所を聞く
  4. 医療的ケアがあるお子様は、都道府県の医療的ケア児支援センターにも聞く（「医療的ケア児支援センター一覧」）
  5. 2〜3か所を見学して、体験の利用をする
  6. 市区町村で受給者証の手続きをして、事業所とけいやくする

重心型の事業所は数がすくなく、空きを待つことがあります。1か所にきめる前に、いくつか見学しておくと安心です。

見学で聞きたいこと

  • 看護師が、いつも何人いるか（お休みの日の体制も）
  • 吸引、経管栄養、人工呼吸器など、うけ入れられるケア
  • 体調が悪くなったときの連絡と、むかえのきまり
  • 1日のすごし方（体の動きの練習、ねる時間、食事）
  • 長いお休みの日の、開いている時間
  • 高校を卒業したあとの行き先について、相談にのってくれるか

見学のくわしいポイントは、「短期入所の見学ポイント10こ」も参考になります。

よくある困りごと

  • 空きがなく、待つことになった →ほかの事業所にも登録して、使える日を少しずつふやしましょう。待っているあいだは、日中一時支援や訪問のサービスを組み合わせる方法もあります。

  • 体調をくずしやすく、休みがちになる →休みが多くても通いつづけられるか、キャンセルのきまりはどうか、先に聞いておくと安心です。

  • 近くに事業所がない →となりの市の事業所を使えることもあります。家に来てもらう居宅訪問型児童発達支援もかんがえてみてください（「外に出にくい子の家で受けられるサービス」）。

費用のこと

利用料は、原則としてサービスの1割です。世帯の所得にあわせて、1か月の上限がきまっています。また、満3歳になってはじめての4月1日から小学校に入るまでの3年間は、児童発達支援などの利用料がかかりません（おやつ代などは別）。くわしくは「短期入所の費用はいくら？」をご覧ください。

さいごに

重心型の事業所は、お子様にとっては楽しくすごせる場所、お父様・お母様にとっては少し体を休められる時間になります。高校を卒業すると、通う場所は大人の「生活介護」などに変わるので、早めにかんがえておきましょう（「障害児の「18歳の壁」とは？」）。

あずけさき手帖では、医療的ケアや重症心身障害に対応したあずけ先を、地域からさがせます。お住まいの市区町村のページもあわせてご覧ください。

※事業所の体制や送迎、利用できる日数は、事業所や市区町村、年度によって変わります。くわしくは事業所やお住まいの窓口でご確認ください。

お住まいの地域のあずけ先をさがす →都道府県や、お子様に必要なケアからさがせます

あわせて読みたい

  • 日中一時支援と放課後等デイサービスの違い日中一時支援と放課後等デイサービスは、どちらも日中にお子様をあずけられる支援です。目的、使える時間、費用、申しこみ先のちがいと、組み合わせて使う方法を説明します。
  • 重症心身障害児とは？医療的ケア児との違い重症心身障害児と医療的ケア児は、重なるところもありますが意味がちがいます。それぞれの考え方、使えるあずけ先や支援のちがいを、お父様・お母様にもわかるように説明します。
  • 医療的ケア児の預け先は？吸引や経管栄養があっても使える場所たんの吸引や経管栄養など、医療的ケアのあるお子様のあずけ先をまとめました。使える場所の種類、まず相談したい窓口、問い合わせで伝えること、はじめて使うまでの流れを説明します。
  • 相談支援事業所とは？障害児の探し方と選び方相談支援事業所は、受給者証のための計画づくりや、あずけ先さがしを手伝ってくれる場所です。費用、自分で計画を作る方法、見つけ方、選ぶときに見ることをやさしく説明します。
  • 受給者証とは？障害児の取り方と流れをやさしく解説障害のあるお子様が短期入所や日中一時支援を使うには、受給者証が必要です。2つの種類、申しこみの流れ、届くまでの期間、費用や更新のことを、はじめての方にもわかるように説明します。
  • 障害児の「18歳の壁」とは？放課後の預け先が変わる前に18歳の壁とは、高校を卒業すると放課後等デイサービスが使えなくなり、夕方のあずけ先がなくなる問題です。何が変わるのか、卒業までにしておきたいじゅんびを説明します。
  • 外に出にくい子の家で受けられるサービス｜訪問入浴・居宅訪問型児童発達支援・訪問看護のちがい体が弱い、医療的ケアが多いなどで外に出にくいお子様が、家で受けられるサービスをまとめました。訪問入浴、居宅訪問型児童発達支援、訪問看護、ヘルパーのちがいと、申しこむ順番を説明します。
