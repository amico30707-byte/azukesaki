医療型短期入所とは？福祉型との違いと使い方

はじめに

短期入所（ショートステイ）には、「福祉型」と「医療型」があります。重い障害や医療的ケアのあるお子様の場合、医療型を使うことが多いです。

この記事では、医療型短期入所がどんなところか、福祉型とのちがい、はじめて使うまでの流れ、使うときに知っておきたいことをまとめました。

福祉型と医療型のちがい

福祉型 医療型
場所 障害のある方の施設など 病院、診療所、介護老人保健施設、介護医療院
使えるお子様 医療的なケアが多くないお子様 重症心身障害のお子様や、遷延性意識障害のお子様など（くわしい条件は市区町村で確かめる）
いる人 生活支援員など 医師・看護師がいる中で過ごす

国の資料では、医療型の対象は「遷延性意識障害（いしきがもどりにくい状態が長く続いている）のお子様、重症心身障害のお子様など」とされています。国の調査（2019年度）では、医療型短期入所を行っているところの9割以上（96.3%）が、病院や診療所でした。

お泊まりをしない日中だけの利用は、「医療型特定短期入所」とよばれることがあります。お泊まりなしなら、入院のベッドがない診療所でも行うことができます。

もう1つの選択肢「福祉型強化」

福祉型の中には、「福祉型強化短期入所」というしくみもあります。看護師などが常勤で1人以上いる福祉型の施設で、医療的ケアが必要なお子様を受け入れるためのものです。

2024年度からは、福祉型強化で日中だけ使える「福祉型強化特定短期入所」もできました。

近くに医療型がないときや、ケアの内容によっては、こちらが合うこともあります。市区町村や相談支援専門員に、両方の候補を聞いてみてください。

どんなときに使う？

  • ご家族が休みたいとき
  • ご家族が病気や出産、入院のとき
  • 冠婚葬祭や、きょうだいの行事のとき
  • 将来の暮らしにそなえて、家以外で過ごす練習をしたいとき

急な入院などで、すぐにあずけ先が必要になったときのことは「親が急に入院・倒れたときの障害児のあずけ先」にまとめています。

はじめて使うまでの流れ

  1. 市区町村で、医療型短期入所が使える受給者証の手続きをする
  2. 使いたい病院・施設に問い合わせる
  3. 主治医に、紹介状（診療情報提供書）を書いてもらう
  4. 施設で事前の診察や面談を受ける
  5. 見学や、日帰り・ご家族付きそいの体験をする
  6. 契約して、予約できるようになる

施設によっては、受給者証に「短期入所（医療型）」などと書かれていることが、利用の条件になります。手続きのときに、医療型を使いたいことをはっきり伝えてください（「受給者証とは？」）。

施設によっては、はじめての利用まで数か月かかります。急に必要になってからでは間に合わないことがあるので、早めにじゅんびを始めましょう。

ある県立の施設の例

愛知県のある県立の施設では、次のように案内しています。施設ごとにちがうので、あくまで一つの例として見てください。

  • 相談から本利用まで、おおよそ3〜4か月かかる
  • 体験の1回目はご家族付きそい、2回目はご家族なしで泊まる
  • 体験のあと、施設が受け入れを決める
  • 利用は、原則として月1回、8日以内
  • 予約の受付は、利用したい日のおよそ2か月前から
  • 1年以上使っていないと、もう一度受診が必要になる

「早めに登録して、ときどき使っておく」ことが大切な理由が、よく分かります。

知っておきたいこと

  • 入院の方のベッドが空いたときに使うところも多く、希望の日に使えるとは限りません
  • 予約の受付が「利用月の前の月の〇日まで」などと決まっていることが多いです
  • 体調がすぐれない日や、感染症がはやっている時期は、使えないことがあります
  • 利用中に体調をくずすと、むかえに行く必要があることがあります
  • 利用中は、治療や訓練、薬の処方などはしないところがあります
  • 受給者証の期限が切れていると、費用が全額自己負担になることがあります（「受給者証の更新はいつ？」）
  • 送り迎えはご家族がするところが多いです

はじめての利用の日

さきほどの県立の施設では、はじめに受付で受給者証を見せ、お子様の体調を確かめます。そのあと、病棟の看護師が、お子様のケアについて1時間ほど聞き取りをします。

ほかの施設でも、はじめての日は、ケアの手順をくわしく聞かれることが多いです。次のものを用意しておくと安心です。

  • 受給者証
  • お薬と、お薬手帳
  • ケアの手順を書いたメモ（吸引の回数、注入の量と時間、体位を変える間かくなど）
  • いつも使っている医療機器や、その消耗品
  • お子様が安心できるもの（タオル、おもちゃ、音楽など）

持ち物は、施設から一覧表をもらえることが多いです。くわしくは「ショートステイの持ち物リスト」もご覧ください。

よくある困りごと

  • 予約がなかなか取れない →1か所だけでなく、2〜3か所に登録しておくと、使える日がふえます。

  • 近くに医療型がない →福祉型強化短期入所や、レスパイト入院、訪問看護なども考えてみてください。都道府県の医療的ケア児支援センターに聞くと、地域の情報を教えてもらえることがあります（「医療的ケア児支援センター一覧」）。

  • 当日に熱が出て、使えなかった →体調が悪い日は使えないのがふつうです。キャンセルの連絡のしかたを、前もって聞いておきましょう。

  • 受け入れを断られた →理由を聞き、相談支援専門員と次の候補を考えましょう（「障害児の預け先がない・断られたときにできること」）。

費用のこと

利用料は、受給者証に書かれた「1か月の上限」の中でおさまります。そのほかに、食事代や光熱水費がかかるところがあります。くわしくは「短期入所の費用はいくら？」や「子どもの医療費の助成のちがい」をご覧ください。

問い合わせで聞いておきたいこと

  • お子様の年齢やケアの内容で、受け入れてもらえるか
  • 夜の看護師の人数
  • 呼吸器や吸引器、ポンプなどは、家から持っていくか
  • 予約のしかたと、いつから受け付けるか
  • 体験利用の回数と、ご家族の付きそいがいるか

見学のときに見ることは「短期入所の見学ポイント10こ」、持ち物は「ショートステイの持ち物リスト」にまとめています。病院が行うレスパイト入院とのちがいは「レスパイト入院とショートステイの違い」を、対象になる状態は「重症心身障害児とは？」をご覧ください。

さいごに

医療型短期入所は、数が少なく、すぐには使えないことも多いです。だからこそ、元気なうちに登録しておき、ときどき使っておくことが、いざというときの安心につながります。

医療的ケアのあるお子様のあずけ先ぜんたいについては、「医療的ケア児の預け先は？」もご覧ください。あずけさき手帖では、たんの吸引・経管栄養・人工呼吸器など、必要なケアから短期入所を探せます。

※対象や手続き、費用は、年度や施設、市区町村によって変わります。くわしくは施設やお住まいの窓口でご確認ください。

あわせて読みたい

  • 医療的ケア児の預け先は？吸引や経管栄養があっても使える場所たんの吸引や経管栄養など、医療的ケアのあるお子様のあずけ先をまとめました。使える場所の種類、まず相談したい窓口、問い合わせで伝えること、はじめて使うまでの流れを説明します。
  • レスパイト入院とショートステイの違い・どちらを使う？レスパイト入院と短期入所（ショートステイ）のちがいをまとめました。どんなお子様が使えるのか、申しこみ先、費用、ご家族が休むためにどちらを選べばよいかを説明します。
  • 重症心身障害児とは？医療的ケア児との違い重症心身障害児と医療的ケア児は、重なるところもありますが意味がちがいます。それぞれの考え方、使えるあずけ先や支援のちがいを、お父様・お母様にもわかるように説明します。
  • 短期入所の費用はいくら？障害児の利用料のしくみ短期入所の利用料は、原則1割負担で、ひと月の上限があります。上限額の決まり方、食費などの実費、日中一時支援との費用のちがいなど、お金のしくみをやさしく説明します。
