親なきあとの準備は何から？今からできること

はじめに

「自分たちがいなくなったあと、この子はどうなるんだろう」。障害のあるお子様を育てるお父様・お母様の多くが、いつか向き合う不安です。

親なきあとのじゅんびは、「暮らしの場」「お金」「見守ってくれる人」の3つに分けて考えると整理しやすくなります。この記事では、それぞれに使えるしくみを、やさしくまとめました。

1. 暮らしの場

  • 子どものうちから短期入所などを使い、「家以外で過ごす経験」を重ねておく
  • 高校生のころから、グループホームや入所施設の見学を始める
  • お父様・お母様が元気なうちに、お子様が新しい暮らしに慣れる時間をつくる

「親が倒れてから急に探す」のではなく、「親が元気なうちに少しずつ移る」ことが、お子様の安心につながります。

2. お金

障害基礎年金：20歳から受け取れる可能性があります。手続きには時間がかかるので、早めに調べておきます。

障害者扶養共済制度（しょうがい共済）：都道府県や政令指定都市が行っている公的な制度です。保護者が毎月掛金をはらい、保護者が亡くなったときなどに、障害のあるお子様に一生涯、年金が支給されます（解説記事）。窓口は、お住まいの都道府県や市区町村です。入れるのは、保護者が65歳未満で、健康の条件を満たす場合です。早めに窓口で確かめておきましょう。

家族信託：信頼できる親族にお金の管理をまかせ、親が亡くなったあとも、お子様の生活費などを払いつづけるしくみです（解説）。ただし、施設との契約や暮らしの手続きはできないので、成年後見制度とあわせて考えることが多いです。設計には専門家の力が必要です。

遺言：だれに何を残すかを決めておきます。障害のあるお子様にお金を残すときは、管理の方法もあわせて考えることが大切です。

3. 見守ってくれる人

  • 成年後見制度：判断がむずかしい方のお金の管理や契約を、後見人が手伝う制度です。お子様は18歳で成人になるので、そのあとの契約をどうするか、早めに考えておきましょう
  • 相談支援専門員や、通っている施設の職員とのつながりを、今から大切にしておく
  • きょうだいだけに負担がかからないよう、家族で話し合っておく

4. お子様のことを書き残す

お子様の好きなこと、苦手なこと、病気や薬、医療的ケアの方法、これまでの歩み。お父様・お母様の頭の中にあることを、ノートに書き残しておきましょう。サポートブックを少しくわしくしたものと考えると始めやすいです。

どこに相談すればいい？

  • 市区町村の障害福祉の窓口、相談支援事業所
  • 都道府県・政令市の障害者扶養共済制度の窓口
  • 「親なきあと」の相談室など、同じ立場のご家族が運営する相談の場

親なきあとの相談先

親なきあとの相談は、話したい内容によって相談先を使いわけると、進めやすくなります。上の窓口のほかに、次のような場所もあります。

  • 暮らしの場やサービスのこと：基幹相談支援センター（地域の相談の中心になる窓口です。名前や場所は市区町村によってちがいます）
  • 後見のこと：成年後見の相談窓口。たとえば神戸市では、社会福祉協議会が「神戸市成年後見支援センター」を開いています
  • 同じ立場の親の話を聞きたいとき：障害のある子の親が開いている相談の場や勉強会。たとえば、渡部伸さんが主宰する「親なきあと」相談室があります。市区町村のホームページに、親なきあとの講座の案内がのることもあります

民間の相談の場は、内容や費用がそれぞれちがいます。ここであげたのは一例で、あずけさき手帖がすすめるものではありません。まずは市区町村の窓口で「親なきあとの相談をしたい」と伝えると、地域の相談先を教えてもらえることがあります。

出典：新宿区「サービス等利用計画・障害児支援利用計画について」（新宿区基幹相談支援センター）、神戸市「成年後見制度」、神戸市掲載の講座案内「発達障害のある子の親なき後の準備」

きょうだいに任せきりにしないために

親なきあとのことを考えると、「いずれはきょうだいに」と思うこともあるかもしれません。でも、きょうだいにも自分の人生があります。ぜんぶを任せてしまうと、大きな負担になることがあります。

  • きょうだいの気持ちを、早めに聞いておく（関わりたいか、どこまでならできそうか）
  • 暮らしの場・お金・見守る人を、親が元気なうちに決めておき、きょうだいの役わりを小さくしておく
  • お子様のことを書き残したノートを、きょうだいとも共有しておく
  • 後見人は、ご家族だけでなく、社会福祉士・司法書士・弁護士などの専門職や、法人がなることもある（だれにするかは家庭裁判所が決めます）

きょうだいには、「あなたにすべてを任せるつもりはないよ」と、言葉にして伝えてあげてください。きょうだいの気持ちについては、「きょうだい児の気持ちとサポート」でくわしくまとめています。

出典：厚生労働省「成年後見はやわかり」

「親なきあと」をもっと知りたい方へ（PR）

親なきあとのじゅんびを、くわしく知りたい方におすすめの本です。

  • 『障害のある子が将来にわたって受けられるサービスのすべて［第2版］』（渡部伸 監修、自由国民社）：使える制度やサービスを、まとめて知りたい方に
  • 『まんがと図解でわかる障害のある子の将来のお金と生活』（渡部伸 著、自由国民社）：お金と暮らしのことを、まんがでやさしく知りたい方に
  • 『障害のある子が安心して暮らすために』（渡部伸 著、合同出版）：暮らしの場や見守りのことを考えたい方に

障害のある方のための保険

ぜんち共済は、知的障害・発達障害・ダウン症・てんかんのある方とご家族のための保険を取りあつかう会社です。ふつうの保険に入りにくいと感じている方は、一度見てみてください。

運営者から、ひとこと

学生のころ、障害のある方が通う作業所でボランティアをしていました。そこで、あるご家族から「わたしが死んだらどうしようと思って、夜中に泣いて目がさめてしまう」とうかがったことがあります。わたしは当時、お話を聞くことしかできませんでした。

親なきあとの不安は、ひとりで考えると、どんどん大きくなります。でも、使える制度や相談先を知るだけでも、少し気持ちが軽くなることがあります。この記事が、その小さな一歩になればうれしいです。
