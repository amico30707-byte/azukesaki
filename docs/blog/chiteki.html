お子様の状態別

重度知的障害のお子様の預け先・探し方と伝え方のコツ

更新日：2026年11月3日

この記事でわかること

  • 使えるあずけ先
  • 探すときのコツ
  • 問い合わせるときに伝えること
  • 慣れるまでは、少しずつ

はじめに

重度の知的障害のあるお子様は、言葉で気持ちを伝えることがむずかしかったり、目がはなせなかったりします。「うちの子を受け入れてくれるところがあるのか」と不安になるお父様・お母様は多いです。

この記事では、重度の知的障害のあるお子様のあずけ先の種類と、探すときのコツをまとめました。

使えるあずけ先

あずけ先 こんなときに
日中一時支援 放課後や休みの日に、数時間あずけたい
短期入所（福祉型） 日帰りやお泊まりで、まとまった時間あずけたい
子どもの入所施設の短期入所 知的障害のあるお子様の施設で、お泊まりを受けている
居宅介護（ヘルパー） 家でのお世話を手伝ってほしい
移動支援・行動援護 お出かけに付きそってほしい

知的障害のあるお子様の入所施設の中には、地域で暮らすお子様の短期入所や日中のあずかりを受けているところがあります。

探すときのコツ

  • 「知的障害のあるお子様を対象」と書いてある施設から探す
  • 同じ地域で、同じような障害のあるお子様のご家族に聞いてみる
  • 相談支援専門員に、受け入れの実績がある施設を聞く
  • 特別支援学校の先生に、ほかのご家族がどこを使っているか聞いてみる

問い合わせるときに伝えること

  1. お子様の年齢と、療育手帳の判定（分かれば）
  2. 言葉でのやりとりができるか、どんな方法で気持ちを伝えるか
  3. 食事・トイレ・着がえ・おふろで、手助けが必要なこと
  4. 夜の様子（眠れるか、夜中に起きるか）
  5. 苦手なこと、パニックになりやすい場面と、落ち着く方法

「できないこと」だけでなく、「こうすると落ち着きます」「これが好きです」も伝えると、施設の方も受け入れのじゅんびがしやすくなります。

慣れるまでは、少しずつ

場所や人が変わることが苦手なお子様も多いです。

  • まずはご家族と一緒に見学する
  • 短い時間の利用から始める
  • できるだけ同じ施設を、くり返し使う

くり返し使ううちに、お子様にとって「知っている場所」になっていきます。

さいごに

重度の知的障害のあるお子様のあずけ先は、簡単には見つからないこともあります。お子様のことをくわしく伝えることで、受け入れてもらえる場所が見つかりやすくなります。ひとりでかかえこまず、相談支援専門員と一緒に探していきましょう。

あずけさき手帖では、重度の知的障害のあるお子様に関する記載がある施設を探せます。

お住まいの地域のあずけ先をさがす →都道府県や、お子様に必要なケアからさがせます

あわせて読みたい

  • サポートブックの作り方・あずけ先に伝わる書き方サポートブックは、お子様のことをあずけ先に伝えるための手帳です。何を書けばよいか、伝わりやすい書き方、更新のタイミングまで、はじめて作るお父様・お母様向けにまとめました。
  • 強度行動障害でショートステイを使うには？受け入れのコツ強度行動障害のあるお子様が使えるあずけ先と、受け入れてもらうためのじゅんびをまとめました。断られたときの進め方、行動援護というサービス、18歳のあとを見すえた考え方も説明します。
  • 短期入所と日中一時支援の違い・ヘルパーとの使い分け短期入所・日中一時支援・居宅介護（ヘルパー）・移動支援のちがいを、ひと目でわかる表でまとめました。お泊まりか日中だけか、家に来てもらうかなど、ご家庭に合う選び方を説明します。
