お子様の状態別

重症心身障害のお子様のおふろ｜入浴用具・住宅改修と、手伝ってくれるサービス

はじめに

赤ちゃんのころは、だっこして入れられたおふろ。でも、お子様の体が大きくなるにつれて、だきかかえて浴そうに入れるのは、お父様・お母様の腰や体に大きな負担になります。医療的ケアのあるお子様は、チューブや機械にも気をくばりながらの入浴です。

この記事では、おふろを少しでも楽に、安全にするための「道具」「家の改修」「手伝ってくれる人」の3つを、国のしくみと市の例でまとめました。

家に浴そうを持ってきてくれる「訪問入浴」のしくみは、「外に出にくい子の家で受けられるサービス」でくわしくせつめいしています。この記事では、訪問入浴は市ごとの例だけをしょうかいし、どうぐと住宅改修を中心にお伝えします。

まずは、だれに相談する？

おふろのやり方は、お子様の体の状態によってちがいます。どんなどうぐやほうほうが合うかは、じぶんたちだけできめずに、つぎの人に相談してください。

  • 主治医、訪問看護師
  • リハビリの先生（理学療法士・作業療法士）
  • 市区町村の障害福祉の窓口、相談支援専門員

栃木県が作った「医療的ケアが必要なお子さんと家族のための支援ガイドブック」（令和7年3月）には、「お風呂について」のコラムや、福祉用具の活用、住まいを整える支援のページがあります。お住まいの県や市にも、おなじような冊子がないか、さがしてみてください（「あなたの市の「医療的ケア児ハンドブック・支援マップ」はどこ？」）。

おふろのどうぐ：日常生活用具

おふろで使うどうぐの中には、市区町村の「日常生活用具」の給付で手に入れられるものがあります。国の分け方では、入浴補助用具は「自立生活支援用具」のグループに入ります。日常生活用具のしくみは「日常生活用具とは？」をご覧ください。

だれがたいしょうかは市区町村がきめます。例として、浜松市のページ（2025年3月更新）を見てみます。

どうぐ 浜松市のたいしょう（身体障害者手帳のある方のとき）
入浴補助用具 下肢または体幹の機能に障害があり、入浴に介助がひつような方（3歳以上）
入浴担架 下肢または体幹の機能障害2級以上で、入浴にご家族などの介助がひつような方（3歳以上）
移動用リフト 下肢または体幹の機能障害2級以上（3歳以上）

障害者手帳のじょうけんに合わないお子様でも、小児慢性特定疾病の医療費助成をうけていれば、「小児慢性特定疾病児童日常生活用具給付事業」で入浴補助用具をもらえることがあります。たとえば堺市では、入浴に介助がひつような方をたいしょうに、入浴補助用具の基準額を99,000円としています（2026年4月更新のページ。ほかの制度で給付をうけていない方がたいしょう）。

どちらも、買うまえにもうしこむのがきまりです。先に買ってしまうと、給付をうけられないことがあります。

小さな家の改修：居宅生活動作補助用具

日常生活用具の6つ目のグループに、「居宅生活動作補助用具（住宅改修費）」があります。厚生労働省のページでは、「設置に小規模な住宅改修を伴う用具」とされています。浜松市では、下肢・体幹の機能障害か、乳幼児期以前の非進行性の脳病変による移動機能の障害があり、障害の等級が3級以上の方で、学齢児（小学生）以上がたいしょうとされています。ねんれいのじょうけんがあることが多いので、お子様が使えるか、窓口で聞いてみてください。

もっと大きな改修：市の住宅改造の助成

浴室を広くするなど、大きな工事には、市区町村が独自に行っている「住宅改造」「住宅設備改善」の助成が使えることがあります。たとえば土浦市には、重い障害のある方の家のリフォームの費用を助成するしくみ（工事費の4分の3、上限41.2万円）があります（土浦市の記事）。

こうした助成は、あるかどうかも、じょうけんや金額も、市区町村によって大きくちがいます。工事をはじめるまえに、窓口で手順を聞いてください。どんな書類がいるかも、そのときに聞いておきましょう。

手伝ってくれるサービス

どうぐや改修とあわせて、人の手をかりるほうほうもあります。

ほうほう どんなときに もうしこみ先
訪問入浴 家のおふろでは入れるのがむずかしいとき 市区町村の障害福祉の窓口
ヘルパー（居宅介護） 家のおふろで、入浴の手助けがほしいとき 市区町村の障害福祉の窓口
訪問看護 体調を見ながら、入浴を手伝ってほしいとき 主治医（訪問看護指示書がひつよう）

訪問入浴は市区町村の事業なので、お子様が使えるかどうかは、まちによってちがいます。あずけさき手帖の市の記事では、お子様もたいしょうと書かれている市として、つぎのような例をたしかめています。

  • 古河市：お子様もたいしょうで、週2回まで。令和8年4月の利用分から、全身のおふろで1回1,350円、市民税がかからない世帯は0円（古河市の記事）
  • 須賀川市：体に障がいのあるお子様もたいしょうで、週2回まで、1回1,250円。医師の診断書がいる（須賀川市の記事）
  • 行橋市：身体障害者手帳1・2級のお子様もたいしょう。原則として1か月8回まで。市民税がかかる世帯は1回400円、かからない世帯と生活保護の世帯は無料（行橋市の記事）

ヘルパーが見つからないときは「障害児のヘルパーが見つからないときにできること」、訪問看護は「小児の訪問看護とは？」をご覧ください。

窓口や事業所に聞いておきたいこと

  • お子様のねんれいや、手帳の等級で、使えるどうぐやサービスがあるか
  • どうぐは、どこの業者にたのめばよいか。見積書は何まいいるか
  • 自己負担はいくらか。世帯の所得で変わるか
  • 訪問入浴やヘルパーは、1か月に何回まで使えるか。夏は回数がふえるか
  • 医療的ケアのあるお子様の入浴を、受けたことがあるか

おふろのどうぐは、お子様の体の大きさが変わると、合わなくなることもあります。買いかえや、べつのどうぐにかえられるかも、あわせて聞いておくと安心です。

あずけ先でのおふろも聞いておく

短期入所や日中のあずけ先で、おふろに入れてもらえるかどうかは、施設によってちがいます。家でのおふろがたいへんなときは、あずけ先で入れてもらえるかを聞いておくと、ご家族の負担がへることがあります。

見学や問い合わせのときに、「おふろには入れてもらえますか」「どんな浴そうですか」「医療的ケアのある子のおふろは、だれが手伝いますか」と聞いてみてください。見学のポイントは「短期入所の見学ポイント」にまとめています。

すすめる順番

  1. 主治医や訪問看護師、リハビリの先生に、おふろでこまっていることを伝え、合うほうほうを相談する
  2. 身体障害者手帳の等級や、小児慢性特定疾病の受給者証があるかをたしかめる（「身体障害者手帳とは？」）
  3. 市区町村の窓口で、入浴のどうぐ、住宅改修、訪問入浴、ヘルパーのうち、お子様が使えるものを聞く
  4. どうぐや工事は、見積書をそろえて、買うまえ・工事のまえにもうしこむ
  5. 人の手をかりるサービスは、受給者証のてつづきや、事業所さがしを相談支援専門員といっしょに進める

さいごに

おふろは毎日のことなので、少しのくふうで、ご家族の体の負担が大きくかわります。どうぐ、家の改修、人の手。どれか1つでなく、組みあわせて考えてみてください。お子様の体の状態に合うほうほうは、かならず主治医やリハビリの先生と相談してきめましょう。

あずけさき手帖では、短期入所や日中一時支援など、お子様をあずけられる場所を地域からさがせます。

※たいしょうのどうぐやじょうけん、基準額、サービスの回数や料金は、年度や市区町村によって変わります。くわしくはお住まいの窓口でご確認ください。

あわせて読みたい

  • 外に出にくい子の家で受けられるサービス｜訪問入浴・居宅訪問型児童発達支援・訪問看護のちがい体が弱い、医療的ケアが多いなどで外に出にくいお子様が、家で受けられるサービスをまとめました。訪問入浴、居宅訪問型児童発達支援、訪問看護、ヘルパーのちがいと、申しこむ順番を説明します。
  • 日常生活用具とは？障害のあるお子様のための給付｜吸引器・パルスオキシメーター・発電機などたん吸引器やパルスオキシメーター、停電にそなえる発電機など、医療的ケアのあるお子様のくらしに使う道具は、市区町村の「日常生活用具」の給付で買えることがあります。国のきまり、市ごとのちがいの例、障害者手帳がないときの小児慢性特定疾病の給付、申しこみの順番をまとめました。
  • 障害児のおむつ代の助成・日常生活用具と医療費控除障害のあるお子様のおむつ代や、吸引器・入浴補助用具などの道具に使える助成をまとめました。日常生活用具給付等事業のしくみ、自治体ごとのおむつ助成の例、医療費控除の条件を説明します。
  • 補装具で子どもの車いす・バギーを作るには？費用と流れお子様の車いすやバギー、姿勢保持装置に使える補装具費支給制度をまとめました。自己負担と月の上限、18歳未満の所得制限がなくなったこと、申しこみの流れ、買いかえや修理の目安を説明します。
  • 障害児のヘルパーが見つからないときにできる7つのこと受給者証にヘルパーの時間があるのに、来てくれる事業所が見つからない。そんなときに試したい7つのことをまとめました。探し方の工夫や、ほかの支援との組み合わせ方を説明します。
  • 小児の訪問看護とは？回数・費用と在宅レスパイト小児の訪問看護で自宅に来てもらえるケアをまとめました。医療保険で使える回数や時間、費用と医療費の助成、ご家族が休むための在宅レスパイト事業、ステーションの選び方を説明します。
  • 身体障害者手帳とは？子どもの取り方・等級・できること身体障害者手帳は、体の障害がある方のための手帳です。お子様の場合の申請のしかた、何歳から取れるか、1級〜6級の等級、再認定、手帳があるとできることを、はじめてのお父様・お母様向けにまとめました。
  • 重症心身障害児とは？医療的ケア児との違い重症心身障害児と医療的ケア児は、重なるところもありますが意味がちがいます。それぞれの考え方、使えるあずけ先や支援のちがいを、お父様・お母様にもわかるように説明します。
