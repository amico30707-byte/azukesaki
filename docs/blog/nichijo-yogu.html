日常生活用具とは？障害のあるお子様のための給付｜吸引器・パルスオキシメーター・発電機など

公開日：2026年11月12日

この記事でわかること

  • 国のきまり：市区町村がなかみをきめる
  • 市ごとのちがいの例
  • 障害者手帳がないときは、小児慢性特定疾病の給付も
  • もうしこみの順番
  • よくある質問
  • 補装具とのちがい

はじめに

たん吸引器、ネブライザー（薬を霧にしてすいこむ機械）、パルスオキシメーター（指先で血の中の酸素をはかる機械）。医療的ケアのあるお子様のくらしには、高いお金のかかるどうぐがたくさんいります。

こうしたどうぐの中には、市区町村の「日常生活用具」の給付を使って、少ない負担で手に入れられるものがあります。日常生活用具のしくみのきほんと、紙おむつの助成や医療費控除については「障害児のおむつ代の助成・日常生活用具と医療費控除」でまとめました。この記事では、医療的ケアにかかわるどうぐを中心に、市ごとのちがいの例と、もうしこみの順番をくわしく見ていきます。

国のきまり：市区町村がなかみをきめる

日常生活用具の給付は、障害者総合支援法の「地域生活支援事業」の1つで、市町村が行う事業です。厚生労働省のページでは、つぎのようにせつめいされています。

  • たいしょうは、日常生活用具がひつような障害者、障害児、難病患者など
  • 市町村にもうしこみ、市町村が給付をきめてから、どうぐを受けとる
  • 国が2分の1以内、都道府県が4分の1以内のお金を出す。利用者の負担は、市町村がきめる

たいしょうになるどうぐは、「安全で、かんたんに使えて、実用的」「くらしのこまりごとを改善し、自立や社会参加をすすめる」「作るのに障害についての専門の知識や技術がいり、ふつうの生活用品としては広まっていない」という3つにすべて当てはまるもの、とされています。

どうぐは6つのグループに分かれていて、電気式たん吸引器は「在宅療養等支援用具」、入浴補助用具は「自立生活支援用具」に入ります。どのどうぐを、だれに、いくらまで出すかは、市区町村がきめます。そのため、となりの市とでもなかみがちがうことがあります。

市ごとのちがいの例

浜松市のページ（2025年3月更新）では、身体障害者手帳のある方などについて、たとえばつぎのようにたいしょうをきめています。

どうぐ 浜松市のたいしょう（手帳のある方のとき）
電気式たん吸引器 呼吸器機能障害3級以上の方や、家で人工呼吸器を使っている方など（くわしいじょうけんは市でご確認ください）
ネブライザー（吸入器） 電気式たん吸引器とおなじ
パルスオキシメーター 呼吸器機能障害や心臓機能障害などがあり、在宅酸素療法をしているか、人工呼吸器をつけている方（ほかの障害は、医師がひつようとみとめた方）
移動用リフト 下肢または体幹の機能障害2級以上で、3歳以上
特殊寝台（介護用ベッド） 下肢または体幹の機能障害2級以上で、18歳以上

浜松市では、特殊寝台は18歳以上がたいしょうです。このように、ねんれいのきまりで、お子様のうちは使えないどうぐもあります。

ほかの市でも、あずけさき手帖の市の記事で、つぎのような例をたしかめています。

  • 福山市：吸入（吸引）器やパルスオキシメーターもたいしょう。原則として基準額の1割を負担し、市民税がかからない世帯と生活保護の世帯は、基準額の中なら負担なし（福山市の記事）
  • 羽曳野市：令和5年4月から、人工呼吸器のための自家発電機か外部バッテリーのどちらか1つを追加。基準額は10万円（羽曳野市の記事）
  • 塩尻市：家で電気のいる医療機器がかかせない医療的ケア児のための発電機。医師の意見書がいり、限度額は10万円（塩尻市の記事）
  • 木更津市：たん吸引器やネブライザーが、日常生活用具の例としてのっている（木更津市の記事）
  • 八戸市：2026年4月から、聴覚過敏のある方のイヤーマフ・デジタル耳栓がたいしょうに（八戸市の記事）

停電へのそなえは「医療的ケア児の災害・停電へのそなえ」もあわせてご覧ください。

障害者手帳がないときは、小児慢性特定疾病の給付も

医療的ケアのあるお子様の中には、身体障害者手帳の等級がじょうけんに合わない、または手帳をまだ持っていない、というお子様もいます。そんなときは、「小児慢性特定疾病児童日常生活用具給付事業」を使えることがあります。小児慢性特定疾病（国がきめた子どもの長い病気）の医療費助成をうけているお子様のための給付です。

たとえば堺市のページ（2026年4月更新）では、つぎのようなどうぐと基準額がのっています。

どうぐ たいしょう（概要） 基準額
電気式たん吸引器 呼吸器機能に障害のある方 62,040円
ネブライザー（吸入器） 呼吸器機能に障害のある方 39,600円
パルスオキシメーター 人工呼吸器の装着がひつような方 173,250円
人工鼻 人工呼吸器の装着か気管切開がひつような方 128,700円
入浴補助用具 入浴に介助がひつような方 99,000円

堺市では、ほかの制度で給付をうけていない方がたいしょうで、家で療養ができ、医師から「用具がひつよう」と診断されていることがじょうけんです。自己負担は、世帯の所得におうじてきまります。亀岡市でも、小児慢性特定疾病の受給者証を持つ20歳未満の方への用具の給付があります（亀岡市の記事）。小児慢性特定疾病の医療費助成については「子どもの医療費の助成のちがい」をご覧ください。

もうしこみの順番

  1. 主治医や訪問看護師に、どのどうぐがひつようか相談する
  2. 市区町村の障害福祉の窓口で、そのどうぐが日常生活用具のたいしょうか、お子様がじょうけんに合うかを聞く。手帳のじょうけんに合わないときは、小児慢性特定疾病の給付の窓口（保健所など）も聞く
  3. もうしこみ書と、業者の見積書、ひつようなら医師の意見書をそろえて出す
  4. 市区町村から給付の決定の通知（給付券など）がとどく
  5. 通知がとどいてから、業者に注文してどうぐを受けとる

いちばんたいせつなのは、買うまえにもうしこむことです。堺市のページでも、買ってからもうしこむことはできない、とされています。医師の意見書は、病院によってお金がかかることもあります。

よくある質問

  • おなじどうぐを、2つの制度からもらえる？ →堺市の小児慢性特定疾病の給付は、ほかの制度で給付をうけていない方がたいしょうです。どちらの制度を使うかは、窓口で相談してください。

  • こわれたり、古くなったりしたら？ →買いかえができるまでの年数や、修理のあつかいは、市区町村ごとにきまっています。こわれたときは、まず窓口に連絡してください。

  • 引っ越したら？ →日常生活用具は、あたらしい市区町村でもうしこみなおしになることがあります（「障害のあるお子様と引っ越すとき」）。

  • 基準額より高いどうぐがほしいときは？ →基準額をこえた分は、ご家族の負担になることがあります。見積書をもらうときに、基準額の中でえらべるどうぐがあるかも、業者に聞いてみましょう。

補装具とのちがい

車いすやバギー、座位保持装置などは、日常生活用具ではなく「補装具」という国の制度で作ります。もうしこみ先や流れがちがうので、「補装具で子どもの車いす・バギーを作るには？」をご覧ください。おふろのどうぐや家の改修は「重症心身障害のお子様のおふろ」でまとめています。

さいごに

日常生活用具は、市区町村ごとにどうぐもじょうけんもちがいます。「うちの市では対象かな？」と思ったら、買うまえに窓口で聞いてみてください。相談支援専門員にいっしょに調べてもらうのもよいほうほうです（「相談支援事業所とは？」）。

あずけさき手帖では、医療的ケアにたいおうした短期入所などのあずけ先を、地域からさがせます。

※たいしょうのどうぐやじょうけん、基準額、自己負担は、年度や市区町村によって変わります。くわしくはお住まいの窓口でご確認ください。

あわせて読みたい

  • 障害児のおむつ代の助成・日常生活用具と医療費控除障害のあるお子様のおむつ代や、吸引器・入浴補助用具などの道具に使える助成をまとめました。日常生活用具給付等事業のしくみ、自治体ごとのおむつ助成の例、医療費控除の条件を説明します。
  • 補装具で子どもの車いす・バギーを作るには？費用と流れお子様の車いすやバギー、姿勢保持装置に使える補装具費支給制度をまとめました。自己負担と月の上限、18歳未満の所得制限がなくなったこと、申しこみの流れ、買いかえや修理の目安を説明します。
  • 身体障害者手帳とは？子どもの取り方・等級・できること身体障害者手帳は、体の障害がある方のための手帳です。お子様の場合の申請のしかた、何歳から取れるか、1級〜6級の等級、再認定、手帳があるとできることを、はじめてのお父様・お母様向けにまとめました。
  • 子どもの医療費の助成・小児慢性・育成医療・重度心身障害者医療のちがい重い障害や医療的ケアのあるお子様の医療費を軽くする助成には、小児慢性特定疾病、自立支援医療（育成医療）、重度心身障害者医療費助成、こども医療費助成などがあります。それぞれのちがいと、申しこみの順番をやさしくまとめました。
  • 医療的ケア児の災害・停電へのそなえ・今日からできること人工呼吸器や吸引器を使うお子様にとって、災害や停電へのそなえは大切です。電源の確保、避難先の考え方、ふだんから用意しておきたい物を、今日からできる順にまとめました。
  • 医療的ケア児の預け先は？吸引や経管栄養があっても使える場所たんの吸引や経管栄養など、医療的ケアのあるお子様のあずけ先をまとめました。使える場所の種類、まず相談したい窓口、問い合わせで伝えること、はじめて使うまでの流れを説明します。
  • 相談支援事業所とは？障害児の探し方と選び方相談支援事業所は、受給者証のための計画づくりや、あずけ先さがしを手伝ってくれる場所です。費用、自分で計画を作る方法、見つけ方、選ぶときに見ることをやさしく説明します。
  • 重症心身障害のお子様のおふろ｜入浴用具・住宅改修と、手伝ってくれるサービスお子様が大きくなるほど大変になる、毎日のおふろ。入浴補助用具や移動用リフトなどの日常生活用具、小さな住宅改修の給付、市の住宅改造の助成、訪問入浴やヘルパーなど手伝ってくれるサービスを、市の例といっしょにまとめました。
