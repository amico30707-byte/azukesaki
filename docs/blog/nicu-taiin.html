NICUから家に帰る前にしておく、あずけ先のじゅんび

公開日：2026年11月12日

はじめに

「もうすぐ退院です」と言われて、うれしい気もちと同じくらい、不安な気もちになっているお父様・お母様も多いとおもいます。人工呼吸器、たんの吸引、経管栄養。病院では看護師さんがしてくれていたケアを、これからは家でご家族がすることになります。

退院の前は、ケアの練習や機械のじゅんびでいっぱいで、「あずけ先」のことまでかんがえるよゆうはないかもしれません。でも、家での生活が始まると、ご家族が休む時間をつくることが、とてもたいせつになります。

この記事では、NICU（赤ちゃんの集中治療室）などから家に帰る前に、あずけ先や休むためのじゅんびとして、しておきたいことをまとめました。ぜんぶをいちどにしなくて大丈夫です。できるところからで十分です。

医療的ケア児とは

こども家庭庁は、医療的ケア児を、NICUなどに長く入院したあと、人工呼吸器や胃ろうなどを使い、たんの吸引などの医療的ケアが毎日必要なお子様、と説明しています。そして、その支援には、医療・福祉・保健・子育て支援・教育など、いろいろな人の連携が欠かせないとしています。

つまり、ご家族だけでがんばるのではなく、たくさんの人とチームをつくっていくことが前提になっています。医療的ケアのあるお子様のあずけ先ぜんたいは、「医療的ケア児の預け先は？」にまとめています。

退院前の話しあい（カンファレンス）で聞くこと

医療的ケアのある赤ちゃんが家に帰るときは、病院が、地域の支援者といっしょに話しあう場（退院前カンファレンス）をひらくことがあります。

例：神奈川県立こども医療センターの「在宅医療の手引き」第4版（2026年4月）

  • 退院の2〜3週間前に、病院の相談の部署が、地域の支援者との話しあいの計画を立てはじめる
  • 院外からは、在宅医、訪問看護ステーション、行政、医療的ケア児・者コーディネーター、相談支援専門員、保育園や学校などが参加する
  • 緊急のときの対応や、れんらくのしかたなどをたしかめる
  • 医療機器を使って退院するお子様の家を、退院前に訪ねて、機器のおき場所や、停電・災害のときのこともたしかめる
  • 家族むけのチェックシートには、レスパイト、ヘルパー、訪問入浴、訪問看護、相談支援専門員、コーディネーターへのれんらくなどの項目がある

病院によって、やり方はちがいます。話しあいの場があるときは、次のことも聞いてみてください。

  • ご家族が休みたいとき、どこにあずけられるか（短期入所、レスパイト入院など）
  • この病院で、短期入所やレスパイト入院を受けているか
  • 地域で、赤ちゃんを受け入れている短期入所や訪問看護はどこか
  • 相談支援専門員や、医療的ケア児等コーディネーターをしょうかいしてもらえるか

病院の相談室（医療ソーシャルワーカー）は、こうした地域のつながりにくわしいことが多いです。

相談の窓口を、退院前につくっておく

家に帰ってから困ったとき、相談できる人がいると安心です。退院の前に、次の人とつながっておきましょう。

  • 医療的ケア児等コーディネーター：医療・福祉・教育などをつなぐ人（「医療的ケア児等コーディネーターとは？」）
  • 相談支援専門員：福祉サービスの計画をつくり、事業所との調整をしてくれる人（「相談支援事業所とは？」）
  • 市区町村の保健師や、障害福祉の窓口
  • 都道府県の医療的ケア児支援センター（「医療的ケア児支援センター一覧」）

だれに先にれんらくすればよいか分からないときは、病院の相談室か、医療的ケア児支援センターに聞いてみてください。

手つづきのこと

家での生活とあずけ先に関係する手つづきは、いくつかあります。だれが、いつ、どこで手つづきをするのかを、病院の相談室や市区町村の窓口とたしかめておくと安心です。

  • 受給者証：短期入所や訪問のサービスなどを使うための証明書です。手帳がなくても、医師の意見書などで、支援が必要と認められれば使えることがあります（「受給者証とは？」）
  • 医療費の助成：小児慢性特定疾病の医療費助成など、お子様の病気やようすによって使える助成があります（「子どもの医療費の助成のちがい」）
  • 身体障害者手帳：障害の種類によっては、赤ちゃんのうちは認定がむずかしいことがあります（「身体障害者手帳とは？」）

手つづきの名前や順番は、市区町村によってちがいます。お住まいの市区町村でご確認ください。

家で使えるサービスを知っておく

家に帰ってすぐは、外に出るのもたいへんです。まずは、家に来てもらえるサービスからかんがえるご家庭も多いです。

  • 訪問看護：看護師が家に来て、ケアや体調のチェックをしてくれる。赤ちゃんから使える（「小児の訪問看護とは？回数・費用と在宅レスパイト」）
  • 在宅レスパイト：訪問看護師が長めに家にいて、そのあいだご家族が休める。市の事業として行っているところがある
  • 訪問入浴、居宅訪問型児童発達支援など（「外に出にくい子の家で受けられるサービス」）

在宅レスパイトがあるか、何時間使えるかは、市区町村によってちがいます。お住まいの市区町村でご確認ください。

短期入所は「早めに登録」がだいじ

医療的ケアのある赤ちゃんを泊まりで受け入れる短期入所は、数が少なく、はじめて使うまでに、事前の診察や体験利用などで、数か月かかることがよくあります（「医療型短期入所とは？福祉型との違いと使い方」）。

退院してすぐに泊まりであずける必要はありません。でも、「いざというときに使える場所」を知っておくことはたいせつです。退院前に、次のことをしておくと安心です。

  • 地域で、赤ちゃんや小さなお子様を受け入れている短期入所の名前を聞いておく
  • 受け入れの年齢（何か月から、何歳から）をたしかめる
  • 予約や登録のしかたを聞いておく

ご家族が急に入院するなど、もしものときのことは「親が急に入院・倒れたときの障害児のあずけ先」にまとめています。空きの調べ方は「重心・医療的ケアのショートステイの「空き」の調べ方」をご覧ください。

家に帰ってからの、はじめの数か月

退院してしばらくは、家でのケアになれることがいちばんです。そのうえで、次のことをすこしずつ進めておくと、あずけ先の候補がふえていきます。

  1. 訪問看護など、家に来てもらうサービスになれる
  2. 相談支援専門員と、福祉サービスの計画をつくる
  3. 地域の短期入所や病院に問い合わせて、見学する
  4. 事前の診察を受け、日帰りやご家族つきそいの体験をする
  5. 体調が落ちついている時期に、はじめてのお泊まりをためす

「まだ早い」と感じたら、無理に進めなくて大丈夫です。でも、ご家族の体調がくずれたときや、きょうだいの行事があるときに、すぐに使える場所があると、とても心強いです。

停電やもしものときのそなえ

人工呼吸器や吸引器など、電気で動く機器を使うお子様は、停電のときのそなえが欠かせません。さきほどの手引きでも、退院前に家を訪ねて、停電・災害のときをかんがえた機器のおき場所をたしかめるとされています。くわしくは「医療的ケア児の災害・停電へのそなえ」をご覧ください。

さいごに

家に帰る前は、覚えることが多く、気もちも体もいっぱいだとおもいます。あずけ先のじゅんびは、「休んでいいよ」と言ってくれる人や場所を、すこしずつふやしていくことです（「レスパイトとは？障害児の家族が休んでいい理由」）。ひとりでかかえこまず、病院の相談室やコーディネーターに、そのまま気もちを話してみてください。

あずけさき手帖では、医療的ケアのあるお子様を受け入れている短期入所や訪問のサービスを、地域や必要なケアからさがせます。

※制度や手つづき、受け入れの条件は、年度や病院、市区町村によって変わります。くわしくは病院の相談室や、お住まいの窓口でご確認ください。

あわせて読みたい

  • 医療的ケア児の預け先は？吸引や経管栄養があっても使える場所たんの吸引や経管栄養など、医療的ケアのあるお子様のあずけ先をまとめました。使える場所の種類、まず相談したい窓口、問い合わせで伝えること、はじめて使うまでの流れを説明します。
  • 医療的ケア児等コーディネーターとは？何をしてくれる人か・どこにいるか医療的ケア児等コーディネーターは、医療・福祉・教育などの支えをつないでくれる人です。どんなことを相談できるか、相談支援専門員とのちがい、どこにいるか、つながり方をやさしくまとめました。
  • 医療的ケア児支援センター一覧・47都道府県の相談窓口医療的ケア児支援センターは、医療的ケアのあるお子様とご家族の相談窓口です。47都道府県のセンター一覧、相談できること、連絡のしかた、あずけ先さがしでの使い方をまとめました。
  • 相談支援事業所とは？障害児の探し方と選び方相談支援事業所は、受給者証のための計画づくりや、あずけ先さがしを手伝ってくれる場所です。費用、自分で計画を作る方法、見つけ方、選ぶときに見ることをやさしく説明します。
  • 受給者証とは？障害児の取り方と流れをやさしく解説障害のあるお子様が短期入所や日中一時支援を使うには、受給者証が必要です。2つの種類、申しこみの流れ、届くまでの期間、費用や更新のことを、はじめての方にもわかるように説明します。
  • 小児の訪問看護とは？回数・費用と在宅レスパイト小児の訪問看護で自宅に来てもらえるケアをまとめました。医療保険で使える回数や時間、費用と医療費の助成、ご家族が休むための在宅レスパイト事業、ステーションの選び方を説明します。
  • 医療型短期入所とは？福祉型との違いと使い方医療型短期入所は、医療的ケアのあるお子様が病院などでお泊まりできる短期入所です。福祉型とのちがい、どんなときに使うか、はじめて使うまでの流れと知っておきたいことを説明します。
  • 親が急に入院・倒れたときの障害児のあずけ先｜緊急ショートステイお父様・お母様が急に入院したり倒れたりしたとき、重い障害や医療的ケアのあるお子様をどこにあずけるか。緊急の短期入所、地域生活支援拠点、子育て短期支援事業と、元気なうちにしておきたいじゅんびをまとめました。
