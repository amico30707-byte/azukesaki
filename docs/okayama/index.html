医療的ケア児支援センター

岡山県医療的ケア児支援センター

岡山県内にお住まいの医療的ケアを必要とする方、ご家族、支援者が対象。電話は平日8時30分〜17時15分、相談フォームも案内されています。

出典：https://www.cfa.go.jp/assets/contents/node/basic_page/field_ref_resources/5218c3a3-610e-4925-8596-a9116889756f/b536f355/20260617_policies_shougaijishien_care-ji-shien_21.pdf　確認日：2026-03

まとめの記事

  • 岡山県の短期入所・障害児のあずけ先まとめ岡山県で、重い障害や医療的ケアのあるお子様をあずけられる短期入所・日中一時支援の探し方をまとめました。相談の窓口や受給者証の申しこみ先、見学のポイントもやさしく説明します。
  • 岡山市の日中一時支援・移動支援岡山市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。タイムケアとレスパイトのちがいや医療的ケアの窓口も、やさしく説明します。
  • 倉敷市の日中一時支援・移動支援倉敷市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。日中型・タイムケア型・医療型の3つの日中一時支援も、やさしく説明します。
