県の2026年9月25日更新の案内では、9月からメールが ikea-heartchan@shizuoka-na.jp に変更されています。電話054-204-1380、相談は平日10〜16時です。

出典：https://www.cfa.go.jp/assets/contents/node/basic_page/field_ref_resources/5218c3a3-610e-4925-8596-a9116889756f/b536f355/20260617_policies_shougaijishien_care-ji-shien_21.pdf　確認日：2026年3月

まとめの記事

  • 静岡県の短期入所・障害児のあずけ先まとめ静岡県で、重い障害や医療的ケアのあるお子様をあずけられる短期入所・日中一時支援の探し方をまとめました。相談の窓口や受給者証の申しこみ先、見学のポイントもやさしく説明します。
  • 静岡市の日中一時支援・移動支援静岡市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。重心ライフサポート事業や市独自の手当も、やさしく説明します。
  • 浜松市の日中一時支援・移動支援浜松市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。医療的ケア児等相談支援センターや市独自の手当も、やさしく説明します。
  • 沼津市の日中一時支援・移動支援沼津市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。活動支援という名前の日帰りのあずかりや、学校への送り迎えに使える送迎支援型も、やさしく説明します。
  • 富士市の日中一時支援・移動支援富士市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。手帳がなくても使える場合があるライフサポート事業や、県の医療的ケア児の支援も、やさしく説明します。
  • 焼津市の日中一時支援・移動支援焼津市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。お子様なら障害支援区分の認定がいらない日中一時支援や、何年生から使えるかや学校の行事に使えるかが書かれた「焼津市移動支援ガイドライン」も、やさしく説明します。
  • 磐田市の日中一時支援・移動支援磐田市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。ご家族が急に病気や入院になったときにそなえて前もって登録しておく「障がいのある方の緊急時支援」や、県立の施設「磐田学園」も、やさしく説明します。
