医療的ケア児支援センター

秋田県医療的ケア児支援センターコラソン

医療的ケアが必要なお子様とご家族を、コーディネーターと看護師が関係機関と連携して支える窓口です。電話018-827-5730、受付は平日10〜15時と公式ページで確認しました。

出典：https://www.cfa.go.jp/assets/contents/node/basic_page/field_ref_resources/5218c3a3-610e-4925-8596-a9116889756f/b536f355/20260617_policies_shougaijishien_care-ji-shien_21.pdf　確認日：2026年3月

まとめの記事

  • 秋田県の短期入所・障害児のあずけ先まとめ秋田県で、重い障害や医療的ケアのあるお子様をあずけられる短期入所・日中一時支援の探し方をまとめました。相談の窓口や受給者証の申しこみ先、見学のポイントもやさしく説明します。
  • 秋田市の短期入所・日中一時支援・移動支援秋田市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。「短期入所型」と呼ばれる日帰りのしくみも、やさしく説明します。

    にかほ市

    外出の付きそい日中のあずかり

    対象：にかほ市の案内では、移動支援は視覚障がいまたは特定疾患による全身性障がいのあるお子様・成人、日中一時支援は身体・知的・精神・発達障がい等のあるお子様・成人を対象に含みます。事業ごとに対象が異なるため、市へ確認してください。
