施設・事業所の方へ

掲載プランのご案内

あずけさき手帖は、重い障害や医療的ケアのあるお子様のご家族が、あずけ先をさがすためのサイトです。短期入所、日中一時支援、ヘルパー、移動支援、療育などの施設をのせています。

訪問看護ステーション（お子様に対応しているところ）も、施設と同じプランでご利用いただけます。

施設の基本の掲載は無料です。お申し込みがなくても、公式ページや市区町村の案内をもとに、施設の名前、場所、対象、ケアの内容、確かめた日をのせています。

もっとくわしく施設のことを伝えたい方のために、有料のプランもご用意しました。ご家族が「ここなら見学に行ってみたい」と思えるような情報を、施設の方ご自身の言葉でのせることができます。

空き状況は「空きがある」「必ず使える」とは書かず、「〇月ごろ相談可」のような目安としてのせます。いちばん新しい更新日も、あわせて表示します。

はじめのキャンペーン

はじめの3か月は、料金をいただきません

2027年3月31日までにお申し込みの施設は、はじめの3か月の料金はいただきません。4か月目から、えらんだプランの料金になります。3か月のあいだにやめられても、料金はかかりません。

お申し込みでもらえるもの

  • 施設ページに、写真や紹介文をのせる作業は、こちらでお手伝いします。原稿と写真を送っていただければ、3営業日ほどでのせます
  • 空き状況やお知らせは、メールやフォームから送っていただければ、こちらで更新します
  • 月に1回、施設ページが何回見られたかをお知らせします
  • 契約は1か月ごとです。いつでもやめられます。やめたあとも、無料の掲載はそのまま残ります

申し込みの流れ

  1. メール（info@azukesaki.jp）の件名に「掲載プランについて」と書いて、施設の名前とご担当者様のお名前をお送りください
  2. 2営業日ほどで、こちらからメールでご連絡します。ご不明な点は、電話でもお答えします
  3. 写真と紹介文を送っていただき、こちらでページを作ります
  4. 施設の方に内容を見ていただき、よければ公開します

お支払いは、毎月の請求書（銀行振込）を予定しています。

大切にしていること

  • 有料プランでも、一覧の並び順は変わりません。ランキングもしません
  • 目立つ場所での紹介には、かならず「PR」と表示します
  • ご家族からいただいた声を、施設の評価としてのせることはしません
  • 料金をいただいているかどうかで、記事の中身を変えることはありません

求人掲載（準備中）

重症心身障害や医療的ケアのあるお子様を受け入れる施設の求人をのせるページを、準備しています。職種は、看護師、保育士、支援員（児童指導員など）、ヘルパーからはじめます。

  • 料金は、1件 月5,500円（税込）の予定です。プラスプランの施設は、1件まで料金はかかりません
  • 応募は施設に直接していただく形です。あずけさき手帖では、応募する方の情報をおあずかりしません
  • 求人のページから、その施設のページへつなげます。「どんなお子様が通っているか」も、あわせて見ていただけます

はじまったら、このページでお知らせします。
