サポートブック（記入用）

短期入所（ショートステイ）などの前に、お子様のことを施設につたえるための用紙です。印刷して、お父様・お母様が手で書きこんでください。

このページには、入力するところはありません。書いたことが保存されたり、どこかに送られたりすることはありません。

A4の紙で、3〜4枚くらいになります。書ききれないときは、うらや別の紙に書いて、いっしょにわたしてください。医療的ケアや薬のことは、主治医や訪問看護師さんと決めているやり方を書いてください。

書き方のコツは「サポートブックの作り方・あずけ先に伝わる書き方」をご覧ください。
