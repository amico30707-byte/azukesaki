医療的ケア児支援センター

群馬県医療的ケア児等支援センターやっほ

医療的ケアが必要な方に加え、重症心身障害のお子様なども相談できます。県内3拠点で担当地域が異なります。平日9〜16時が基本ですが、各拠点へ確認してください。

出典：https://www.cfa.go.jp/assets/contents/node/basic_page/field_ref_resources/5218c3a3-610e-4925-8596-a9116889756f/b536f355/20260617_policies_shougaijishien_care-ji-shien_21.pdf　確認日：2026-03

まとめの記事

  • 群馬県の短期入所・障害児のあずけ先まとめ群馬県で、重い障害や医療的ケアのあるお子様をあずけられる短期入所・日中一時支援の探し方をまとめました。相談の窓口や受給者証の申しこみ先、見学のポイントもやさしく説明します。
  • 前橋市の日中一時支援・移動支援前橋市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。「日帰りショートステイ」とも呼ばれるしくみや、市の手当も、やさしく説明します。
  • 高崎市の日中一時支援・移動支援高崎市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。市の「生活サポート事業」や、市の手当も、やさしく説明します。
