医療的ケア児支援センター

新潟県医療的ケア児支援センターゆい・にじいろ

医療的ケア児者、重症心身障害児者とご家族などの相談窓口です。平日9〜17時に、電話・来所・訪問等で相談でき、関係機関との調整も行うことを県公式ページで確認しました。

出典：https://www.cfa.go.jp/assets/contents/node/basic_page/field_ref_resources/5218c3a3-610e-4925-8596-a9116889756f/b536f355/20260617_policies_shougaijishien_care-ji-shien_21.pdf　確認日：2026年3月

まとめの記事

  • 新潟県の短期入所・障害児のあずけ先まとめ新潟県で、重い障害や医療的ケアのあるお子様をあずけられる短期入所・日中一時支援の探し方をまとめました。相談の窓口や受給者証の申しこみ先、見学のポイントもやさしく説明します。
  • 新潟市の日中一時支援・移動支援新潟市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。病児保育室のレスパイト利用や市独自の手当も、やさしく説明します。
  • 長岡市の日中一時支援・移動支援長岡市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。市内にある新潟県医療的ケア児支援センターや、県のレスパイト入院も、やさしく説明します。
  • 上越市の日中一時支援・移動支援上越市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。看護師のいる事業所での日中のあずかりや、新潟県立中央病院のレスパイト入院も、やさしく説明します。

三条市

  • なでしこ青空支援センター 医療的ケア児日中一時支援

    三条市

    日中のあずかり

    対象：三条市に住む0歳から18歳までの医療的ケアが必要なお子様が対象です。

    ご家族の負担を軽くするため、医療的ケアが必要なお子様を一時的に預かり、看護等のケアを行う日中一時支援です。宿泊する短期入所ではなく、同じ施設の一般一時預かり・病児病後児保育とも別の事業です。

    医療的ケア

    体調に合わせて日帰りから始め、宿泊へ進めることもできる医療型短期入所です。支援学校の下校後からの利用例も案内しています。
