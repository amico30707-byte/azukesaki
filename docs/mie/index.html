医療的ケア児支援センター

三重県医療的ケア児・者相談支援センター（本部）

お子様・ご家族からの相談は本部が対応します。電話059-231-5768、9〜16時（土日祝・年末年始を除く）。支部は主に支援者への助言を行う案内です。

出典：https://www.cfa.go.jp/assets/contents/node/basic_page/field_ref_resources/5218c3a3-610e-4925-8596-a9116889756f/b536f355/20260617_policies_shougaijishien_care-ji-shien_21.pdf　確認日：2026-03

まとめの記事

  • 三重県の短期入所・障害児のあずけ先まとめ三重県で、重い障害や医療的ケアのあるお子様をあずけられる短期入所・日中一時支援の探し方をまとめました。相談の窓口や受給者証の申しこみ先、見学のポイントもやさしく説明します。
  • 津市の日中一時支援・移動支援津市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。総合支所での相談や、月額7,000円の市の心身障害児童福祉年金も、やさしく説明します。
  • 四日市市の日中一時支援・移動支援四日市市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。お子様の負担の上限が低い日中一時支援・移動支援や、市の重度障害児手当も、やさしく説明します。

施設の一覧

22か所をのせています。

  • 亀山市 お子様の移動支援・日中一時支援

    亀山市

    外出の付きそい日中のあずかり

    対象：亀山市は、障がい児を含め、障がいの種類に関係なくサービスを提供すると案内しています。移動支援は障がいのあるお子様の社会参加のための外出、日中一時支援は保護者の不在やご家族の休息のための日帰りの預かりです。年齢や支援区分により使えるサービスが異なるため、お子様ごとの対象を市へ確認してください。

    亀山市で、お子様の外出の付きそいと、宿泊しない日中の預かりを相談するための入口です。日中一時支援と泊まりの短期入所は、市の案内でも別の支援として示されています。

    くわしく（亀山市 お子様の移動支援・日中一時支援）

  • 伊勢市 医療的ケア児在宅レスパイト事業

    伊勢市

    家に来るヘルパー

    医療保険の適用時間を超える自宅での訪問看護や、医療保険の適用外となる訪問看護による病院受診・外出の付き添いにかかる費用を助成し、ご家族の休息時間と介護負担の軽減を図る市の事業です。

    くわしく（伊勢市 医療的ケア児在宅レスパイト事業）
