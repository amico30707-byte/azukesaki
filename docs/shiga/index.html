医療的ケア児支援センター

滋賀県重症心身障害児者・医療的ケア児等支援センターこあゆ

重症心身障害児者・医療的ケア児とご家族などの相談を受け、市町村、医療、福祉、保育、教育などと連携する窓口です。施設の空きや利用決定を示すものではありません。電話077-566-0746。

出典：https://www.cfa.go.jp/assets/contents/node/basic_page/field_ref_resources/5218c3a3-610e-4925-8596-a9116889756f/b536f355/20260617_policies_shougaijishien_care-ji-shien_21.pdf　確認日：2026-03

まとめの記事

  • 滋賀県の短期入所・障害児のあずけ先まとめ滋賀県で、重い障害や医療的ケアのあるお子様をあずけられる短期入所・日中一時支援の探し方をまとめました。相談の窓口や受給者証の申しこみ先、見学のポイントもやさしく説明します。
  • 大津市の日中一時支援・移動支援大津市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。使った時間で決まる日中一時支援の料金や、移動支援のくわしい決まりも、やさしく説明します。
  • 草津市の日中一時支援・移動支援草津市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。1日250円から使える日中一時支援や、送り迎えに使えることもある移動支援も、やさしく説明します。
