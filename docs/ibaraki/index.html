医療的ケア児支援センター

茨城県医療的ケア児支援センターみちしるべ

医療的ケアの必要なお子様・ご家族の相談や支援先の情報提供、関係機関との調整を行います。電話029-287-8627、受付は月〜金10〜16時と公式に案内しています。

出典：https://www.cfa.go.jp/assets/contents/node/basic_page/field_ref_resources/5218c3a3-610e-4925-8596-a9116889756f/b536f355/20260617_policies_shougaijishien_care-ji-shien_21.pdf　確認日：2026-03

まとめの記事

  • 茨城県の短期入所・障害児のあずけ先まとめ茨城県で、重い障害や医療的ケアのあるお子様をあずけられる短期入所・日中一時支援の探し方をまとめました。相談の窓口や受給者証の申しこみ先、見学のポイントもやさしく説明します。
  • 水戸市の日中一時支援・移動支援水戸市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。医療的ケア児等コーディネーターの窓口や、市独自の心身障害児（者）福祉手当も、やさしく説明します。
