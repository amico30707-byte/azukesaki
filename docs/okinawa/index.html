医療的ケア児支援センター

沖縄県医療的ケア児支援センター

年齢を問わず、医療的ケア児（者）とご家族、支援者からの相談を受ける窓口です。平日9〜17時の相談と、2026年6月末時点の短期入所先一覧を公式ページで確認しました。

出典：https://www.cfa.go.jp/assets/contents/node/basic_page/field_ref_resources/5218c3a3-610e-4925-8596-a9116889756f/b536f355/20260617_policies_shougaijishien_care-ji-shien_21.pdf　確認日：2026年3月

まとめの記事

  • 沖縄県の短期入所・障害児のあずけ先まとめ沖縄県で、重い障害や医療的ケアのあるお子様をあずけられる短期入所・日中一時支援の探し方をまとめました。相談の窓口や受給者証の申しこみ先、見学のポイントもやさしく説明します。
  • 那覇市の短期入所・日中一時支援・移動支援那覇市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。医療的ケアのあるお子様も使える通学支援も、やさしく説明します。
  • 浦添市の短期入所・日中一時支援・移動支援浦添市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。お子様の幼いころから大人になるまでの相談を受ける「ピアラルうらそえ」や、通学にも使える場合がある移動支援も、やさしく説明します。
  • 名護市の短期入所・日中一時支援・移動支援名護市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。医療的ケアのあるお子様が泊まれる「名護療育医療センター」や、北部の「医療的ケア児と家族の育児・療育サポートガイド」も、やさしく説明します。
  • 沖縄市の短期入所・日中一時支援・移動支援沖縄市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。医療型の区分や長い休みの「長期」の決め方がある日中一時支援や、医療的ケアのある小さなお子様を受け入れる「沖縄中部療育医療センター」も、やさしく説明します。
  • うるま市の短期入所・日中一時支援・移動支援うるま市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。基本的に毎日使える日中一時支援・移動支援や、医療的ケアのあるお子様とご家族のための「サポートガイド」も、やさしく説明します。
  • 宜野湾市の短期入所・日中一時支援・移動支援宜野湾市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。重症心身障害のあるお子様が保育所や幼稚園、特別支援学校などに通うときにも使える移動支援も、やさしく説明します。
