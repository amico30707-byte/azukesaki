  • 福岡県の短期入所・障害児のあずけ先まとめ福岡県で、重い障害や医療的ケアのあるお子様をあずけられる短期入所・日中一時支援の探し方をまとめました。相談の窓口や受給者証の申しこみ先、見学のポイントもやさしく説明します。
  • 北九州市の日中一時支援・移動支援北九州市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。日帰りショートや医療的ケア児レスパイト事業も、やさしく説明します。
  • 福岡市の日中一時支援・移動支援福岡市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。時間が広がった在宅レスパイト事業も、やさしく説明します。
