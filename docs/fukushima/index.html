医療的ケア児支援センター

福島県医療的ケア児支援センター

医療的ケアの必要なお子様、重症心身障害のお子様と、ご家族・支援者の困りごとの相談窓口です。県の公式ページで相談対象を確認しました。

出典：https://www.cfa.go.jp/assets/contents/node/basic_page/field_ref_resources/5218c3a3-610e-4925-8596-a9116889756f/b536f355/20260617_policies_shougaijishien_care-ji-shien_21.pdf　確認日：2026-03

まとめの記事

  • 福島県の短期入所・障害児のあずけ先まとめ福島県で、重い障害や医療的ケアのあるお子様をあずけられる短期入所・日中一時支援の探し方をまとめました。相談の窓口や受給者証の申しこみ先、見学のポイントもやさしく説明します。
  • 郡山市の日中一時支援・移動支援郡山市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。自己負担なしの医療的ケア児在宅レスパイト事業や、市の手当も、やさしく説明します。
  • いわき市の日中一時支援・移動支援いわき市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。2026年9月にはじまった医療的ケア児在宅レスパイト事業や、市の手当も、やさしく説明します。
  • 福島市の日中一時支援・移動支援福島市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。訪問看護師が家に来る医療的ケア児在宅レスパイト事業や、市独自の手当も、やさしく説明します。
