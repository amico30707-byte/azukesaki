医療的ケア児支援センター

長崎県医療的ケア児支援センターつなぐ

医療的ケア児とご家族、支援する関係機関の相談を受け、必要な支援先との調整や地域への訪問支援を行う窓口です。電話相談は平日9〜16時、相談フォームは24時間受け付けと公式ページで案内されています。施設の予約や空きの確認窓口ではありません。

出典：https://www.cfa.go.jp/assets/contents/node/basic_page/field_ref_resources/5218c3a3-610e-4925-8596-a9116889756f/b536f355/20260617_policies_shougaijishien_care-ji-shien_21.pdf　確認日：2026年3月

まとめの記事

  • 長崎県の短期入所・障害児のあずけ先まとめ長崎県で、重い障害や医療的ケアのあるお子様をあずけられる短期入所・日中一時支援の探し方をまとめました。相談の窓口や受給者証の申しこみ先、見学のポイントもやさしく説明します。
  • 長崎市の短期入所・日中一時支援・移動支援長崎市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。3つの型の日中一時支援や医療的ケア児レスパイト事業も、やさしく説明します。
  • 佐世保市の短期入所・日中一時支援・移動支援佐世保市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。看護師が家に来る訪問型レスパイト事業や、5つの地域の基幹相談支援センターも、やさしく説明します。
  • 諫早市の短期入所・日中一時支援・移動支援諫早市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。日中一時支援と短期入所をしている「みさかえの園 むつみの家」や、市独自の「諫早市心身障害児福祉手当」も、やさしく説明します。
  • 大村市の短期入所・日中一時支援・移動支援大村市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。「医療的ケア児訪問型レスパイト事業」や、短期入所と日中一時支援をしている「みさかえの園 あゆみの家」も、やさしく説明します。
  • 島原市の短期入所・日中一時支援・移動支援島原市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。日中にお子様を見守る人がいないときに使える日中一時支援や、看護師が家に来てくれる「医療的ケア児訪問型レスパイト事業」も、やさしく説明します。
