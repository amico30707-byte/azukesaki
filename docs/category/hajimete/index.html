はじめての方へ

8本の記事があります。

  • 受給者証とは？障害児の取り方と流れをやさしく解説

    障害のあるお子様が短期入所や日中一時支援を使うには、受給者証が必要です。2つの種類、申しこみの流れ、届くまでの期間、費用や更新のことを、はじめての方にもわかるように説明します。

  • 障害児の預け先はいつから？年齢ごとのじゅんび地図

    障害のあるお子様のあずけ先は、困ってから探すと間に合わないことがあります。0歳から18歳まで、年齢ごとにしておきたいじゅんびを、ひとつの地図のようにまとめました。

  • 相談支援事業所とは？障害児の探し方と選び方

    相談支援事業所は、受給者証のための計画づくりや、あずけ先さがしを手伝ってくれる場所です。費用、自分で計画を作る方法、見つけ方、選ぶときに見ることをやさしく説明します。

  • 短期入所の費用はいくら？障害児の利用料のしくみ

    短期入所の利用料は、原則1割負担で、ひと月の上限があります。上限額の決まり方、食費などの実費、日中一時支援との費用のちがいなど、お金のしくみをやさしく説明します。

  • 特別児童扶養手当と障害児福祉手当の違い・もらえる条件

    障害のあるお子様のご家族がもらえる手当、特別児童扶養手当と障害児福祉手当のちがいをまとめました。対象になる方、金額の目安、所得の制限、申しこみの窓口を説明します。

  • 療育手帳と受給者証の違い・どちらが必要？

    療育手帳と受給者証は、名前は似ていても役割がちがいます。それぞれ何に使うのか、手帳がなくても受給者証は取れるのか、申しこむ順番などを、はじめての方向けに説明します。

  • 受給者証の日数を増やしたいとき・支給量の見直し方

    受給者証の日数が足りないときは、支給量の見直しをお願いできます。市区町村への伝え方、相談支援専門員さんとの進め方、理由の書き方のコツを、はじめての方にもわかるようにまとめました。

  • 受給者証の更新はいつ？期限切れを防ぐじゅんび

    受給者証には期限があり、更新の手続きがいります。更新の時期やお知らせが来るころ、年度替わりの1月〜3月のじゅんび、負担上限月額の見直し、忘れたときのことをまとめました。
