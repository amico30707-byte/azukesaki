旧サイトの移転案内を確認し、新しい公式URLへ更新。高知県内全域から相談でき、相談とコーディネーター利用のご家族負担はないと案内されています。

まとめの記事

  • 高知県の短期入所・障害児のあずけ先まとめ高知県で、重い障害や医療的ケアのあるお子様をあずけられる短期入所・日中一時支援の探し方をまとめました。相談の窓口や受給者証の申しこみ先、見学のポイントもやさしく説明します。
  • 高知市の日中一時支援・移動支援高知市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。看護師が家に来る在宅レスパイト事業や、通院の付きそいを助ける事業も、やさしく説明します。

    いの町で、外出の支援と、日中の活動場所・見守りを相談する制度の入口です。日中一時支援はご家族の就労や一時的な休息を目的とし、宿泊する短期入所とは別です。
