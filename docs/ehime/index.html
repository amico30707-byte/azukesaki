医療的ケア児支援センター

愛媛県医療的ケア児支援センター

県の相談フォームから申込みできます。電話などの連絡先は子ども療育センターの公式ページで確認してください。

出典：https://www.cfa.go.jp/assets/contents/node/basic_page/field_ref_resources/5218c3a3-610e-4925-8596-a9116889756f/b536f355/20260617_policies_shougaijishien_care-ji-shien_21.pdf　確認日：2026-03

まとめの記事

  • 愛媛県の短期入所・障害児のあずけ先まとめ愛媛県で、重い障害や医療的ケアのあるお子様をあずけられる短期入所・日中一時支援の探し方をまとめました。相談の窓口や受給者証の申しこみ先、見学のポイントもやさしく説明します。
  • 松山市の日中一時支援・移動支援松山市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。医療的ケア児支援のしおりや市独自の福祉年金も、やさしく説明します。
  • 今治市の日中一時支援・移動支援今治市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。「レスパイトサービス」とよばれる日中一時支援や、訪問看護の費用を助ける医療的ケア児在宅レスパイト事業も、やさしく説明します。
  • 新居浜市の日中一時支援・移動支援新居浜市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。放課後児童クラブで受け入れがむずかしいお子様を一時的にあずかる「タイムケア事業」や、「日中短期入所事業」も、やさしく説明します。
  • 西条市の日中一時支援・移動支援西条市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。「医療的ケア児支援のしおり」にのっている、医療的ケア児等コーディネーターのいる相談支援事業所や、停電にそなえる電源の助成も、やさしく説明します。
