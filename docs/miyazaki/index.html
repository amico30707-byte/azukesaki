医療的ケア児支援センター

宮崎県医療的ケア児支援センター

出典：https://www.cfa.go.jp/assets/contents/node/basic_page/field_ref_resources/5218c3a3-610e-4925-8596-a9116889756f/b536f355/20260617_policies_shougaijishien_care-ji-shien_21.pdf　確認日：2026年3月

まとめの記事

  • 宮崎県の短期入所・障害児のあずけ先まとめ宮崎県で、重い障害や医療的ケアのあるお子様をあずけられる短期入所・日中一時支援の探し方をまとめました。相談の窓口や受給者証の申しこみ先、見学のポイントもやさしく説明します。
  • 宮崎市の短期入所・日中一時支援・移動支援宮崎市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。外出介護のしくみや自己負担なしの在宅レスパイト事業も、やさしく説明します。
  • 都城市の短期入所・日中一時支援・移動支援都城市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。サービスをどれくらい使えるかの基準（令和8年1月改正）や、夏休みなどに日数をふやせるしくみも、やさしく説明します。
  • 延岡市の短期入所・日中一時支援・移動支援延岡市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。サービスをどれくらい使えるかの目安をまとめた「支給決定基準」や、医療的ケアのあるお子様のための「医療的ケア児在宅レスパイト事業」も、やさしく説明します。
