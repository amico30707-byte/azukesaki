医療的ケア児支援センター

青森県小児在宅支援センター

日常的に医療的ケアが必要なお子様とご家族の相談を受け、県内の関係機関・市町村と連携する窓口です。平日9時30分〜16時30分、電話017-752-9678と公式ページで確認しました。

出典：https://www.cfa.go.jp/assets/contents/node/basic_page/field_ref_resources/5218c3a3-610e-4925-8596-a9116889756f/b536f355/20260617_policies_shougaijishien_care-ji-shien_21.pdf　確認日：2026-03

まとめの記事

  • 青森県の短期入所・障害児のあずけ先まとめ青森県で、重い障害や医療的ケアのあるお子様をあずけられる短期入所・日中一時支援の探し方をまとめました。相談の窓口や受給者証の申しこみ先、見学のポイントもやさしく説明します。
  • 青森市の日中一時支援・移動支援青森市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。重症心身障がいのあるお子様の日中一時支援の料金や、障害者外出介護サービスも、やさしく説明します。
  • 八戸市の日中一時支援・移動支援八戸市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。医療的ケア児等コーディネーターの窓口や、家に来てくれる療育支援事業も、やさしく説明します。
  • 弘前市の日中一時支援・移動支援弘前市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。2025年10月にできた基幹相談支援センターや、県立さわらび療育福祉センターでの日中のあずかりも、やさしく説明します。

    つがる市

    外出の付きそい日中のあずかり

    対象：日中一時支援は障害児・障害者を対象に含み、2026年4月発行の福祉のしおりでは、放課後などに一時的な見守りが必要な障害のある児童・生徒を案内しています。移動支援のお子様ごとの対象は市へ確認してください。

    屋外での移動が難しい方の外出を支える移動支援と、お子様の日中の活動場所を確保し、ご家族の就労や休息を支える日中一時支援です。

    自宅での身体介護や家事援助などを案内する、むつ市の事業所です。居宅介護等の対象にお子様を含む公式記載があります。希望する支援と訪問できる地域を事前に相談してください。

    むつ市の公式パンフレットで、お子様も利用できる居宅介護の事業所、移動支援の受託先として確認できる営業所です。制度の利用決定と、事業所の現在の担当可否は別に確認します。

    三沢市で、お子様の外出を支える移動支援と、日中の活動場所をつくり介護するご家族の休息につなげる日中一時支援を相談する入口です。
