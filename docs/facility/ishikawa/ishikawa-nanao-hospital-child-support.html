国立病院機構 七尾病院 通所・日中一時支援・短期入所

空きや受け入れは、かならず施設にご確認ください

利用を考えるときは

電話0767-53-1890

確認日：2026年10月17日（あずけさき手帖が公式の情報を確かめた日）

施設のこと

地域
七尾市
サービスの種類
通う療育日中のあずかりお泊まり（短期入所）
対象年齢
児童発達支援・放課後等デイサービスは在宅の重症心身障害児、短期入所は在宅で生活する重症心身障害児を案内しています。日中一時支援は障害のある方が対象で、お子様の詳しい年齢・状態は要確認です。
ひとこと
重症心身障害児向けの児童発達支援・放課後等デイサービス、日中一時支援、宿泊を伴う短期入所を同じ病院で相談できます。生活介護は成人向けの別事業です。通所中の診療と送迎は、公式資料の説明差も含めて個別確認が必要です。
空き・受付について
現在の空き、新規受付、希望日の利用、日中一時支援と短期入所の詳しい時間、利用地域、実費、送迎表示の対象、吸引・経管栄養・人工呼吸器の処置別対応、夜間体制、電話でのお子様ごとの受け入れは未確認です。石川県一覧の「空床型」は短期入所の事業形態で、現在の空きを示しません。
利用の条件
通所・日中一時支援は市町村の支給決定と受給者証を確認し、病院窓口で手続きします。短期入所は短期入所の受給者証に加え、病院医師の診察で利用可能か検討した後、契約等を行います。見学・体験は病院へ相談できます。
利用までの流れ
通所・日中一時支援：市町村へ申請 → 支給決定・受給者証 → 病院窓口で登録・契約。短期入所：市町村へ申請 → 短期入所受給者証 → 病院医師の診察・利用検討 → 契約 → 日程を調整。緊急時も事前相談が必要です。
医療的ケア
あり
医療的ケアについて
通所は看護師を中心に必要な医療的ケア、日中一時支援は看護・健康管理、短期入所は医療的ケアを行うと記載しています。通所中の診療は原則行わず、緊急時や希望する一般診療・定期診療・処置はご家族の付き添いが必要です。吸引・経管栄養・人工呼吸器の処置別対応や夜間体制は未確認です。
利用できる時間
児童発達支援・放課後等デイサービス等の通所は月〜金曜8時35分〜17時。病院ページの日課には15時から送迎とありますが、児童発達支援・放課後等デイサービスの支援プログラムはいずれも送迎なしと記載しています。利用する事業・地域・曜日ごとに確認してください。日中一時支援の時間、短期入所の入退所時刻・日数は要確認です。
地域・送迎
施設は七尾市にあります。利用できる市町村、送迎範囲、県外利用は未確認です。
料金
市町村が世帯収入に応じて負担上限月額を決める案内です。食事、入浴、日用品などの実費と事業別の支払額は要確認です。
住所
石川県七尾市松百町八部3番地の1

確認日

サービスごとのこと

児童発達支援・放課後等デイサービス
在宅の重症心身障害児を対象に、月〜金曜8時35分〜17時、必要な医療的ケア・看護・機能訓練・療育などを行います。支援プログラムは送迎なしです。生活介護は成人向けの別事業です。
出典：nanao.hosp.go.jp
確認日：2026年10月17日
日中一時支援
障害のある方を日中に預かり、看護、療育、食事・入浴などの日常生活支援、健康管理を行います。市町村の支給決定が必要です。お子様の詳しい条件は要確認です。
出典：nanao.hosp.go.jp
確認日：2026年10月17日
短期入所（宿泊あり）
在宅の重症心身障害児を介護するご家族が一時的に介護できないときに、病棟へ宿泊して看護・療育・生活支援・医療的ケアを受けます。日帰り利用ではありません。事前に病院医師の診察と利用検討があり、緊急時も事前相談が必要です。
出典：nanao.hosp.go.jp
確認日：2026年10月17日
