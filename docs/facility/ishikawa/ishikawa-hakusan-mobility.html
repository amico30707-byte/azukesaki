白山市 移動支援事業

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
白山市
サービスの種類
外出の付きそい
対象年齢
白山市の移動支援ガイドブックでは、原則として身体障害者手帳・療育手帳・精神障害者保健福祉手帳を持つ方が対象です。手帳がなくても市長が必要と認める場合があるため、お子様の詳しい状態・外出目的は市へ確認してください。
ひとこと
屋外での移動が難しいお子様・成人の外出を支える白山市の移動支援です。2026年8月7日更新のお子様向けページから、申請書と移動支援ガイドブックが案内されています。
利用の条件
本人またはご家族が白山市障害福祉課へ申請し、市が月の利用時間を決めます。その範囲内で市と契約する事業所を選んで契約し、事業所がガイドヘルパーを調整します。複数事業所との契約も可能ですが、合計は決定時間の範囲内です。原則としてご家族は同行せず、お子様とガイドヘルパーで利用します。通院は居宅介護の通院等介助等を使い、通学・通勤は原則対象外です。保護者の入院等の事情がある通学は市へ相談してください。
利用までの流れ
本人またはご家族が白山市障害福祉課へ相談・申請 → 市が月の利用時間を決定 → 市と契約する事業所から候補を選ぶ（複数契約も可） → 外出目的・地域・日時・実費・必要な介助を確認 → 事業所と契約 → ガイドヘルパーを調整。
医療的ケアについて
市の移動支援案内では、医療的ケア一般、吸引、経管栄養、人工呼吸器に対応する事業所を確認できませんでした。必要な処置は市と候補事業所へ一つずつ確認してください。
利用できる時間
市が月の利用時間を決め、その範囲内で利用します。事業所ごとの曜日・時間と希望日の担当可否は、市と候補事業所へ確認してください。
地域・送迎
白山市へ申請し、市と契約する事業所を使う制度です。ガイドブックには約30事業所とありますが、冊子内に現在の基準日が見当たらないため、現行件数としては扱いません。候補事業所と実際の外出範囲は市へ確認してください。
料金
市は地域生活支援事業について、サービスの種類により自己負担が必要な場合があると案内しています。移動支援のお子様の負担額、月額上限、交通費等の実費は市と事業所へ確認してください。
