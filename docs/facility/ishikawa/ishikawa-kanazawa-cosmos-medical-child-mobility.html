こすもす訪問看護ステーション金沢（医療的ケア児移動介護支援）

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
金沢市
サービスの種類
外出の付きそい
対象年齢
金沢市の医療的ケア児移動介護支援の登録事業者です。訪問看護では小児・医療的ケア児を対象に含みます。お子様ごとの利用決定と現在の担当可否は要確認です。
ひとこと
金沢市の2026年8月1日現在の移動支援等サービス事業所一覧で、医療的ケア児移動介護支援と重症心身障害児・者移動支援の登録を確認できる訪問看護ステーションです。
利用の条件
金沢市障害福祉課へ対象・外出目的・必要時間を相談し、保護者が申請します。利用決定後、事業所と必要な医療的ケア、備品、感染予防、緊急時対応、個別支援計画、希望日時を確認してください。一般の訪問看護や移動支援とは別に、利用する制度名を伝えます。
利用までの流れ
金沢市障害福祉課へ相談 → 保護者が申請 → 市の利用決定と制度名を確認 → 事業所へ外出目的・希望日時・必要な医療的ケアを相談 → 緊急時対応・個別支援計画等を確認 → 利用日を調整。
医療的ケア
あり
医療的ケアについて
市制度は看護職員が医療的ケアを伴う移動介護を行います。訪問看護の公式一覧では痰の吸引、経管栄養、人工呼吸器管理等を掲載していますが、移動介護で同じ処置を今担当できるとは確定せず、個別に確認が必要です。
利用できる時間
市制度の基本上限は月30時間です。事業所が移動介護を担当できる曜日・時間と、現在の看護職員体制は未確認です。
地域・送迎
金沢市の医療的ケア児移動介護支援・重症心身障害児者移動支援の登録事業者です。市外在住のお子様や市外への外出条件は未確認です。
料金
医療的ケア児移動介護支援はサービス利用料の1割が基本で、世帯区分により月額上限0円・4,600円・18,600円。重度の障害者手帳がある方の免除案内があります。交通費などの実費は未確認です。
