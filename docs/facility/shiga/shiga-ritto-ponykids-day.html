PONYKIDS 日中一時支援

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
栗東市
サービスの種類
日中のあずかり
対象年齢
草津市の2026年度委託事業所一覧では、重症心身障害のあるお子様を主な対象としています。草津市内に住所があり、障害者手帳を持つ方、または特別支援学級・特別支援学校に在籍する方が市制度の対象候補です。詳しい条件は市と事業所へ確認してください。
ひとこと
ホースセラピーを通じて日中の活動の場を提供し、見守りや日常的な訓練を行う日中一時支援です。草津市の2026年度委託事業所一覧に掲載されています。
利用の条件
新規利用は、先に事業所へ利用日数・時間・必要な支援を相談し、調整後に草津市障害福祉課へ障害者手帳等を持参して申請します。市の利用決定と、事業所の希望日の受け入れは別です。
利用までの流れ
PONYKIDSへ希望日・時間・必要な支援を相談 → 草津市障害福祉課（市役所1階19番・20番窓口）へ障害者手帳等を持参して申請 → 市の決定 → 事業所と日時・実費・個別ケアを確認。
