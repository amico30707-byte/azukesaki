滋賀県立総合病院 療育センター・こども棟

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
守山市
サービスの種類
通う療育お泊まり（短期入所）
対象年齢
児童発達支援は就学までの乳幼児期で、運動発達や知的発達に重度の障害があるお子様が対象です。医療型短期入所は原則、滋賀県内在住の18歳未満で支給決定を受けた方が対象です。登録・利用中に18歳を超えた方は個別に継続できます。
ひとこと
療育センターの親子通園に加え、こども棟では2026年4月から、ご家族の休息・私用・学校行事などで在宅介護が難しいときの医療型短期入所を行っています。
利用の条件
通園はご家族も療育活動へ参加します。短期入所は市町から医療型短期入所の支給決定・受給者証を受け、病院の外来受診、お試し入院、院内判定、契約が必要です。
利用までの流れ
短期入所は地域医療推進室へ相談 → 市町へ支給申請 → かかりつけ医から外来紹介 → 外来受診・聞き取り → お試し入院 → 院内判定 → 契約・受給者証確認 → 毎月の申込期間に申込み → 利用決定の連絡を確認。通園は療育センターへ別に相談します。
医療的ケア
あり
医療的ケアについて
通園では注入栄養や呼吸器管理が必要なお子様も対象に含まれます。2026年7月3日版の短期入所の持ち物表には、人工呼吸器・酸素機器、吸引器具、胃ろう接続チューブ・注入物などが分けて案内されています。機器や方法、回数、夜間体制、希望日の個別受け入れは要確認です。
利用できる時間
短期入所は1回最大6日で、平日11時入所・10時退所です。同じ月に複数回の申込みはできません。通園の曜日、開始・終了時刻、利用回数は未確認です。
地域・送迎
施設は守山市にあります。短期入所は原則、滋賀県内在住の18歳未満が対象です。通園の利用市町村、送迎の有無・範囲は未確認です。
料金
短期入所のサービス費は原則1割で、市町が決める月の負担上限までです。医療費、食事、消耗品等は別に必要な場合があります。食費は2025年12月現在で1日1,530円または1,000円ですが、変更の可能性があります。通園の費用は未確認です。
