鹿児島こども病院 レスパイト入院・日中ショートステイ

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
日置市
サービスの種類
お泊まり（短期入所）日中のあずかり
対象年齢
レスパイト入院は、在宅で医療的ケアを必要とする15歳までのお子様が対象です。日中ショートステイは、主に重症心身障害児・医療的ケア児を対象とします。どちらもお子様の状態やケア内容によって受け入れが難しい場合があります。
ひとこと
医療保険で2日から1週間程度入院するレスパイト入院と、障害福祉サービスの受給者証で日中だけ利用する医療型特定短期入所があります。名前が似ていますが、制度・時間・付きそい・送迎・費用を分けて確認します。
利用の条件
まず病院へ相談し、レスパイト入院か日中ショートステイかを伝えます。レスパイト入院は初回のみお父様・お母様の付きそいをお願いする場合があります。日中ショートステイは付きそい不要と案内されていますが、受給者証、個別のケア、希望日の利用は事前確認が必要です。
利用までの流れ
病院へ相談 → レスパイト入院か日中ショートステイかを伝える → お子様の年齢・状態・医療的ケア、受給者証、初回手続き、必要物品を確認 → 受け入れ判断 → 希望日、付きそい、送迎、費用を確認。
医療的ケア
あり
医療的ケアについて
公式ページは、レスパイト入院で吸引、経管栄養、在宅酸素療法などを行うと明記しています。日中ショートステイは看護師による医療的ケアと医師の体調変化対応を案内していますが、個別の処置名は示されていません。人工呼吸器、処置回数、機器の持ち込みは事前確認が必要です。
利用できる時間
レスパイト入院は2日から1週間程度です。日中ショートステイは9時〜16時30分で、月・火・水・金・土曜日に開所し、木・日曜日、祝日、お盆、年末年始は休みです。入退院時刻、申込時期、利用回数は病院へ確認してください。
地域・送迎
施設は日置市にあります。日中ショートステイは、ご家族の送迎が難しい場合に自宅への送迎を相談できます。送迎は他の利用者との調整が必要で、希望にそえない場合があります。利用対象地域は未確認です。
料金
レスパイト入院は医療保険です。日中ショートステイは障害福祉サービスの受給者証を使い、送迎費は日置市内無料、市外30km未満300円、市外30km以上500円、高速料金は実費です。医療保険の自己負担、食事代等と、障害福祉サービスの利用者負担は分けて確認してください。
