キッズステーションみらe

空きや受け入れは、かならず施設にご確認ください

利用を考えるときは

公式ページを見る伊佐市｜障害福祉サービス事業所一覧（2025年11月現在）

電話0995-28-1030

確認日：2026年10月6日（あずけさき手帖が公式の情報を確かめた日）

施設のこと

地域
伊佐市大口宮人
サービスの種類
通う療育
対象年齢
児童発達支援は3〜5歳の未就学のお子様、放課後等デイサービスは6〜18歳のお子様が対象です。事業ごとの利用条件は市と施設へ確認してください。
ひとこと
伊佐市大口宮人で、3〜5歳の児童発達支援と、6〜18歳の放課後等デイサービスを行う多機能型の事業所です。
空き・受付について
施設案内に申込・見学受付の記載がありますが、現在の空き、新規契約、希望曜日、放課後等デイサービスの送迎地域、自宅送迎、利用者負担・実費、電話でのお子様ごとの受け入れ、医療的ケア・処置別対応は未確認です。
利用の条件
お住まいの市町村へ障害児通所支援を相談し、受給者証等を確認してから施設へ申し込みます。公式案内の「申込・見学受付中」は、希望曜日の空きや利用契約を確約するものではありません。
利用までの流れ
お住まいの市町村へ児童発達支援または放課後等デイサービスを相談 → 受給者証等を確認 → 施設へ年齢、希望曜日、送迎、昼食、必要な支援を相談 → 見学・契約・利用日を調整。
医療的ケアについて
今回確認した市一覧と施設案内には、看護職員の配置や、吸引・経管栄養・人工呼吸器、全面介助、強度行動障害への個別対応は掲載されていません。
利用できる時間
児童発達支援は8時30分登園・14時30分降園で、クラスごとに通う曜日が決まっています（3歳は木曜、4歳は月・火曜、5歳は金曜）。土・日曜、祝日、12月29日〜1月3日は休みです。放課後等デイサービスは、学校がある日は15時30分ごろの登園・お迎えから17時30分まで、月1回の土曜登校日は12時ごろ〜17時30分、春・夏・冬休みは9時〜17時30分です。曜日ごとの利用枠は施設へ確認してください。
地域・送迎
施設は伊佐市大口宮人にあります。利用できる市町村、放課後等デイサービスの送迎地域、自宅への送迎は公式案内では確認できませんでした。
料金
障害児通所支援の利用者負担と、昼食・活動等の実費は受給者証と施設へ確認してください。児童発達支援の昼食は希望制と案内されていますが、金額は確認できませんでした。
住所
鹿児島県伊佐市大口宮人463番地30
電話

確認日
