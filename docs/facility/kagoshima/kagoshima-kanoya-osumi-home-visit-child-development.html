おおすみ笑顔のわ 居宅訪問型児童発達支援

お知らせご自宅への訪問でも、生活介助を行う居宅介護ではなく発達支援です。児童発達支援との併用はできないと案内されています

空きや受け入れは、かならず施設にご確認ください

利用を考えるときは

公式ページを見るおおすみ笑顔のわ｜居宅訪問型児童発達支援

電話0994-43-3831

確認日：2026年10月28日（あずけさき手帖が公式の情報を確かめた日）

施設のこと

地域
鹿屋市・肝付町・東串良町
サービスの種類
通う療育
対象年齢
障がい等により自宅から出ることが難しく、市町村から受給者証を交付されたお子様が対象です。
ひとこと
専門職がご自宅を訪問し、発達段階に応じた遊び、姿勢・動作の学習、外出機会、集団活動や通所への移行を支える療育です。身体介護等を行う居宅介護とは別です。
空き・受付について
2026年10月28日に法人公式ページで、対象、原則の利用地域、曜日・時間、利用回数、児童発達支援との併用、申請から契約までの流れ、電話を確認しました。電話確認はしていません。現在の新規受付・空き、訪問日時、費用・実費、個別ケアは未確認です。
利用の条件
市町村の受給者証が必要です。法人は児童発達支援との併用はできないと案内しています。利用回数はお子様の発達状況を踏まえて保護者と相談して決めます。
利用までの流れ
法人へ電話・フォームで相談 → 見学・面談 → 市役所で受給者証等を申請 → 相談支援事業所等が利用計画案を作成 → 契約 → 訪問日時・回数を調整して利用開始。
医療的ケアについて
外出が難しいお子様を対象に含みますが、今回の公式ページでは医療的ケア一般、看護師配置、重症心身障害、重度知的障害、強度行動障害、全面介助、吸引、経管栄養、人工呼吸器の処置別対応は確認できませんでした。
利用できる時間
利用日は月〜土曜。月〜金曜9時30分〜17時30分、土曜9時〜17時です。日曜・祝日・年末年始の休暇時は休みです。実際の訪問日時・回数は相談して決めます。
地域・送迎
原則として鹿屋市、肝付町、東串良町に住むお子様が対象です。住所欄は相談窓口で、実際の支援場所はお子様のご自宅です。
料金
制度による利用者負担、訪問に伴う交通費・教材等の実費は、市町村と事業者へ確認してください。
住所
相談窓口：鹿児島県鹿屋市笠之原町1520-1（一般社団法人 おおすみ笑顔のわ）
