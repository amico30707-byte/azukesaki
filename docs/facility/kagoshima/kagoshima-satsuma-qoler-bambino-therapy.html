施設のこと

地域
さつま町
サービスの種類
通う療育
対象年齢
児童発達支援は就学前のお子様、放課後等デイサービスは小学1年生から高校3年生のお子様が対象です。
ひとこと
さつま町で、児童発達支援、放課後等デイサービス、保育所等訪問支援を行う児童発達支援センターです。
空き・受付について
現在の空き、新規受付、見学後の契約、希望曜日、電話でのお子様ごとの受け入れ、利用地域、対象校・住所ごとの送迎、実費額、医療的ケア・処置別対応は未確認です。さつま町の全額助成は、施設の空きや町外の方への適用を示すものではありません。
利用の条件
さつま町にお住まいの方は、役場本庁こども課こども支援係または障害児相談支援事業所へ相談し、町へ申請します。障害児支援利用計画案は相談支援専門員と作る方法と、お父様・お母様が作るセルフプランがあります。見学後すぐに利用できるとは限らず、受給者証、契約、希望日の調整が必要です。町外の方はお住まいの市町村へ確認します。
利用までの流れ
役場本庁こども課こども支援係または障害児相談支援事業所へ相談 → 町へ申請・窓口で聞き取り → 障害児支援利用計画案を提出 → 町の支給決定・受給者証 → 見学・利用する事業とグループを相談 → 施設と契約・利用日を調整。
医療的ケアについて
今回確認した町と施設の公式ページには、医療的ケア一般や、吸引・経管栄養・人工呼吸器などの処置別対応は掲載されていません。
利用できる時間
児童発達支援は一日利用と午前のグループ、放課後等デイサービスは放課後や学校休業日の利用があります。曜日・利用時刻は、お子様のグループと希望日ごとに確認してください。
地域・送迎
施設はさつま町轟町にあります。利用できる住所の範囲は未確認です。放課後等デイサービスは一部の小学校への迎えを案内していますが、対象校とご自宅への送迎範囲は要確認です。
料金
障害児通所支援の利用者負担は原則1割ですが、さつま町はお父様・お母様の負担を軽くするため、利用者負担を全額助成しています。食費などの実費は助成対象外です。町外の方への適用や実費額は、お住まいの市町村とセンターへ確認してください。
