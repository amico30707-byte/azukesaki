翠のこかげ 医療型短期入所

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
前橋市
サービスの種類
お泊まり（短期入所）
対象年齢
18歳未満の障害児で障害支援区分1以上の方が対象です。小学生以上で、未就学のお子様は対象外です。
ひとこと
医療的ケアが必要な方、重症心身障害児・者などを対象とする医療型短期入所です。公式料金表には宿泊と、宿泊を伴わない医療型特定短期入所が載っています。宿泊を伴わない利用も日中一時支援とは別です。
利用の条件
18歳未満は障害支援区分1以上の小学生以上が対象です。医療型または福祉型の受給者証が必要です。見学・面談で受け入れ可能か判断した後に契約します。医療的ケアがある方は診療情報提供書と主治医指示書が必要で、中田クリニックの受診歴がない方は利用前に受診します。
利用までの流れ
市町村の障害福祉課へ支給申請 → 受給者証の支給決定を確認 → 施設見学とご家族・本人の面談 → 受け入れ可能な場合に契約 → 受診歴がなければ中田クリニックを受診 → 2か月前の1日から希望日を予約。契約時は受給者証、手帳等、健康保険の資格確認書類、診療情報提供書、医療的ケアがある場合は主治医指示書が必要です。
医療的ケア
あり
医療的ケアについて
医療的ケアが必要な方を対象に含む医療型短期入所です。利用案内は『呼吸器の方』の受け入れを1日2人までとしています。呼吸器の機種・設定・夜間対応、吸引・経管栄養の対応は未確認で、医療型という名称から推測していません。
利用できる時間
予約は利用月の2か月前の1日から9時〜17時に受け付けます。原則6泊7日までです。入所は9時〜11時30分または14時〜17時、退所は17時まで。日曜・祝日の受け入れは不可と案内されています。希望日を利用できるかは予約時に確認が必要です。
地域・送迎
施設は前橋市にあります。利用できる市町村、県外利用、送迎は未確認です。
料金
受給者証の種類と障害区分に応じたサービス自己負担に、食費・水道光熱費・リネン代などの実費が加わります。料金表では水道光熱費250円／日、リネン代350円／泊。食費は加算対象者が朝240円・昼420円・夕420円、対象外が朝400円・昼580円・夕580円です。おむつ等を使う場合は別途実費があります。
