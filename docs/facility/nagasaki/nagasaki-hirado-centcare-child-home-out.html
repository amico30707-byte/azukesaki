セントケア平戸

施設のこと

地域
平戸市戸石川町
サービスの種類
家に来るヘルパー外出の付きそい
対象年齢
長崎県の県北資源マップは、居宅介護の対象欄で『児童』を対象として掲載しています。お子様ごとの年齢・支給条件は市町と事業所へ確認してください。
ひとこと
平戸市戸石川町の訪問事業所です。長崎県の2025年10月更新の資源マップでは、お子様を含む居宅介護、同行援護、平戸市の移動支援が掲載されています。法人の現在の施設検索は介護保険の「訪問介護」とだけ表示するため、障害福祉サービスの現在の受付は別に確認してください。
利用の条件
平戸市で居宅介護の支給決定を受ける場合は、市へ介護給付費等の支給申請書と同意書を提出し、支給決定・受給者証等を確認してから事業所と契約します。平戸市の移動支援は、市へ移動支援事業申請書と同意書を提出します。資源マップへの掲載、法人の加算資料、24時間の提供時間は、現在の新規受付や希望日時の担当を示しません。
利用までの流れ
平戸市福祉課障害福祉班へ、家での介助か外出支援かを分けて相談 → 居宅介護は介護給付費等の支給申請書と同意書、移動支援は移動支援事業申請書と同意書を提出 → 支給決定・受給者証等を確認 → セントケア平戸へお子様の年齢、住所、希望日時、身体介護・家事援助・外出目的を相談 → 障害福祉サービスの現在の受付を確認して契約・担当調整。市の窓口は0950-22-9130、平日8時30分〜17時15分です。
医療的ケアについて
身体介護の案内はありますが、看護職員の配置や、吸引・経管栄養・人工呼吸器などの処置別対応は掲載されていません。
