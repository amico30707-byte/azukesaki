島原市 医療的ケア児訪問型レスパイト事業

お知らせ人工呼吸器の使用など、要綱に定めるすべての対象条件を満たす必要があります

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
島原市
サービスの種類
家に来るヘルパー
対象年齢
島原市に住む0歳から18歳到達後最初の3月31日までのお子様で、在宅でご家族の介護を受け、医師の指示書により訪問看護で医療的ケアを受け、人工呼吸器を使用している方が対象です。すべての条件を満たす必要があります。
ひとこと
指定訪問看護ステーションの看護師がご自宅を訪れ、ご家族に代わって看護を行い、お父様・お母様の負担を軽くするための市の補助事業です。2026年4月1日に始まりました。
利用の条件
利用する指定訪問看護ステーションを経由して市へ申請します。利用申請書に、医師の訪問看護指示書の写しまたは医療的ケアを受けていることが分かる書類を添えます。ご家族は申請・請求等を訪問看護ステーションへ委任します。
利用までの流れ
島原市福祉課と利用する指定訪問看護ステーションへ相談 → 対象条件・指示書等を確認 → 訪問看護ステーション経由で申請 → 市の利用決定 → 希望日時・医療的ケア・実費を訪問看護ステーションと調整 → 利用。
医療的ケア
あり
医療的ケアについて
要綱は医療的ケアを人工呼吸器による呼吸管理、痰吸引、その他の日常生活に不可欠な医療行為と定義し、対象者には人工呼吸器の使用を必須としています。実際の吸引方法・回数、機器、その他の処置は訪問看護ステーションと個別確認が必要です。経管栄養は処置名として確認できませんでした。
利用できる時間
1年度96時間までです。月ごとの利用時間は、健康保険の訪問看護時間を除き、1日ごとの時間を合計して1時間未満を切り捨てます。希望日時の担当可否は訪問看護ステーションとの調整が必要です。
地域・送迎
島原市の住民基本台帳に記録され、現に市内で在宅生活する対象のお子様の制度です。実際の訪問範囲と希望日時は、利用する指定訪問看護ステーションへ確認してください。
料金
健康保険の対象外となる訪問看護について、1時間7,500円で計算した額を年度96時間まで補助する要綱です。実際の自己負担、上限を超えた費用、交通費・衛生用品等の実費は市と訪問看護ステーションへ確認してください。
