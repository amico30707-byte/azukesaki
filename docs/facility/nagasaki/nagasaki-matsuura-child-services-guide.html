松浦市 お子様の障害福祉・通所支援の申請案内

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
松浦市
サービスの種類
通う療育家に来るヘルパーお泊まり（短期入所）
対象年齢
市の令和7年版しおりでは、障害児通所支援は18歳未満で、障害者手帳、自立支援医療受給者証、特定疾患医療受給者証を持つ方、または発達センター・医療機関等で障害があると判断された方を対象例として案内しています。事業別の対象は市へ確認してください。
ひとこと
松浦市で、障害福祉サービスや障害児通所支援を申請するときの書類と、同じ世帯で複数サービスを使った場合の負担合算を確認できる市の窓口です。
利用の条件
障害福祉サービスと障害児通所支援では申請書が分かれています。しおりでは、手帳等がない場合は医師意見書が必要になることがあります。利用者負担が世帯の基準額を超えた場合の給付は自動ではなく、領収書等をそろえて市へ申請します。市の支給決定と事業所の契約・空きは別です。
利用までの流れ
松浦市福祉事務所障害福祉係へ、使いたい支援を分けて相談 → 申請書、個人番号が確認できるもの、手帳・受給者証等を確認して申請（手帳等がない場合は医師意見書が必要になることあり） → 認定調査・利用計画・支給決定 → 受給者証を確認 → 事業所と契約・利用調整。複数サービスの負担が基準額を超えた場合は、領収書等をそろえて別に申請します。
医療的ケアについて
今回確認した申請・負担案内には、看護職員の配置や、吸引・経管栄養・人工呼吸器などの処置別対応は掲載されていません。事業所ごとに確認してください。
