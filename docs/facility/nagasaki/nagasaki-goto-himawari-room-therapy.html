さゆり会 ひまわりルーム

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
五島市
サービスの種類
通う療育
対象年齢
児童発達支援は、集団療育・個別療育が必要と認められた未就学のお子様が対象です。放課後等デイサービスは、学校や専修学校等に就学し、授業後や休業日に支援が必要と認められたお子様が対象です。施設での個別の利用可否は別に確認します。
ひとこと
五島市で児童発達支援、放課後等デイサービス、保育所等訪問支援を行い、感覚・運動・遊び・集団活動などを通じて発達を支える施設です。
利用の条件
利用したい支援を選び、五島市へ相談・申請します。市の調査等と支給決定を受け、受給者証の交付後に施設と契約します。市の2026年度版しおりの掲載や定員は、ひまわりルームの現在の空き・新規受付を示すものではありません。
利用までの流れ
五島市または相談支援事業所へ通所支援を相談 → 市へ申請 → 市の調査等と支給決定 → 通所受給者証の交付 → ひまわりルームへ年齢・希望曜日・必要な支援を相談 → 見学・契約・利用日を調整。
医療的ケアについて
今回確認した市のしおりと施設ページには、医療的ケア一般や、吸引・経管栄養・人工呼吸器などの処置別対応は掲載されていません。
利用できる時間
公式ページの業務時間は8時30分〜17時30分、定休日は日曜・祝日・年末年始です。児童発達支援・放課後等デイサービスそれぞれのお子様の利用時間は要確認です。
地域・送迎
施設は五島市下大津町にあります。送迎の有無・範囲、市内の離島間の利用、市外利用は未確認です。
料金
制度による自己負担、食事・活動等の実費は未確認です。五島市と施設へ確認してください。
