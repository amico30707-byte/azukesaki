長岡市 移動支援（個別支援型）

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
長岡市
サービスの種類
外出の付きそい
対象年齢
屋外での移動が難しい障がい児者が対象です。お子様は、対象となる身体障がいの条件に当てはまる場合、知的障がい、または精神障がいのある場合が案内されています。詳しい状態・外出目的は市へ確認してください。
ひとこと
社会生活に必要な外出や余暇活動などの社会参加を支える長岡市の個別移動支援です。市の対象、相談先、利用者負担、事業所一覧への入口が公開されています。事業所一覧ページは2026年9月1日更新ですが、移動支援を含む地域生活支援事業一覧自体は2025年5月1日基準です。
利用の条件
長岡市福祉課、各支所、または委託相談支援事業所へ相談します。地域生活支援事業の支給決定では障害支援区分の認定は不要と案内されています。市の登録事業所が行う、原則1日で終わる外出の支援です。
利用までの流れ
長岡市福祉課・各支所・相談支援事業所へ相談 → 地域生活支援事業を申請 → 市の支給決定を確認 → 市の事業所一覧から候補を選ぶ → 外出目的・地域・日時・実費・介助を確認 → 契約・利用調整。
医療的ケアについて
市の制度ページでは、医療的ケア一般、吸引、経管栄養、人工呼吸器に対応する移動支援事業所を確認できませんでした。必要な処置は市と候補事業所へ一つずつ確認してください。
利用できる時間
市の案内では事業所ごとの曜日・時間を確認できません。市の支給量と、事業所の提供時間・希望日の担当可否を分けて確認してください。
地域・送迎
長岡市へ申請する制度です。市が現在案内する2025年5月1日基準の移動支援登録事業所一覧には30件が掲載され、主な対象に児童欄があります。30件は現在の空きやお子様を担当できる件数ではありません。候補ごとに児童欄、出発地・行き先・市外外出・訪問範囲を確認してください。
料金
原則1割負担で、所得に応じた月額上限があります。市の案内では、お子様の一般1は月4,600円、一般2は月37,200円、低所得・生活保護世帯は0円です。交通費や入場料などの実費は事業所へ確認してください。
