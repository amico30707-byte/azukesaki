重症児デイサービス あすなろくれよん

空きや受け入れは、かならず施設にご確認ください

利用を考えるときは

公式ページを見る長岡市こども家庭センター｜障害児通所支援事業所ガイドブック（2024年12月発行）

電話0258-89-7969

確認日：2026年11月17日（あずけさき手帖が公式の情報を確かめた日）

施設のこと

地域
長岡市曙
サービスの種類
通う療育
対象年齢
重症児のためのデイサービスです。児童発達支援は小学校に入る前のお子様、放課後等デイサービスは小学生〜高校生です。くわしい年齢の範囲は要確認です。
ひとこと
長岡市の重症児デイサービスです。市のガイドブックに、看護師が常駐していて、経鼻チューブや胃ろうの経管栄養、吸引に対応すると書かれています。
空き・受付について
2026年11月17日に長岡市のガイドブック（2024年12月）、長岡市の一覧（2024年4月）、県の「ふれあい」資料編（令和8年度版）を確認しました。事業所の公式ページは見ていません。電話での確認はしていません。いまの時間、電話番号、いまの空き、ほかの処置は未確認です。
利用の条件
通所受給者証と障害児支援利用計画が必要です。医療的ケアの内容と受け入れができるかを、かならず事業所に確認してください。
利用までの流れ
長岡市こども家庭センター（こども発達相談室）に相談 → 相談支援事業所で利用計画の作成 → 受給者証の交付 → 事業所と契約 → 利用開始。
医療的ケア
あり
医療的ケアについて
長岡市のガイドブックに「看護師が常駐しておりますので、経鼻チューブや胃ろうの経管栄養、吸引はお任せ下さい」と書かれています。人工呼吸器など、ほかの処置への対応は書かれていないため、要確認です。
利用できる時間
資料によって書き方がちがいます。長岡市のガイドブック（2024年12月）では、児童発達支援は平日・長期休み10時〜15時、放課後等デイサービスは平日14時〜18時、長期休み10時〜18時です。長岡市の一覧（2024年4月）では、放課後等デイサービスは平日14時〜18時、土・日曜日、祝日、長期休み10時〜17時です。いまの営業日と時間は事業所へ確認してください。定員は5名（ほかの事業と合わせて）です。
地域・送迎
事業所は長岡市曙にあります。送迎はありますが、冬（12月〜3月）は場所によって相談と書かれています。利用できる地域は要確認です。
料金
受給者証にもとづく利用者負担のほか、おやつ代などで100円と書かれています。くわしくは事業所へ確認してください。
