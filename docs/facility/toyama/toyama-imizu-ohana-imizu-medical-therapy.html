重症児デイサービス おはな いみず

お知らせ公式ページに、おはないみずの移転リニューアルは工事を延期し、時期が決まり次第知らせるとの案内があります。場所・開所日は事前に確認してください

空きや受け入れは、かならず施設にご確認ください

利用を考えるときは

公式ページを見る株式会社ラ・ファミーユ｜おはな・おはないみず 放課後等デイサービス

電話0766-54-0817

確認日：2026年11月13日（あずけさき手帖が公式の情報を確かめた日）

施設のこと

地域
射水市
サービスの種類
通う療育
対象年齢
放課後等デイサービスで、小学1年生〜高校3年生が対象です。重症心身障害と認定されているお子様、超重症児・準超重症児（医師の意見書が必要）、医療的ケア児・病弱児が対象と公式ページに書かれています。
ひとこと
株式会社ラ・ファミーユが運営する、射水市の重症児向け放課後等デイサービスです。高岡市の「おはな」と同じ法人で、小児看護の経験のある看護師が医療的ケアを行うと案内しています。
空き・受付について
2026年11月13日に事業所の公式ページを確認しました。電話確認はしていません。移転リニューアルの延期の案内があり、現在の場所・開所日・時間はおはなと分けて書かれていないため要確認です。空き、定員、料金の金額は未確認です。
利用の条件
障害児通所受給者証が必要です（重症心身障害の判定の手続きを含む）。相談支援専門員への相談、事業所での面談、契約を経て利用開始です。
利用までの流れ
必要に応じて見学 → 重症心身障害の判定・障害児通所受給者証の手続き → 相談支援専門員へ相談 → 事業所で面談 → 契約・初回利用日の決定 → 利用開始。
医療的ケア
あり
医療的ケアについて
医師の指示書と保護者の依頼・同意にもとづき、所属看護師（すべて小児看護の経験あり）が、吸引（口腔・鼻腔・気管カニューレ内）、経管栄養（胃ろう・腸ろう・経鼻）、吸入、導尿・浣腸、発作時の対応を行うと公式ページに書かれています（おはなと共通のページ）。持ち物の案内に「呼吸器」「カフアシスト」があり、呼吸器と吸引チューブは事業所で準備しているとも書かれていますが、医療的ケアの項目に人工呼吸器の管理はないため、人工呼吸器を使うお子様は要確認です。酸素の記載はありません。現在の人員と個別の受け入れも要確認です。
利用できる時間
公式ページの放課後等デイサービスの時間は、平日14時〜17時、隔週の土曜日と学校休業日9時30分〜16時30分です。おはな（高岡）と共通の記載のため、おはないみずの時間・開所日は要確認です。
地域・送迎
公式ページの送迎範囲は高岡市・射水市・氷見市（その他は相談）ですが、おはなと共通の記載のため、おはないみずの送迎範囲は要確認です。
料金
利用料の1割が自己負担で、利用時間と世帯の所得に応じた月の上限があります。送迎は送迎加算として請求されます。金額は事業所・市町村へ確認してください。
