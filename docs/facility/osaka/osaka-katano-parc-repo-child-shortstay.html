ひとこと
PARCウィル（児童発達支援・放課後等デイサービス）に通うお子様だけが使える、1泊2日の短期入所（ショートステイ）です。看護師や保育士などがいつもいると書かれています。福祉型か医療型かは書かれていないため要確認です。
空き・受付について
空きは未確認・施設へお問い合わせください。PARCウィルに通うことが前提です。対象年齢、費用、福祉型か医療型か、処置ごとの受け入れ、電話での確認は未確認です。
利用の条件
PARCウィルを利用していることが前提です。肢体不自由のお子様や、医療的ケアが必要なお子様が対象と書かれています。受給者証などの手続きは要確認です。
利用までの流れ
PARCウィルを利用する → スタッフと個別相談（プランの提案） → 申し込み → くわしいアセスメント → 利用開始。見学はいつでも受け付けています（お泊まり体験はありません）。
医療的ケア
あり
医療的ケアについて
看護師などがいつもいて、医療的ケアが必要なお子様にも対応していると書かれています（ふしみ・かたの共通のページ）。吸引機・在宅酸素などはご家族が持っていきます。処置ごとの受け入れと、福祉型・医療型のどちらかは書かれていないため、ご確認ください。
利用できる時間
利用は1泊2日です。受け付けの時間や曜日は要確認です。
地域・送迎
施設は交野市にあります。対象地域は要確認です。
料金
料金は短期入所のページに書かれていないため要確認です。食事・おやつは用意がないため持参です。
