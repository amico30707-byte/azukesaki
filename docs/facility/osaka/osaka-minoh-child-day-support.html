箕面市 お子様の日中一時支援

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
箕面市
サービスの種類
日中のあずかり
対象年齢
障がいがあり、日中に一時的な見守りが必要な方が対象です。市の負担上限案内では18歳未満を障害児として区分しています。お子様ごとの対象、手帳等の要件、登録事業所ごとの年齢・障害種別は市と事業所へ確認してください。
ひとこと
障がいのあるお子様等の日中の活動場所を確保する、宿泊しない箕面市の地域生活支援事業です。市の利用決定と、登録事業所への直接申込の両方が必要です。
利用の条件
マイナンバーを確認できる書類と本人確認書類を持って総合保健福祉センター総合相談窓口で申請します。後日、市から利用決定通知書または却下通知書が届きます。利用時は決定通知書を登録事業所へ提示し、直接申し込みます。
利用までの流れ
箕面市障害福祉課へ相談 → 対象・必要書類・現在の登録事業所を確認 → 総合相談窓口で申請 → 市の利用決定通知書を受け取る → 登録事業所へ通知書を提示して直接申込 → 現在の受付・空き・希望日時・送迎・実費・支援内容を確認 → 利用。
医療的ケアについて
市の制度・登録事業所一覧から、重症心身障害、重度知的障害、強度行動障害、全面介助、吸引、経管栄養、人工呼吸器、看護師配置等の個別対応は確認できませんでした。登録されていることから個別ケアを推測していません。
利用できる時間
費用区分は4時間未満、8時間未満、12時間未満です。これは登録事業所の営業時間、希望日の空き、利用できる上限時間を示すものではありません。曜日・時間は事業所へ確認してください。
地域・送迎
箕面市の制度です。地域生活支援事業は、2026年9月1日現在の市登録事業所一覧に載る事業所だけ利用できます。支援場所、市外事業所の利用、送迎範囲は事業所ごとに確認してください。
料金
1回の利用料は4時間未満200円、8時間未満400円、12時間未満600円です。月額上限は生活保護・市町村民税非課税世帯0円、課税世帯4,000円です。複数事業所で上限を超えて支払った場合は、市から超過分の返還案内があります。食事・送迎等の実費は別に確認してください。
住所
申請・相談窓口：大阪府箕面市萱野5丁目8番1号 総合保健福祉センター 障害福祉課（支援場所ではありません）
電話
072-727-9514箕面市 総合保健福祉センター障害福祉課。対象、申請、利用決定、現在利用できる登録事業所を確認してください。事業所一覧ページの代表窓口は072-727-9506です。
確認日
2026年10月11日
