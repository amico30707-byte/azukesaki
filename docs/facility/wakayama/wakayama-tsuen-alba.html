児童発達支援センター 通園あるば

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
和歌山市
サービスの種類
通う療育
対象年齢
身体・知的・精神（発達）に障害がある、6歳までの未就学のお子様が対象です。
ひとこと
和歌山市内の未就学のお子様が通い、生活動作、遊び、集団生活への適応を支える児童発達支援センターです。毎日通所と園などとの併行通所があり、2026年8月12日に和歌山市から地域の中核的な役割を担う児童発達支援センターに選ばれたと案内しています。
利用の条件
見学後に和歌山市障害者支援課へ申請し、受給者証を取得して施設と契約します。手帳がない場合は、利用に関する医師の意見書が必要と案内されています。
利用までの流れ
保健センターまたは通園あるばへ相談 → 見学 → 和歌山市障害者支援課へ利用申請 → 受給者証を取得 → 通園あるばと契約 → 通園開始。
医療的ケアについて
2026年4月1日時点で非常勤の准看護師1名を確認しました。歩けないお子様について、集団生活が可能と医師が判断した場合は状態を見て受け入れを検討するとの説明がありますが、これは医療的ケア実施の案内ではありません。吸引・経管栄養・人工呼吸器の受け入れは未確認です。
利用できる時間
利用時間は9時30分〜15時30分です。ご利用案内は月〜金曜と土曜午前に開所する場合があると案内する一方、施設概要は土日祝、春・夏・年末年始などを休みと案内しています。実際の開所日は利用前に確認してください。
地域・送迎
支援地域は和歌山市内全域です。送迎が必要なお子様は集合場所までの送迎を相談できます。自宅への個別送迎とは限りません。
料金
保育料は和歌山市が定めた額で、満3歳から自己負担が免除されます。給食費は世帯区分により1日250円・350円・450円、日用品・教材費等は実費です。
