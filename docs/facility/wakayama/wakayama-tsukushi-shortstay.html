つくし医療・福祉センター

お知らせ合計定員は12名ですが、主案内は第1棟6・第2棟2・第3棟4、2024年4月1日からの変更告知は第1棟8・第2棟0・第3棟4と内訳が異なります。予約時期も主案内の2か月前と予約画面の約3か月先で表記が異なるため、現在の棟・予約締切を確認してください

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
岩出市
サービスの種類
日中のあずかりお泊まり（短期入所）
対象年齢
在宅の重症心身障害のお子様・成人が対象です。年齢だけで利用できるとは決まらず、診察・受入判定・体験があります。
ひとこと
宿泊する短期入所と、日帰りの日中一時支援を提供しています。利用定員は合計12名です。利用前に紹介状、診察、判定、体験が必要です。療育棟別の内訳は公式ページ内で異なるため、利用する棟は確認が必要です。
利用の条件
市町村の支給決定と事前登録が必要です。診療情報提供書と調査書を提出し、診察・月1回の受入準備委員会・1〜2回ほどの体験を経て登録します。疾病による入退院後は、次の利用までに診療情報提供書の再提出が必要です。手続きを進めても利用が保証されるわけではありません。
利用までの流れ
地域連携室へ相談 → 主治医の紹介状と調査・確認用の書類を提出 → センターの医師の診察 → 受入判定 → 1〜2回ほど体験 → 登録 → 予約画面または担当者へ希望日を申し込む → 決定通知を確認。入退院後は診療情報提供書を再提出します。
医療的ケア
あり
医療的ケアについて
医療的ケアが必要な方は医師用の判断スコア提出が必要です。疾病による入退院後は診療情報提供書の再提出が必要です。吸引・経管栄養・人工呼吸器の個別対応は未確認です。
利用できる時間
主案内は原則2か月前から予約と記載する一方、登録後の予約画面は約3か月先まで、前月10日までの予約、前月14〜17日頃の決定通知を案内しています。2026年10月24日のつくし祭り当日と前後は入退所に制限・影響があり、短期入所は2026年12月30日〜2027年1月3日休所です。日中一時支援の年末年始対応、通常の入退所時刻は要確認です。
地域・送迎
施設は岩出市にあります。利用できる市町村の範囲は公式ページで確認できていません。
料金
市町村が定める利用者負担額に加え、食事代（朝250円・昼400円・夕400円）、洗濯代1日200円などの実費があります。おむつは基本的に持参です。
