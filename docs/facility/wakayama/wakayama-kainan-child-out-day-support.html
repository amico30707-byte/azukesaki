海南市 お子様の移動支援・日中一時支援

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
海南市
サービスの種類
外出の付きそい日中のあずかり
対象年齢
海南市の地域生活支援給付の対象には障害児と保護者が含まれます。移動支援・日中一時支援を利用できる年齢、障害の状態、必要な支援は事業ごとに市へ確認してください。
ひとこと
海南市が地域生活支援事業として行う、外出を支える移動支援と、宿泊せず日中に一時的な活動場所・見守りを提供する日中一時支援です。市の制度と、現在利用できる事業所の受け入れを分けて確認します。
利用の条件
障害のあるお子様の保護者が市へ申請し、市が支給の要否とサービス量を決めます。決定後は地域生活支援サービス受給者証が交付されます。申請書のほか、負担上限の確認書類等が必要になる場合があります。
利用までの流れ
海南市社会福祉課へ相談 → お子様が移動支援・日中一時支援の対象になるか、必要書類と負担を確認 → 保護者が申請 → 市の審査・支給決定、支給量、受給者証を確認 → 現在の実施事業所へ受付・空き、希望日時、地域・実費・必要な支援を相談 → 契約・利用。
医療的ケアについて
市の制度から、医療的ケア一般、重症心身障害、重度知的障害、強度行動障害、全面介助、吸引、経管栄養、人工呼吸器等への個別対応を推測していません。
利用できる時間
市の規則から、現在の実施事業所、営業日・時間、利用上限、希望日の利用枠は確認できませんでした。
地域・送迎
海南市に住む方が原則対象です。現在の実施事業所、事業所所在地、外出範囲、市外利用、送迎範囲は公式ページだけでは確認できませんでした。
料金
18歳未満は世帯全員の所得により自己負担が必要となる場合があります。具体的な利用者負担、食事・交通・送迎等の実費は、市と事業所へ確認してください。
住所
申請・相談窓口：和歌山県海南市南赤坂11番地 海南市社会福祉課 障害福祉班（支援場所ではありません）
