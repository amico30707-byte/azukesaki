上田市 タイムケア（障がい児者の一時預かり・見守り）

お知らせ申請は随時受け付け、年間300時間が上限ですが、現在の登録介護者や希望日時の受け入れを示すものではありません

空きや受け入れは、かならず施設にご確認ください

利用を考えるときは

公式ページを見る上田市｜障がい児者の一時預かり、一時見守りサービス（タイムケア）

電話0268-23-5158

確認日：2026年10月20日（あずけさき手帖が公式の情報を確かめた日）

施設のこと

地域
上田市
サービスの種類
日中のあずかり
対象年齢
常時介護を必要とする在宅の身体・知的・精神障がい者で、お子様を含みます。個別の登録条件は市へ確認してください。
ひとこと
ご家族が一時的に介護できないとき等に、登録介護者がご自宅または登録介護者宅等で時間単位の介護を行う上田市のタイムケアです。
空き・受付について
対象、利用場所、年間上限、申請書、窓口、負担と実費を確認しました。現在の登録介護者、新規登録、希望日時、電話でのお子様ごとの受け入れ、個別ケアは未確認です。
利用の条件
利用登録証交付申請書、利用者状況表、利用計画書を、市役所障がい者支援課または各地域自治センターへ提出します。申請は随時受け付けています。
利用までの流れ
上田市の窓口へ申請書・利用者状況表・利用計画書を提出 → 利用登録の内容を確認 → 登録介護者と場所・日時・介助・実費を調整 → 利用。
医療的ケアについて
市の制度ページでは、登録介護者による医療的ケア一般、吸引、経管栄養、人工呼吸器、全面介助を確認できませんでした。必要なケアは申請時と登録介護者との調整時に確認してください。
利用できる時間
時間単位で利用し、1人年間300時間が上限です。希望日時に対応できる登録介護者は要確認です。
地域・送迎
上田市の制度です。実際に使える場所は利用者の自宅または登録介護者宅等で、登録介護者との調整が必要です。
料金
介護サービスの利用者負担はありません。飲食物費その他の実費は利用者負担で、登録介護者へ直接支払います。
住所
利用者の自宅、または登録介護者の自宅等
電話
0268-23-5158上田市障がい者支援課。お子様の年齢、必要な介助、利用場所、希望日時を伝えてください。
確認日
2026年10月20日

サービスごとのこと

タイムケア
常時介護が必要な在宅の障がい児者へ、利用者宅または登録介護者宅等で時間単位の介護を提供します。1人年間300時間が上限です。申請は随時受け付けていますが、現在の登録介護者や希望日時の受け入れは別に確認します。
