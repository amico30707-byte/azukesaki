飯山市 日中一時支援・タイムケア

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
飯山市
サービスの種類
日中のあずかり
対象年齢
飯山市に住む障がいのあるお子様が対象です。日中一時支援は障がい児、発達障がい児、難病患者等を含み、タイムケアは重症心身障がい児、知的障がい児、身体障がい児、発達障がい児等を対象に含みます。
ひとこと
放課後や休日に事業所等で過ごす日中一時支援と、障害福祉サービスを補うタイムケアを分けて案内する飯山市の制度です。
利用の条件
日中一時支援は地域生活支援事業サービス利用証交付申請書、障害者手帳等を市へ提出します。タイムケアは利用登録証交付申請書、障害者手帳等が必要です。希望する制度名を市へ伝えます。
利用までの流れ
飯山市保健福祉課へ相談 → 日中一時支援またはタイムケアの申請書と手帳等を提出 → 利用証・登録証、上限時間、利用できる登録先を確認 → 希望日、場所、介助、実費を調整。
医療的ケアについて
市の制度ページでは、医療的ケア一般、吸引、経管栄養、人工呼吸器、全面介助の対応を確認できませんでした。利用する登録先へ項目ごとに確認してください。
