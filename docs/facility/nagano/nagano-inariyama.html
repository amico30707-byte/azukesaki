施設のこと

地域

サービスの種類
通う療育日中のあずかりお泊まり（短期入所）
対象年齢
児童発達支援センターたんぽぽは未就学から高校生まで。短期入所・日中のお預かりは肢体不自由児者・重症心身障害児者が対象です。
ひとこと
医療的ケアを含む療育と、肢体不自由・重症心身障害のあるお子様の宿泊する短期入所、日中のお預かりを行っています。
空き・受付について
たんぽぽの定員30人は現在の空きではありません。2026年4月21日の短期入所受付案内は事業の受付継続を示す案内ですが、希望日の空きやお子様ごとの受け入れを示すものではありません。短期入所は空床利用で、事前登録済みでも希望日の利用が確定するわけではありません。電話確認はしていません。
利用の条件
たんぽぽは定員30人で、見学後に専門小児科の診察と面談を行い、通所可否を検討します。短期入所等は事前登録が必要で、診察・多職種面談・支援会議を経て受給者証と契約が必要です。2026年4月21日の案内でも、初めての方は登録、登録済みの方は利用日相談と案内しています。日程確定後でも感染予防で利用できない場合があります。
利用までの流れ
医療相談室へ相談・見学 → 診察・面談 → 相談支援専門員による支援会議 → 市町村の受給決定 → センターと契約・登録 → 短期入所申込書で希望日を相談。
医療的ケア
あり
医療的ケアについて
たんぽぽは看護師・医師による医療的ケアを行うと公式ページにあります。吸引・経管栄養・人工呼吸器の個別項目と、短期入所・日中預かりでの医療的ケアは未確認です。
利用できる時間
短期入所等は宿泊を伴う利用と日帰り利用の両方を案内しています。曜日・利用時間は要確認です。空床利用で、希望日を申込書で提出します。
地域・送迎
所在地は千曲市。利用できる地域、送迎、日中のお預かりの制度名は要確認です。

サービスごとのこと

児童発達支援センターたんぽぽ
未就学から高校生まで、定員30人。看護師・医師による医療的ケアとリハビリの支援があります。見学後に専門小児科の診察・面談・支援会議が必要です。令和8年度安全計画と令和7年度自己評価等が掲載されていますが、定員や現在年度の資料は現在の空きではありません。
出典：inariyama-iryo.jp
確認日：2026年10月16日
短期入所・日中のお預かり
肢体不自由児者・重症心身障害児者を空床で受け入れ、宿泊を伴う場合と日帰りの場合の両方に対応すると案内しています。2026年4月21日の案内でも、短期入所は初回登録後に希望日を相談します。診察、面談、支援会議、受給決定、契約の後に申込書で希望日を相談します。日中のお預かりの制度名は要確認です。
出典：inariyama-iryo.jp
確認日：2026年10月16日
