八代市 日中短期入所・障がい児タイムケア

空きや受け入れは、かならず施設にご確認ください

利用を考えるときは

電話0965-33-5110

確認日：2026年10月11日（あずけさき手帖が公式の情報を確かめた日）

施設のこと

地域
八代市
サービスの種類
日中のあずかり
対象年齢
日中短期入所は、在宅で介護を受けることが難しい障がい者手帳を持つお子様・成人が対象です。障がい児タイムケアは、障がい者手帳を持つ小学1年生から高校3年生までのお子様が対象です。
ひとこと
宿泊を伴わず日中に活動の場を提供する日中短期入所と、放課後・土日・長期休暇中のお子様を支える障がい児タイムケアを分けて案内する八代市の制度です。
空き・受付について
2026年4月時点の市公式一覧には12事業所があり、パステール八代は2024年4月10日から休止中です。他の掲載事業所を含め、現在の新規受付・空き・希望日の受け入れは確認していません。送迎は希望制ですが時間・場所により対応できない場合があります。電話でのお子様ごとの利用可否と個別ケアは未確認です。
利用の条件
八代市へ毎年度の利用申請が必要です。利用申請後、審査を経て決定通知書が送られ、希望する事業所へ提示します。市は通常の申請では決定通知書を申請約10日後に送ると案内していますが、1〜3月申請分は3月中旬以降です。
利用までの流れ
八代市障がい者支援課へ日中短期入所か障がい児タイムケアかを相談 → 毎年度の利用申請 → 審査・決定通知書 → 2026年4月時点の一覧から候補を確認 → 希望日、時間、送迎、実費、現在の受付、必要な支援を事業所へ確認 → 決定通知書を提示して利用。
医療的ケアについて
市の制度ページでは、医療的ケア一般、吸引、経管栄養、人工呼吸器、全面介助への対応を確認できませんでした。実施事業所へ項目ごとに確認してください。
利用できる時間
障がい児タイムケアは放課後・土曜日・長期休暇中などに実施され、2026年4月時点の一覧に事業所別の時間が掲載されています。日曜日、希望日の受け入れ、送迎時間・場所は各事業所へ確認してください。
地域・送迎
八代市へ申請する制度です。2026年4月時点のタイムケア一覧には八代市内11事業所と宇城市内1事業所があります。事業所の所在地と実際の送迎・利用可能地域は別に確認してください。
料金
障がい児タイムケアは1日あたり4時間未満215円、4時間以上8時間未満430円、8時間以上537.5円で、障害児支援区分3は加算があります。非課税世帯・生活保護世帯は自己負担なし。食事・おやつ・活動等の実費は事業所ごとに異なります。日中短期入所は原則1割負担で、非課税・生活保護世帯は自己負担なしです。
住所
2026年4月時点の障がい児タイムケア一覧に12事業所（八代市内11・宇城市内1）を掲載。支援場所は各事業所で、パステール八代は2024年4月10日から休止中と記載されています。

サービスごとのこと

日中短期入所
障がい者（児）を宿泊なしで一時的に預かり、活動の場を提供し、ご家族の就労・休息を支えます。日中短期入所の事業所一覧は別PDFで確認します。
出典：city.yatsushiro.lg.jp
確認日：2026年10月11日
障がい児タイムケア
小学1年生〜高校3年生を対象に、放課後・土曜日・長期休暇中の活動場所と預かりを提供します。2026年4月時点で12事業所が掲載され、1事業所は休止中です。掲載は現在の受付・空きを示しません。
出典：city.yatsushiro.lg.jp
確認日：2026年10月11日
