放課後等デイサービス事業所ウイング（日中一時支援）

お知らせ事業所名に『放課後等デイサービス』とありますが、市ガイドで今回確認したのは日中一時支援です。放課後等デイサービスの開所時間・定員・空きを、日中一時支援へ当てはめていません。

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
天草市
サービスの種類
日中のあずかり
対象年齢
天草市の2026年版ガイドで、お子様の日中一時支援事業所として掲載されています。市の区分判定が区分1以上となるお子様が制度の対象です。詳しい年齢・在籍条件は市へ確認してください。
ひとこと
放課後、土日、夏休み等の長期休暇中を含め、お子様の日中の活動場所と見守りを提供する天草市の日中一時支援事業所です。放課後等デイサービスとは申請・利用決定が別の日中一時支援として掲載しています。
利用の条件
天草市福祉課へ日中一時支援を申請し、聞き取り調査・区分判定・利用決定を受けた後、ウイングへ希望日時を相談します。事業所一覧への掲載や送迎ありの表示だけで、利用決定・希望日の送迎・空きは分かりません。
利用までの流れ
天草市福祉課へ日中一時支援を相談 → 利用申請・聞き取り調査・区分判定 → 市の利用決定 → ウイングへ希望日・時間・送迎・必要な介助を相談 → 負担・実費を確認 → 利用。
医療的ケアについて
市ガイドから、医療的ケア、重症心身障害、重度知的障害、強度行動障害、全面介助、吸引、経管栄養、人工呼吸器、看護師配置への対応は確認できません。項目ごとに相談してください。
利用できる時間
市ガイドは放課後・土日・長期休暇中を利用場面として案内しています。ウイングの日中一時支援としての曜日・時間・休業日・希望日の受付は未確認です。
地域・送迎
事業所所在地は天草市北浜町です。市外利用、送迎範囲、出発・到着場所は市と事業所へ確認してください。
料金
市ガイドは原則としてサービス費の1割負担、所得に応じた月額上限、18歳未満の基準額、送迎加算を案内しています。実際の支払額、食事・活動費等の実費は市と事業所へ確認してください。
