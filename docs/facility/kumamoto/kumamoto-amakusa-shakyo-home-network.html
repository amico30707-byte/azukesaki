天草市 訪問系サービス・天草市社協ヘルパー拠点

お知らせ2020年8月18日更新の移動支援ページと、2022年4月1日施行の要綱で費用率が異なります。新しい要綱を基準にしつつ、現在の決定通知書・負担額を市へ確認してください。事業者一覧PDFには基準日の表示がなく、現在の登録・受付も要確認です

空きや受け入れは、かならず施設にご確認ください

利用を考えるときは

公式ページを見る天草市｜障がい福祉サービス（介護給付・訓練給付・障がい児通所支援）

電話0969-32-2552

確認日：2026年10月27日（あずけさき手帖が公式の情報を確かめた日）

施設のこと

地域
天草市（本渡・牛深・御所浦・倉岳・五和・河浦）
サービスの種類
家に来るヘルパー外出の付きそい
対象年齢
天草市の障害福祉案内は障がい児を対象に含み、居宅介護等の訪問系サービスを案内しています。市の移動支援ページも障害のあるお子様を対象に含む条件を示しています。各拠点・事業者の現在のお子様の受付は要確認です。
ひとこと
天草市内の社協ヘルパー拠点と、市の移動支援を確認する入口です。社協の現在ページは居宅介護等を案内し、市の移動支援ページは個別支援と通所・通学支援、9事業者の一覧を公開しています。制度の対象と各事業者の現在の受付は別に確認します。
空き・受付について
天草市の居宅介護等の制度・事業所一覧・社協の現在ページに加え、移動支援ページ、9事業者の公式一覧、2022年4月1日施行の要綱を2026年10月27日に確認しました。古い移動支援ページと新しい要綱で費用率が異なり、一覧に基準日はありません。現在の新規受付・登録、電話でのお子様ごとの利用可否、地域・時間、決定通知書の負担額、希望日時、個別ケアは未確認です。
利用の条件
居宅介護等は天草市・相談支援へ対象と支給決定を相談します。移動支援は、市内住所等の条件に加え、身体障害者手帳1・2級で車いすを常用する方または視覚障害の方、療育手帳を持つ方または同程度の方、精神障害者保健福祉手帳を持つ方、市長が必要と認める方が対象です。個別支援の社会生活上必要な外出は通院・通勤を除きます。事前に事業者へ相談してから市福祉課・各支所へ申請し、決定通知書を受け取ります。重度訪問介護・行動援護等が優先される場合や、お子様の外出目的・通所通学の条件も確認してください。
利用までの流れ
居宅介護等：天草市・相談支援へ相談 → 支給内容を確認 → 社協拠点へ現在の受付等を相談。移動支援：事業者へ事前相談 → 市福祉課・各支所へ申請 → 決定通知書を事業者へ提示 → 利用日時・地域・費用を調整。
医療的ケアについて
居宅介護・重度訪問介護の表示から、医療的ケア一般、重症心身障害、全面介助、吸引、経管栄養、人工呼吸器への個別対応を推測していません。必要なケアは方法・回数・時間帯を伝えて確認してください。
利用できる時間
お子様の障害福祉サービスについて、拠点ごとの受付時間・提供時間・希望日時の担当可否は現在の公式ページで確認できませんでした。
地域・送迎
社協の現在ページは本渡・牛深・御所浦・倉岳・五和・河浦の居宅訪問拠点を案内しています。市の移動支援事業者一覧は市内外の9事業者を載せていますが、住所と実際の訪問・送迎地域は同じとは限りません。
料金
居宅介護等の負担・月額上限と実費は市と事業所へ確認してください。移動支援は、2022年4月1日施行の要綱では基準額の1割負担で、非課税・生活保護世帯は無料です。月額上限は、市民税所得割16万円未満が9,300円、18歳未満で28万円未満が4,600円です。個別支援の基準額は外出目的等で1時間1,970円または1,300円、通所・通学支援はお子様の車両利用・距離等で1回650円・1,000円です。これらの基準額は、そのまま支払う額ではありません。一方、2020年8月18日更新の市ページには個別支援3％または8％、通所・通学10％との古い案内が残るため、現在の決定通知書と負担額を市へ確認してください。
住所
天草市社会福祉協議会本所：熊本県天草市五和町御領2943（利用するヘルパー拠点は別住所）
電話
0969-32-2552天草市社会福祉協議会本所。お住まいの地域と、お子様の障害福祉の訪問支援を希望すると伝えてください。
確認日
2026年10月27日
