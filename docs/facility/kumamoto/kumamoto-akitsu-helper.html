秋津ヘルパー事業所

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
熊本市東区
サービスの種類
家に来るヘルパー
対象年齢
居宅介護は身体障害・知的障害のあるお子様を対象に含みます。重度訪問介護は身体障害のあるお子様を対象に含みますが、支給決定と個別条件の確認が必要です。
ひとこと
お子様のいるご家庭へヘルパーが訪問し、入浴・排せつ・食事・着替えなどの身体介護や、掃除・調理などの家事援助、通院等の介助を行います。公式ページにはヘルパー約50名とありますが、現在の空きや希望時間の担当確保を示すものではありません。
利用の条件
熊本市の障害福祉サービスの支給決定を受け、事業所と契約して利用します。希望の曜日・時間に職員を配置できない場合があります。
利用までの流れ
熊本市の障がい福祉窓口へ相談 → 支給決定・受給者証 → 事業所へ相談 → 契約と居宅介護計画 → 曜日・時間・支援内容を調整。
医療的ケア
なし
医療的ケアについて
重要事項説明書に、事業所の従業者は医療行為を行わないと明記されています。吸引・経管栄養・人工呼吸器などをヘルパーへ依頼できるとは扱っていません。
利用できる時間
窓口は月〜金曜8時30分〜17時15分。サービス提供は7〜22時。土日祝日と12月29日〜1月3日の窓口は電話転送で対応する案内です。
地域・送迎
通常の実施地域は熊本市東区の秋津・若葉・健軍・東町・桜木・尾ノ上・山ノ内・月出・長嶺・西原・託麻地域などと、中央区の砂取・帯山・帯山西・託麻原。地域外は交通費を含め事前確認が必要です。
料金
原則は法定の自己負担で、所得に応じた月額上限や熊本市の軽減があります。通常地域外の交通費は自動車1kmあたり14円または公共交通の実費、当日キャンセルは600円と案内されています。現在の適用は受給者証と契約書で確認してください。
