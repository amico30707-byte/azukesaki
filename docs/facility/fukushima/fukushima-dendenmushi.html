居宅介護事業所でんでん虫

お知らせ市の居宅介護等一覧の基準日は2025年9月1日です。2026年10月20日のページ確認日と混ぜず、現在の指定・受け入れは市と事業所へ確認してください

空きや受け入れは、かならず施設にご確認ください

利用を考えるときは

公式ページを見る相馬市｜障がい福祉の手引き（2026年4月版）

電話0244-26-7515

確認日：2026年10月20日（あずけさき手帖が公式の情報を確かめた日）

施設のこと

地域
相馬市
サービスの種類
家に来るヘルパー外出の付きそい
対象年齢
相馬市の2026年4月版の手引きは、障がいのあるお子様を障害福祉サービスの対象に含め、居宅介護を案内しています。移動支援も障害のあるお子様が対象です。事業ごとの詳しい年齢と現在の受け入れは要確認です。
ひとこと
相馬市の現在の事業所一覧で居宅介護の指定を確認でき、市の移動支援実施事業所にも掲載されています。家での入浴・排せつ・食事などの介助と、屋外での移動を支える外出支援は別の制度として確認します。
空き・受付について
居宅介護と移動支援の掲載は確認しましたが、現在の空き、新規受付、事業ごとのお子様の受け入れ、訪問・外出地域、曜日・時間、個別ケア、電話確認は未確認です。
利用の条件
居宅介護は市の支給決定と受給者証の交付後、事業所と契約します。市の一覧には重度訪問介護も掲載されていますが、お子様へ同じ条件を当てはめていません。移動支援では、通勤、宿泊を伴う移動、片道100kmを超える移動は対象外です。同じ事業所は重度身体障がい者訪問入浴の実施先にも掲載されていますが、市ページは対象年齢を明記していないため、お子様向けの検索条件には加えていません。
利用までの流れ
相馬市社会福祉課障がい福祉係へ相談・申請 → 市の調査・支給決定 → 受給者証の交付 → でんでん虫へ希望する居宅介護または外出内容、曜日・時間、費用を相談 → 契約・利用。市窓口は0244-37-2109です。
利用できる時間
曜日・利用時間は未確認です。
地域・送迎
相馬市の居宅介護・移動支援の案内に掲載されています。事業所が実際に訪問・外出支援できる地域、市外からの利用は要確認です。
料金
居宅介護などの障害福祉サービスは原則1割負担で、所得に応じた月額上限があります。移動支援の1回あたりの料金は身体介護あり／なしで分かれ、30分未満230円／80円、30分以上1時間未満400円／150円、1時間以上1時間30分未満580円／225円です。1時間30分以上は30分ごとに82円が加わります。お子様の実際の負担と実費は市へ確認してください。
住所
相馬市中野字北反町85

サービスごとのこと

居宅介護（障害福祉サービス）
市の2026年4月版ガイドは、障がいのあるお子様を対象に含む居宅介護を案内し、2025年9月1日現在の一覧は、でんでん虫を居宅介護事業所として掲載しています。ガイドの版、一覧の基準日、ページを読んだ日を分けています。現在のお子様の受け入れ、訪問地域、曜日・時間は要確認です。
出典：city.soma.fukushima.jp
確認日：2026年10月20日
移動支援（地域生活支援事業）
障害のあるお子様を含む外出支援です。居宅介護とは別に、市へ外出の目的と対象を確認します。
出典：city.soma.fukushima.jp
確認日：2026年10月20日
重度身体障がい者訪問入浴（お子様対象は未確認）
市は身体障害者手帳1級・2級の方を対象とし、でんでん虫を実施先に掲載しています。対象年齢の記載がないため、お子様へそのまま当てはめず、検索対象にも加えていません。利用を考える場合は市へ年齢、診断書等の必要書類、1回あたりの負担を確認してください。
出典：city.soma.fukushima.jp
確認日：2026年10月20日
