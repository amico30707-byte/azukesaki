対象年齢
いわき市の移動支援・日中一時支援は、障害のあるお子様を対象に含みます。手帳・状態等の詳しい対象は市へ確認してください。
ひとこと
社会参加等の外出を支える移動支援と、ご家族の就労・休息等のために日中に活動・見守りの場を提供する日中一時支援です。市は2026年4月1日時点の事業所一覧を公開しています。
空き・受付について
市の一覧は2026年4月1日時点の事業所候補で、現在の空き一覧ではありません。新規受付、電話でのお子様ごとの受け入れ、事業所別の地域・曜日・時間・送迎・実費・個別ケアは未確認です。
利用の条件
お住まいの地区の保健福祉センターへ申請します。移動支援・訪問入浴・日中一時支援は、市の地域生活支援事業利用申請書を使います。市の利用決定後、一覧から事業所へ年齢・地域・支援内容・日時を相談します。一覧掲載は現在の空きや個別の受け入れを保証しません。
利用までの流れ
地区保健福祉センターへ相談 → 地域生活支援事業利用申請書で移動支援・日中一時支援を申請 → 利用決定 → 2026年4月1日時点一覧から候補を選ぶ → 事業所へ対象・地域・日時・実費・個別ケアを確認 → 契約・利用調整。
医療的ケアについて
市の制度ページと一覧だけでは、事業所ごとの医療的ケア一般、吸引、経管栄養、人工呼吸器への対応を確認できません。個別に確認してください。
利用できる時間
各事業所の曜日・時間、希望日の利用可否は一覧だけでは分かりません。日中一時支援は宿泊を伴わない日中の支援です。
地域・送迎
いわき市の制度です。各事業所の送迎・外出地域、市内の地区ごとの対応、市外に住むお子様の利用は未確認です。
料金
移動支援・日中一時支援は、原則として所定額の1割を市へ手数料として納めます。課税状況・収入・ほかのサービス利用に応じた負担上限があり、運賃や材料費などの実費が別に必要な場合があります。移動支援の単価基準は2025年10月1日に改定されています。
