白河市 子育て短期支援（白河学園）

お知らせ一般の子育て短期支援です。障害福祉サービスの短期入所とは別です

空きや受け入れは、かならず施設にご確認ください

利用を考えるときは

公式ページを見る白河市｜子育て短期支援事業（ショートステイ、2026年9月8日更新）

電話0248-28-5521

確認日：2026年10月30日（あずけさき手帖が公式の情報を確かめた日）

施設のこと

地域
白河市
サービスの種類
お泊まり（短期入所）
対象年齢
白河市に住民登録がある、原則2歳以上18歳未満のお子様が対象です。障害の有無を条件にした制度ではありません。
ひとこと
お父様・お母様の病気、仕事、心身や生活環境上の理由などで、ご家庭での養育が一時的に難しいとき、児童養護施設でお子様を一時的に養育・保護する一般の子育て短期支援です。障害福祉の短期入所とは別制度です。
空き・受付について
2026年10月30日に、2026年9月8日更新の白河市公式ページを確認しました。電話確認はしていません。現在の新規受付・空き、希望日の利用、泊数・入退所時刻、食事・持ち物等の実費、障害のあるお子様や医療的ケアのあるお子様の個別受け入れは未確認です。市または白河学園が申請後に受け入れ可能性を確認します。
利用の条件
事前に白河学園を見学して利用登録を行い、原則として利用の1週間前までに白河市こども支援課へ申請します。緊急時は事情が分かった時点で申請します。市が受け入れ可能性を確認し、受け入れ可能な場合は面談と利用決定通知を経て利用します。
利用までの流れ
白河学園を見学して事前登録 → 原則1週間前までに白河市こども支援課へ申請 → 市または白河学園が受け入れ可能性を確認 → 受け入れ可能ならお父様・お母様とお子様が面談 → 市から利用決定通知 → 利用開始。
医療的ケアについて
市の一般の子育て短期支援の案内から、障害のあるお子様や医療的ケアのあるお子様の受け入れ、重症心身障害、重度知的障害、強度行動障害、全面介助、吸引、経管栄養、人工呼吸器等への個別対応を推測していません。見学・申請時に必要な支援を伝えて確認してください。
利用できる時間
宿泊を伴うショートステイですが、利用できる泊数、入退所時刻、延長の上限は公式ページで確認できませんでした。必要な期間と希望日を市へ相談してください。
地域・送迎
白河市に住民登録があるお子様が対象です。実施施設は白河市の白河学園です。市外のお子様の利用は公式ページの対象に含まれていません。
料金
1日あたり、生活保護世帯と市民税非課税のひとり親家庭等は0円、市民税非課税のひとり親家庭等以外は1,000円、その他の世帯は2,750円です。やむを得ず施設送迎を利用する場合は、片道0円・60円・200円の世帯区分別負担があります。学校等への付き添い支援や送迎には加算負担が生じます。
