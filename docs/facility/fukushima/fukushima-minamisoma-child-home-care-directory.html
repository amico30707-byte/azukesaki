ひとこと
ご自宅でホームヘルプを受ける障がい福祉サービスです。南相馬市の公式ページは、2024年10月16日更新ページが居宅介護4事業所、2021年12月20日更新の指定事業所一覧が6事業所で一致していません。
利用の条件
市がサービスの種類と量を決め、利用する方が事業所を選んで契約します。2つの市公式ページは掲載数が違うため、どちらかを現在の契約先一覧と決めず、市へ現在の事業所を確認してください。市の一覧への掲載は、現在の空きや、お子様・必要な介助の受け入れを保証するものではありません。
利用までの流れ
南相馬市 社会福祉課へ相談・申請 → 市がサービスの種類・支給量を決定 → 受給者証等を確認 → 市の一覧にある事業所へ、お子様の年齢、住所、希望日時、必要な介助を伝える → 現在の受け入れを確認して契約・利用。
医療的ケアについて
市の一覧から、吸引、経管栄養、人工呼吸器、全面介助等の個別対応は確認できませんでした。事業所ごとに、必要な支援と時間帯を伝えて相談してください。
利用できる時間
希望日時に担当できるか、曜日・時間、緊急時の対応は事業所ごとに確認してください。
地域・送迎
南相馬市の制度です。2つの市公式ページに掲載された事業所の所在地は市内ですが、訪問できる地域や市外利用は今回読んだ市のページでは確認できませんでした。
料金
原則としてサービス費用の1割。世帯に応じた月額上限があり、市町村民税非課税世帯は無料と案内されています。実費は事業所へ確認してください。
