第二やすらぎの郷 短期入所・日中一時支援

お知らせ短期入所と日中一時支援は別事業です。県一覧の定員欄2も、市の時間別費用も、現在の空きではありません

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
小浜市
サービスの種類
お泊まり（短期入所）日中のあずかり
対象年齢
福井県の2026年7月1日現在の一覧と地域の公式案内で、福祉型障害児入所支援と短期入所を行う施設であることを確認しました。小浜市の日中一時支援は障がい児も対象です。事業別の詳しい年齢は要相談です。
ひとこと
福祉型障害児入所施設に併設する短期入所と、宿泊しない日中一時支援です。市町村の支給決定・受給者証と申請先が異なる場合があるため、使いたい事業名を伝えて確認します。
利用の条件
短期入所はお住まいの市町村へ支給決定・受給者証を相談し、施設へ事前の見学・契約、希望日の申込方法を確認します。小浜市の日中一時支援は市へ利用申請後に支給決定を受け、受給者証を施設へ提示して契約し、利用時に直接申し込みます。
利用までの流れ
短期入所は、お住まいの市町村へ相談 → 支給決定・受給者証 → 施設へ見学・契約・希望日を確認。小浜市の日中一時支援は、市へ申請 → 意向確認・支給決定 → 受給者証を施設へ提示して契約 → 利用時に施設へ直接申込み。
医療的ケアについて
地域の公式案内に医療連携や重度障害への支援がありますが、短期入所での医療的ケア一般、吸引、経管栄養、人工呼吸器、全面介助、強度行動障害への個別対応は確認できませんでした。必要な支援ごとに確認してください。
利用できる時間
相談受付は8時45分〜17時45分です。これは短期入所・日中一時支援の利用時間や入退所時刻ではありません。利用日、泊数、日中の利用時間は事業ごとに施設へ確認してください。
地域・送迎
施設は小浜市にあり、地域の公式案内では福井県全域を対象地域としています。送迎、入退所方法、市町村ごとの手続きは要確認です。
料金
短期入所は障害福祉サービスの基準と実費を確認してください。小浜市の日中一時支援は、時間別費用額と送迎料の原則1割負担で、市民税非課税世帯・生活保護世帯は無料です。実際の区分、上限、食費等は市と施設へ確認してください。
