敦賀医療センター 多機能型通所支援事業所 あさひ

お知らせ送迎はありません。はじめての利用日は保護者の付きそいが必要です

空きや受け入れは、かならず施設にご確認ください

利用を考えるときは

公式ページを見る敦賀医療センター｜重症心身障害児（者）支援について（あさひ）

電話0770-25-1600

確認日：2026年11月13日（あずけさき手帖が公式の情報を確かめた日）

施設のこと

地域
敦賀市
サービスの種類
通う療育日中のあずかり
対象年齢
原則として身体障害者手帳（1種1級・2級）と療育手帳（A1・A2）の両方を持つ方などが対象です。児童発達支援は主に未就学のお子様、放課後等デイサービスは学校に通うお子様、生活介護は18歳以上です。
ひとこと
敦賀医療センターの中にある通所の事業所です。児童発達支援、放課後等デイサービス、日中一時支援、生活介護を行い、医師・看護師が必要な医療的ケアをします。送迎はありません。
空き・受付について
2026年11月13日に病院の公式ページと支援プログラムで、対象、事業別の時間、医療的ケア、送迎なしをあらためて確認しました。電話確認はしていません。空き、希望曜日、費用、処置ごとの対応は要相談です。
利用の条件
受給者証が必要です。はじめて利用する日は保護者の付きそいが必要です。経管栄養のお子様は栄養食を持参します。
利用までの流れ
療育指導室へ問い合わせ → 見学 → 小児科の重心外来（予約制）を受診 → 受給者証の確認 → 初回利用（保護者の付きそい）。
医療的ケア
あり
医療的ケアについて
支援プログラムに「医師、看護師による必要な医療ケアを実施します」とあります。経管栄養のお子様は栄養食の持参が必要です。吸引・人工呼吸器などの個別の対応と、日中一時支援での医療的ケアは要相談です。
利用できる時間
児童発達支援は平日9時30分〜15時30分です。放課後等デイサービスは、病院のページでは平日15時30分〜17時45分（学校休業期間は9時30分〜17時30分）、2024年11月の支援プログラムでは平日の放課後15時30分〜17時30分です。土日・祝日・年末年始は休みです。くわしい時間は要確認です。
地域・送迎
所在地は敦賀市です。送迎はありません。利用できる市町村の範囲は要確認です。
料金
制度による利用者負担と実費は病院へ確認してください。
住所
福井県敦賀市桜ケ丘町33-1（敦賀医療センター内）
電話
0770-25-1600敦賀医療センター（代表）。「療育指導室」へ、あさひの利用相談とお伝えください。
