福岡県こども療育センター新光園

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
糟屋郡新宮町
サービスの種類
日中のあずかりお泊まり（短期入所）通う療育
対象年齢
短期入所・日帰り支援は、おおむね2歳以上18歳未満の障がいのあるお子様が主な対象です。児童発達支援『わくわく』は、新光園で訓練を受け、療育が必要と診断された就学前のお子様が対象です。
ひとこと
重度の障がいがあるお子様の短期入所・日帰り支援に加え、就学前のお子様の集団療育を行う児童発達支援『わくわく』があります。
利用の条件
短期入所・日帰り支援は、市町村の支給決定、受給者証、小児科の予約診察、受け入れ判断、契約が必要です。2026年4月1日更新の県ページは、高度な医療管理が必要な場合に受け入れできないことがあると案内しています。児童発達支援は、指定障害児相談支援事業所で利用計画を作成し、市町村の通所受給者証を受けて新光園と契約します。
利用までの流れ
児童発達支援：市町村へ相談 → 指定障害児相談支援事業所で利用計画 → 通所受給者証 → 新光園と契約。短期入所：市町村へ支給申請 → 小児科を予約受診 → 受け入れ判断 → 契約 → 空き確認 → 原則7日前までに申込書を提出。
医療的ケアについて
服薬管理を含む健康管理の案内がありますが、高度な医療管理が必要な場合は受け入れできないことがあります。吸引・経管栄養・人工呼吸器の処置別対応は未確認です。
