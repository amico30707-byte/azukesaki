対象年齢
飯塚市社会福祉協議会の公式ページは、ホームヘルパーが障がいのあるお子様のご自宅を訪問すると明記しています。詳しい年齢、障がいの状態、支給要件は市と事業所へ確認してください。
ひとこと
飯塚市で、障がいのあるお子様のご自宅へホームヘルパーが訪問し、身体介護や家事援助等を行う居宅介護の事業所です。法人の現在ページで、お子様の訪問対象と所在地・連絡先を確認しました。
空き・受付について
2026年10月31日に飯塚市社会福祉協議会の障がい福祉サービスページと飯塚支所ページを確認しました。電話確認はしていません。現在のお子様の新規受付・空き、訪問地域、提供曜日・時間、詳しい年齢・支給要件、費用、電話でのお子様ごとの利用可否、個別介助・処置は未確認です。
利用の条件
利用前に飯塚市へ申請し、支給決定と受給者証を確認してから事業所と契約・利用調整をします。公式ページは重度訪問介護も併記していますが、お子様の個別該当を確認した情報ではないため、この記録は居宅介護だけを検索対象にしています。
利用までの流れ
飯塚市へ居宅介護を相談・申請 → 支給決定・受給者証・支給量を確認 → 障害者介護サービスステーションへ訪問地域、希望曜日・時間、身体介護・家事援助、必要な介助を相談 → 契約・利用日を調整。
医療的ケアについて
身体介護の掲載だけから、重症心身障害、重度知的障害、強度行動障害、全面介助、吸引、経管栄養、人工呼吸器への対応を推測していません。必要な介助・処置は支給内容と一緒に市と事業所へ確認してください。
利用できる時間
公式ページで、障がいのあるお子様への居宅介護の提供曜日・時間を確認できませんでした。掲載の法人受付時間8時30分〜17時は、ヘルパーの提供時間とは限りません。
地域・送迎
所在地は飯塚市柏の森です。訪問できる地域、市外利用、支所ごとの担当は事業所と市へ確認してください。
料金
障害福祉サービスの利用者負担、世帯所得による月額上限、交通費等の実費を市と事業所へ確認してください。
