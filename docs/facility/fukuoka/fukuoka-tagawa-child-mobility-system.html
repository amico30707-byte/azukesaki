田川市 お子様の移動支援

施設のこと

地域
田川市
サービスの種類
外出の付きそい
対象年齢
田川市の2026年4月1日更新ページは障がい児を対象に含み、全身性・視覚・知的障がいの条件を案内しています。お子様ごとの手帳・身体状況・外出の必要性は市へ確認してください。
ひとこと
田川市で、お子様の社会生活上必要な外出や余暇・社会参加を支えるガイドヘルプサービスの申請入口です。実施事業所そのものや現在の空き一覧ではありません。
空き・受付について
2026年11月1日に田川市の2026年4月1日更新の制度ページと2026年3月6日更新の申請案内を確認しました。電話確認はしていません。現在の実施事業所、新規受付・空き、希望日時、電話でのお子様ごとの利用可否、外出範囲、支給時間、個別介助・処置は未確認です。
利用の条件
市内在住または田川市から支給決定を受け、在宅で暮らす方が対象です。全身性・視覚・知的障がいの要件を市へ確認し、利用申請・市の決定後に事業所と契約します。
利用までの流れ
田川市高齢障がい課 障がい者支援係へ対象・外出目的を相談 → ガイドヘルプサービス利用申請書を提出 → 市の利用決定・支給条件・現在の実施事業所を確認 → 事業所へ希望日時、外出先、必要な介助、実費を相談して契約。
医療的ケアについて
手帳・身体要件、個別支援型の案内から、重症心身障害、重度知的障害、強度行動障害、全面介助、吸引、経管栄養、人工呼吸器への事業所別対応を推測していません。必要な介助・処置は実施事業所へ確認してください。
利用できる時間
制度ページからガイドヘルプの支給時間・事業所の提供曜日・時間は確認できませんでした。希望日時と支給量は市と事業所へ確認してください。
地域・送迎
田川市の制度です。ガイドヘルプの外出範囲、田川市郡外への利用、現在の実施事業所は市と事業所へ確認してください。別の移送サービスは田川市郡内の医療機関等への車両移送で、乗降介助は含まれず、ご家族等の付き添いが必要です。
料金
生活保護・市町村民税非課税世帯は無料、課税世帯はサービス利用料の1割です。ヘルパーの交通費・施設入場料等は利用者負担です。別事業の移送サービスは1回500円で、原則月2回までです。
住所
申請・相談窓口：福岡県田川市中央町1番1号 田川市 高齢障がい課 障がい者支援係（支援場所ではありません）
電話
0947-85-7130田川市 高齢障がい課 障がい者支援係。対象、申請、現在の実施事業所を確認してください。
