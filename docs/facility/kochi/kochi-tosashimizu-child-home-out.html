施設のこと

地域
土佐清水市
サービスの種類
家に来るヘルパー外出の付きそい
対象年齢
土佐清水市は、障害児も居宅介護、行動援護、同行援護、移動支援を利用できると案内しています。お子様ごとの年齢・障害・生活状況を踏まえて市が支給を決め、実際の受け入れは選ぶ事業所へ確認します。
ひとこと
土佐清水市で、お子様の家での介助や外出支援を相談する入口です。居宅介護は自宅での入浴・排せつ・食事など、同行援護・行動援護・移動支援は障害や目的に応じた外出を支えます。これは市の制度案内であり、特定の事業所の空き情報ではありません。
空き・受付について
障害児が利用できる居宅介護・同行援護・行動援護・移動支援、申請書類、原則1割と月額上限、市の負担助成を確認しました。これは市制度の案内です。現在の指定事業所、空き・新規受付、電話でのお子様ごとの受け入れ、訪問地域、曜日・時間、実費、個別ケアは未確認です。
利用の条件
土佐清水市福祉事務所へ申請し、相談支援事業所等が作るサービス等利用計画案を提出して、市の支給決定を受けます。申請書、収入申告書、同意書、手帳または診断書の写しなどが案内されています。事業ごとの詳しい判定条件と必要書類は窓口へ確認してください。
利用までの流れ
土佐清水市福祉事務所へ使いたい場面と事業名を相談 → 申請書などを提出 → サービス等利用計画案 → 市の支給決定・受給者証 → 候補事業所へお子様の年齢・住所・希望日時・介助内容を相談 → 契約・利用。
医療的ケアについて
市の制度案内では、医療的ケア一般、吸引、経管栄養、人工呼吸器、全面介助をどの事業所が担当できるか確認できませんでした。制度上の対象から個別ケアを推測していません。
利用できる時間
市福祉事務所の開庁時間と、ヘルパー事業所のサービス提供時間は別です。希望曜日・時間、ご家族の在宅、通学・通院・余暇などの外出目的、担当者の有無を候補事業所へ確認してください。
地域・送迎
土佐清水市の支給決定を受けるお子様向けの制度案内です。利用する事業所、事業所の所在地・訪問地域、市外事業所の利用可否はこのページでは確認できません。
料金
原則1割負担で、月額上限は生活保護・低所得0円、障害児の一般1は4,600円、一般2は37,200円です。市には利用者負担の助成制度もあります。交通費・入場料などの実費、助成の対象と申請は市と事業所へ確認してください。
