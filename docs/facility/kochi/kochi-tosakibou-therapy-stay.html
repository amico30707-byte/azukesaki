土佐希望の家 医療福祉センター（通所・短期入所）

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
南国市
サービスの種類
通う療育お泊まり（短期入所）
対象年齢
通所事業は、重症心身障害があり通所受給者証をお持ちのお子様を対象に、児童発達支援と放課後等デイサービスを行います。短期入所は、在宅で暮らす重症心身障害児者を対象に含みます。短期入所の詳しい年齢は要確認です。
ひとこと
重症心身障害のあるお子様の児童発達支援・放課後等デイサービスと、宿泊する短期入所を案内しています。通所と宿泊は別の事業として条件を確認します。
利用の条件
通所事業は通所受給者証が必要です。電話相談または相談支援事業所からの相談後、面接・施設見学・医師の外来診察・体験利用・契約を経て利用を始める案内です。短期入所は、身体障害者手帳1・2級と療育手帳Aをあわせてお持ちの方、または障害福祉サービス受給者証に重心・療養介護の医療型短期入所の支給決定がある方を対象に案内しています。利用前に見学、診療情報提供書・サービス等利用計画を持参した外来受診、1〜2回の短時間体験があります。通所事業所全体の定員25名は生活介護も含み、短期入所8床も現在の空きを示しません。
利用までの流れ
通所：施設または相談支援事業所へ相談 → 面接・見学 → 医師の外来診察 → 体験利用 → 契約・個別支援計画 → 利用開始。短期入所：短期入所担当へ相談 → 見学 → 診療情報提供書・サービス等利用計画を持参して外来受診 → 1〜2回の短時間体験 → 希望日ごとに調整。市町村への申請と受給者証の支給決定も先にご確認ください。
医療的ケアについて
施設全体の医療機能と、短期入所前に外来受診があることは確認しましたが、通所・短期入所での吸引・経管栄養・人工呼吸器などの個別対応は未確認です。入所病棟の案内を通所・短期入所へ当てはめていません。
利用できる時間
通所事業の利用曜日・時間、短期入所の入退所時刻・利用日数は未確認です。短期入所は2026年4月から8床と案内されていますが、希望日の空き人数ではありません。
地域・送迎
施設は南国市にあります。通所・短期入所を利用できる市町村、送迎範囲、県外利用の条件は未確認です。
料金
通所・短期入所の利用者負担、食費、実費は未確認です。市町村と施設へご確認ください。
