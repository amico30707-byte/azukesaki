施設のこと

地域
周南市
サービスの種類
外出の付きそい
対象年齢
周南市は、障害者および障害児を対象に含むと明記しています。障がいの状態、年齢、外出目的ごとの詳しい条件は市へ確認してください。
ひとこと
障がいのあるお子様・成人が円滑に外出できるよう支える周南市の移動支援です。申請窓口と8委託事業者の名称・所在地・連絡先が公開されています。
空き・受付について
市のお子様を含む対象・申請窓口・8委託事業者・負担上限は確認しましたが、現在の空き、新規受付、電話でのお子様ごとの受け入れ、事業者別の地域・曜日・時間・実費・個別ケアは未確認です。
利用の条件
障害福祉サービスの対象にならない外出のうち、市が必要と認めたものが対象です。市の利用決定後も、委託事業者へ希望する外出、日時、必要な介助を伝え、担当できるか確認してください。
利用までの流れ
周南市障害者支援課または各総合支所へ相談・申請 → 市の利用決定を確認 → 公開中の委託事業者から候補を選ぶ → 外出目的・地域・日時・費用・介助を確認 → 契約・利用調整。
医療的ケアについて
市の移動支援案内と委託事業者一覧では、医療的ケア一般、吸引、経管栄養、人工呼吸器への対応を確認できませんでした。必要な処置は市と候補事業者へ一つずつ確認してください。
利用できる時間
市のページでは委託事業者ごとの曜日・時間を確認できません。希望日時と外出目的を伝え、現在の担当可否を確認してください。
地域・送迎
周南市へ申請する制度です。市ページには8委託事業者が掲載され、周南市外の事業者も含まれます。8件は現在のお子様担当や空きの件数ではありません。事業者ごとの訪問範囲、市外外出、出発地・帰着地は要確認です。
料金
利用料は障害福祉サービスに準じ、原則1割です。市の案内では、お子様の月額上限は生活保護・低所得世帯0円、一般1が4,600円、一般2が37,200円です。移動支援への現在の適用区分、交通費・入場料等の実費、キャンセル料は市と事業者へ確認してください。
