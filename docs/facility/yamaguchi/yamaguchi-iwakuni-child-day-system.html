岩国市 お子様の日中一時支援

お知らせ市の制度上の原則時間や委託先一覧は、現在の空き・希望日の受け入れを示すものではありません

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
岩国市
サービスの種類
日中のあずかり
対象年齢
岩国市内に住み、手帳等の条件に当たる方のほか、特別支援学級・特別支援学校に通うお子様、診断書等で精神障害・発達障害があると認められる方などで、市が長時間の見守りを必要と認めた方が対象です。
ひとこと
お父様・お母様等の就労や一時的な休息を支えるため、日中に委託事業所で一時的な見守りを行う市の制度です。
利用の条件
岩国市へ申請後、相談支援事業所の訪問調査を受け、市が利用可否と料金を決定します。利用決定通知書を事業所へ示して手続きを行います。委託先ごとの対象年齢・時間・送迎・事前見学等は別に確認してください。
利用までの流れ
岩国市障害者支援課へ相談・申請 → 相談支援事業所の訪問調査 → 市の利用・料金決定 → 利用決定通知書を希望する委託先へ提示 → 対象年齢、日時、送迎、食費、必要な介助を確認 → 利用手続き。
医療的ケアについて
市の制度案内と委託先一覧から、医療的ケア一般、吸引、経管栄養、人工呼吸器、全面介助等への個別対応を推測していません。
利用できる時間
市の制度上は原則8時〜19時ですが、委託先ごとに実施日・時間・対象年齢が異なり、原則時間より短い場合があります。現在の希望日の受付・空きは未確認です。
地域・送迎
岩国市内に住む方の制度です。2026年4月資料には岩国市内を中心とする複数の委託先が載っています。市外事業所を含む利用条件と送迎範囲は事業所ごとに確認します。
料金
市民税課税世帯は、単独利用が1日166円・332円・498円の時間区分、送迎1回60円です。他サービスとの重複利用は別の時間区分です。生活保護・市民税非課税世帯は送迎を含め0円、食費は実費です。年度ごとに見直されるため、決定通知と事業所で確認します。
