あいの実ストロベリー（日中一時支援・日帰りの医療型短期入所）

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
仙台市泉区
サービスの種類
日中のあずかり
対象年齢
重症心身障害・医療的ケアのあるお子様を含む全年齢を案内しています。医療型短期入所は、受給者証の医療型（重心・医療的ケア）または施設が案内する判定基準を確認します。
ひとこと
仙台市の日中一時支援一覧に載り、施設では放課後等デイサービス後の日中一時支援と、宿泊を伴わない医療型短期入所（デイショート）を案内しています。同じ場所でも制度・受給者証・利用手順を分けて確認します。
利用の条件
日中一時支援は仙台市へ事前申請します。医療型短期入所は、受給者証の対象区分を確認し、事前登録、施設の診療所受診・カルテ作成、契約、予約の順で進みます。およそ2か月ごとの診察も案内されています。
利用までの流れ
日中一時支援：仙台市へ事前申請 → 利用決定 → 施設へ対象・希望日時を相談。医療型短期入所：受給者証の区分を確認 → 事前登録 → 診療所受診・カルテ作成 → 契約 → 予約。
