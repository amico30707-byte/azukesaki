施設のこと

地域
石巻市
サービスの種類
家に来るヘルパー外出の付きそい
対象年齢
石巻圏域の2026年10月1日現在の公式一覧では、KAIの居宅介護・重度訪問介護に児童欄の提供中表示があります。行動援護・移動支援を含む、お子様ごとの年齢・支給要件・担当可否は要確認です。
ひとこと
居宅介護、行動援護、重度訪問介護、移動支援を行う事業所です。自宅での身体介護・家事援助と、外出の支援を案内しています。
空き・受付について
2026年10月1日現在の石巻圏域一覧の『提供中』表示と、2026年1月1日現在の仙台市移動支援登録一覧への掲載は、現在の空きや希望日時の担当を示しません。2026年10月23日更新の市ページにある精神障害者コミュニティサロン“KAI”は、居宅介護事業所とは別の窓口です。新規受付、お子様ごとの担当可否、住所ごとの訪問可否、費用・実費、医療的ケアは未確認です。
利用の条件
石巻市へ利用申請し、支給決定・受給者証を確認したうえで、事業所と契約します。居宅介護、行動援護、移動支援は別の条件があるため、使いたい支援名を伝えます。
利用までの流れ
石巻市障害福祉課（0225-95-1111）または相談支援へ相談 → 保護者が利用申請 → 支給決定・受給者証 → 事業所へ支援名・地域・日時・介助内容を相談 → 契約・利用日を調整。
医療的ケアについて
公式ページで医療的ケアや処置別対応を確認できませんでした。吸引・経管栄養・人工呼吸器などは処置ごとに要確認です。
利用できる時間
営業は月〜日曜の予約制で9〜18時です。12月29日〜1月3日は休みです。希望日時に担当できる意味ではありません。
地域・送迎
法人ページのサービス対象地域は石巻市・東松島市・女川町です。仙台市の2026年1月1日現在の移動支援登録一覧には、市外事業所としてKAIの掲載がありますが、法人ページの通常地域が仙台市全域へ広がった意味にはしていません。お住まいの市町村と事業所の両方へ確認してください。
料金
制度上の自己負担、外出時の交通費などの実費は石巻市と事業所へ確認してください。

サービスごとのこと

居宅介護・行動援護・重度訪問介護
自宅での身体介護・家事援助、通院・外出の付きそいを案内。石巻市の2026年10月1日現在一覧では居宅介護・重度訪問介護の児童欄に提供中表示があります。営業は毎日予約制の9〜18時です。お子様の個別担当と希望日時は要確認です。
出典：city.ishinomaki.lg.jp
確認日：2026年10月21日
移動支援
通院、買い物、余暇活動などの外出支援を案内。法人ページの対象地域は石巻市・東松島市・女川町です。仙台市の登録一覧にも市外事業所として掲載がありますが、通常の訪問地域が仙台市全域という意味ではありません。
出典：city.sendai.jp
確認日：2026年10月20日
同じ『KAI』名の別窓口と区別
石巻市が2026年10月23日に更新した『障害者コミュニティサロン“KAI”』は、精神疾患のある市民向けの交流場所で、所在地は穀町11番29号、電話は0225-93-2924です。門脇の居宅介護事業所ヘルプグループ“KAI”とは別の窓口です。ヘルパーを相談するときは、事業所名・住所・電話を確かめてください。
