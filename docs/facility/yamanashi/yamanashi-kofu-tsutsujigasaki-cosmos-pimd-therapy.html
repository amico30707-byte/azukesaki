児童発達支援事業 こすもす（つつじが崎学園）

施設のこと

地域
甲府市岩窪町
サービスの種類
通う療育
対象年齢
在宅の重症心身障害児（者）が対象です。くわしい年齢の範囲は要確認です。
ひとこと
社会福祉法人宮前福祉会 つつじが崎学園が行う、在宅の重症心身障害のお子様のための児童発達支援です。通園で日常生活動作や運動機能などの療育を行い、看護師・理学療法士などを配置しています。定員は5名です。
空き・受付について
法人の公式ページで、対象、定員、職員、利用者負担、所在地、電話を確認しました。曜日・時間、いまの空き、送迎、医療的ケアの受け入れ、電話での確認はしていません。
利用の条件
児童発達支援の受給者証が必要です。お子様の状態、必要なケア、通園のしかたは事業所へ相談してください。
利用までの流れ
お住まいの市町村へ受給者証を相談 → こすもすへ問い合わせ → 見学・お子様の状態の相談 → 契約・通園日の調整。
医療的ケアについて
看護師1名の配置と、歯科医師による摂食指導（年4回）の記載はありますが、医療的ケアの受け入れや処置名は書かれていません。吸引・経管栄養などはお子様ごとに確認してください。
利用できる時間
公式ページに曜日・時間の記載はありません。事業所へ確認してください。
地域・送迎
事業所は甲府市岩窪町にあります。利用できる地域と送迎は公式ページに記載がないため要確認です。
料金
満3歳になって初めての4月1日から3年間は無償で、1日の諸経費500円がかかります。それ以外のお子様は、保護者の年間所得890万円までは上限4,600円、890万円以上は上限37,200円です。
