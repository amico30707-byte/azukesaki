放課後デイ みだい

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
韮崎市
サービスの種類
通う療育
対象年齢
学校へ通学中の障がいのあるお子様が対象です。施設案内には卒業後、満20歳になるまでの方も記載されていますが、在学中と卒業後で必要な支給決定を確認してください。
ひとこと
放課後や学校休業日に、自立につながる活動や交流、居場所を提供する放課後等デイサービスです。2026年7月17日更新の山梨県ページにある2026年6月1日現在の障害児施設一覧と、2025年4月公表の施設自己評価で事業の掲載を確認しました。
利用の条件
市町村へ放課後等デイサービスの利用を相談し、通所受給者証の内容を確認したうえで、施設へ見学、利用曜日、送迎、卒業後の扱いを確認してください。
利用までの流れ
市町村へ利用相談 → 通所の支給決定・受給者証を確認 → 施設へ見学を相談 → 対象地域、曜日、送迎、実費を確認 → 契約・利用調整。
医療的ケア
なし
医療的ケアについて
放課後等デイサービスでの医療的ケア一般、吸引、経管栄養、人工呼吸器は公式案内で確認できていません。
利用できる時間
施設案内では月〜金曜13時〜17時、土・日曜・祝日・長期休み9時〜17時です。2023年度から第1・3・5日曜と祝日を臨時休業（例外あり）とする記載もあるため、現在の営業日と時間は確認してください。
地域・送迎
施設案内では南アルプス市・韮崎市、その他は要相談です。現在の送迎範囲と利用できる市町村は確認してください。
料金
施設案内では登録料なし、おやつ代・活動費は実費です。制度の自己負担と現在の実費を確認してください。
