施設のこと

地域
富士吉田市
サービスの種類
通う療育日中のあずかり
対象年齢
0〜18歳が対象です。児童発達支援は0〜6歳の未就学のお子様、放課後等デイサービスは6〜18歳のお子様向けと案内されています。利用には市町村発行の受給者証が必要です。
ひとこと
児童発達支援、放課後等デイサービス、保育所等訪問支援、日中一時支援を行う事業所です。児童発達支援と放課後等デイサービスの定員は合わせて10名です。
空き・受付について
LUPEの公式ページで、0〜18歳、児童発達支援・放課後等デイサービス・保育所等訪問支援・日中一時支援、提供時間、定員、受給者証と利用手順、通所の料金目安を確認しました。現在の新規受付・空き、希望日時、電話でのお子様ごとの利用可否、日中一時支援の対象・時間・料金、利用地域・送迎、個別ケアは未確認です。
利用の条件
まず電話等で問い合わせ、見学・事業所説明を受けます。受給者証がない場合は市町村へ通所受給者申請を行い、受給者証の取得後に契約・利用開始となります。公式案内では初回発行に1〜3か月程度かかる場合があるとしています。
利用までの流れ
LUPEへ問い合わせ → 見学・事業所説明 → 市町村へ通所受給者申請（受給者証がない場合） → 受給者証を確認 → 契約・利用開始日を調整 → 現在の受付・空き・送迎・実費・必要な支援を確認して利用。
医療的ケアについて
理学療法士の紹介と運動療育の記載はありますが、医療的ケア一般や、重症心身障害、重度知的障害、強度行動障害、全面介助、吸引、経管栄養、人工呼吸器等の個別対応は推測していません。お子様ごとに事業所へ確認してください。
利用できる時間
月〜金曜日。児童発達支援9時〜12時、放課後等デイサービスは平日13時30分〜17時、長期休暇中9時〜16時、保育所等訪問支援9時〜17時。長期休暇中は職員配置により放課後等デイサービスを優先し、児童発達支援・訪問支援が休みになる場合があります。日中一時支援の時間は未確認です。
地域・送迎
事業所は富士吉田市にあります。利用対象地域、学校への迎え・園への送りの範囲、市外のお子様の利用は要確認です。
料金
利用料の目安は1回約1,000円、利用者負担は1割と案内されています。世帯収入による月額上限があり、放課後等デイサービスはおやつ代100円／回が別途必要です。実際の負担、日中一時支援の料金、ほかの実費は確認してください。
