甲斐市 お子様の居宅介護・障がい児通所支援

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
甲斐市
サービスの種類
家に来るヘルパー通う療育
対象年齢
居宅介護は身体・知的・精神の障がいのあるお子様を対象に含みます。児童発達支援は障がいのあるお子様、医療型児童発達支援は未就学のお子様、放課後等デイサービスは就学しているお子様が制度上の対象です。利用先ごとの年齢・状態は別に確認してください。
ひとこと
ご自宅で入浴・排せつ・食事等を支える居宅介護と、児童発達支援・放課後等デイサービス等の制度を甲斐市へ相談する入口です。未就学のお子様には、市独自の昼食・おやつ代給付の案内もあります。
利用の条件
甲斐市障がい者支援課または各支所の窓口で支給申請を確認します。昼食費等の給付は、児童発達支援または医療型児童発達支援の通所給付決定を受けた未就学のお子様の保護者が対象です。
利用までの流れ
甲斐市障がい者支援課へ相談 → 居宅介護または障がい児通所支援の対象・申請書類を確認 → 支給決定・受給者証を確認 → 事業所へ現在の受付・空き・曜日・時間・送迎・実費・個別の支援を確認 → 契約・利用 → 対象となる未就学のお子様は昼食費等給付を保護者または代理受領で申請。
医療的ケアについて
医療型児童発達支援や居宅訪問型児童発達支援の制度名は掲載されていますが、特定事業所の医療的ケア受け入れを示すものではありません。重症心身障害、重度知的障害、強度行動障害、全面介助、吸引、経管栄養、人工呼吸器、看護師配置などは利用先へ確認してください。
利用できる時間
市の制度ページは事業所ごとの曜日・時間を示していません。居宅介護の希望日時、児童発達支援・放課後等デイサービスの療育時間、送迎は利用先へ確認してください。
地域・送迎
甲斐市の制度・申請窓口です。市内外のどの事業所を利用できるか、居宅介護の訪問地域、療育の送迎範囲は事業所ごとに確認してください。
料金
通常の利用者負担上限と実費は市へ確認してください。甲斐市の昼食費等給付は、対象となる未就学のお子様について昼食・おやつ代を1人1日500円まで給付します。持参した弁当や購入した昼食も対象になり、購入分は領収書等が必要です。
住所
申請・相談窓口：山梨県甲斐市篠原2610（甲斐市役所 障がい者支援課）
