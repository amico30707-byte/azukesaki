確認日：2026年11月11日（あずけさき手帖が公式の情報を確かめた日）

施設のこと

地域
鈴鹿市
サービスの種類
通う療育
対象年齢
重症心身障害児・医療的ケア児の児童発達支援と放課後等デイサービスです。くわしい年齢は要確認です。
ひとこと
重症心身障害児・医療的ケア児のための通所支援です。看護師による健康管理と医療的ケアの体制をつくっていると書かれています。
空き・受付について
空き、新規受付、定員、休みの日、送迎範囲、お子様に必要なケアを受けられるかは未確認です。
利用の条件
「重症心身障害児対象」の通所受給者証が必要です。医療的ケアは主治医の指示書と保護者の同意にもとづき、看護師と研修を受けた介護士が行います。
利用までの流れ
施設見学 → 「重症心身障害児対象」の通所受給者証の手続き → 相談支援専門員へ連絡・相談 → 施設で面談 → 契約。
医療的ケア
あり
医療的ケアについて
公式ページに、吸引、経管栄養、吸入、導尿・浣腸、発作時の対応などを行うと書かれています。人工呼吸器の記載はありません。お子様に必要なケアを受けられるかは施設に確認してください。
利用できる時間
児童発達支援は9時〜15時です。放課後等デイサービスは平日が下校時間から17時、長期休暇・祝日は9時〜15時です。休みの日は要確認です。
地域・送迎
施設は鈴鹿市にあります。放課後等デイサービスは施設の車で学校へのお迎え、または保護者の送迎で、学校からの送迎は相談のうえです。範囲は要確認です。
料金
自己負担は利用料金の1割で、世帯所得に応じた月の上限があります。おやつ代50円です。
住所
三重県鈴鹿市三日市南三丁目17番20号
