鈴鹿市社会福祉協議会 訪問介護事業所『社協』

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
鈴鹿市
サービスの種類
家に来るヘルパー外出の付きそい
対象年齢
在宅で生活する、障害者総合支援法の対象となる障がい児を利用対象に含みます。居宅介護・移動支援それぞれの詳しい条件は、市の利用決定と事業所へ確認してください。
ひとこと
在宅の障がい児者へ身体介護・生活援助・外出支援を行う鈴鹿市社会福祉協議会の訪問介護事業所です。移動支援は市の利用決定後に事業所と契約し、支援計画を作ります。
利用の条件
移動支援は『鈴鹿市障害者等移動支援事業利用決定通知書』の決定内容を確認し、事業所へ連絡します。事業所の説明を受け、契約後に移動支援計画を作成します。居宅介護は受給者証等の手続き・契約を別に確認してください。
利用までの流れ
鈴鹿市へ使いたい支援を相談・申請 → 市の利用決定通知書または受給者証を確認 → 事業所へ地域・日時・介助・費用を相談 → 説明・契約 → 支援計画の作成 → 利用日を調整。
医療的ケアについて
移動支援の重要事項説明書では、ヘルパーが行わない行為に『医療行為』を明記しています。居宅介護での医療的ケア一般、吸引、経管栄養、人工呼吸器の対応は未確認で、移動支援と分けて確認してください。
利用できる時間
移動支援の重要事項説明書では年中無休、サービス提供時間帯7時〜21時、電話等の受付は月〜金曜8時30分〜17時15分です。これは希望日時に担当者がいるという意味ではなく、居宅介護の提供時間も別に確認が必要です。
地域・送迎
通常の移動支援提供地域は鈴鹿市です。通常地域外に住む方へサービスを行う場合、通常地域を越えた地点から片道1kmにつき20円の交通費が必要と説明されています。居宅介護の訪問地域、市外外出、実際の適用は事業所へ確認してください。
料金
移動支援は利用者負担上限月額の範囲でサービス費用の1割です。通常地域外に住む方へサービスを行う場合は、通常地域を越えた地点から片道1kmにつき20円です。公共交通、入場料・利用料、食事等は実費で、前日までの連絡がない当日キャンセルは体調不良等を除き1,000円の場合があります。居宅介護の料金は別に確認してください。
