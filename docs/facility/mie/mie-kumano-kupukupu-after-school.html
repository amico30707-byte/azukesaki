放課後等デイサービス くぷくぷ

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
熊野市有馬町
サービスの種類
通う療育
対象年齢
事業者公式ページは、小学生から18歳までの、発達支援を必要とするお子様を対象と案内しています。利用には障害児通所受給者証が必要です。
ひとこと
熊野市有馬町の放課後等デイサービスです。学校日、土曜日、長期休みで利用時間を分け、見学から受給者証の申請、契約、利用開始までの流れを案内しています。
利用の条件
施設へ問い合わせ・見学 → 受給者証がなければ市町村へ申請 → 受給者証の交付 → 施設との契約 → 利用開始です。現在の空き、新規受付、希望曜日は別に確認してください。
利用までの流れ
施設へ問い合わせ・見学 → 市町村へ受給者証を申請（未取得の場合） → 受給者証の交付 → 施設と契約 → 利用開始。必要書類、申請窓口、開始日は市町村と施設へ確認してください。
医療的ケアについて
医療的ケア一般、重症心身障害、重度知的障害、強度行動障害、全面介助、吸引、経管栄養、人工呼吸器への対応は公式ページで確認できませんでした。発達支援の案内から個別ケアを推測していません。
利用できる時間
平日は放課後〜17時15分、学校が休みの土曜日は9時〜16時、学校がある土曜日は放課後〜16時、長期休みは9時〜16時です。開所時間は平日12時15分〜18時15分、学校が休みの土曜日と長期休みは8時15分〜17時30分、学校がある土曜日は10時〜17時30分と案内されています。
地域・送迎
施設は熊野市有馬町にあります。熊野市外の送迎には距離別の費用案内がありますが、現在送迎できる市町村・学校・自宅は公式ページで確認できませんでした。
料金
事業者ページは制度上の利用者負担のほか、おやつ1日50円、注文する昼食350円、保険料年2,000円、活動の実費を案内しています。熊野市外の送迎は、市境から片道10km未満300円、10km以上500円の案内です。現在の適用と詳しい条件は契約前に確認してください。
