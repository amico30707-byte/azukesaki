施設のこと

地域
伊勢市黒瀬町
サービスの種類
通う療育
対象年齢
心身の発達に遅れや心配のある1歳から小学生までのお子様が対象です。小学生は特別支援学校または特別支援学級に在籍するお子様と案内されています。児童発達支援と放課後等デイサービスで対象が異なるため、利用する事業名を伝えて確認してください。
ひとこと
伊勢市の児童発達支援センターです。児童発達支援、特別支援学校・特別支援学級の小学生を対象とする放課後等デイサービス、保育所等訪問支援、療育相談、障害児相談支援を案内しています。
空き・受付について
2026年7月29日更新の伊勢市公式ページを2026年10月26日に確認し、対象年齢・居住地、事業、施設全体の時間、休業日、住所、電話を確認しました。現在の空き、新規受付、電話でのお子様ごとの利用可否、事業ごとの日時、送迎、費用、個別ケアは未確認です。
利用の条件
伊勢市、鳥羽市、志摩市、玉城町、度会町、大紀町、南伊勢町に住む対象年齢のお子様が案内されています。利用方法は、おおぞら児童園へ問い合わせるよう市が案内しています。
利用までの流れ
おおぞら児童園へ希望する事業とお子様の年齢・居住地を相談 → 市町村で通所受給者証等の手続きを確認 → 事業ごとの通い方、費用、必要な支援、現在の利用調整を確認 → 契約・利用。
医療的ケアについて
市の施設案内から、医療的ケア一般、重症心身障害、重度知的障害、強度行動障害、全面介助、吸引、経管栄養、人工呼吸器への対応は確認できませんでした。療育や専門職の記載から個別ケアを推測していません。
利用できる時間
業務時間・利用時間は8時30分〜17時30分です。土曜日、日曜日、祝日、年末年始は休みです。事業ごとの通所曜日・時間、希望日の利用は別に確認してください。
地域・送迎
伊勢市、鳥羽市、志摩市、玉城町、度会町、大紀町、南伊勢町に住むお子様。送迎の有無・範囲は公式ページで確認できませんでした。
料金
伊勢市の公式ページは、利用料金をおおぞら児童園へ問い合わせるよう案内しています。利用者負担、食費等の実費、減免は未確認です。

サービスごとのこと

児童発達支援
基本的生活習慣、感覚・運動・認知・言語の発達を支え、音楽療法、感覚運動遊び、作業療法、言語療法、心理療法、保護者相談を案内しています。利用する内容と頻度は要確認です。
出典：city.ise.mie.jp
確認日：2026年10月26日
放課後等デイサービス
特別支援学校または特別支援学級に在籍する小学生が対象で、個別・グループ活動、作業療法、言語療法、保護者の心理相談を案内しています。
出典：city.ise.mie.jp
確認日：2026年10月26日
保育所等訪問支援・相談支援
保育所、幼稚園、小学校等への訪問支援、療育相談、障害児支援利用計画の作成を案内しています。通所とは別の支援です。
出典：city.ise.mie.jp
確認日：2026年10月26日
