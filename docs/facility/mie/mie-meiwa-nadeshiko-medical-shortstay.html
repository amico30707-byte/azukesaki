済生会明和病院 なでしこ 短期入所・日帰り短期入所

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
明和町
サービスの種類
お泊まり（短期入所）日中のあずかり
対象年齢
重症心身障害児・者が対象です。お子様の詳しい年齢条件は要確認です。
ひとこと
ご家族の病気・疲労・休息などの際に、宿泊する短期入所と日帰りの短期入所を相談できます。日帰り短期入所は、市町村の地域生活支援事業である日中一時支援とは別に確認してください。
利用の条件
受給者証の支給量内で利用します。初回は医療情報・薬の情報を提出し、支援会議で受け入れを検討した後、面談・見学、市町村への医療型短期入所の申請、体験利用・診察・契約へ進みます。体験利用はご家族の付き添いが必要です。希望日は調整会議で決まり、希望者が多い場合は希望に添えないことがあります。
利用までの流れ
病院へ相談 → 医療情報・薬の情報を提出 → 支援会議で受け入れ検討 → 面談・見学 → 市町村へ医療型短期入所を申請 → ご家族同伴の体験利用・診察・契約 → 利用申込み → 調整会議後に電話で利用日の連絡。
医療的ケア
あり
医療的ケアについて
医療型障害児入所施設に併設する短期入所です。吸引・経管栄養・人工呼吸器などの処置別対応は未確認で、医療型という名称から推測していません。
利用できる時間
利用開始日は月〜金曜です。利用日数は受給者証の支給量内です。利用希望の受付は土日祝を除く9時〜17時で、予定が分かり次第なるべく早く申し込む案内です。受付時間は利用時間ではなく、日帰りの利用時間、宿泊の入退所時刻は要確認です。
地域・送迎
施設は三重県明和町にあります。利用できる市町村、県外利用、送迎は未確認です。
料金
受給者証に記載された月の負担上限額が目安です。食費、おむつ等は制度の給付外となる案内です。現在の具体的な実費は要確認です。
住所
