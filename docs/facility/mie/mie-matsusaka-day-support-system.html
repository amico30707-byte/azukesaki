松阪市 日中一時支援

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
松阪市
サービスの種類
日中のあずかり
対象年齢
日中に監護する方がいないため、一時的な見守り等の支援が必要な障がい児・障がい者が対象です。お子様の詳しい障害・年齢条件は市へ確認してください。
ひとこと
日中の一時的な見守りや活動の場を提供し、お子様ご本人の社会への適応や、ご家族の事情を支える松阪市の地域生活支援事業です。
利用の条件
松阪市の地域生活支援事業利用申請書を提出します。日中活動系サービスと同じ日に日中一時支援を使う場合は、同一日利用に関する申請書も公開されています。支給決定、受給者証・利用証、事業所との契約の詳しい順番は市へ確認してください。
利用までの流れ
松阪市障がい福祉課へ日中の困りごとと希望を相談 → 地域生活支援事業利用申請書を提出 → 必要に応じて同一日利用の申請 → 利用決定と利用できる事業所を確認 → 事業所と日時・実費・必要な支援を調整。
医療的ケアについて
市の手引き・申請ページでは、医療的ケア一般、吸引、経管栄養、人工呼吸器、全面介助に対応する事業所を確認できませんでした。利用する事業所へ項目ごとに確認してください。
