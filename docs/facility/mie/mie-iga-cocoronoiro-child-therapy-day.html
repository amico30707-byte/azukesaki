ココロノイロ 放課後等デイサービス・日中一時支援

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
伊賀市
サービスの種類
通う療育日中のあずかり
対象年齢
放課後等デイサービスは小学1年生から高校3年生までと案内されています。日中一時支援の年齢は現行の公式ページで確認できないため、利用する事業名とお子様の年齢を伝えて確認してください。
ひとこと
2026年4月に移転し、建物の2階で放課後等デイサービスを行う多機能事業所です。放課後等デイサービスとは別に、開所前後の日中一時支援も案内しています。
利用の条件
放課後等デイサービスは、相談、見学、体験、契約、利用開始の順です。日中一時支援に必要な市の利用決定・受給者証等と、放課後等デイサービスとの同日利用条件は別に確認してください。
利用までの流れ
施設へ利用したい事業、年齢、希望曜日を相談 → 見学・体験 → 市の利用決定・受給者証等と費用を確認 → 契約 → 利用開始。日中一時支援は市の手続きも別に確認してください。
医療的ケアについて
医療的ケア一般、重症心身障害、重度知的障害、強度行動障害、全面介助、吸引、経管栄養、人工呼吸器への対応は公式ページで確認できませんでした。生活介護との多機能事業所であることから、お子様向け事業の個別ケアを推測していません。
