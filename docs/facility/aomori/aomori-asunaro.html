施設のこと

地域
青森市
サービスの種類
日中のあずかりお泊まり（短期入所）通う療育
対象年齢
身体の機能や運動発達などに障害のあるお子様、重症心身障害児・者などを支える県立センターです。日中一時支援は未就学児と就学児の枠を分け、短期入所は福祉型・医療型を分けています。詳しい対象状態は事業ごとに要確認です。
ひとこと
2026年4月開始の日中一時支援、福祉型・医療型短期入所に加え、児童発達支援「あぷるん」と放課後等デイサービス「かしすん」を案内しています。かしすんは2026年8月から送りのみの送迎を始めました。
空き・受付について
公式ページは2026年9月28日更新ですが、内容の基準日は2026年8月末です。その時点で福祉型・医療型短期入所と児童発達支援・放課後等デイサービスを『利用可能』・申込み受付中と案内しています。短期入所の定員、契約者数、実利用者数は現在の空き人数ではなく、希望日・曜日と今の受付は電話で確認が必要です。日中一時支援の現在の空きは未確認です。
利用の条件
日中一時支援は青森市の制度申請後、センターへ利用枠と条件を確認します。短期入所は市町村の障害福祉サービス受給者証と利用計画が必要で、初回は親子見学、外来健康診断、原則1泊2日の親子体験、受入判定、契約へ進みます。児童発達支援・放課後等デイサービスは相談、外来診察、母子体験、受入検討、契約の順です。
利用までの流れ
日中一時支援は青森市障がい者支援課へ申請 → センターへ対象・時間・利用枠を確認 → 契約・利用日調整。児童発達支援・放課後等デイサービスは相談 → 外来診察 → 母子体験 → 受入検討 → 契約。短期入所は親子見学 → 外来健康診断 → 原則1泊2日の親子体験 → 受入判定 → 受給者証・利用計画 → 契約。
医療的ケア
あり
医療的ケアについて
医療型短期入所を行うことは公式に確認できました。吸引・経管栄養・人工呼吸器など、個別の処置と時間帯は未確認です。
利用できる時間
日中一時支援は未就学児1名・就学児1名の1日枠を案内していますが、利用時間は要確認です。児童発達支援は月〜金曜日、放課後等デイサービスは月〜金曜日の放課後〜16時45分、長期休みは8時45分〜16時45分。短期入所の翌月分は前月1日から受け付け、初回体験は原則1泊2日です。
地域・送迎
所在地は青森市。放課後等デイサービスは2026年8月から送りのみの送迎を実施しています。利用地域、送迎先・時刻、ほかの事業の送迎は要確認です。
料金
青森市の日中一時支援は時間と区分による利用料・所得に応じた上限があります。短期入所は制度対象費用の1割負担（軽減制度あり）のほか、食事・光熱水費・日用品等の実費があります。

サービスごとのこと

日中一時支援
在宅で介護するご家族の休息や、やむを得ない事情があるときに見守り等を行います。未就学児と就学児は各1名の1日枠ですが、現在の空きではありません。
出典：pref.aomori.lg.jp
確認日：2026年10月13日
福祉型短期入所
1日3名（うち緊急1名）の枠が案内されています。定員は希望日の空きを示すものではなく、個別の受け入れは判定後に決まります。
出典：pref.aomori.lg.jp
確認日：2026年10月13日
医療型短期入所
1日3名の枠が案内されています。必要な医療的ケアを一つずつ相談し、福祉型と医療型のどちらの支給決定が必要かを市町村と施設に確認してください。
出典：pref.aomori.lg.jp
確認日：2026年10月13日
児童発達支援・放課後等デイサービス
主に重症心身障害または肢体不自由のあるお子様が対象。児童発達支援は親子通園、放課後等デイサービスは小学1年〜高校3年で、2026年8月から送りのみの送迎を実施しています。
出典：pref.aomori.lg.jp
確認日：2026年10月13日
