施設のこと

地域
八戸市
サービスの種類
お泊まり（短期入所）
対象年齢
居宅で生活する障害児または障害者が対象です。障害児入所施設では主に知的発達に遅れのあるお子様等を受け入れていますが、短期入所のお子様ごとの年齢・障害条件は要確認です。
ひとこと
ご家族の病気などで在宅での療育が難しいときに、食事・入浴・排せつなどの支援を受けながら宿泊できる短期入所です。
空き・受付について
2026年10月15日に短期入所ページと施設のお知らせを確認しました。最新のお知らせは2026年9月15日の学園だよりで、短期入所の空き情報ではありません。1日2名は定員であり、現在の空き、希望日の利用、お子様ごとの受け入れ、利用地域、送迎、個別ケア、電話確認は未確認です。
利用の条件
まず施設へ相談し、お父様・お母様とお子様が面談・見学します。次にお住まいの自治体へ相談して障害福祉サービス受給者証の交付を受け、施設と契約します。
利用までの流れ
うみねこ学園へ相談 → お父様・お母様・お子様との面談と見学 → お住まいの自治体へ相談して受給者証を取得 → 施設と契約 → 前月の予約開始日以降に利用日を予約。
医療的ケアについて
食事・入浴・排せつ等の日常生活支援は確認しました。医療的ケア一般、吸引、経管栄養、人工呼吸器の個別対応は未確認です。
利用できる時間
入所は7時30分から、退所は19時まで。施設行事等により利用できない場合があります。原則、利用月の前月15日9時から予約を受け付けます。15日が土日祝日の場合は前日です。
地域・送迎
施設は八戸市にあります。利用できる市町村と送迎は未確認です。
料金
世帯所得やお子様の状況で異なります。公式ページの一例では1泊2日・3食で、利用者負担1,822円と実費960円です。食事は1食520円、食事提供加算が適用される場合は1食320円。これは全員に同じ金額ではありません。
