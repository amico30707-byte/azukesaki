天理市 お子様の日中一時支援・障害児通所支援

施設のこと

地域
天理市
サービスの種類
日中のあずかり通う療育
対象年齢
日中一時支援は天理市に住む障がいのあるお子様を対象に含みます。児童発達支援は未就学、放課後等デイサービスは就学中のお子様が対象です。居宅訪問型児童発達支援は、重い障がい等により通所が難しいお子様を対象に含みます。
ひとこと
日中の活動・見守りとご家族の就労・休息を支える日中一時支援、児童発達支援・放課後等デイサービス等の通所支援を、市の窓口で申請する入口です。日中一時支援と通所支援は原則同じ日に使えないため、希望日ごとに分けて確認します。
空き・受付について
2026年5月20日更新の通所支援案内と市の日中一時支援要綱を読み、対象、申請、支給量、同日利用の原則、料金・上限を確認しました。現在の実施事業所・新規受付・空き、電話でのお子様ごとの受け入れ、希望日時、送迎、食費等の実費、個別ケアは未確認です。
利用の条件
日中一時支援は市へ地域生活支援事業利用申請書と住所・所得等の書類を提出し、決定後に受給者証を事業者へ提示します。通所支援は、事業所を選び、市で申請・お子様の状況確認、利用計画案またはセルフプラン、受給者証、事業所との契約の順です。
利用までの流れ
日中一時支援：天理市社会福祉課へ申請 → 市の利用決定・受給者証を確認 → 事業者へ提示して申込み。通所支援：事業所を選ぶ → 市へ申請・聞き取り → 利用計画案またはセルフプラン → 審査・受給者証 → 事業所と契約・利用。
医療的ケアについて
市の制度案内から、医療的ケア一般、重症心身障害、重度知的障害、強度行動障害、全面介助、吸引、経管栄養、人工呼吸器、看護師配置などを推測していません。利用先と日時ごとに確認してください。
利用できる時間
日中一時支援の支給量は原則4時間を1単位として月21単位までです。これは事業所の営業時間や希望日の空きを示しません。通所支援の曜日・時間・送迎も事業所へ確認してください。
地域・送迎
日中一時支援は原則として天理市に住む方が対象です。通所支援は天理市の申請窓口ですが、事業所ごとの利用地域・送迎範囲は別に確認してください。
料金
日中一時支援は市要綱の別表額の1割、他の地域生活支援事業と合わせた月額上限37,200円で、生活保護・市民税非課税等は全額免除です。通所支援は世帯区分により月額上限0円・4,600円・37,200円で、食費・課外活動の交通費等は別です。
住所
申請・相談窓口：奈良県天理市川原城町605（天理市役所 社会福祉課）
電話
0743-63-1001天理市 社会福祉課。日中一時支援または障害児通所支援の対象、申請、受給者証を確認してください。
確認日
2026年10月10日

サービスごとのこと

日中一時支援（宿泊なし）
日中の活動場所、見守り、日常的な訓練等を行い、ご家族の就労や一時的な休息を支えます。原則月21単位までで、障害児通所支援等との同日利用は原則できません。
出典：city.tenri.nara.jp
確認日：2026年10月10日
児童発達支援・放課後等デイサービス
未就学または就学中のお子様への通所支援です。市の審査期間は約2週間ですが、基準量を超える申請はさらに時間がかかります。これは施設の待ち期間ではありません。
出典：city.tenri.nara.jp
確認日：2026年10月10日
居宅訪問型児童発達支援
重い障がい等により通所支援を受けるための外出が難しいお子様へ、ご自宅を訪問して支援する制度です。現在の実施事業所・地域・空きは要確認です。
出典：city.tenri.nara.jp
確認日：2026年10月10日
