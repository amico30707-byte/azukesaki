ひとこと
奈良市宝来町で、重い障がいのあるお子様の児童発達支援・放課後等デイサービスを案内する事業所です（利用時間10時〜17時）。奈良市の一覧には居宅訪問型児童発達支援の指定ものっていますが、おうちへの訪問をしているかは施設へご確認ください。
利用の条件
お住まいの市町村へ居宅訪問型児童発達支援を相談し、障害児通所受給者証等の手続きを確認します。現在の実施、対象、訪問できる地域、契約の順番はRicoraへ確認してください。
利用までの流れ
お住まいの市町村へ居宅訪問型児童発達支援を相談 → 必要な受給者証・利用計画を確認 → Ricoraへ現在の実施・対象・訪問地域・希望日時を確認 → 契約・個別支援計画 → 利用開始。
医療的ケアについて
訪問療育での医療的ケア一般、吸引・経管栄養・人工呼吸器等の個別対応は未確認です。
利用できる時間
事業者の現在ページは施設全体の利用時間を10時〜17時と案内していますが、居宅訪問型児童発達支援の訪問時間としては確認できていません。希望日時とあわせて要確認です。
地域・送迎
事業所所在地は奈良市宝来町です。ご自宅へ訪問する事業ですが、訪問できる市町村・範囲は未確認です。
