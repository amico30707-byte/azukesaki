わかくさ愛育園 さくらキッズ・ポコッチェリ

空きや受け入れは、かならず施設にご確認ください

電話0744-32-0200

確認日：2026年10月15日（あずけさき手帖が公式の情報を確かめた日）

施設のこと

地域
磯城郡田原本町
サービスの種類
通う療育
対象年齢
さくらキッズは常時介護や医療的ケアが必要な就学前の重症心身障害児、ポコッチェリは小学1年生〜高校3年生の重症心身障害児・医療的ケア児が対象です。
ひとこと
就学前の単独通園『さくらキッズ』と、就学児の放課後等デイサービス『ポコッチェリ』を行い、保育・看護・訓練を組み合わせて支援します。
空き・受付について
2026年10月15日に公式ページを読み直し、2026年5月のさくらキッズ親子保育体験、就学前・就学児の対象、ポコッチェリの地域・時間を確認しました。体験は手帳がなくても相談できますが、状態により受け入れられない場合があり、通常利用の空きではありません。現在の空き、電話でのお子様ごとの受け入れ、さくらキッズの地域・時間、料金、吸引・経管栄養、ポコッチェリでの人工呼吸器対応は未確認です。
利用の条件
希望する事業名、お子様の年齢、必要なケア、お住まいの市町村を伝えて施設へ相談し、市町村の障害児通所支援の決定・受給者証、見学・契約の順番を確認してください。2026年5月の親子保育体験は手帳がなくても参加を相談できましたが、状態により受け入れられない場合があります。体験は通常利用の契約や現在の空きを保証する案内ではありません。
利用までの流れ
施設へ希望事業・年齢・ケア・地域を相談 → 見学や体験の可否を確認 → お住まいの市町村へ障害児通所支援を申請 → 支給決定・受給者証 → 施設と契約・利用日を調整。
医療的ケア
あり
医療的ケアについて
わかくさ愛育園は就学前のお子様への医療的ケアを明記し、人工呼吸器を装着している方も相談できると案内しています。2026年5月の親子保育体験も人工呼吸器使用を対象に含みます。通常利用の現在の受け入れ、吸引・経管栄養と、ポコッチェリでの人工呼吸器対応は未確認です。
利用できる時間
ポコッチェリは月〜金曜、学校のある日13〜17時、長期休み10〜16時。祝日と12月29日〜1月3日は休みです。さくらキッズの曜日・時間は公式ページで確認できていません。
地域・送迎
ポコッチェリの対象地区は、大和高田市、橿原市、桜井市、五條市、御所市、香芝市、葛城市、宇陀市、磯城郡各町、上牧町、広陵町、大淀町、高市郡の町村です。さくらキッズの対象地域と送迎は要確認です。
料金
障害児通所支援の利用者負担、月額上限、食事・日用品などの実費は公式ページで確認できていません。市町村と施設へ確認してください。
住所
奈良県磯城郡田原本町大字多722番地
