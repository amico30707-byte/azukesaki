加須市 心身障害児（者）生活サポート事業

お知らせ市の補助制度・申請窓口です。登録団体そのもの、現在の空き、希望日時のお子様ごとの受け入れを示す施設情報ではありません。

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
加須市
サービスの種類
日中のあずかり家に来るヘルパー外出の付きそい
対象年齢
加須市の公式ページは、お子様と成人の両方を対象にし、身体障害者手帳、療育手帳・児童相談所等の判定、医師により発達障害と診断された方等の条件を案内しています。お子様ごとの対象は市へ確認してください。
ひとこと
加須市に登録した団体から、一時預かり、家庭への派遣介護、送迎、外出援助等を受けるときの費用を市が補助する制度です。市役所は申請窓口で、現在の実施団体・空き・受け入れ人数を示す掲載ではありません。
利用の条件
利用前に加須市障がい者福祉課へ申請し、対象確認と利用券の交付を受けます。利用する登録団体へ、希望日時、支援場所、送迎・外出、必要な介助を別に確認してください。
利用までの流れ
加須市障がい者福祉課へ対象・使いたい支援を相談 → 申請し利用券の交付を受ける → 現在の登録団体を確認 → 団体へ希望日時、預かり・家庭での介護・送迎・外出援助、必要な介助、実費を相談 → 利用。
医療的ケアについて
市の制度案内から、登録団体ごとの看護師配置、医療的ケア一般、重症心身障害、重度知的障害、強度行動障害、全面介助、吸引、経管栄養、人工呼吸器への対応を推測していません。必要な支援は項目ごとに確認してください。
利用できる時間
年間150時間までと案内されています。これは登録団体の営業時間や現在の空きではありません。曜日・時間、連続利用、送迎は団体へ確認してください。
地域・送迎
加須市の制度です。登録団体の所在地、加須市内外で利用できる範囲、送迎・外出先は市と団体へ確認してください。
料金
お子様は世帯の所得区分により1時間0〜950円です。年間150時間を超える利用、送迎・交通費等の実費、キャンセル時の扱いは市と登録団体へ確認してください。
住所
申請・相談窓口：埼玉県加須市三俣二丁目1番地1 加須市 障がい者福祉課（支援場所ではありません）
電話
0480-62-1111加須市役所代表。障がい者福祉課へ、生活サポート事業の対象・申請・現在の登録団体を確認してください。
