ひとこと
一般社団法人あいらんどの事業所です。法人全体の説明では、重症心身障害児のための児童発達支援・放課後等デイサービス・相談支援を運営し、看護師・理学療法士・作業療法士が常にいると書かれています。大きな車いすでも送迎でき、お風呂に入ってから自宅へ送ると案内しています。
空き・受付について
2026年11月12日に公式ページを確認しました。電話確認はしていません。空き・新規受付、送迎の範囲、料金、処置ごとの対応は未確認です。
利用の条件
児童発達支援・放課後等デイサービスの通所受給者証が必要です。お住まいの市町村の障害福祉の窓口か相談支援事業所に相談して申請します。お子様の状態と必要なケアは、利用前に事業所とくわしく相談してください。
利用までの流れ
事業所へ電話などで相談・見学 → 市町村の窓口で通所受給者証を申請 → 相談支援事業所と利用計画を作成 → 契約 → 利用開始。くわしい順番は事業所と市町村へご確認ください。
