施設のこと

地域
神川町
サービスの種類
家に来るヘルパー外出の付きそい日中のあずかりお泊まり（短期入所）
対象年齢
町の障害福祉サービスは障害児を対象に含みます。生活サポートは18歳未満のお子様の負担軽減も案内しています。移動支援・日中一時支援の個別要件は町へ確認してください。
ひとこと
神川町で、家での介助、外出の付き添い、日中の見守り、一時あずかり、短期入所を相談する制度です。生活サポートには送迎・一時預り・家庭への介護・外出援助が含まれます。
空き・受付について
神川町の現行ページ（2026年4月1日更新）で、お子様を含む障害福祉サービス、居宅介護・短期入所、生活サポート・移動支援・日中一時支援、利用登録と費用を確認しました。登録団体、現在の空き、新規受付、年齢・地域・曜日・時間、送迎、短期入所の泊数・実費、電話でのお子様ごとの受け入れ、個別ケアは未確認です。
利用の条件
事前に神川町へ相談・申請または利用登録が必要です。生活サポート・移動支援・日中一時支援は町に登録された団体を利用します。制度の決定後も、希望日時とお子様の受け入れは事業者へ確認します。
利用までの流れ
神川町町民福祉課へ使いたい事業を相談 → 申請・利用登録 → 対象と支給・登録内容を確認 → 登録団体または短期入所事業者へ連絡 → 希望日時、送迎、介助内容、実費を確認 → 契約・利用。
医療的ケアについて
町の制度ページでは、事業者ごとの看護体制、医療的ケア一般、吸引、経管栄養、人工呼吸器、全面介助を確認できませんでした。必要なケアを町と候補事業者へ一つずつ伝えてください。
利用できる時間
事業者と支給・登録内容によります。曜日、時間、送迎、外出範囲、短期入所の泊数は公式制度ページで確認できず、要相談です。
地域・送迎
神川町の制度です。町に登録された団体の所在地や対応地域は事業者ごとに異なるため、町外の事業者を使える場合も対象地域を別に確認してください。
料金
生活サポートは1時間950円で、18歳未満のお子様は世帯所得に応じた軽減制度があります。移動支援・日中一時支援は原則1割負担。短期入所の負担上限や食費等の実費は要確認です。

サービスごとのこと

居宅介護・短期入所
障害児を含む障害福祉サービスとして、居宅介護と短期入所が案内されています。利用する事業者、年齢、希望日時、短期入所の泊数・費用は要確認です。
出典：town.kamikawa.saitama.jp
確認日：2026年10月5日
生活サポート
町登録団体による送迎、一時預り、家庭への介護、外出援助。1時間950円で、18歳未満のお子様は世帯所得に応じた負担軽減があります。
出典：town.kamikawa.saitama.jp
確認日：2026年10月5日
移動支援
屋外での移動が難しい方の外出支援です。町への事前登録と原則1割負担を確認しました。外出目的・経路・希望日時は要確認です。
出典：town.kamikawa.saitama.jp
確認日：2026年10月5日
日中一時支援
日中の活動場所と見守りを提供する町登録制の事業です。宿泊する短期入所とは別で、原則1割負担です。
出典：town.kamikawa.saitama.jp
確認日：2026年10月5日
