ゆめの園中野林ヘルパーステーション

空きや受け入れは、かならず施設にご確認ください

利用を考えるときは

公式ページを見る法人｜中野林の施設・連絡先

電話048-620-5700番号は公式ページでご確認ください

確認日：2026年10月16日（あずけさき手帖が公式の情報を確かめた日）

施設のこと

地域
さいたま市西区
サービスの種類
家に来るヘルパー外出の付きそい
対象年齢
居宅介護・移動支援ともお子様の対象記載あり。行動援護は18歳未満の知的障害・精神障害のお子様も対象に含みます。制度上の利用条件は別に確認が必要です。
ひとこと
ご自宅での居宅介護と、移動支援・行動援護などの外出の支援を案内しています。
空き・受付について
空き・お子様ごとの受け入れ・電話での確認は未確認です。施設ページの「ショートステイ空き情報」は高齢者向けで、お子様の居宅介護・移動支援の空きではありません。
利用の条件
市町村の決定と支援計画に沿って利用します。移動支援は、官公庁・買い物・冠婚葬祭など生活に必要な外出、通学・通所、余暇活動などを案内しています。お子様の行動援護の記載から、強度行動障害の個別受け入れを確定していません。同じ施設の高齢者向け短期入所・デイサービスと、その空き情報は、お子様の居宅介護・移動支援の条件へ当てはめていません。
利用までの流れ
市町村へ希望する制度を相談・支給決定を受ける → 事業所へ電話し、年齢・支援内容・希望時間を相談 → 重要事項の説明 → 契約 → 支給量とお子様の状況に沿った計画の説明・同意 → 日程を調整。希望日時の担当可否と個別の開始日は未確認です。
医療的ケアについて
居宅介護の説明では医療行為を行わないと記載。一方、同じ説明書の料金表には喀痰吸引等支援体制加算の項目があります。料金項目だけでは実際の処置を確認できないため、吸引・経管栄養・人工呼吸器は未確認として扱っています。
利用できる時間
居宅介護等は毎日8時30分〜17時30分、時間外は要相談。移動支援も同時間帯ですが年末年始を除きます。
地域・送迎
通常の実施地域は、さいたま市全域と川越市。移動支援はお住まいの市の利用条件も確認してください。
料金
2026年4月の説明書では、居宅介護・移動支援とも原則1割負担と市区町村の月額上限を案内しています。通常の実施地域外へヘルパーが訪問する交通費、外出中のヘルパーの入場料・公共交通費などは実費です。移動支援は前営業日17時30分より後のキャンセルで、予定3時間未満800円、3時間以上1,000円の案内があります。急な体調不良・入院は除くとしています。実際の負担、時間外・2人介助は希望内容に合わせて確認してください。
住所
さいたま市西区中野林650-1
電話
048-620-5700施設ページ、居宅介護等の説明書、移動支援説明書のキャンセル・緊急連絡先に掲載。移動支援説明書の事業所概要だけ049表記のため、公式施設ページの048-620-5700を掲載しています。番号は公式ページでご確認ください
確認日
2026年10月16日

サービスごとのこと

居宅介護（家のヘルパー）
お子様を対象に含む説明書で、食事・入浴・排せつなどの介助、家事援助、通院等介助を案内。医療行為を行わないという記載もあります。計画は市町村が決めた支給量とお子様の状況・意向に沿って作り、説明・同意・写しの交付を行います。
出典：happynet.or.jp
確認日：2026年10月16日
移動支援（地域生活支援事業）
18歳未満のお子様を対象に含み、生活に必要な外出、通学・通所、余暇活動などの支援を案内しています。通常地域外の訪問交通費、外出中のヘルパーの入場料・交通費、遅いキャンセルの費用は別に確認します。行き先・目的・時間数、希望日時の担当は市と事業所へ相談してください。
出典：happynet.or.jp
確認日：2026年10月16日
行動援護・同行援護
行動援護は18歳未満の知的障害・精神障害のお子様の対象記載あり。同行援護にも児童の記載がありますが、各制度の条件は別です。
出典：happynet.or.jp
確認日：2026年10月16日
重度訪問介護の児童条件
説明書の児童対象は、15歳以上で児童相談所長が法律の規定により利用を認めた場合に限る案内です。居宅介護と同じ年齢条件にはしていません。
出典：happynet.or.jp
確認日：2026年10月16日
