けあビジョン加須（居宅介護・同行援護）

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
加須市
サービスの種類
家に来るヘルパー外出の付きそい
対象年齢
加須市は、居宅介護と同行援護をお子様も利用できるサービスとして案内しています。2025年3月31日現在の市内事業所一覧では、けあビジョン加須を居宅介護・重度訪問介護と同行援護に掲載しています。現在のお子様の受付は市と事業所へ確認してください。
ひとこと
加須市の公的一覧で、居宅介護と同行援護の事業所として確認できる支援先です。法人の現在ページで所在地・電話を、法人の障がい福祉サービスページで身体介護・家事援助・通院介助・同行援護を確認しました。
利用の条件
加須市の障がい者福祉課または各総合支所へ相談・申請し、支給決定と受給者証を確認してから事業所と契約します。同行援護は視覚障がいにより移動が難しい方への支援です。希望する介助・外出目的・日時は個別に確認してください。
利用までの流れ
加須市の窓口へ居宅介護または同行援護を相談・申請 → 支給決定・受給者証を確認 → けあビジョン加須へお子様の年齢、介助・外出内容、希望日時を相談 → 担当・負担・実費を確認 → 契約・利用。
医療的ケアについて
身体介護の一般案内から、医療的ケア、重症心身障害、重度知的障害、強度行動障害、全面介助、吸引、経管栄養、人工呼吸器への対応を推測していません。必要な支援を項目ごとに確認してください。
