けあビジョン加須（居宅介護・同行援護）

お知らせ市一覧は2025年3月31日現在です。法人全体の『可能な限り24時間365日』という案内を、加須事業所がお子様へ現在提供できる時間や空きとして扱っていません。

空きや受け入れは、かならず施設にご確認ください

利用を考えるときは

公式ページを見る加須市｜市内分野別障害福祉サービス等事業所（2025年3月31日現在）

電話0480-98-2008

確認日：2026年11月1日（あずけさき手帖が公式の情報を確かめた日）

施設のこと

地域
加須市
サービスの種類
家に来るヘルパー外出の付きそい
対象年齢
加須市は、居宅介護と同行援護をお子様も利用できるサービスとして案内しています。2025年3月31日現在の市内事業所一覧では、けあビジョン加須を居宅介護・重度訪問介護と同行援護に掲載しています。現在のお子様の受付は市と事業所へ確認してください。
ひとこと
加須市の公的一覧で、居宅介護と同行援護の事業所として確認できる支援先です。法人の現在ページで所在地・電話を、法人の障がい福祉サービスページで身体介護・家事援助・通院介助・同行援護を確認しました。
空き・受付について
2026年11月1日に加須市の制度ページ、2025年3月31日現在の市内事業所一覧、法人の現在の拠点・サービスページを確認しました。電話確認はしていません。現在のお子様の新規受付・空き、訪問・外出範囲、希望日時、担当、負担・実費、個別介助・処置は未確認です。
利用の条件
加須市の障がい者福祉課または各総合支所へ相談・申請し、支給決定と受給者証を確認してから事業所と契約します。同行援護は視覚障がいにより移動が難しい方への支援です。希望する介助・外出目的・日時は個別に確認してください。
利用までの流れ
加須市の窓口へ居宅介護または同行援護を相談・申請 → 支給決定・受給者証を確認 → けあビジョン加須へお子様の年齢、介助・外出内容、希望日時を相談 → 担当・負担・実費を確認 → 契約・利用。
医療的ケアについて
身体介護の一般案内から、医療的ケア、重症心身障害、重度知的障害、強度行動障害、全面介助、吸引、経管栄養、人工呼吸器への対応を推測していません。必要な支援を項目ごとに確認してください。
利用できる時間
法人は障がい福祉サービス全体について、可能な限り24時間365日の対応を案内しています。加須事業所の現在の担当・提供日時・空きは確認できないため、希望日時を個別に相談してください。
地域・送迎
事業所所在地は加須市久下です。実際の訪問地域、同行する出発地・目的地、市外利用は事業所へ確認してください。
料金
加須市は原則1割負担と所得区分ごとの月額上限を案内しています。交通費、外出時の実費、加算は受給者証と契約内容により異なるため、市と事業所へ確認してください。
