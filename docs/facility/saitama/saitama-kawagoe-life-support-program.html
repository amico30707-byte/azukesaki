川越市 障害児（者）生活サポート事業

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
川越市
サービスの種類
日中のあずかり外出の付きそい
対象年齢
在宅の障害のあるお子様を含む制度です。身体障害者手帳・療育手帳をお持ちの方が対象で、手帳がなくても医師の診断により利用できる場合があります。
ひとこと
市に登録した民間団体が、送迎、外出援助、一時預かり、介護者の一時派遣などを行う川越市の事業です。個別の施設や現在の空きを示す一覧ではありません。
利用の条件
先に川越市障害者福祉課で利用者登録し、サービス利用者証の交付を受けます。登録申請書は市のページから取得できます。その後、市に登録されたサービス団体へ直接申し込みます。利用できる方は居宅介護・移動支援・日中一時支援等が優先です。
利用までの流れ
川越市障害者福祉課へ相談 → 市ページの登録申請書、手帳等、18歳未満は所得確認書類を準備 → 利用者登録・サービス利用者証の交付 → 市の登録サービス団体へ直接申し込み → 支援内容・日時・実費を確認。
医療的ケアについて
市の制度ページで医療的ケアや処置別対応を確認できませんでした。登録団体ごとに吸引・経管栄養・人工呼吸器などを確認してください。
利用できる時間
利用時間は年150時間で、利用者証の交付月により異なります。登録団体ごとの曜日・時間、希望日時の受け入れは未確認です。
地域・送迎
川越市の在宅の障害児（者）向け制度です。登録団体ごとの支援地域・送迎範囲は未確認です。
料金
18歳未満は世帯の市民税所得割額により1時間0円・250円・400円・650円・850円・950円です。別途実費がかかる場合があります。
住所
埼玉県川越市元町1丁目3番地1（川越市役所 障害者福祉課）
電話
049-224-6317川越市 障害者福祉課 福祉サービス担当。生活サポート事業の対象、登録書類、利用者証、登録団体を確認してください。
