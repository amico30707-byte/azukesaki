居宅訪問型児童発達支援事業所 翼

お知らせ施設は、先に通所支援事業所と契約すると居宅訪問型児童発達支援を利用できない場合があると案内しています。契約前に市町村・相談支援・翼へ利用順を確認してください。人工呼吸器等は対象例であり、訪問中の処置実施を示すものではありません。

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
小城市
サービスの種類
通う療育
対象年齢
0歳から18歳までで、重度の障害等により外出が著しく難しく、障害児通所支援を利用するための外出が困難なお子様を対象としています。
ひとこと
言語聴覚士・看護師などがお子様のご自宅を訪問し、発達支援、日常生活の基本動作、言葉・口腔、子育ての支援を行う居宅訪問型児童発達支援です。
利用の条件
居住地の市町村へ申請し、障害児支援利用計画案、支給決定・受給者証、翼との面談・契約を経て利用します。通所支援との併用や契約順は事前確認が必要です。
利用までの流れ
居住地の市町村へ申請 → 障害児支援利用計画案を作成 → 市町村の支給決定・受給者証 → 翼と面談 → 契約・個別支援計画 → 訪問支援を開始。
医療的ケア
あり
医療的ケアについて
人工呼吸器の装着や日常的な医療の必要性を対象例として案内しています。吸引・経管栄養・人工呼吸器等を訪問中に実施するか、機器・方法・回数は未確認です。
利用できる時間
事業案内のページに「時間 9:00〜18:00」の記載がありますが、訪問の曜日は公式ページで確認できていません。訪問日時は支援計画と個別調整によるため、希望日時の受け入れや空きは要確認です。
地域・送迎
事業所は小城市三日月町にあり、ご自宅へ訪問します。訪問できる市町村・範囲は公式ページで確認できていません。
料金
利用者負担の月額上限は、生活保護・市町村民税非課税0円、市町村民税課税世帯4,600円または37,200円と案内しています。3歳から6歳までの児童発達支援の無償化も案内していますが、訪問に伴う実費は要確認です。
住所
小城市三日月町長神田1731番地18
電話
