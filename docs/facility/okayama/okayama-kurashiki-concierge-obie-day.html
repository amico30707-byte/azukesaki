施設のこと

地域
倉敷市
サービスの種類
日中のあずかり
対象年齢
日中一時支援は、合理的な配慮が必要と考えられる概ね3歳から中学生までのお子様が対象です。施設欄では概ね3歳から小学生と案内されているため、中学生の利用条件は事業所へ確認してください。
ひとこと
学童保育などで居場所を見つけにくいお子様が、放課後や学校休業日に安心して過ごすための日中一時支援です。日中型とタイムケアを分けて利用します。
空き・受付について
2026年10月15日に公式ページを読み直し、ページには2026年9月17日更新で月〜金曜各1名、土曜3名の受入可能人数が引き続き掲載されていました。これは現在の空きの電話確認ではありません。希望日とお子様ごとの受け入れは、利用前に事業所へ確認してください。
利用の条件
倉敷市が発行する受給者証が必要です。受給者証を受け取ったあと事業所へ連絡し、見学、希望に応じた体験、契約を経て利用します。
利用までの流れ
倉敷市へ受給者証を申請 → 受給者証を受け取る → 事業所へ連絡して見学日を決める → 希望に応じてお子様が体験 → 契約 → 日中型またはタイムケアで利用。
医療的ケアについて
公式ページに医療的ケア一般、吸引、経管栄養、人工呼吸器の受け入れ記載は見つかりませんでした。未確認であり、対応なしという意味ではありません。
利用できる時間
平日は放課後から18時まで。土曜・学校休業日は8時30分から18時まで。日曜・祝日、お盆・年末年始等の指定日は休みです。日中型は単独事業所だけで1日6時間、タイムケアは放課後から18時までです。
地域・送迎
施設は倉敷市帯高にあります。学校がある日の放課後は各小学校への迎えを案内しています。学校休業日の自宅への迎えと帰宅時の送りは個別調整です。利用できる学校・地域は要確認です。
料金
利用日数、日中型・タイムケア、受給者証の区分で決まります。管理費として1回100円が別にかかり、冷房・教材・外出等の実費がかかる場合があります。
