多機能型事業所 りんどう

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
岡山市南区
サービスの種類
通う療育日中のあずかり
対象年齢
児童発達支援は受給者証を持つ3歳以上の未就学児、放課後等デイサービスは受給者証を持つ小学生〜高校生です。日中一時支援は岡山市の2026年10月1日現在の名簿に掲載されていますが、日中一時支援の年齢は要確認です。
ひとこと
岡山市南区の児童発達支援・放課後等デイサービスと日中一時支援です。通所支援の年齢・時間・料金は公式ページで確認できますが、日中一時支援の条件は市名簿と事業所へ別に確認します。
利用の条件
通所支援は電話・フォームで相談し、ヒアリング、見学・体験、受給者証の申請、契約、個別支援計画の作成を経て利用を始めます。日中一時支援は、お住まいの市町村へ地域生活支援事業の利用決定を相談し、正式な事業名を伝えて事業所へ確認してください。
利用までの流れ
事業所へ相談 → ヒアリング・見学・無料体験 → お住まいの市町村へ使いたい事業の受給者証・利用決定を相談 → 契約・個別支援計画 → 利用開始。事業ごとの年齢、希望日、送迎、費用、必要な介助を確認してください。
医療的ケアについて
医療的ケア一般、吸引、経管栄養、人工呼吸器、全面介助、重症心身障害、重度知的障害、強度行動障害への対応は公開情報から確認できませんでした。療育内容から個別ケアを推測せず、項目ごとに相談してください。
利用できる時間
児童発達支援は月〜金曜10時〜12時。放課後等デイサービスは月〜金曜16時30分〜18時、長期休暇14時30分〜17時、土曜14時〜16時です。電話受付は平日9時30分〜17時です。日中一時支援の曜日・時間は未確認です。
地域・送迎
学校園・ご家庭への送迎を案内しています。下校時の送迎先として南輝小学校・芳泉小学校・操明小学校を掲載し、他の学校園は要相談です。片道15分以上が目安の遠方では、曜日・時間が限られる場合があります。日中一時支援の送迎範囲は要確認です。
料金
通所支援はサービス利用料の1割負担で、世帯収入に応じた月額上限は0円・4,600円・37,200円と案内されています。学習用テキスト、おやつ代（長期休業日のみ）などの実費がかかる場合があります。日中一時支援の負担・実費は別に確認してください。
