施設のこと

地域
宇都宮市
サービスの種類
通う療育
対象年齢
はりゆん（児童発達支援）は0歳から小学校入学前、わらゆん（放課後等デイサービス）は小学1年生から高校3年生までです。どちらも重症心身障害児の認定を受けたお子様が主な対象で、重症児スコアで超重症児・準超重症児と判定されたお子様も対象です。
ひとこと
認定NPO法人うりずんの、重症心身障害のあるお子様のための児童発達支援と放課後等デイサービス（重心型）です。主治医の指示書をもとに、吸引・経管栄養などの医療的ケアを看護師や研修を受けた介護士が行います。
空き・受付について
2026年11月11日に、はりゆん・わらゆんのページと宇都宮市の一覧を確認しました。電話確認はしていません。定員、現在の空き・新規受付、送迎の範囲は未確認です。
利用の条件
障害児通所受給者証（重症心身障害児としての支給決定）が必要です。事業所での面談、連携医療機関（ひばりクリニック）の受診、契約をへて利用します。
利用までの流れ
見学（必要に応じて） → 相談支援専門員へ相談 → 重症心身障害児としての支給決定・通所受給者証 → 事業所で面談 → ひばりクリニックの受診 → 契約・初回の日を決める → 利用開始。
医療的ケア
あり
医療的ケアについて
ページに、主治医の指示書をもとに、保護者の依頼と同意を受けて医療的ケアを行うと書かれています。はりゆん・わらゆんとも、吸引（口・鼻・気管カニューレ内）、経管栄養（胃ろう・腸ろう・経鼻）、吸入、導尿・浣腸、発作時の対応、人工呼吸器の管理をのせています（導尿・浣腸、発作時の対応、人工呼吸器の管理は看護師）。お子様ごとの受け入れや、希望日の体制は事業所へご確認ください。
利用できる時間
はりゆん：月・火・水・金曜日は9時から14時、木曜日は9時45分から14時、土曜日（予約制）は9時30分から15時30分。わらゆん：通学籍は月〜金曜日の放課後から17時、訪問籍は月・火・水・金曜日9時30分から15時30分（木曜日は9時45分から）、土曜日・長期休みは予約制で9時30分から15時30分。日曜日・祝日・お盆・年末年始は休みです。
地域・送迎
事業所は宇都宮市徳次郎町にあります。わらゆんは平日、できる範囲で学校へのお迎えがあります（家族送迎をお願いすることもあります）。利用後の自宅への送りは相談と書かれています。土曜日・長期休みは家族送迎です。はりゆんの送迎はページにのっていません。
料金
利用料の1割が自己負担で、月の上限は世帯の所得により0円・4,600円・37,200円です。はりゆんは、年少から年長までの利用料は無償化と書かれています。わらゆんは送迎を使うと送迎加算がかかります。ゆうちょ銀行からの引き落としです。
