2026年10月1日に指定された短期入所です。定員4人は現在の空き人数ではありません。県の整備計画資料と短期入所の指定一覧では住所表記が異なるため、この掲載は短期入所一覧の浅沼町150を使用しています。

利用の条件
お住まいの市町村へ短期入所の支給決定・受給者証を相談し、施設へ初回手続き、契約、希望日の申込みを確認してください。県の指定一覧への掲載だけで利用は決まりません。
利用までの流れ
お住まいの市町村へ短期入所を相談 → 支給決定・受給者証を確認 → 第二とちのみ学園へ年齢、初回手続き、希望日、必要な支援、費用を確認 → 利用日を調整。詳しい順番は要確認です。
医療的ケアについて
県一覧でお子様対象は確認しましたが、医療的ケア一般、吸引、経管栄養、人工呼吸器、全面介助、重度知的障害、強度行動障害への個別対応は確認できませんでした。必要な支援ごとに確認してください。
利用できる時間
利用できる曜日、泊数、入退所時刻、申込期間は未確認です。
地域・送迎
施設は佐野市浅沼町にあります。利用できる市町村の範囲、送迎、入退所方法は未確認です。
