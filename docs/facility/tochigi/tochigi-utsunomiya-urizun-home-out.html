うりずん 居宅介護・重度訪問介護・移動支援

施設のこと

地域
宇都宮市
サービスの種類
家に来るヘルパー外出の付きそい
対象年齢
障がいのある方が対象です。移動支援は通学・通所にも使えることや、医療的ケアは保護者の依頼と同意で行うことが書かれていますが、お子様が使えるかと年齢の条件ははっきり書かれていないため、事業所へご確認ください。重度訪問介護は重度の身体障がい・知的障がいのある方が対象です。
ひとこと
認定NPO法人うりずんの、家に来るヘルパー（居宅介護・重度訪問介護）と外出の付きそい（移動支援）です。主治医の指示書をもとに、看護師や研修を受けた介護士が吸引・経管栄養などを行うと案内しています。
空き・受付について
2026年11月11日に法人のページを確認しました。電話確認はしていません。お子様の利用、伺える地域、現在の新規受付・空きは未確認です。
利用の条件
障がい福祉サービス受給者証や、移動支援の利用決定通知書が必要です。利用は原則として曜日と時間を決めて行います。
利用までの流れ
事業所へ問い合わせ → 必要に応じて相談支援専門員（保健師など）へ相談 → 受給者証・利用決定通知書の手続き → 契約・初回の日を決める → 利用開始。
医療的ケア
あり
医療的ケアについて
ページに、主治医の指示書をもとに、本人または保護者の依頼と同意を受けて、吸引（口・鼻・気管カニューレ内）、経管栄養（胃ろう・経鼻）、吸入を行うと書かれています。お子様への対応や、移動支援の中での実施は事業所へご確認ください。
利用できる時間
居宅介護・移動支援は月曜日から金曜日の9時から18時（土日祝・お盆・年末年始は休み。時間外は相談）。重度訪問介護は年中無休・24時間対応と書かれています。
地域・送迎
事業所は宇都宮市にあります。伺える地域はページにのっていないため、事業所へご確認ください。
料金
利用料の1割が自己負担で、月の上限は0円・4,600円・37,200円のいずれかです（利用時間と世帯の所得、事業・市町村によりちがいます）。ゆうちょ銀行からの引き落としです。
