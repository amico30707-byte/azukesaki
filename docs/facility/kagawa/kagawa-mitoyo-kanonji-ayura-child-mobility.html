あゆら 移動支援（三豊市・観音寺市は要条件確認）

お知らせ2025年4月15日更新の三豊市の委託契約事業所一覧には掲載されていません。法人の開始案内は同年7月以降のため、現在の市との契約・登録とお子様の利用可否を必ず確認してください。

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
三豊市・観音寺市を提供地域に掲載（事業所は多度津町）
サービスの種類
外出の付きそい
対象年齢
三豊市の移動支援は18歳未満のお子様を含む利用者負担区分を案内しています。あゆらのページは年齢を明記していないため、お子様の利用可否と市の利用決定・契約対象を三豊市または観音寺市と事業所へ確認してください。
ひとこと
特定非営利活動法人希兵隊が運営するヘルパー事業所です。2025年7月から移動支援を開始し、三豊市・観音寺市を提供地域に含むと案内しています。事業所は西讃地域内ではなく多度津町にあります。
利用の条件
お住まいの市へ移動支援を申請し、利用決定通知書・受給者証等を確認してから事業所へ相談します。法人は三豊市・観音寺市について『利用条件があります』と案内しています。外出目的、通学・通勤、車両利用、介護タクシーとの併用条件は別に確認してください。
利用までの流れ
三豊市または観音寺市へ移動支援を相談・申請 → 利用決定・受給者証等を確認 → あゆらへ希望する外出、日時、経路、お子様の年齢・必要な介助を相談 → 市との契約対象、担当、負担・実費を確認 → 利用。
医療的ケアについて
移動支援・居宅介護・重度訪問介護の事業開始から、お子様の医療的ケア、重症心身障害、重度知的障害、強度行動障害、全面介助、吸引、経管栄養、人工呼吸器への対応を推測していません。成人向けの重度訪問介護をお子様へ当てはめていません。
利用できる時間
提供曜日・時間、学校日・休業日、早朝・夜間、現在の担当は公開ページから確認できませんでした。
地域・送迎
事業所所在地は多度津町です。移動支援の提供地域として丸亀市、坂出市、三豊市、観音寺市、善通寺市、多度津町、宇多津町を掲載しています。三豊市・観音寺市は条件付きです。
料金
利用者負担は市町村ごとに異なると法人が案内しています。三豊市は月額上限を所得区分別に案内していますが、実際の負担、交通費、車両・介護タクシー等の実費は市と事業所へ確認してください。
住所
香川県仲多度郡多度津町奥白方35番地2
電話
070-1521-5910あゆらのホームヘルパー問い合わせ。三豊市または観音寺市でお子様の移動支援を希望すると伝えてください。
確認日
2026-11-01
