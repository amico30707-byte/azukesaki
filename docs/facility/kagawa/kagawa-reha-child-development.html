施設のこと

地域
高松市
サービスの種類
通う療育
対象年齢
上肢、下肢または体幹に機能の障がいがあり、親子で通園できる就学前のお子様が対象です。
ひとこと
身体に障がいのある就学前のお子様が親子で通い、診療、リハビリ、保育、健康管理を受ける児童発達支援センターです。現在公式ページから案内されている令和7年の支援プログラムでは、医療的ケアが必要なお子様への支援も示されています。
空き・受付について
対象、親子通園、診療・リハビリ・保育、入園許可と市町村相談、体験保育、支援プログラムの営業時間と医療的ケアの一般案内は確認しました。体験できることは現在の空きを示しません。現在の空き、電話でのお子様ごとの受け入れ、利用地域、通園曜日・登降園時刻、費用、送迎、吸引・経管栄養・人工呼吸器など処置別の個別ケアは未確認です。
利用の条件
担当医師の入園許可を得たうえで、お住まいの市役所・町役場へ利用申請を相談します。入園前に月2回程度の親子での体験保育を相談できます。
利用までの流れ
こども発達支援センターへ相談 → 親子での体験保育を相談 → 担当医師の入園許可 → お住まいの市役所・町役場へ利用申請を相談 → 支給決定・契約 → 通園日を調整。
医療的ケア
あり
医療的ケアについて
現在公式ページから案内されている令和7年の支援プログラムに、医療的ケアが必要なお子様への支援と必要な医療的ケアの提供が明記されています。吸引・経管栄養・人工呼吸器など処置別の条件、通園日ごとの体制、個別の受け入れは未確認です。
利用できる時間
令和7年の支援プログラムに記載された営業時間は9時30分〜16時です。登園日数に合わせて1週間のプログラムが決まり、午前中にリハビリや保育を行います。実際の通園曜日・登降園時刻、休業日は要確認です。
地域・送迎
施設は高松市にあります。利用できる市町村、送迎の有無・範囲は公式ページで確認できていません。親子通園が条件です。
料金
障害児通所支援の自己負担、食事・活動などの実費、月額上限は公式ページで確認できていません。市町村とセンターへ確認してください。

サービスごとのこと

児童発達支援（親子通園）
身体に障がいのある就学前のお子様が親子で通い、診療、リハビリ、保育、健康管理を受けます。担当医師の入園許可と市町村への相談が必要です。支援プログラム記載の営業時間は9時30分〜16時です。

確認日：2026年10月15日
体験保育
入園を検討するお子様とご家族向けに、月2回程度の親子保育を行います。体験できることと利用決定・空きは別です。
出典：kagawa-reha.net
確認日：2026年10月15日
医療的ケアを含む支援プログラム
令和7年の支援プログラムは、医療的ケアが必要なお子様への支援と必要な医療的ケアの提供を示しています。処置別の対応と現在の個別受け入れは別に確認が必要です。
出典：kagawa-reha.net
確認日：2026年10月15日
