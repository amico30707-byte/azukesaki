施設のこと

地域
浜松市中央区
サービスの種類
家に来るヘルパー外出の付きそい
対象年齢
浜松市の主に中央区と近隣地域に住む、知的障がい・自閉症のあるお子様を対象に明記しています。
ひとこと
お子様を含む方へ、居宅介護・重度訪問介護・行動援護・移動支援を行う事業所です。自宅での食事・トイレ・入浴・就寝・家事の支援と、余暇・買い物・手続き等の外出支援を分けて案内しています。浜松市が2026年10月19日から配布した障害福祉のしおりでも、現在の事業所一覧を確認できます。
利用の条件
お問い合わせと面談後、市役所へ申請して手帳・受給者証を確認し、事業所と契約・個別支援計画を作成します。利用は前月までに予約し、ヘルパーを調整します。
利用までの流れ
事業所へ問い合わせ → 面談・状況確認 → 浜松市で手帳・受給者証の申請・交付 → 事業所と契約・個別支援計画 → 前月までに予約 → ヘルパー調整後に利用開始。
医療的ケアについて
公式ページで医療的ケアや処置別対応を確認できませんでした。吸引・経管栄養・人工呼吸器などは処置ごとに要確認です。
