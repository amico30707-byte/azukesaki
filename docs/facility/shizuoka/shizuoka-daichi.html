施設のこと

地域
袋井市
サービスの種類
通う療育日中のあずかり
対象年齢
児童発達支援は未就学、放課後等デイサービスは小学生〜高校生です。旧公式ページでは日中一時支援を障害のあるお子様向けと案内していますが、新サイトでは日中一時支援の記載が見つからず、継続と詳しい年齢条件は要確認です。
ひとこと
新しい公式ページは児童発達支援30名、放課後等デイサービス20名、保育所等訪問支援を案内しています。旧公式ページにある日中一時支援は新サイトで確認できないため、終了と決めつけず、継続を直接確認してください。定員は現在の空き人数ではありません。
空き・受付について
法人は旧サイトを2026年11月30日に閉じ、新サイトへ移す予定です。新サイトには児童発達支援・放課後等デイサービス・保育所等訪問支援が掲載されていますが、旧サイトにある日中一時支援は掲載されていません。日中一時支援の継続、空き、お子様ごとの受け入れ、電話での確認は未確認です。
利用の条件
親子通園・1日通園・重症心身障害児通園は児童発達支援の案内です。新サイトでは保育士、看護師、公認心理師、言語聴覚士、作業療法士、理学療法士、精神保健福祉士等を掲載し、給食はアレルギー・食事形態の個別対応を案内しています。これを日中一時支援の対象・ケア・食事条件へ広げず、事業別におたずねください。
利用までの流れ
旧公式ページの児童発達支援案内は、市へ申請 → 相談支援事業所で利用計画案 → 支給決定 → 見学・面談 → 契約 → 利用開始です。新サイトには見学・問い合わせフォームがあります。日中一時支援の継続、申請・契約・予約の手順は別に確認してください。
医療的ケアについて
新サイトに看護師等の専門職員と重症心身障害児通園の記載がありますが、吸引・経管栄養・人工呼吸器の対応は未確認です。日中一時支援でのケアも別に確認してください。
利用できる時間
2026年11月30日まで公開予定の旧公式ページでは、通う支援は月〜金、児童発達支援9〜14時、放課後等デイは学校終了後〜17時、学校休業日10〜15時、延長・送迎は要相談と案内しています。新サイトでは直通電話の受付9〜17時を確認できますが、支援の提供時間と同じとは扱いません。日中一時支援の曜日・時間は未確認です。
地域・送迎
事業所は袋井市にあります。利用対象の市町村と送迎範囲は要確認です。
料金
新サイトと旧サイトで、事業ごとの利用料、給食・延長・送迎などの費用は確認できないため、利用前に要確認です。
