清水町 障害者日中一時支援事業

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
清水町
サービスの種類
日中のあずかり
対象年齢
身体・知的・精神に障害があり手帳の交付を受けているお子様を対象に含みます。手帳がない場合は、事業の必要性が分かる医師の意見書を提出して相談できます。
ひとこと
ご家族の就労や一時的な休息のため、お子様が宿泊せず日中に過ごす場所と見守りを相談する清水町の制度です。
利用の条件
清水町福祉介護課へ申請書と障害者手帳を提出します。手帳がない場合は事前相談の上、必要性が分かる医師の意見書を用意します。利用する事業所と希望日は別に調整してください。
利用までの流れ
清水町福祉介護課へ相談 → 申請書と手帳、必要な場合は医師の意見書を提出 → 利用決定を確認 → 登録事業所へ年齢、希望日時、送迎、食事、介助、個別ケアを確認 → 利用。
医療的ケアについて
料金表に重度心身障害児の区分がありますが、現在の登録事業所や、吸引、経管栄養、人工呼吸器、全面介助等の処置別受け入れを示すものではありません。
利用できる時間
2026年4月1日から1人あたり月80時間が上限です。1回4時間まで、6時間まで、6時間超の料金区分がありますが、事業所ごとの曜日・時間と希望日の空きは要確認です。
地域・送迎
清水町の制度です。登録事業所の所在地と利用対象地域、送迎範囲は町と事業所へ確認してください。
料金
原則1割負担です。重度心身障害児以外は1回240〜560円、重度心身障害児は480〜1,450円の時間区分です。市町村民税非課税世帯と生活保護世帯は無料です。食費等は全額自己負担です。現在額とお子様の区分は町へ確認してください。
住所
静岡県駿東郡清水町堂庭210番地の1
お知らせ
放課後等デイサービス・児童発達支援事業所の延長預かりは、日中一時支援ではなく通所支援の延長支援として案内されています。利用中の事業所へ確認してください
