長泉町 移動支援・日中一時支援

空きや受け入れは、かならず施設にご確認ください

利用を考えるときは

公式ページを見る長泉町｜さまざまな支援サービス（地域生活支援事業）

電話055-989-5512

確認日：2026年10月25日（あずけさき手帖が公式の情報を確かめた日）

施設のこと

地域
長泉町
サービスの種類
外出の付きそい日中のあずかり
対象年齢
外出が難しい障害児を含む移動支援と、在宅の障害児を含む日中一時支援です。手帳または発達障害等の条件があり、お子様ごとの対象は町へ確認してください。
ひとこと
長泉町のお子様が、外出の付き添いと、宿泊しない日中の見守り・活動場所を相談する地域生活支援事業です。
空き・受付について
2026年10月25日に長泉町の制度ページ、2026年度福祉事業所マップ、子育て支援ガイドを確認し、お子様を含む移動支援・日中一時支援、月30時間・月20日の上限、原則1割・非課税世帯免除、相談窓口を再確認しました。現在の空き、新規受付、事業所別の年齢・地域・曜日・時間、送迎・実費、電話でのお子様ごとの受け入れ、個別ケアは未確認です。
利用の条件
長泉町福祉保険課へ申請し、手帳等を確認します。町の登録事業所一覧から候補を探し、事業所へ対象年齢、希望日時、送迎、必要な介助を確認して契約します。
利用までの流れ
長泉町福祉保険課へ相談 → 申請書・手帳等を提出 → 利用決定内容を確認 → 登録事業所一覧から候補を探す → 年齢、地域、希望日時、送迎、介助内容、実費を事業所へ確認 → 契約・利用。
医療的ケアについて
町の制度ページと事業所マップから、登録事業所ごとの看護体制、医療的ケア一般、吸引、経管栄養、人工呼吸器、全面介助を確認できませんでした。
利用できる時間
移動支援は原則1日の範囲内の外出で月30時間まで。日中一時支援は月20日まで。事業所別の曜日・時間・希望日の受け入れは要確認です。
地域・送迎
長泉町の制度です。登録事業所の所在地と利用対象地域は同じとは限らないため、町外事業所を含む対応地域を別に確認してください。
料金
原則1割負担。非課税世帯は自己負担分が免除されると案内されています。食事、交通、送迎等の実費は事業所へ確認してください。

サービスごとのこと

移動支援
社会生活上必要な外出や余暇活動など、原則1日の範囲内の外出を支えます。通勤・通学は原則対象外、月30時間まで、原則1割負担です。
出典：town.nagaizumi.lg.jp
確認日：2026年10月25日
日中一時支援
在宅の障害児・者に活動場所と一時的な見守りを提供し、ご家族の就労と日中の負担軽減を支えます。宿泊を伴わず、月20日まで、原則1割負担です。
出典：town.nagaizumi.lg.jp
確認日：2026年10月25日
登録事業所の探し方
町の2026年度子育て支援ガイドでも、特別な支援が必要なお子様向けに日中一時支援・移動支援を案内しています。登録事業所一覧と2026年度福祉事業所マップから候補を探し、サービス、年齢、希望日時、現在の空きを事業所へ直接確認します。
出典：town.nagaizumi.lg.jp
確認日：2026年10月25日
