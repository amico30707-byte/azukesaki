練馬区立こども発達支援センター（ひかり・なないろ）

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
東京都練馬区
サービスの種類
通う療育日中のあずかり
対象年齢
通所支援は発達相談・医療相談で支援が必要と判断された18歳までのお子様が対象です。重症心身障害児向けの児童発達支援は2〜5歳、放課後等デイサービスは小学生〜高校生。一時あずかり『なないろ』は練馬区内の1歳6か月〜小学校6年生が対象です。
ひとこと
重症心身障害児向けの児童発達支援・放課後等デイサービスと、保護者の病気・休養・行事などに使う障害児一時あずかりを行う区立施設です。療育と一時あずかりは、対象・時間・手続きが別です。
利用の条件
通所支援は発達相談・医療相談から支援の必要性を確認します。ちゅうりっぷ組は、単独通所ができる4歳以上の重症心身障害児（医療的ケアが必要なお子様を含む）について、お子様だけの通所にも対応します。なないろは利用相談、親子面談、事前登録のあとに予約し、医療的ケアが必要なお子様は事前相談が必要です。
利用までの流れ
療育：発達相談・医療相談 → 支援の必要性を確認 → クラスと利用条件を相談。なないろ：電話で利用相談 → 親子面談と必要書類 → 登録カード発行 → 前月初日の平日9時から前日正午までオンライン予約 → 利用。当日の申請書・連絡票と料金が必要です。

あり
医療的ケアについて
児童発達支援ちゅうりっぷ組は医療的ケアが必要な重症心身障害児を含み、単独通所ができる4歳以上はお子様だけの通所にも対応すると案内しています。なないろは医療的ケアが必要なお子様を事前相談とし、受け入れを保証していません。処置別対応は未確認です。
