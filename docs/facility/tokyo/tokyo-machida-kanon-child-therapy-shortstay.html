地域生活支援センターかのん 児童発達支援・放課後等デイ・短期入所

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
町田市
サービスの種類
通う療育お泊まり（短期入所）
対象年齢
児童発達支援は障がいのある未就学のお子様、放課後等デイサービスは障がいのある就学中のお子様が対象です。短期入所は障がいのある方が対象ですが、2026年10月25日の公式案内では新規受付をお子様に限っています。
ひとこと
児童発達支援、放課後等デイサービスと、宿泊する短期入所を同じ事業所で行います。事業ごとに対象と新規受付が異なり、短期入所の空きカレンダーは契約済みの方へ向けた案内です。
利用の条件
町田市の障害児通所支援・短期入所の相談と申請を行い、支給決定・受給者証等を確認したうえで事業所へ申し込みます。事業所への申込みでは、お子様の氏名・性別・年齢・学校等・お住まいの地域・連絡先を伝え、放課後等デイサービスは希望曜日も相談します。
利用までの流れ
お住まいの地域の障がい者支援センター等へ相談 → 町田市へ申請 → 支給決定・受給者証等を確認 → かのんへ事業名、お子様の年齢・住所・学校等、希望曜日や宿泊希望日、必要な支援を伝える → 見学・契約・日程調整。
医療的ケアについて
医療的ケア一般、吸引、経管栄養、人工呼吸器、看護師配置等の処置別対応は公式ページで確認できません。障がい児通所支援・短期入所の実施から個別ケアを推測していません。
利用できる時間
児童発達支援の支援プログラムは平日9時〜15時、放課後等デイサービスは平日9時〜18時・学校休業日9時〜16時と案内しています。短期入所の入退所時刻と泊数は要確認です。
地域・送迎
事業所は町田市にあります。通所の送迎範囲、町田市外からの通所利用、短期入所の詳しい利用地域は公式ページで確認できず、要相談です。
料金
障害児通所支援・短期入所の制度負担と、食費・日用品等の実費は町田市と事業所へ確認してください。公式ページでは、お子様ごとの支払額や追加費用を確認できませんでした。
