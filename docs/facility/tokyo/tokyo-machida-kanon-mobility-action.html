地域生活支援センターかのん 移動支援・行動援護

新規受付を休止中2026年10月25日の公式ページ確認では、移動支援・行動援護の新規受付は休止中です。

空きや受け入れは、かならず施設にご確認ください

利用を考えるときは

公式ページを見るNPO法人はとぽっぽ｜地域生活支援センターかのん

電話042-736-4239

確認日：2026年10月25日（あずけさき手帖が公式の情報を確かめた日）

施設のこと

地域
町田市
サービスの種類
外出の付きそい
対象年齢
町田市の移動支援は、一人での外出が難しい中学生以上の方が対象です。手帳・障がいの状態などの要件があります。かのんの行動援護のお子様の詳しい条件は要確認です。
ひとこと
町田市の移動支援と行動援護で、ガイドヘルパーが外出に同行し、道案内、移動、外出中の身の回りの介助を行います。2026年10月25日の確認では、移動支援・行動援護とも新規受付をしていません。
空き・受付について
2026年10月25日の公式ページ確認では、移動支援・行動援護の新規受付は休止中です。既存利用者の希望日時、再開時期、電話でのお子様ごとの受け入れ、実費、処置別対応は未確認です。短期入所は児童のみ新規受付可と別に案内されていますが、この外出支援の受付状況へ混ぜていません。
利用の条件
移動支援はお住まいの地域の障がい者支援センターへ申請し、認定・支給決定後に町田市登録事業者と契約します。行動援護の支給を受けている方は町田市移動支援の対象外です。利用する事業を分けて相談してください。
利用までの流れ
町田市の移動支援は、障がい者支援センターへ申請 → 認定・支給決定通知 → 登録事業者と契約 → ヘルパー派遣を依頼 → 支給管理票で時間を管理。新規申請は利用したい月の前月15日までですが、かのんは現在新規受付をしていません。
医療的ケアについて
吸引、経管栄養、人工呼吸器などの処置別対応は確認できていません。移動・身の回りの介助の案内から医療的ケアを推測していません。
利用できる時間
移動支援は月20時間までで、1回の時間制限はありませんが、宿泊を伴う外出には使えません。事業所の対応曜日・時間は要確認です。
地域・送迎
事業所は町田市にあります。移動支援は町田市の制度です。行動援護で対応できる地域は要確認です。
料金
町田市の移動支援利用料は無料です。交通費・入場料等はヘルパー分も利用者負担です。行動援護の制度負担と実費は別に確認してください。
