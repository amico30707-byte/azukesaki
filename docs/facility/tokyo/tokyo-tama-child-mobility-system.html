多摩市 お子様の移動支援（2026年度通学利用の見直し）

お知らせこれは市の制度・申請窓口です。移動支援事業所の現在の受付・空き・担当可能日時を示す掲載ではありません。通学利用は対象となる学級等が限られます。

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
多摩市
サービスの種類
外出の付きそい
対象年齢
愛の手帳・精神障害者保健福祉手帳を持つ方、手帳がなくても診断書で発達障害等が確認できる方、身体障害者手帳1・2級で下肢・体幹機能障害があり外出に車いすが必要な方を対象に含みます。小学生・中学生は月10時間、高校生は月20時間以内です。
ひとこと
多摩市で、屋外での移動が難しい障がいのあるお子様の外出支援を申請する入口です。2026年度から、条件を満たす市立小・中学校の通学区域外特別支援学級への通学等が一部対象になりました。市の制度案内であり、支援する事業所そのものではありません。
利用の条件
社会生活上必要な外出や社会参加のための外出が対象です。通年・長期の通学等は原則対象外ですが、2026年度から、単独通学とお父様・お母様等の付き添いが難しく、通学区域外にある市立小・中学校の特別支援学級へ通う場合は一部利用できます。通常学級、特別支援教室、通級指導教室、特別支援学校、通学区域内の特別支援学級は対象外です。
利用までの流れ
多摩市障害福祉課へ相談 → 手帳または診断書、本人確認書類を用意して申請 → 対象・支給時間・通学利用の条件を確認 → 決定後、実施事業所へ外出目的、学校、希望日時、地域、介助、実費を相談 → 毎年3月31日の有効期限前に更新を確認。
医療的ケアについて
市の制度案内から、重症心身障害、重度知的障害、強度行動障害、全面介助、吸引、経管栄養、人工呼吸器への事業所別対応は確認できませんでした。手帳・診断書・身体要件は、個別ケアの受け入れを示すものではありません。
利用できる時間
小学生・中学生は月10時間、高校生は月20時間以内です。これは支給上限であり、事業所の営業時間や希望日時の空きではありません。
地域・送迎
多摩市の制度です。実際の外出地域、学校、担当事業所、交通手段は市と事業所へ確認してください。
料金
市民税課税世帯は事業費の1割です。対象区分により30分100円または150円、市民税非課税世帯・生活保護世帯は無料です。交通費等の実費は事業所へ確認してください。
住所
申請・相談窓口：東京都多摩市関戸6丁目12番地1 多摩市役所 障害福祉課（支援場所ではありません）
電話
042-338-6847多摩市 障害福祉課 相談支援担当。対象、通学利用、申請、現在の実施事業所を確認してください。
確認日
2026年10月31日
