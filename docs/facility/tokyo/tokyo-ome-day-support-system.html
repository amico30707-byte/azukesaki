空き・受付について

利用の条件
青梅市障がい者福祉課へ相談・申請し、調査と利用決定を受けて地域生活支援事業受給者証の交付後、実施事業所と契約します。市は、地域生活支援事業だけを利用する場合はサービス等利用計画案が不要と案内しています。制度の決定だけでは希望日時の受け入れは決まりません。
利用までの流れ
青梅市障がい者福祉課へ相談・申請 → 市の調査・利用決定 → 地域生活支援事業受給者証を受け取る → 実施事業所を確認して契約 → 希望日時と介助内容を事業所へ相談。地域生活支援事業だけを利用する場合はサービス等利用計画案が不要です。オンライン手続きは受給者証の再交付で、新規申請とは分けて案内されています。
