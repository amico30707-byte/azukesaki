羽村市 居宅介護・移動支援・日中一時支援

サービスの種類

対象年齢
羽村市の案内は、障害のあるお子様を福祉サービスの対象に含みます。居宅介護・移動支援・日中一時支援を利用できるかは、市が生活状況、必要な支援、申請内容を確認して決定します。
ひとこと
羽村市のお子様が、ご家庭での介助、外出の付き添い、宿泊しない日中の見守りを相談する制度です。2026年9月30日公開の2025年度事務報告では、2026年3月31日時点の支給決定数と年度の利用実績が障害者・障害児別に示されています。
利用の条件
羽村市障害福祉課へ相談し、申請書等の提出と聞き取り、サービス利用計画、必要な場合は区分認定を経て受給者証の交付を受けます。その後、事業所へ連絡して契約します。
利用までの流れ
羽村市障害福祉課へ相談 → 申請・聞き取り → サービス利用計画 → 必要な場合は区分認定 → 受給者証の交付 → 事業所へ年齢、地域、希望日時、介助内容、費用を確認 → 契約・利用。
医療的ケアについて
市の制度案内から、事業所ごとの看護体制、医療的ケア一般、吸引、経管栄養、人工呼吸器、全面介助の受け入れを確認できませんでした。必要なケアは市への相談時と事業所との契約前に伝えてください。
利用できる時間
2025年度事務報告では、2026年3月31日時点のお子様の支給決定数は移動支援9人、日中一時支援4人です。年度の移動支援実績は実利用2人・延べ284.5時間、日中一時支援は実利用0人・0回でした。過去1年度の集計であり、現在の支給量、事業所の営業時間・空き・希望日の受け入れを示しません。
地域・送迎
羽村市の制度です。事業所の所在地、訪問・外出地域、送迎範囲は同じとは限らないため、契約前に確認してください。
料金
サービスの利用者負担があります。市の案内だけでは制度別の負担上限、交通費・食費等の実費を確認できないため、受給者証、市、事業所へ確認してください。
