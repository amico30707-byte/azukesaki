神奈川県立こども医療センター 重症心身障害児施設 ひだまり

空きや受け入れは、かならず施設にご確認ください

利用を考えるときは

公式ページを見る神奈川県立こども医療センター｜ひだまりの短期入所・対象・申込手順

電話045-711-2351

確認日：2026年10月14日（あずけさき手帖が公式の情報を確かめた日）

施設のこと

地域
横浜市南区
サービスの種類
お泊まり（短期入所）
対象年齢
入所時18歳未満で、神奈川県内に住む重症心身障害児が対象です。重心認定、または短期入所（重症心身障害児）・医療型児童入所支援等の支給決定が必要です。
ひとこと
ご自宅で暮らす重症心身障害児を一時的に預かり、健康管理、食事、入浴、排せつ、日中活動などを支える短期入所です。相談・見学・受診・聞き取りを経て申し込みます。
空き・受付について
申し込みは先着順ではなく、希望多数の場合は利用できないことがあります。現在の空き、希望日の利用、個別処置の受け入れ、電話でのお子様ごとの確認は未確認です。
利用の条件
公式ページの対象条件すべてに当てはまる必要があります。初回は生活支援課へ相談し、施設見学、神経内科受診、来所での聞き取りを行います。申し込み後、入所調整会議で利用者が決まり、先着順ではありません。
利用までの流れ
生活支援課へ相談 → 施設見学 → 神経内科受診・来所聞き取り → 利用月の2か月前の25日までに申し込み → 入所調整会議 → 医療的ケア・生活の聞き取り → 利用。
医療的ケア
あり
医療的ケアについて
施設は医療的ケアの重さに関わらず在宅支援を行う方針を掲げ、人工呼吸器、気管切開、持続注入、胃ろう等への医療面の対応も案内しています。ただし、希望日の処置別受け入れは申し込み前に個別確認が必要です。
利用できる時間
申込電話は平日13〜16時、来所は平日9〜16時です。利用月の2か月前の25日までに申し込み、前月10日ごろまでに可否の連絡があります。入所時刻は原則9〜10時です。
地域・送迎
神奈川県内に住む方が対象です。施設は横浜市南区にあります。県外からの利用は対象条件に含まれていません。
料金
負担額はお子様ごとに異なるため、生活支援課へ確認する案内です。2026年6月1日から短期入所の食事療養費は1食730円、流動食のみの場合は665円です。制度利用の負担と食費等を分けて確認してください。
住所
神奈川県横浜市南区六ツ川2-138-4
電話
045-711-2351ひだまり生活支援課（内線2770）。初回相談は平日9〜16時。
