横浜市多機能型拠点こまち

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
横浜市瀬谷区
サービスの種類
日中のあずかり通う療育家に来るヘルパー外出の付きそいお泊まり（短期入所）
対象年齢
日中一時支援は医療的ケアのあるお子様など。放課後等デイは学校に通う医療的ケアのある重症心身障害のお子様。宿泊しない医療型特定短期入所は医療的ケアのある重症心身障害児等、宿泊する福祉型強化短期入所は医療的ケアのある障害児者（未就学児から）が対象です。居宅介護などもお子様の案内があります。
ひとこと
医療的ケアのあるお子様の日中のあずかり、宿泊しない医療型特定短期入所、最大2泊3日の福祉型強化短期入所、放課後の支援、家や外出のヘルパーを案内しています。
利用の条件
事業ごとに地域・時間・送迎の条件が異なります。日中一時支援と宿泊しない医療型特定短期入所は初回の契約が必要です。福祉型強化短期入所は横浜市の短期入所の支給決定が必要で、生活介護・医療型特定短期入所・放課後等デイサービスなど、普段から顔の見える事業の利用をお願いする案内があります。2026年8月24日付で11〜12月の開所予定日が公表され、開所日以外や緊急のご家族の休息も相談する案内ですが、希望日の空きや利用決定を示すものではありません。ヘルパーは市の支給決定などを確認してください。
利用までの流れ
使いたい事業を伝えて相談 → 地域・年齢・ケア・支給決定・書類を確認 → 事前契約 → 利用希望月の2か月前の1〜10日に申込み → 施設の調整 → 利用希望月の1か月前の初旬〜中旬に文書で決定。希望日に利用できるとは限りません。

医療的ケアについて
日中一時支援・放課後等デイ・居宅支援・2種類の短期入所に医療的ケアの案内があります。宿泊しない医療型特定短期入所には酸素・気管切開・人工呼吸器による呼吸管理等、宿泊する福祉型強化短期入所には気管切開・人工呼吸器等の記載があります。外出中の処置は未確認です。吸引は居宅支援の記載に限り、ほかの事業へ広げて判断しないでください。経管栄養の方法も個別に確認してください。
