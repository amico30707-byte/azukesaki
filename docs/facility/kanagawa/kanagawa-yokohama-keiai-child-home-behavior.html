敬愛 障がい者居宅介護事業所

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
横浜市中区
サービスの種類
家に来るヘルパー外出の付きそい
対象年齢
障害福祉情報サービスかながわは、居宅介護と行動援護の主な対象に障害児を明記しています。重度訪問介護は成人等の対象表示であり、お子様向けとしてこの検索条件へ含めていません。
ひとこと
障がいのあるお子様を対象に含む居宅介護と行動援護の事業所です。居宅介護では身体介護、家事援助、通院等介助を掲載しています。行動援護は2026年5月1日指定です。
利用の条件
お住まいの区福祉保健センター等へ相談し、使いたい居宅介護・行動援護の対象、申請、支給決定を確認した後、事業所へ年齢、訪問地域、頼みたい介助、希望日時を相談してください。
利用までの流れ
区福祉保健センター等へ相談 → 居宅介護・行動援護の対象と申請を確認 → 支給決定・受給者証を確認 → 事業所へ年齢、地域、希望日時、介助を相談 → 費用・実費と担当可否を確認 → 契約・利用。
医療的ケアについて
身体介護や通院等介助の掲載から、重症心身障害、重度知的障害、強度行動障害、全面介助、吸引、経管栄養、人工呼吸器等の対応を推測していません。行動援護の指定も、強度行動障害のあるすべてのお子様の受け入れを確約するものではありません。
利用できる時間
居宅介護は平日・土曜9時〜18時、行動援護は平日9時〜18時を掲載しています。これは事業所の営業情報であり、希望日時に担当できる意味ではありません。
地域・送迎
居宅介護・行動援護とも、横浜市西区・中区・南区・港南区を実施地域として掲載しています。区外や市外は未確認です。
料金
障害福祉サービスの利用者負担、月額上限、交通費等の実費は、確認した事業所ページでは確認できませんでした。区の窓口と事業所へ確認してください。
