お泊まり（短期入所）
対象年齢
公式案内の障害児欄は18歳以下。重症心身障害、または医療的ケアのスコア16点以上のお子様
ひとこと
重症心身障害や医療的ケアのあるお子様の、医療型のお泊まりを案内しています。
空き・受付について
空きは未確認・施設へお問い合わせください
利用の条件
受給者証に「医療型短期入所」の支給決定が必要です。事前診察・紹介状・面談・日帰り体験を経て利用します。お子様の状態によっては利用が難しい場合があります。18歳の方はどの対象区分になるか確認してください。
利用までの流れ
電話相談 → 紹介状を用意し診察・見学・面談 → ご家族同伴の日帰り体験 → ご本人の日帰り体験 → 1泊2日から利用。
