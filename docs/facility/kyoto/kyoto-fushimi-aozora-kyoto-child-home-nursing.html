訪問看護ステーション あおぞら京都（医療法人財団はるたか会）

空きや受け入れは、かならず施設にご確認ください

利用を考えるときは

公式ページを見るはるたか会｜訪問看護ステーション あおぞら京都

電話075-748-7355

確認日：2026年11月11日（あずけさき手帖が公式の情報を確かめた日）

施設のこと

地域
伏見区
サービスの種類
家に来るヘルパー
対象年齢
0〜100歳が対象で、お子様の利用が7割以上と案内しています。
ひとこと
お子様の利用が7割以上の訪問看護ステーションです。重い障がいや、たくさんの医療的ケアがあるお子様とご家族を支えると案内しています。在宅酸素や人工呼吸器などの医療機器の管理、発達の支援などをしています。
空き・受付について
空き、訪問できる曜日・時間、長い時間の訪問（在宅レスパイト）、料金、電話での確認は未確認です。
利用の条件
医療保険の訪問看護には、主治医の「訪問看護指示書」が必要です。お子様の状態と必要なケアを、ステーションへ相談してください。
利用までの流れ
主治医に訪問看護を相談 → 訪問看護指示書を書いてもらう → ステーションへ連絡・面談 → 契約 → 訪問の開始。医療保険でも介護保険でも、かかりつけ医の指示書が必要と案内しています。
医療的ケア
あり
医療的ケアについて
公式ページで、医療機器の管理として在宅酸素・人工呼吸器をあげています。京都府の小児リハビリテーション施設情報（令和7年度版）では、医療的ケアについて「どんな医療ケアも対応します」と書かれています。お子様ごとのケアと、希望の時間に訪問できるかは、ステーションへご確認ください。家族が休むための長い時間の訪問（在宅レスパイト）は、公式ページに書かれていません。
利用できる時間
訪問できる曜日と時間は公式ページに書かれていないため、要確認です。
地域・送迎
京都市南部を中心に、市内全域へ訪問していると案内しています。
料金
医療保険などの自己負担があります。金額と、子どもの医療費の助成が使えるかは、ステーションと市区町村へご確認ください。
住所
京都市伏見区奈良屋町408番地 香珠マンション303号室
