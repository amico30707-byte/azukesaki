施設のこと

地域
秋田市
サービスの種類
通う療育日中のあずかりお泊まり（短期入所）
対象年齢
ニコリアは0歳から就学前のお子様が対象です。医療型短期入所は支給を受けた重症心身障害児（者）、福祉型短期入所と日中一時支援は身体障害児が対象です。
ひとこと
親子で通う児童発達支援と、医療型・福祉型の短期入所、宿泊しない日中一時支援を行っています。
空き・受付について
現在の空きは未確認です。2024年度の定員7名以内、契約者141人、年間利用実績は、2026年10月28日の空き人数ではありません。申込後に利用可否の連絡があり、病床・体調・必要な処置等により利用できない場合があります。電話で希望日や個別ケアを確認していません。
利用の条件
ニコリアはセンター受診、説明、療育体験、市町村への申請、通所受給者証、契約の順です。短期入所等は原則として身体障害者手帳が必要で、市町村の受給者証、センター受診、契約、事前申込を行います。
利用までの流れ
療育は受診 → 説明・体験 → 市町村申請 → 通所受給者証 → 契約。短期入所等は市町村の受給者証 → センター受診 → 契約 → 事前申込。秋田市の日中一時支援は、市障がい福祉課へ申請 → 支給決定・通知 → 事業所と契約 → 希望日を事前連絡、の順です。
医療的ケア
あり
医療的ケアについて
医療型短期入所を行うことは公式に確認できました。2024年度業務概要では、医療型障害児入所施設ひばり病棟の長期入所者は全面介助が必要で、人工呼吸器管理から経管栄養までのケアがあること、同じ病棟に空床型短期入所3床があることが掲載されています。ただし、病棟全体の説明を、短期入所を希望するお子様の吸引・経管栄養・人工呼吸器の受け入れ可とは扱いません。処置ごとに要相談です。日中一時支援へ医療型短期入所の条件を広げていません。
利用できる時間
短期入所・日中一時支援は2か月先まで予約できます。連続利用は原則7日間です。利用可否は原則、利用希望日の前月中旬〜下旬ごろに連絡されます。総合相談の受付は平日9〜16時です。ニコリアの2025年4月1日更新案内では、午前保育は10〜13時、1日保育は10〜14時30分、個別指導は9時30分〜10時または14時30分〜15時です。ひつじグループは希望日に主に個別指導を行う案内です。現在の曜日・時間は申込み前に確認してください。
地域・送迎
所在地は秋田市。利用できる地域、通園・送迎範囲は要確認です。
料金
短期入所は制度による自己負担、食事・日用品などの実費が要確認です。秋田市の日中一時支援（短期入所型）は、4時間以下150円、4時間超8時間以下300円、8時間超450円で、原則月6単位までです。市民税非課税世帯・生活保護受給中の方は無料ですが、食費等の実費は別です。市外など別の制度条件はお住まいの市町村へ確認してください。変更・キャンセルはセンターの案内で原則、前日15時30分まで、当日は9時までです。締切後は食事代などの実費がかかることがあります。

サービスごとのこと

児童発達支援センターニコリア
0歳から就学前のお子様とご家族が一緒に通います。受診、説明、集団または個別療育の体験、市町村申請、契約の順に進みます。2025年4月1日更新の案内では午前保育10〜13時、1日保育10〜14時30分、個別指導の時間帯も掲載されています。現在のグループと曜日・時間は確認してください。
出典：airc.or.jp
確認日：2026年10月16日
短期入所（医療型・福祉型）
医療型は重症心身障害児（者）の日帰り・宿泊、福祉型は身体障害児の宿泊が対象です。2024年度業務概要の定員は短期入所・日中一時支援を合わせて7名以内、2025年3月末の契約者は141人、2024年度の短期入所利用は延べ106人・310サービス日です。定員・契約者数・年間実績は現在の空きではありません。病棟全体の人工呼吸器管理・経管栄養の説明も、お子様ごとの短期入所受け入れ保証ではありません。
出典：airc.or.jp
確認日：2026年10月28日
日中一時支援（短期入所型）
宿泊しない支援です。同じ施設の『日中利用の医療型短期入所』とは別の制度名として表示します。秋田市の制度では、障害のあるお子様も対象に含み、同センターは1日の受入可能人数5人と掲載されています。これは現在の空き人数ではありません。秋田市以外の対象・負担はお住まいの市町村へ確認してください。
出典：city.akita.lg.jp
確認日：2026年10月28日
