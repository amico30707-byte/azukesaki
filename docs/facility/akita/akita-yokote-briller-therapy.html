ブリエ十文字 児童発達支援・放課後等デイサービス

確認日：2026年10月19日（あずけさき手帖が公式の情報を確かめた日）

施設のこと

地域
横手市
サービスの種類
通う療育
対象年齢
児童発達支援は0〜6歳の就学前のお子様、放課後等デイサービスは小学1年生〜高校3年生が対象です。児童発達支援は、重症心身障害や医療的ケアが必要なお子様も対象に含みます。
ひとこと
就学前の療育と、就学中のお子様の放課後等デイサービスを行います。横手市の空き案内は事業ごとに分かれているため、希望する事業名を伝えて確認します。
空き・受付について
横手市の現在ページでは、児童発達支援は空きなし、放課後等デイサービスは空きありです。ただし本文は2026年9月1日現在、添付一覧は10月1日現在と基準日の表記が分かれ、市も最新は各事業所へ確認するよう案内しています。電話での最新状況、希望日、送迎、個別ケア、人工呼吸器等は未確認です。
利用の条件
施設へ問い合わせ・見学相談 → 市役所窓口で手続き → 施設と契約 → 利用。受給者証、希望日、送迎、必要なケアを事業ごとに確認してください。
利用までの流れ
ブリエ十文字へ希望する事業を伝えて問い合わせ → 見学・相談 → 市役所窓口で受給者証等を手続き → 契約 → 希望日・送迎・費用・必要なケアを確認して利用。
医療的ケア
あり
医療的ケアについて
児童発達支援は医療的ケアが必要な未就学のお子様を対象に含み、喀痰吸引・経管栄養等を明記しています。放課後等デイサービスは医療的ケア一般を案内していますが、処置別の対応は未確認です。人工呼吸器、全面介助、強度行動障害の個別対応は未確認です。
利用できる時間
児童発達支援は9時〜16時（時間外8時30分〜18時）、放課後等デイサービスは9時〜18時（時間外8時30分〜19時）。いずれも日曜・祝日・年末年始は休みです。提供時間は希望日の空きを示しません。
地域・送迎
横手市十文字町に所在します。利用できる市町村と送迎範囲は、希望する事業と住所を伝えて確認してください。
料金
受給者証と事業所体制に基づく利用料・各種加算です。詳しい自己負担、給食・活動等の実費は施設と市へ確認してください。
