居宅介護 愛あい

お知らせ看護師や喀痰吸引等研修修了者の在籍は、吸引等が必要なお子様の現在の受け入れを確約する情報ではありません

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
宮古島市
サービスの種類
家に来るヘルパー外出の付きそい
対象年齢
法人公式ページは、介護が必要な障がい者・児を対象に居宅介護等を行うと明記しています。年齢、障害支援区分に相当する支援の度合、受給者証等は市と事業所へ確認してください。
ひとこと
宮古島市で、障がいのあるお子様・成人のご自宅を訪問し、入浴・排せつ・食事、家事等を支える居宅介護と、視覚障害のある方の同行援護を行う事業所です。
利用の条件
宮古島市障がい福祉課へ居宅介護・同行援護を相談・申請し、支給決定・受給者証を確認した後、事業所へ年齢、訪問地域、介助、外出目的、希望日時を相談してください。
利用までの流れ
宮古島市障がい福祉課へ相談 → 居宅介護・同行援護の対象、申請、支給決定を確認 → 受給者証を確認 → 愛あいへ年齢、地域、日時、介助・外出目的を相談 → 費用・実費と担当可否を確認 → 契約・利用。
医療的ケアについて
看護師、強度行動障害支援者養成研修修了者、喀痰吸引等研修修了者等の在籍を掲載していますが、重症心身障害、重度知的障害、強度行動障害、全面介助、吸引、経管栄養、人工呼吸器等のお子様の受け入れや処置別対応は未確認です。
利用できる時間
月〜土曜8時30分〜17時30分。こどもの日、お盆送り日、12月30日〜1月3日を除きます。時間外も可能な限り相談に応じる案内ですが、希望日時の担当可否は未確認です。
地域・送迎
事業所所在地は宮古島市平良久貝です。宮古島市内の訪問地域、離島・遠隔地、外出先の範囲、送迎は公式ページで確認できませんでした。
料金
障害福祉サービスの利用者負担、月額上限、交通費・入場料等の実費は確認したページでは確認できませんでした。市と事業所へ確認してください。
