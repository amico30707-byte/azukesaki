うるま市 移動支援事業

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
うるま市
サービスの種類
外出の付きそい
対象年齢
うるま市にお住まいの障がい者・障がい児が対象です。屋外での移動が難しいことや障がいの状態など、詳しい条件は市へ確認してください。
ひとこと
社会生活上必要な外出や余暇活動などの社会参加を支える、うるま市の移動支援です。お子様を含む対象、申請窓口、負担、登録事業所一覧への入口が公開されています。
利用の条件
通勤・通学、営業活動など長く続く外出や、制度の目的に合わない外出は対象外です。市へ申請し、利用決定後に市と契約している事業所から候補を探します。
利用までの流れ
うるま市障がい福祉課へ対象・外出目的を相談 → 障がい者手帳と、該当する場合は年金・手当額の分かる書類や生活保護証明書を用意して申請 → 利用決定を確認 → 2025年11月1日現在の登録11事業所から候補を探す → お子様の対象・外出地域・日時・実費・介助を確認 → 契約・利用調整。
医療的ケアについて
市の制度ページと案内資料では、医療的ケア一般、吸引、経管栄養、人工呼吸器に対応する事業所を確認できませんでした。必要な処置は市と候補事業所へ一つずつ確認してください。
利用できる時間
現在の市ページから案内されるパンフレットでは、基本的に毎日、8時〜21時とされています。ただし、制度上の案内であり、各事業所の営業日・希望日の担当可否を示すものではありません。
地域・送迎
うるま市へ申請する制度です。市のページから開く2025年11月1日現在の登録事業所一覧には11事業所がありますが、現在のお子様担当や空きの件数ではありません。候補ごとにお子様の対象、外出範囲を確認してください。
料金
現在の市ページから案内されるパンフレットでは原則1割負担で、月額上限は生活保護0円、低所得1が15,000円、低所得2が24,600円、一般が37,200円です。申請時に最新の区分・実費を確認してください。交通費や入場料等の実費は候補事業所へ確認が必要です。
