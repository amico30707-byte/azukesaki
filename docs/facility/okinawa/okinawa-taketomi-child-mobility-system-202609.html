施設のこと

地域
竹富町
サービスの種類
外出の付きそい
対象年齢
竹富町の2026年9月改訂のしおりは、屋外での移動が難しく、移動中の見守りや介助が必要な障がい者・児を対象に移動支援を案内しています。詳しい年齢、障害・介助の条件は町へ確認してください。
ひとこと
竹富町の障がいのあるお子様を対象に含む、地域生活支援事業の移動支援です。これは町の制度・申請入口で、実際に支援する事業所や支援場所を示す施設情報ではありません。
空き・受付について
2026年10月29日に竹富町の2026年9月改訂しおりと現在の別の移動制度ページを確認しました。電話確認はしていません。実際の担当事業所、利用できる島・地域、曜日・時間、現在の受付、希望日時、個別ケアは未確認です。
利用の条件
竹富町こども未来課へ、外出目的、年齢、必要な見守り・身体介護を伝え、対象、申請、利用決定、担当事業所を確認してください。
利用までの流れ
竹富町こども未来課へ移動支援を相談 → 外出目的、年齢、介助、利用する島・地域を伝える → 対象、申請、利用決定、担当事業所を確認 → 希望日時の担当、利用者負担・実費を確認 → 契約・利用調整。
医療的ケアについて
移動中の見守り・介助や身体介護ありの料金区分から、重症心身障害、重度知的障害、強度行動障害、全面介助、吸引、経管栄養、人工呼吸器等のお子様の個別受け入れを推測していません。
利用できる時間
利用できる曜日・時間、担当事業所の営業時間、希望日時の担当可否は未確認です。
地域・送迎
竹富町の制度です。利用できる島、島内・石垣島・町外の外出、出発地、担当事業所の地域は確認したしおりでは確認できませんでした。
料金
しおりの利用者負担は、30分未満が身体介護なし75円・あり230円、30分以上1時間未満が150円・400円、1時間以上1時間30分未満が225円・580円です。1時間30分以降は30分ごとに70円加算し、生活保護世帯は自己負担なしです。交通費・入場料等の実費と現在の決定額は町へ確認してください。
住所
申請窓口：沖縄県石垣市美崎町11番地1 竹富町役場
