日出町 医療的ケア児等在宅レスパイト事業

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
日出町
サービスの種類
家に来るヘルパー
対象年齢
日出町に住所がある0歳から18歳到達後最初の3月31日までの医療的ケア児または重症心身障がい児が対象です。
ひとこと
訪問看護事業者が、ご家族に代わって自宅や自宅以外で看護等を行う日出町の在宅レスパイトです。居宅介護、移動支援、施設での短期入所とは別の事業です。
利用の条件
日出町に住所があり、同居のご家族が在宅で介護し、医師の訪問看護指示書による医療行為が必要で、訪問看護を利用していること等が条件です。重症心身障がい児は身体障害者手帳1・2級と療育手帳Aの両方を持つお子様と定義されています。
利用までの流れ
現在の訪問看護事業者へ相談 → 申請書と医師の訪問看護指示書の写しを事業者経由で町へ提出 → 利用決定通知 → 希望日時・場所・必要なケアを事業者と調整 → 利用。
医療的ケア
あり
医療的ケアについて
医師の訪問看護指示書に基づき訪問看護事業者が看護等を行います。吸引、経管栄養、人工呼吸器等の処置別対応、方法・回数・時間帯、外出先での対応は未確認です。
利用できる時間
1年度144時間が上限です。希望する曜日・時間を訪問看護事業者が担当できるかは別に確認します。
地域・送迎
日出町の制度です。自宅のほか、訪問看護事業者が支援できる自宅以外の場所も対象です。具体的な外出先、移動中、市外は事業者と町へ確認してください。
料金
上限内のサービス費の利用者負担はありません。町が訪問看護事業者へ1時間7,520円を支払います。交通費・衛生用品・取消料等の実費は要確認です。
住所
申請・相談窓口：大分県速見郡日出町2974番地1（日出町 介護福祉課）。訪問看護の提供場所ではありません。
お知らせ
年度144時間は希望日時の担当や空きを示しません。公式ページの登録事業所一覧は令和7年度のため、現在の契約状況を町へ確認してください
