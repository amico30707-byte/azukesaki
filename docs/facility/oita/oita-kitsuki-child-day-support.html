施設のこと

地域
杵築市
サービスの種類
日中のあずかり
対象年齢
杵築市の日中一時支援は障がい児の料金区分を定めています。原則として市内に住所があり、身体障害者手帳・療育手帳・精神障害者保健福祉手帳の交付を受けている方、対象となる難病の方、市が必要と認める方等が対象です。お子様ごとの利用可否は市へ確認してください。
ひとこと
障がいのあるお子様等へ日中の活動場所、見守り、社会に適応するための訓練等を提供し、ご家族の就労と一時的な休息を支える、宿泊しない杵築市の事業です。
空き・受付について
杵築市の要綱と2026年8月26日更新の窓口ページで、お子様を含む料金区分、日中の支援、申請・利用決定・事業所への依頼、認定期間、1割負担・月額上限、窓口を確認しました。市内事業所一覧は日中一時支援の現在の指定事業所一覧ではありません。現在の実施先・新規受付・空き、希望日時、電話でのお子様ごとの利用可否、支援場所・送迎・追加実費、個別ケアは未確認です。
利用の条件
市へ利用申請書を提出し、障害の程度、日常生活、介護する方の状況等の確認を受けます。利用決定後は決定通知書を事業所へ示して直接依頼します。認定期間は決定日から最初に来る6月30日までで、継続する場合は満了前1か月以内に更新申請します。
利用までの流れ
杵築市福祉事務所へ相談 → 対象・必要書類・利用できる事業所を確認 → 保護者が利用申請 → 市が障害の程度・生活・介護者の状況等を確認して利用決定 → 決定通知書を事業所へ提示 → 現在の受付・希望日時・費用・送迎・支援内容を確認 → 利用。
医療的ケアについて
市の要綱には障がいの程度による料金区分として全面介助や行動障害の基準がありますが、これは現在の事業所がお子様を受け入れることや、重症心身障害・強度行動障害・吸引・経管栄養・人工呼吸器等へ対応できることの確認ではありません。検索条件の個別支援には反映していません。
利用できる時間
日中に限る事業で、費用基準は4時間未満、4時間以上8時間未満、8時間以上に分かれます。これは事業所の営業時間や希望日の空きを示すものではありません。
地域・送迎
原則は杵築市内に住所がある方が対象です。住所地特例に当たる場合等の扱いがあります。現在の日中一時支援の指定事業所、支援場所、市外事業所の利用、送迎範囲は未確認です。
料金
原則は事業費の1割です。障がい児の月額上限は、生活保護・市民税非課税世帯0円、市民税所得割28万円未満の世帯4,600円、それ以上の世帯37,200円です。食事、送迎等の実費と実際の負担は市と事業所へ確認してください。
