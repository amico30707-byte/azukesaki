別府市 子育て短期支援（泊まり・夜間・休日）

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
別府市
サービスの種類
お泊まり（短期入所）日中のあずかり
対象年齢
別府市に住む0歳から18歳未満のお子様と保護者が対象です。障がいの有無に限らない子育て短期支援で、障害福祉の短期入所とは別の制度です。
ひとこと
保護者の病気・仕事・育児疲れ等で家庭での養育が一時的に難しいときに、泊まりのショートステイ、平日夜のトワイライトステイ、休日の日中預かりを市へ相談する制度です。
利用の条件
利用前に別府市こども家庭課へ連絡し、市が実施施設へ受け入れ可能か確認します。利用開始日までに申請書またはオンライン申請が必要です。初回は施設への事前見学が必要な場合があります。
利用までの流れ
別府市こども家庭課へ相談 → 泊まり・平日夜・休日のどれが必要か伝える → 市が実施施設の受け入れを確認 → 申請書またはオンライン申請 → 必要に応じ事前見学 → 送迎・持ち物・体調条件・料金を確認 → 利用。
医療的ケアについて
料金表に慢性疾患児の区分がありますが、医療的ケア一般、吸引、経管栄養、人工呼吸器、看護師配置等の個別対応は確認できていません。希望日と実施先ごとに市へ確認してください。
利用できる時間
ショートステイは原則月1回かつ7日以内。トワイライトステイは平日17時〜21時、休日預かりは土・日・祝日8時〜17時で、両方を合わせて原則年間30日以内です。
地域・送迎
別府市内に住むお子様が対象です。実施先として市内の児童福祉施設等と里親宅が案内されています。施設ごとの年齢、希望日の受け入れ、送迎支援の範囲は要確認です。
料金
その他世帯は、ショートステイが1日あたり2歳未満児または慢性疾患児5,350円、2歳以上児2,750円、トワイライト750円、休日預かり1,350円、送迎支援620円です。世帯区分による0円・減額があります。料金は1人1日あたりで、施設へ直接支払います。
住所
申請・相談窓口：大分県別府市西野口町15番33号（別府市保健センター内 こども家庭課こども支援係）
電話
0977-21-1239別府市 こども家庭課こども支援係。施設へ直接申し込まず、まず市へ受け入れ確認を依頼してください。
