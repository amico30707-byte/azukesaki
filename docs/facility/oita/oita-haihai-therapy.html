施設のこと

地域
大分市
サービスの種類
通う療育
対象年齢
児童発達支援は受給者証をお持ちの未就学のお子様、放課後等デイサービスは受給者証をお持ちの6歳から18歳の就学中のお子様が対象です。
ひとこと
未就学のお子様の児童発達支援と、6〜18歳の就学中のお子様の放課後等デイサービスを案内しています。
空き・受付について
公式ホームには2026年5月14日付で、木・金曜に空き、月〜水曜は利用形態により受け入れ可との案内があります。2026年10月15日にページ掲載を再確認しましたが、掲載日から時間が経っているため、現在の空きや希望日の決定とは扱いません。お子様ごとの受け入れと電話確認は未確認です。
利用の条件
見学・相談後、お住まいの市町村の福祉窓口へ申請して受給者証の交付を受け、施設との面接・契約を経て利用を始めます。
利用までの流れ
施設へ見学・相談 → お住まいの市町村の福祉窓口へ申請 → 受給者証の交付 → 施設と面接・契約 → 利用開始。学校日・休業日の送迎方法を分けて確認します。
医療的ケアについて
看護師配置、医療的ケア一般、吸引、経管栄養、人工呼吸器への対応は、今回確認した公式ページでは未確認です。
利用できる時間
月〜金曜の営業は8時30分〜17時30分、サービス提供は9時〜17時です。月〜金曜の祝日も開所する案内ですが、状況により休所する場合があります。実際の開所日は事前に確認してください。
地域・送迎
サービス提供地域は大分市の大道・春日・金池・西の台の各校区で、その他の地域も相談を受け付けています。送迎は、学校がある日は学校へのお迎えとご自宅への送り、学校が休みの日はご自宅への送りが案内されています。送迎できる範囲は公式ページに別に書かれていないため、事前に確認してください。
料金
障害児通所支援の利用者負担と実費は、受給者証、市町村、施設へ確認してください。今回確認した公式ページでは金額を確認できませんでした。
