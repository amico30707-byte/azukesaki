ホームヘルプ温寿荘

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
鶴岡市温海地域
サービスの種類
家に来るヘルパー外出の付きそい
対象年齢
鶴岡市の2026年2月版お子様向けしおりに、居宅介護の事業所として掲載され、移動支援は年齢不問と記載されています。法人の現在ページは居宅介護・重度訪問介護・移動支援を案内していますが、現在のお子様の新規受付と詳しい年齢は要確認です。
ひとこと
鶴岡市で、家での入浴・排せつ・食事等の手助けをする居宅介護と、外出を支える移動支援を案内する事業所です。高齢者向けの訪問介護とは別に確認できます。
利用の条件
居宅介護は市の障害福祉サービスの支給決定、移動支援は鶴岡市の地域生活支援事業の決定を確認します。2026年2月版しおりの時間・年齢表示を、現在の受付や希望日時の担当可否にしていません。
利用までの流れ
鶴岡市福祉課または地域庁舎へ相談 → 居宅介護・移動支援の対象と申請を確認 → 支給決定・受給者証等を確認 → 事業所へ希望する支援、訪問・外出地域、日時、必要な介助を伝える → 現在の受付・費用を確認 → 契約・支援計画・利用調整。
医療的ケアについて
法人の居宅介護の身体介護や入浴介助の案内から、全面介助、吸引、経管栄養、人工呼吸器等のお子様の個別対応を推測していません。重度訪問介護の成人向け条件をお子様へ当てはめません。
