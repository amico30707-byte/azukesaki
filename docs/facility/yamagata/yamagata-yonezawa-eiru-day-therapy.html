Reはーと えいる（日中一時支援・通所支援）

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
米沢市（長井市の日中一時支援契約先）
サービスの種類
日中のあずかり通う療育
対象年齢
長井市の2024年4月1日版の日中一時支援案内では、障がい児・重症心身障がい者の利用先です。山形県の2026年4月版一覧と施設の現在ページは、児童発達支援で知的・発達・身体・肢体不自由・重症心身障がい・医療的ケア児を主な対象に含めています。放課後等デイサービスと日中一時支援の詳しい年齢・対象、日中一時支援の現在の契約継続は要確認です。
ひとこと
米沢市にある児童発達支援・放課後等デイサービス事業所で、長井市の日中一時支援契約先にも掲載されています。施設の所在地と、制度を利用できるお住まいの地域を分けて確認します。
利用の条件
長井市の日中一時支援を使う場合は、市へ相談・申請し、5領域20項目の調査、支給決定、受給者証・利用管理票の交付後に事業所と契約します。米沢市で児童発達支援・放課後等デイサービスを申請する場合は、やまがたe申請の事前入力または市役所1階15番窓口で申請し、療育の必要性が分かる書類、印鑑、持っている場合は障害者手帳、マイナンバー確認書類を用意します。市の調査、利用計画、支給決定・受給者証、施設との契約を経ます。施設の最新のお知らせは2026年2月15日の自己評価公表ですが、現在の空きや日中一時支援の契約継続を示すものではありません。
利用までの流れ
長井市の日中一時支援：福祉あんしん課または相談支援事業所へ相談・申請 → 調査 → 約2週間を目安に支給決定・受給者証等の交付 → 事業所へ受給者証・利用管理票を示して契約。米沢市の児童発達支援・放課後等デイサービス：やまがたe申請で事前入力または市役所1階15番窓口で申請 → 市の調査 → 障がい児支援利用計画 → 支給決定・受給者証 → 施設と契約。事業ごとに希望日、送迎、実費、必要な支援を確認します。

あり
医療的ケアについて
山形県の2026年4月版一覧は、児童発達支援の主な対象に医療的ケア児を含めています。施設は看護師・理学療法士・作業療法士の在籍も案内しています。ただし、放課後等デイサービスや日中一時支援での医療的ケア、吸引、経管栄養、人工呼吸器、全面介助の対応は未確認です。
