施設のこと

地域
長井市（市外の契約先を含む）
サービスの種類
日中のあずかり
対象年齢
長井市内に住所があり、在宅で暮らす障がいのあるお子様。手帳、精神障害、難病等の条件は市へ確認してください。
ひとこと
ご家族の就労や休息等のとき、お子様が日帰りで活動する場を確保する長井市の制度です。市が現在案内する資料には、お子様を対象に含む市内・市外の契約先が複数掲載されています。
空き・受付について
市の制度と、2024年4月1日版資料にあるお子様向け契約先を確認しました。現在も契約中か、空き、新規受付、希望日時、送迎、個別の介助・医療的ケアへの対応は未確認です。
利用の条件
市へ相談・申請し、お子様は5領域20項目の調査を受けます。支給決定後、受給者証と利用管理票を受け取り、選んだ事業所と契約します。継続時は更新申請、氏名・住所・支給量等が変わるときは変更届が必要です。掲載資料はページ上でR6.6と案内されていますが、資料末尾は2024年4月1日版です。現在の契約継続と個別の受け入れは市と事業所へ確認してください。
利用までの流れ
長井市へ相談・申請（新規時は聞き取り調査） → お子様の5領域20項目を調査 → 支給決定（市の案内では申請から約2週間） → 受給者証・利用管理票を受け取る → 契約先を選び、現在の受け入れと条件を確認 → 事業所と契約して利用。継続は更新申請、氏名・住所・支給量等の変更は変更届を市へ提出します。
医療的ケアについて
契約先一覧にはお子様の対象区分がありますが、吸引、経管栄養、人工呼吸器等の処置別対応は確認できませんでした。必要な処置と時間帯を事業所ごとに相談してください。
利用できる時間
利用できる曜日・時間・日数は事業所ごとに異なり、今回読んだ市の資料では確認できませんでした。
地域・送迎
長井市在住のお子様向けの制度です。契約先には長井市外の事業所も含まれます。施設所在地と制度を利用できる住所を分けて確認してください。
料金
利用者負担は費用の5％。月額上限は世帯区分により0円、9,300円、37,200円です。食事・入浴等の実費が別に必要な場合があります。
