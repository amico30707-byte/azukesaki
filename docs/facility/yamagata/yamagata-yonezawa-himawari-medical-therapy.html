児童発達支援センター 米沢市立ひまわり学園

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
米沢市
サービスの種類
通う療育
対象年齢
米沢市と近隣市町村にお住まいの未就学のお子様と保護者が対象です。山形県置賜総合支庁の2026年4月版一覧では、知的障がい、発達障がい、身体障がい、肢体不自由、重症心身障がい、医療的ケア児を主な対象として掲載しています。
ひとこと
あそびを通して、一人ひとりの発達に応じた日常生活・社会適応・ことばなどの支援を行う児童発達支援センターです。2026年10月公開の公式資料では、保育園・幼稚園・認定こども園等へ訪問する保育所等訪問支援も案内しています。
利用の条件
児童発達支援は、米沢市社会福祉課で申込み、通所受給者証の発行後に施設から重要事項の説明を受け、保護者と施設が契約して利用を始めます。保育所等訪問支援は、ひまわり学園へ相談した後、市町村窓口への申請、相談支援事業所による利用計画案、支給決定・受給者証、園との申込み・契約の順です。現在の新規受付と開始時期は確認が必要です。
利用までの流れ
児童発達支援：米沢市社会福祉課へ相談・申込み → 通所受給者証 → 重要事項の説明 → 園と契約。保育所等訪問支援：ひまわり学園へ相談 → 市町村窓口へ申請 → 相談支援事業所へ利用計画案を依頼 → 支給決定・受給者証 → ひまわり学園へ申込み・契約 → 利用開始。
医療的ケア
あり
医療的ケアについて
山形県の2026年4月版一覧で医療的ケア児と重症心身障がいを主な対象に含むことを確認しました。吸引、経管栄養、人工呼吸器、全面介助などの処置別対応、職員配置、送迎中の対応は未確認です。
利用できる時間
月曜日から金曜日の7時30分から14時45分。休業日は土曜・日曜・祝日・年末年始です。県の2026年4月版一覧には年数回の土曜親子通園も掲載されています。希望する曜日・登園日数と現在の日程は施設へ確認してください。
地域・送迎
米沢市と近隣市町村にお住まいのお子様が対象です。近隣市町村の具体的な範囲、送迎の有無・範囲は未確認です。
料金
通所受給者証に基づく利用者負担、食事・おやつ・活動などの実費は、今回確認した公式ページでは分かりませんでした。米沢市の窓口と施設へ分けて確認してください。
