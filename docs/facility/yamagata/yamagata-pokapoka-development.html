ぽかぽか保育園（児童発達支援）

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
山形市
サービスの種類
通う療育
対象年齢
児童発達支援を利用する未就学のお子様が対象です。山形市の2026年7月版ガイドでは、医療的ケア児・身体障がい児・重症心身障がい児が利用可能と案内されています。
ひとこと
医療的ケアや身体の障がいがある未就学のお子様が単独で通う児童発達支援です。リハビリ、食形態の調整、小規模保育園との交流を案内しています。
利用の条件
山形市の支給決定と事業所との契約が必要です。医療的ケアは県の登録一覧で処置項目を確認できましたが、現在のお子様ごとの受け入れ、方法、回数、時間帯は事業所へ確認してください。
利用までの流れ
指定障がい児相談支援事業所へ相談 → 山形市へ利用申請 → 調査・利用意向の確認 → 利用計画案 → 支給決定・受給者証 → ぽかぽか保育園と契約 → 利用開始。
医療的ケア
あり
医療的ケアについて
山形市の2026年7月版児童サービスガイドで医療的ケア児の利用を確認。山形県の2026年8月1日時点の『特定の者』向け登録特定行為事業者一覧では、児童発達支援として吸引・経管栄養の項目に登録があります。新しい利用者には別途実地研修が必要と明記されており、登録は現在の個別受け入れや空きを保証しません。
利用できる時間
月〜金曜（祝日も営業）9時〜17時。実際の利用時間は受給者証、支援計画、事業所との契約で確認してください。
地域・送迎
施設は山形市にあります。利用できる市町村の範囲は未確認です。送迎はありません。
料金
原則はサービス費用の1割で、世帯所得に応じた月額上限があります。3歳になった後の最初の4月1日から小学校入学前までの児童発達支援は無償化の対象ですが、食費などの実費は別に確認してください。
