長井市 お子様の移動支援（個別・通所・通学）

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
長井市
サービスの種類
外出の付きそい
対象年齢
長井市に住所がある在宅の障がい児を対象に含みます。個別支援・通所支援は障がい児を対象要件に明記し、通学支援は市外の特別支援学校へ自力で通うことが難しい障がい児が対象です。個別の対象は市の確認が必要です。
ひとこと
社会生活上必要な外出や余暇、児童発達支援・放課後等デイサービス等への通所、市外の特別支援学校への通学を支える長井市の制度です。利用目的により対象・回数・負担が異なります。
利用の条件
個別支援、通所支援、通学支援のどれを希望するかを市へ伝え、対象確認と支給決定を受けます。個別支援は通勤・営業、社会通念上適当でない外出、宗教・政治・特定利益の団体活動等が対象外です。市の利用決定と、事業所の現在の受付・希望日時の対応は別に確認してください。
利用までの流れ
長井市福祉あんしん課へ、個別の外出・通所・通学のどれを希望するか伝えて相談 → 対象と必要書類を確認して申請 → 市の利用決定 → 実施事業所へ対応地域、日時、費用、必要な介助を確認 → 契約・利用調整。
医療的ケアについて
障がい児の対象は確認できますが、医療的ケア一般、吸引、経管栄養、人工呼吸器の対応事業所は確認できません。必要なケアを市と事業所へ個別に相談してください。
