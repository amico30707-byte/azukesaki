施設のこと

地域
旭市
サービスの種類
通う療育
対象年齢
通所受給者証をお持ちの未就学児と、小学生・中学生・高校生が対象です。児童発達支援と放課後等デイサービスの事業別条件は施設へ確認してください。
ひとこと
2025年8月に開所した、児童発達支援と放課後等デイサービスの事業所です。旭市の公式資源マップで、対象地域、開所時間、職種、送迎・実費を確認できます。
空き・受付について
2026年10月28日に旭市の2026年4月1日更新資源マップを確認しました。電話確認はしていません。現在の新規受付・空き、希望曜日、一部土曜の対象日、お子様ごとの支援時間、実費の金額、個別ケアは未確認です。公式資源マップに記載された事業所サイトは確認時に取得できず、施設側の現在のお知らせは未確認です。
利用の条件
通所受給者証が必要です。見学・相談、支給決定、契約、利用開始の順と、必要な書類をお住まいの市町村と施設へ確認してください。
利用までの流れ
お住まいの市町村または施設へ相談 → 見学・対象事業を確認 → 通所受給者証の申請・支給決定 → 契約、利用曜日・時間・実費・必要な支援を確認 → 利用開始。
医療的ケアについて
公式資源マップに記載された職種から、医療的ケア一般、重症心身障害、重度知的障害、強度行動障害、全面介助、吸引、経管栄養、人工呼吸器等への個別対応を推測していません。
利用できる時間
施設の開所時間は月〜金曜8時30分〜17時、放課後等デイサービスは一部の土曜も実施と案内されています。お子様ごとの実際の支援時間・利用曜日・現在の空きとは別に確認してください。
曜日・休み
月〜金曜。放課後等デイサービスは一部の土曜も実施と案内されています。土曜の対象日と現在の利用可否は要確認です。
地域・送迎
旭市・銚子市・匝瑳市・香取市と近隣地域が対象と案内されています。具体的な住所・学校から利用できるかは施設へ確認してください。
料金
イベント代・材料費等の実費がかかる場合があります。受給者証に基づく利用者負担、実費の内容と金額は確認してください。
