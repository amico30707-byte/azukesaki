千葉県千葉リハビリテーションセンター えぶりキッズ・えぶりクラブ

お知らせ事業の対象と目的は2026年10月17日に現在の公式ページで確認しました。現在のページから2024年版パンフレットへ案内されていますが、曜日・時間・食費・入浴費・申込期限などの詳しい条件は2024年版によるため、現在の条件を確認してください。

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
千葉市緑区
サービスの種類
通う療育
対象年齢
えぶりキッズは、障害が重く地域の幼稚園・保育所などへ通うことが難しい未就学のお子様とご家族が対象です。えぶりクラブは、濃厚な医療的ケアなどの理由で地域の放課後等デイサービスへ十分に通えない就学児が対象です。
ひとこと
未就学のお子様の親子通園『えぶりキッズ』と、就学児の放課後等デイサービス『えぶりクラブ』を行う児童発達支援センターです。
利用の条件
センターへ電話相談し、見学・面談を行います。小児神経科の受診歴がない場合は受診が必要です。お住まいの市町村へ申請し、支給決定・受給者証の交付後に個別支援計画を作り利用します。
利用までの流れ
センターへ電話相談 → 小児神経科の受診歴を確認 → 見学・面談 → お住まいの市町村へ申請 → 支給決定・受給者証 → 個別支援計画・契約 → 前月15日までに利用希望を連絡。
医療的ケア
あり
医療的ケアについて
現在の公式ページで、えぶりクラブの医療的ケアと健康管理、えぶりキッズの個別訓練・家族支援を確認しました。2024年版の持ち物には呼吸器・吸引器・注入物等が含まれますが、持ち物の記載だけから現在の個別処置の受け入れを確定していません。処置、時間帯、親子通園・単独利用を分けて確認してください。
利用できる時間
えぶりキッズは月〜金曜10〜14時で祝日と季節休暇は休み。えぶりクラブは月〜金曜14時30分〜17時30分で、長期休暇中は定期利用者向けの1日利用を数日行います。
地域・送迎
施設は千葉市緑区にあります。えぶりキッズは家族による送迎です。えぶりクラブは原則家族送迎ですが、袖ケ浦特別支援学校へは職員が迎えに行く案内があります。利用できる市町村は要確認です。
料金
障害児通所支援の利用者負担があります。2024年版案内では、えぶりキッズは食費290円または610円、えぶりクラブは入浴1回200円と記載されています。現在の金額、月額上限、その他の実費は要確認です。
