豊四季光風園（日中一時支援）

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
柏市
サービスの種類
日中のあずかり
対象年齢
柏市の2026年10月1日現在の指定日中一時支援事業所一覧で、『児童』と『知的』に○があります。短期入所も実施していますが、お子様の短期入所条件は公式ページで確認できないため、短期入所検索には含めていません。
ひとこと
在宅の知的障害のある方を短期間受け入れ、食事や入浴等の生活支援を行う日中一時支援です。
利用の条件
利用前にお子様とご家族で見学し、その後に契約、本人面接、具体的な利用方法の相談を行います。柏市は、18歳未満のお子様について手帳のほか、診断書、特別児童扶養手当等の証書、公的機関・こども発達センター・関係事業所の意見書等を申請時の確認資料として案内しています。どの資料が必要かは申請前に障害福祉課へ確認してください。
利用までの流れ
柏市障害福祉課へ日中一時支援を相談 → 対象・申請書類・支給決定を確認 → 豊四季光風園へ見学を相談 → お子様とご家族で見学 → 契約・本人面接 → 利用方法と希望日を調整。
医療的ケアについて
公式ページと市一覧では、医療的ケア一般、吸引、経管栄養、人工呼吸器の対応を確認できませんでした。身体障害の欄は×ですが、これだけで個別ケアの対応なしとは判断しません。
利用できる時間
利用曜日・時間は未確認です。市の一覧では送迎は×、食事は○です。
地域・送迎
施設は柏市にあります。柏市指定の事業所一覧に掲載されています。柏市外からの利用、送迎範囲、利用地域は未確認です。
料金
柏市の地域生活支援サービスは、所得に応じて無料または費用の1割負担で、生活保護・非課税・一般1は月額上限0円、一般2は37,200円と案内されています。食費・入浴・日用品等の実費と、施設での現在額は未確認です。
