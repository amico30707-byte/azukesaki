柏市 移動支援

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
柏市
サービスの種類
外出の付きそい
対象年齢
屋外で一人で移動することが難しい、原則として就学児以上の方が対象です。下肢・体幹・移動機能の重い障害、知的障害、精神障害、発達障害のある方が対象に含まれ、発達障害については18歳未満と案内されています。お子様ごとの利用可否は柏市が決定します。
ひとこと
柏市のお子様が、余暇活動やボランティア活動などの外出の付き添いを相談する地域生活支援事業です。通勤、営業活動、宗教・政治活動などには利用できないと案内されています。
利用の条件
柏市へ申請し、支給決定後に移動支援事業所と契約・日時調整をします。市の2026年10月1日現在の一覧は39事業所を掲載し、児童欄と休止中の表示を分けています。児童欄が○でも現在のお子様の担当、新規受付、希望日時の利用は事業所へ確認してください。
利用までの流れ
柏市障害福祉課へ移動支援を相談 → 対象・申請書類・支給量を確認 → 支給決定 → 2026年10月1日現在の事業所一覧で児童欄と休止中表示を確認 → 事業所へ年齢、外出目的、地域、希望日時、介助内容、実費を確認 → 契約・利用。
医療的ケアについて
市の制度案内と事業所一覧から、看護体制、医療的ケア一般、吸引、経管栄養、人工呼吸器、全面介助の事業所別対応は確認できませんでした。必要なケアは申請時と契約前に伝えてください。
利用できる時間
利用できる時間数、曜日・時間、通学等への利用可否は、支給決定と事業所の体制により異なります。市の事業所一覧では現在の担当可能時間を確認できません。
地域・送迎
柏市の制度です。事業所所在地と、実際に外出支援を行う地域は同じとは限りません。市外での外出、集合場所、送迎との違いは市と事業所へ確認してください。
料金
柏市の地域生活支援サービスは、生活保護・非課税・一般1が月額上限0円、一般2が37,200円と案内されています。交通費、入場料等の実費と事業所ごとの扱いは、利用前に確認してください。
