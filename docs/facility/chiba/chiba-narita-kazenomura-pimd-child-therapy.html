生活クラブ風の村 重心通所なりた（児童発達支援・放課後等デイサービス）

施設のこと

地域
成田市
サービスの種類
通う療育
対象年齢
主に重症心身障がいのある方の全年齢（未就学・学齢・18歳以上）が対象です。未就学のお子様は児童発達支援、学齢のお子様は放課後等デイサービス、18歳以上は生活介護を使います。
ひとこと
社会福祉法人生活クラブが運営する、重症心身障がい児者のための通所施設です。児童発達支援・放課後等デイサービス・生活介護をしています。
空き・受付について
2026年11月11日に、生活クラブ風の村の施設ページと千葉県の事業所一覧（2026年7月1日現在）を確認しました。電話確認はしていません。現在の空き、定員、費用、処置ごとの対応は未確認です。
利用の条件
児童発達支援・放課後等デイサービスの通所受給者証が必要です。くわしい条件は施設へ確認してください。
利用までの流れ
電話・フォームで見学・相談 → 市町村の窓口で通所受給者証を申請 → 契約 → 利用開始。
医療的ケア
あり
医療的ケアについて
公式ページでは、医療的配慮の必要な方のために看護師が毎日3名以上いて、医療的ケアについては看護師を複数名配置していると書かれています。食事は普通食・きざみ・ペースト・注入に対応します。吸引・人工呼吸器などの処置ごとの受け入れは書かれていないため、施設へ確認してください。
利用できる時間
児童発達支援は月曜日〜土曜日の9時〜15時です。放課後等デイサービスは、平日は下校後〜17時30分、学校休業日は9時〜17時30分、土曜日は9時〜15時です。
地域・送迎
施設は成田市にあります。送迎は希望に応じて行うと書かれています。範囲は施設へ確認してください。
料金
利用者負担や実費は確認できませんでした。受給者証とあわせて施設へ確認してください。
