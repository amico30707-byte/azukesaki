ひとこと
日中に見守る方がいないとき、障害のあるお子様へ日中の活動場所と見守り等を提供し、ご家族の負担を軽くする匝瑳市の地域生活支援事業です。宿泊する短期入所とは別です。
空き・受付について
2026年10月28日に匝瑳市の現在の申請書ページ・申請書・障害児を含む制度ページと、2023年4月の資源マップを確認しました。電話確認はしていません。資源マップは現在の実施事業所・空き一覧ではありません。現在の新規受付・空き、事業所ごとのお子様対象、曜日・時間、送迎、負担・実費、個別ケアは未確認です。
利用の条件
市の申請書で日中一時支援を申請し、市の利用決定後に現在の実施事業所と契約・予約します。2023年4月の資源マップ掲載先を、現在のお子様受け入れ一覧や空き一覧とは扱いません。
利用までの流れ
匝瑳市福祉課へ日中一時支援を相談 → 市の利用申請書を提出 → 対象・利用決定・負担を確認 → 現在の実施事業所を確認 → 事業所へ年齢、希望日、時間、送迎、実費、必要な介助を相談 → 契約・利用。
医療的ケアについて
市の制度・申請情報から、実施事業所ごとの医療的ケア一般、重症心身障害、重度知的障害、強度行動障害、全面介助、吸引、経管栄養、人工呼吸器等への対応を推測していません。
利用できる時間
市の現在の申請ページから、事業所ごとの曜日・時間・希望日の利用は確認できませんでした。
地域・送迎
匝瑳市の申請・相談入口です。利用できる事業所の所在地、匝瑳市外の事業所を使えるか、送迎範囲は福祉課へ確認してください。
料金
