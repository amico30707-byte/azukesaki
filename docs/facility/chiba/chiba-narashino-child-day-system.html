習志野市 お子様の日中一時支援

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
習志野市
サービスの種類
日中のあずかり
対象年齢
身体障害者手帳のあるお子様、療育手帳または児童相談所等の判定・診断書等で知的障がいを確認できるお子様、精神障害者保健福祉手帳・自立支援医療受給者証・診断書等で精神障がいを確認できるお子様が対象に含まれます。
ひとこと
日中・日中活動後・放課後等に活動の場を提供し、ご家族の就労や一時的な休息を支える、習志野市の日中一時支援です。見守りや社会に適応するための訓練等を行います。
利用の条件
市または相談支援事業所へ相談・申請し、心身・生活状況の聞き取り、支給決定、受給者証の交付を受けます。その後、登録事業所を選び、受給者証を示して契約します。市外事業所も習志野市へ登録していれば利用できます。
利用までの流れ
習志野市障がい福祉課または相談支援事業所へ相談・申請 → 本人・ご家族への聞き取り → 支給決定・受給者証 → 2026年8月5日時点の登録一覧を参考に、現在の登録・受付・日時・送迎・実費・必要な介助を確認 → 契約・利用。
医療的ケアについて
対象となる障がい種別や見守りの記載から、重症心身障害、重度知的障害、強度行動障害、全面介助、医療的ケア一般、吸引、経管栄養、人工呼吸器等への個別対応を推測していません。
