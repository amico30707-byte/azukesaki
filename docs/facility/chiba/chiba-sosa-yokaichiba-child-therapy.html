八日市場学園 児童発達支援・放課後等デイサービス

お知らせ同じ施設の『日中一時支援』について、お子様の現在の対象・時間は確認できていないため療育と分けています

空きや受け入れは、かならず施設にご確認ください

利用を考えるときは

公式ページを見る八日市場学園｜児童発達支援・放課後等デイサービス

電話0479-74-1181

確認日：2026年10月28日（あずけさき手帖が公式の情報を確かめた日）

施設のこと

地域
匝瑳市
サービスの種類
通う療育
対象年齢
児童発達支援は主に就学前、放課後等デイサービスは就学中のお子様が対象です。施設公式ページは両事業を合わせた定員10名と案内しています。
ひとこと
お子様とご家族に合わせた計画を作り、児童発達支援と放課後等デイサービスを行う匝瑳市の事業所です。同じ所在地にある日中一時支援とは別の事業です。
空き・受付について
2026年10月28日に法人公式ページと匝瑳市の制度ページを確認しました。電話確認はしていません。現在の新規受付・空き、希望曜日、送迎、実費、日中一時支援のお子様対象、個別ケアは未確認です。
利用の条件
匝瑳市へ障害児通所支援を申請し、通所受給者証の支給決定後に事業所と契約します。現在の新規受付と希望曜日は事業所へ確認してください。
利用までの流れ
匝瑳市福祉課へ児童発達支援または放課後等デイサービスを相談・申請 → 通所受給者証を確認 → 事業所へ年齢、通学、希望曜日、送迎、必要な支援を相談 → 見学・契約 → 利用。
医療的ケアについて
法人は医療的ケア児等コーディネーター養成研修等の修了を掲載していますが、研修修了を吸引、経管栄養、人工呼吸器等の受け入れ可否とは扱っていません。重症心身障害、重度知的障害、強度行動障害、全面介助も個別に要確認です。
利用できる時間
月〜土曜（祝日・12月29日〜1月3日を除く）。児童発達支援9時〜13時、放課後等デイサービス13時30分〜17時30分、学校休業日は9時30分〜15時30分です。学校休業日は放課後等デイサービスのみです。
曜日・休み
月〜土曜。祝日と12月29日〜1月3日は休みです。
地域・送迎
施設は匝瑳市にあります。利用できる市町村と送迎範囲は未確認です。
料金
障害児通所支援は原則1割負担で、世帯収入に応じた月額上限があります。学校休業日の昼食は各自で弁当を持参します。その他の実費は要確認です。
住所
千葉県匝瑳市安久山310-5
電話
0479-74-1181八日市場学園。児童発達支援または放課後等デイサービスの希望と、お子様の年齢・希望曜日を確認してください。
確認日
2026年10月28日
