東名古屋病院 重症心身障害児（者）の短期入所

お知らせ利用のきまり・料金は、2024年4月1日現在の職員体制がのった病院の説明書によります。現在の内容は病院へ確認してください

空きや受け入れは、かならず施設にご確認ください

利用を考えるときは

公式ページを見る東名古屋病院｜「短期入所サービス利用契約」にかかる説明書

電話052-801-1151

確認日：2026年11月12日（あずけさき手帖が公式の情報を確かめた日）

施設のこと

地域
名古屋市名東区
サービスの種類
お泊まり（短期入所）
対象年齢
在宅の重症心身障害児（者）が対象です。病院の説明書に年齢の記載はありません。お子様の年齢での利用は病院へ確認してください。
ひとこと
国立病院機構の病院の重症心身障害児（者）病棟で行う短期入所です。在宅でケアをするご家族の支えとして、短期入所を受け入れています。
空き・受付について
病院の説明書（2024年4月1日現在の職員体制）と2026年1月の広報誌を確認しました。現在の空き、新規の受付、お子様の年齢での利用、処置ごとの受け入れ、現在の料金、電話でのお子様ごとの利用可否は未確認です。
利用の条件
原則として障害福祉サービスの支給決定（受給者証）が必要です。契約の前に、原則この病院で診察を受けます。日帰りの利用はありません。ベッドの空きや感染症の状況で、希望日に利用できないことがあります。
利用までの流れ
お住まいの市町村へ短期入所を相談し受給者証を受け取る → 東名古屋病院の児童指導員へ連絡 → 原則この病院で診察 → 契約 → 希望月の3か月前の1日（休日なら翌日）から申し込み（例：8月10日の利用は5月1日から）。
医療的ケアについて
説明書には、服薬の管理、健康チェック、看護、飲みこむ力に合わせた食事の介助が書かれています。吸引・経管栄養・人工呼吸器など処置ごとの受け入れは確認できていません。お子様ごとに病院へ確認してください。
利用できる時間
入退所は原則平日です。入所は9時〜11時、退所は15時までです。利用日数は受給者証の支給日数の範囲です（病院の説明書、職員体制は2024年4月1日現在）。
地域・送迎
病院は名古屋市名東区にあります。利用対象地域の記載は確認できませんでした。お住まいの市町村と病院へ確認してください。
料金
市町村が決めた利用者負担（受給者証の月の上限まで）のほか、食費1食270円・光熱水費1日300円（税込）、日用品は事前の取り決めによります。障害者医療証がない方は、入所中の医療費が別にかかります（2024年4月時点の説明書）。
住所
愛知県名古屋市名東区梅森坂五丁目101番地
電話
052-801-1151東名古屋病院（代表）。短期入所の担当（児童指導員）へ、お子様の年齢、必要なケア、希望時期を伝えてください。
確認日
2026年11月12日
