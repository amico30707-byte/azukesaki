施設のこと

地域

サービスの種類
家に来るヘルパー
対象年齢
障がいのあるお子様も利用対象候補です。障害者手帳がなくても、医療的ケア判定スコアや地域療育センターの判定などから必要と認められる場合があります。
ひとこと
ご自宅で食事、入浴、排せつなどの介助を受ける支援です。区役所・支所への申請、障害児支援利用計画案、受給者証、指定事業所との契約を順に進めます。
空き・受付について
制度の対象・申請・費用は確認しましたが、指定事業所ごとの空き、訪問地域、曜日・時間、ご家族の在宅条件、実費、個別ケア、お子様ごとの受け入れ、電話確認は未確認です。
利用の条件
お住まいの区の区役所福祉課・支所区民福祉課へ申請します。お子様の様子とご家族の状況の聞き取り、障害児支援利用計画案、市の支給決定と受給者証を経て、指定事業所と契約します。
利用までの流れ
区役所福祉課・支所区民福祉課へ申請 → お子様の様子などの聞き取り → 障害児相談支援事業所と契約 → 障害児支援利用計画案を提出 → 支給決定・受給者証 → 指定事業所と契約 → 利用開始。
医療的ケアについて
手帳がない場合の確認に医療的ケア判定スコアの記載がありますが、これは居宅介護事業所が吸引・経管栄養・人工呼吸器へ対応できる根拠ではありません。処置ごとに事業所へ確認してください。
利用できる時間
市が決めた支給量の範囲で、指定事業所が受け入れられる曜日・時間を調整します。受給者証があっても、希望日時の空きは別の確認です。
地域・送迎
名古屋市へ申請する制度です。事業所ごとの訪問地域や、市外に住むお子様の利用は未確認です。
料金
サービス費用の原則1割で、18歳未満は保護者の所得状況に応じた月額上限があります。市の案内では0円、4,600円、18,600円、37,200円の区分があります。実費は事業所へ確認してください。
