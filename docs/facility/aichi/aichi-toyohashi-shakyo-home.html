施設のこと

地域
豊橋市
サービスの種類
家に来るヘルパー外出の付きそい
対象年齢
豊橋市の2026年10月1日時点の一覧で主な対象者の児童欄を含む居宅介護事業所として掲載されています。市は障害児を原則18歳未満と案内し、法人公式ページも在宅の身体・知的障害のあるお子様を含む支援を案内しています。手帳がない場合を含め、詳しい対象は市へ相談が必要です。
ひとこと
在宅で生活する障がいのあるお子様・成人へ、身体介護・家事援助・通院等介助の居宅介護、同行援護、移動支援を案内する豊橋市社会福祉協議会の事業所です。
空き・受付について
2026年10月1日時点の市一覧と現行の市・社会福祉協議会ページを2026年10月19日に再確認しました。お子様を含む対象、居宅介護・同行援護・移動支援、申請順、負担の考え方、所在地、電話を確認しました。現在の空き、新規受付、電話でのお子様ごとの受け入れ、訪問地域・日時・実費・個別ケアは未確認です。
利用の条件
まず事業所へ希望する支援を相談し、豊橋市障害福祉課へ支給申請します。市の案内では、利用計画案、区分認定、受給者証の交付、事業所との契約を経て利用します。お子様の状態によって手続きが異なるため、市へ確認してください。
利用までの流れ
事業所へ利用希望を相談 → 豊橋市障害福祉課へ支給申請 → 相談支援へ利用計画案を依頼 → 必要な区分認定・計画案の提出 → 受給者証 → 事業所と契約 → 利用調整。
医療的ケアについて
市一覧と法人公式ページで、医療的ケア一般、吸引、経管栄養、人工呼吸器への対応は確認できませんでした。お子様の対象記載から個別の処置を推測していません。
利用できる時間
居宅介護の受付時間、提供時間、希望日時の担当可否は公開ページで確認できませんでした。
地域・送迎
事業所は豊橋市佐藤にあります。通常の訪問地域や住所ごとの担当可否は公開ページで確認できませんでした。
料金
豊橋市は、サービス利用料の1割の範囲内で所得に応じた月額上限があると案内しています。外出時の交通費等の実費、キャンセルの扱い、この事業所での最終負担額は市と事業所へ確認してください。
