愛知県医療療育総合センター中央病院 こばと棟（短期入所）

空きや受け入れは、かならず施設にご確認ください

利用を考えるときは

公式ページを見る愛知県医療療育総合センター｜短期入所（ショートステイ）のご案内

電話0568-88-0811

確認日：2026年10月15日（あずけさき手帖が公式の情報を確かめた日）

施設のこと

地域
春日井市
サービスの種類
お泊まり（短期入所）
対象年齢
3歳以上の重症心身障害児者が対象です。18歳未満の認定は児童相談センターが行う案内です。
ひとこと
ご家族の病気、用事、仕事、休養などで介護が一時的に難しいときに利用する医療型短期入所です。原則、月1回・8日以内で、空床を使うため利用できる人数は変わります。
空き・受付について
空床利用のため人数は変わります。2026年10月15日更新の追加利用カレンダーも、こばと棟の空きを示さない案内です。2026年10月13日のオンライン予約開始のお知らせは中央病院向けで、こばと棟の予約方法変更とは扱っていません。現在の空き、希望日の利用、利用地域、電話でのお子様ごとの受け入れ、処置の方法・時間帯・夜間体制は未確認です。
利用の条件
受給者証に短期入所（重心・医療型・療養介護のいずれか）と利用日数の記載が必要です。相談、外来受診、ご家族付き添いのお試し利用、付き添いなしのお試し利用、院内会議を経て本利用が決まります。初回相談から本利用までは3〜4か月ほどが目安です。契約後は電話またはショスパイト24で予約し、年1回は担当医の外来受診が必要です。
利用までの流れ
市町村・相談支援専門員へ相談 → 受給者証を準備 → 事前調査票等を提出・面談 → 外来受診 → 1回目のお試し（こばと棟は日帰り・ご家族付き添い） → 2回目のお試し（1泊2日・付き添いなし） → 院内会議 → 契約 → 電話またはショスパイト24で本利用を予約。こばと棟の予約は2か月前の最初の平日から5平日間で、電話は9時30分〜17時30分、オンラインは初日9時〜5日目17時です。初回相談から本利用までは3〜4か月ほどが目安です。
医療的ケア
あり
医療的ケアについて
令和7年7月時点の基本受入情報は、こばと棟の短期入所で経鼻経管、胃ろう、気管切開、経鼻咽頭エアウェイ、吸引を掲載しています。人工呼吸器は別途相談で、個別の方法・希望日の体制は確認が必要です。
利用できる時間
こばと棟の入所は平日で、入所時刻は10時・10時30分・14時・14時30分、退所は10時〜16時です。原則、月1回・8日以内です。
地域・送迎
施設は春日井市にあります。利用できる市町村の範囲は要確認です。
料金
受給者証の負担上限月額内の自己負担、食事療養費、光熱水費390円／日があります。食事代と光熱水費は2026年4月1日時点です。
