今治市 移動支援

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
今治市
サービスの種類
外出の付きそい
対象年齢
在宅で屋外の移動が難しい障がい児を対象に含みます。身体障がいのあるお子様は、全身性障がいまたは車いす常用などの条件があります。詳しい対象は市へ確認してください。
ひとこと
社会生活に必要な外出や余暇活動などの社会参加を支える今治市の移動支援です。市の決定後、市ページに掲載される26事業所から候補を選びます。掲載件数は現在の空きやお子様の担当可否を示しません。
利用の条件
本庁障がい福祉課または各支所住民サービス課へ申請し、市の審査後に決定通知書と受給券等を受け取ります。事業者へ受給券と上限管理票を提示します。
利用までの流れ
今治市障がい福祉課または各支所へ申請 → 市の審査・決定通知書・受給券を確認 → 市の事業者一覧から候補を選ぶ → 外出目的・地域・日時・費用・必要な介助を確認 → 契約・利用調整。
医療的ケアについて
市の制度ページでは、医療的ケア一般、吸引、経管栄養、人工呼吸器に対応する事業者を確認できませんでした。必要な処置は市と候補事業者へ一つずつ確認してください。
利用できる時間
市の料金表は日中8時〜18時、夜間早朝6時〜8時・18時〜22時、深夜22時〜6時を分けています。これは希望日時に担当者がいるという意味ではありません。
地域・送迎
今治市へ申請する制度です。市の事業者一覧には市外の事業者も含まれるため、実際の外出範囲、出発地、送迎の扱いは事業者ごとに確認してください。
料金
日中料金は30分未満で身体介護なし105円・あり254円、30分以上1時間未満で197円・402円、1時間以上1.5時間未満で276円・584円、1.5時間以上2時間未満で346円・667円、2時間以上2.5時間未満で416円・750円、2.5時間以上3時間未満で486円・833円、以後30分ごとに70円・83円です。夜間早朝は1.25倍、深夜は1.5倍。月額上限は0円・9,300円・18,600円で、交通費等の実費は事業者へ確認してください。
