障害者支援施設スマイル 日中一時支援

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
松山市
サービスの種類
日中のあずかり
対象年齢
日常生活に介護が必要な18歳未満の障害児が対象です。18歳以上は松山市在住という条件が別に案内されています。
ひとこと
見守り等が必要なお子様などへ日中の活動と社会に適応するための支援を提供し、ご家族の就労や一時的な休息を支える施設です。
利用の条件
お住まいの市町村から日中一時支援の支給決定を受け、施設と直接契約します。公式ページは詳しい手続きについて担当者への問い合わせを案内しており、初回面談・見学・必要な証書は要確認です。
利用までの流れ
お住まいの市町村へ日中一時支援の申請・支給決定を確認 → スマイルの担当者へ対象・契約手順・希望日を問い合わせ → 施設と直接契約 → 日時・食事・持ち物・必要な介助を調整。見学は公式ページで確認できないため、必要かを問い合わせてください。
医療的ケアについて
日常生活に介護が必要なお子様を対象に含みますが、医療的ケア一般、吸引、経管栄養、人工呼吸器への対応は確認できませんでした。
