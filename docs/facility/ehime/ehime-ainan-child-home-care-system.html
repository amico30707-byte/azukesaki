愛南町 お子様の居宅介護

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
愛南町
サービスの種類
家に来るヘルパー
対象年齢
愛南町が2026年に掲載した支給決定基準に、居宅介護の「障害児」区分があります。身体・知的・精神障がいまたは難病等があり、町が必要と認める方の制度です。
ひとこと
お子様がご自宅で利用するホームヘルプについて、町の障害福祉サービス案内と支給量の基準を確認できる制度情報です。介護者の状況により月の基準時間が分かれます。
利用の条件
愛南町保健福祉課へ相談し、お子様の状態、必要な介助、介護者の状況を伝えて申請・支給決定・受給者証と現在利用できる事業所を確認します。基準を超える支給量は町の審査会で決定すると案内されています。
利用までの流れ
愛南町保健福祉課へ相談 → 対象、介護者の状況、必要な介助、申請・支給決定・受給者証を確認 → 現在利用できる居宅介護事業所へ訪問地域、受付、希望日時、実費、必要な介助を確認 → 契約・利用。
医療的ケアについて
居宅介護の障害児区分から、重症心身障害、重度知的障害、強度行動障害、全面介助、医療的ケア一般、吸引、経管栄養、人工呼吸器等への事業所の対応を推測していません。
