施設のこと

地域
宮古市
サービスの種類
家に来るヘルパー
対象年齢
宮古市の2025年9月版手引きは、障がいのあるお子様を障害福祉サービスの対象に含め、居宅介護を案内しています。掲載事業所ごとの詳しい年齢と現在の受け入れは要確認です。
ひとこと
ご自宅で入浴、排せつ、食事などの介助を受けるため、市へ申請し、受給者証の交付後に事業所と調整する支援です。
空き・受付について
市の制度、2025年9月版の6事業所、2026年6月18日更新の利用者負担無償化を確認しました。ただし、現在の空き、新規受付、各事業所のお子様の受け入れ、訪問地域、曜日・時間、医療費・食費等の実費、個別ケア、電話確認は未確認です。
利用の条件
市の手引きは、宮古市社会福祉協議会、ニチイケアセンター宮古、ニチイケアセンター八木沢、ニチイケアセンター宮古西町、ニチイケアセンター西ヶ丘、ハートランド宮古を掲載しています。掲載は現在のお子様の受け入れや希望日時の担当を保証しません。
利用までの流れ
宮古市福祉課へ相談・申請 → 調査・サービス等利用計画の作成 → 市の支給決定 → 受給者証の交付 → 掲載事業所へ対象、訪問地域、曜日・時間、費用、必要な介助を相談 → 契約・利用。
医療的ケアについて
市の手引きでは、吸引、経管栄養、人工呼吸器などの事業所別対応を確認できませんでした。必要な処置を一般の居宅介護から推測せず、事業所へ一つずつ確認してください。
利用できる時間
希望する曜日・時間、担当できる職員は未確認です。
地域・送迎
宮古市の制度案内です。各事業所の訪問地域、市外からの利用は要確認です。
料金
宮古市では、満18歳になった年度の3月31日までのお子様について、居宅介護を含む障害福祉サービスの利用者負担を、2024年4月利用分から無償としています。3歳から18歳は手続き不要です。医療費、食費等の実費は無償化の対象外です。受給者証の記載と実費を市へ確認してください。

満18歳になった年度の3月31日までのお子様の障害福祉サービス利用者負担は、2024年4月利用分から無償です。3歳から18歳は手続き不要ですが、医療費・食費等の実費は対象外です。
