施設のこと

地域
盛岡市
サービスの種類
お泊まり（短期入所）日中のあずかり
対象年齢
主に知的障がいのあるお子様（児童）が対象の福祉型障害児入所施設です。短期入所・日中一時支援の対象年齢は施設へ確認してください。
ひとこと
岩手県社会福祉事業団の福祉型障害児入所施設です。在宅で暮らすお子様のために、宿泊する短期入所と、日帰りの日中一時支援を行うと案内されています。
空き・受付について
2026年11月13日に、岩手県社会福祉事業団のよつばのページ、てしろもりの丘のページ、サービス別一覧を確認しました。電話確認はしていません。現在の新規受付・空き、年齢、時間、送迎、費用、医療的ケアへの対応は未確認です。
利用の条件
短期入所はお住まいの市町村の支給決定、日中一時支援は市町村の利用決定が必要です。現在の受付、お子様ごとの利用、必要な介助は施設へ確認してください。
利用までの流れ
お住まいの市町村へ短期入所・日中一時支援を相談 → 支給決定・利用決定を確認 → てしろもりの丘へ年齢、希望日、必要な介助を相談 → 契約・利用日を確認。
医療的ケアについて
公式ページには、医療的ケアや看護師、吸引・経管栄養などの記載はありませんでした。必要なケアは施設へ確認してください。
利用できる時間
短期入所の入退所時刻、日中一時支援の曜日・時間は確認できませんでした。
地域・送迎
所在地は盛岡市手代森です。利用できる市町村、送迎の有無は確認できませんでした。
料金
制度による利用者負担と、食事などの実費は確認できませんでした。
