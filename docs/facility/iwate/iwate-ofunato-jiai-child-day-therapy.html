施設のこと

地域
大船渡市
サービスの種類
通う療育日中のあずかり
対象年齢
大船渡市の現在案内では、児童発達支援は未就学のお子様、放課後等デイサービスは小学生から高校生が対象です。2024年度事業報告の日中一時支援は利用者（児）としていますが、詳しい年齢は要確認です。
ひとこと
児童発達支援・放課後等デイサービスと、ご家族の就労・休息を支える日中一時支援を行う大船渡市の事業所です。療育の受給者証と、地域生活支援事業の日中一時支援を分けて掲載します。
空き・受付について
大船渡市の現在案内と法人の2024年度事業報告を2026年10月29日に確認しました。日中一時支援の2024年度利用実績0名は現在の休止・受付不可を示しません。電話確認はしていません。現在の新規受付・空き、希望日時、利用地域、送迎、費用・実費、看護体制、お子様ごとの個別ケアは未確認です。
利用の条件
療育は市こども家庭センターまたは相談支援事業所へ相談し、見学、申請、通所受給者証の支給決定後に契約します。日中一時支援はお住まいの市町村へ別に相談し、対象・利用決定・希望日時・必要な介助を確認してください。
利用までの流れ
療育は大船渡市こども家庭センターまたは相談支援へ相談 → 見学 → 市へ申請・計画案 → 支給決定・通所受給者証 → 事業所と契約。日中一時支援はお住まいの市町村へ別に相談 → 利用決定を確認 → 事業所へ年齢・希望日・介助・医療的ケア・費用を相談。
医療的ケア
あり
医療的ケアについて
2024年度事業報告は、療育で酸素療法が必要な医療的ケア児を支援した実績と、日中一時支援の医療的ケアは療育と同じと記載しています。現在の受け入れや希望日の看護体制を示すものではありません。吸引、経管栄養、人工呼吸器等は未確認です。
利用できる時間
2024年度事業報告では、療育の利用児受け入れ7時30分〜9時30分、家族迎えまで17時30分、日中一時支援の通学支援時程等を掲載しています。これは2024年度の運営報告で、現在の開所時間や希望日の受け入れを確約しません。
地域・送迎
所在地は大船渡市です。2024年度事業報告は、日中一時支援について大船渡市・陸前高田市から許可を受けた沿革を掲載しています。現在の利用対象地域、送迎、その他の市町村からの利用は要確認です。
料金
療育と日中一時支援で制度・利用決定・負担が異なります。制度の利用者負担、食事・おやつ・活動・送迎等の実費と現在額は、市町村と事業所へ確認してください。
