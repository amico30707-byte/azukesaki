宮古市 こども誰でも通園制度

お知らせ一般の乳幼児向け通園制度です。障害福祉の日中一時支援・児童発達支援とは別です

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
宮古市
サービスの種類
日中のあずかり
対象年齢
宮古市民で、保育所・認定こども園・小規模保育・家庭的保育・認可外保育施設等に在籍していない、0歳6か月から満3歳未満のお子様が対象です。施設によって満2歳だけの場合があります。
ひとこと
お父様・お母様の就労の有無を問わず、月10時間まで時間単位等で保育施設へ通える制度です。障害福祉の日中一時支援や児童発達支援ではありません。
利用の条件
宮古市へ総合支援システムから利用登録を申請し、市が登録して認定証を発行した後、利用希望施設との初回面談を予約します。面談後に利用予約を行い、施設が受け入れ可能と確認して承認した場合に予約が確定します。
利用までの流れ
総合支援システムで宮古市へ利用登録申請 → 市の確認・認定証発行 → 希望施設との初回面談を予約 → 面談後に利用予約 → 施設が受け入れ可能と確認し承認すると予約確定 → 利用当日に二次元コードで開始・終了を登録。
医療的ケアについて
市の一般の通園制度の案内から、障害のあるお子様や医療的ケアのあるお子様の個別受け入れ、重症心身障害、重度知的障害、強度行動障害、全面介助、吸引、経管栄養、人工呼吸器等への対応を推測していません。初回面談前に必要な支援を伝えてください。
利用できる時間
お子様1人につき月10時間まで。宮古泉幼稚園は満2歳・毎週水曜9時30分〜11時30分、あかまえこども園は0歳6か月〜満3歳未満・月〜金曜9時〜11時または13時〜15時、ククナの家は0歳6か月〜満3歳未満・火・水曜9時30分〜11時30分です。利用可能日は総合支援システムで確認します。
地域・送迎
宮古市民が対象です。2026年4月以降の実施先は認定こども園宮古泉幼稚園、認定こども園あかまえこども園、2026年5月以降は小規模保育事業所ククナの家も掲載されています。
料金
宮古市公式ページは無料と案内しています。給食・おやつ・行事等の実費は公式ページで確認できないため、利用施設へ確認してください。
電話
0193-62-2111宮古市こども家庭センター。こども誰でも通園制度の登録・認定証・施設選びについて確認してください。各施設の直通電話ではありません。
確認日
2026年10月30日
