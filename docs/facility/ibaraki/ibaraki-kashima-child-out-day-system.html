施設のこと

地域
鹿嶋市
サービスの種類
外出の付きそい日中のあずかり
対象年齢
鹿嶋市の地域生活支援事業として、障がいのあるお子様を対象に含みます。移動支援は屋外の移動が難しいお子様の外出支援、日中一時支援は一時的な見守り・指導・訓練等を行う日帰りの支援です。
ひとこと
お子様の外出をヘルパーが支える移動支援と、ご家族の休息等のために日帰りで見守りを受ける日中一時支援の、鹿嶋市の申請入口です。市役所は申請窓口であり、支援場所・実施事業所ではありません。
空き・受付について
2026年10月29日に鹿嶋市の2026年度版子育てガイド、移動支援・日中一時支援の要綱、障がい福祉課ページを確認しました。電話確認はしていません。現在の実施事業所、新規受付・空き、希望日時、利用地域、送迎、お子様ごとの利用可否、費用・実費、個別ケアは未確認です。
利用の条件
利用前に鹿嶋市へ地域生活支援事業の申請を行い、市の利用決定を受けます。決定通知書を事業所へ示し、希望日時、外出目的または日中の預かり、必要な支援を事業所と直接調整します。利用決定は原則として最初に来る6月30日までで、継続時は期限前1か月以内に更新申請します。
利用までの流れ
鹿嶋市障がい福祉課へ、移動支援か日中一時支援かを伝えて申請 → 市の審査・利用決定 → 決定通知書を実施事業所へ提示 → 地域・日時・外出目的または預かり時間・費用・必要な支援を確認 → 事業所と利用手続き。
医療的ケアについて
市の制度要綱は、日中一時支援の重症心身障害児等に関する料金区分を定めていますが、これは実施事業所が現在受け入れる証拠ではありません。重症心身障害、重度知的障害、強度行動障害、全面介助、吸引、経管栄養、人工呼吸器等の個別対応は未確認です。
利用できる時間
移動支援は原則1日の範囲内です。日中一時支援の利用時間は4時間未満、4時間以上8時間未満、8時間以上の区分がありますが、これは料金区分であり、事業所の開所時間・希望日の受け入れを示すものではありません。
地域・送迎
鹿嶋市の制度です。移動支援は原則1日のうちに用務を終える外出が対象です。実施事業所、実際の外出地域、日中一時支援の預かり場所・送迎、市外利用は未確認です。
料金
移動支援・日中一時支援は、市の要綱に定める額の1割を事業所へ支払い、世帯の所得等による上限があります。移動支援の有料道路・駐車場等は別に実費が必要です。日中一時支援の送迎加算は市から事業所へ支払うサービス提供費の計算であり、お子様の現在の追加負担額とは扱っていません。

サービスごとのこと

移動支援
屋外の移動が難しいお子様の個別外出を支援します。原則1日の範囲内で、事前申請と市の利用決定が必要です。

確認日：2026年10月29日

出典：city.kashima.ibaraki.jp
確認日：2026年10月29日
