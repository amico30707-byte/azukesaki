施設のこと

対象年齢
神栖市の2026年版『やさしい福祉』は、障害福祉サービスの対象に児童を含めています。市内の居宅介護事業所一覧はありますが、各事業所が現在お子様を受け入れていることや詳しい年齢を示す一覧ではありません。
ひとこと
お子様の居宅介護を神栖市へ申請し、市内事業所一覧から契約先を探すための制度入口です。市役所は申請窓口であり、家へ来る支援者を派遣する事業所ではありません。
利用の条件
利用前に市または相談支援事業所へ相談し、市へ申請します。サービス等利用計画案、支給決定を経て、一覧に載る事業所へお子様の年齢、家で必要な介助、訪問地域、希望日時、現在の受け入れを確認し、契約します。市の一覧掲載だけではお子様の担当可否は分かりません。
利用までの流れ
神栖市または相談支援事業所へ相談 → 市へ利用申請 → サービス等利用計画案 → 市の支給決定 → 市内事業所へお子様対象・訪問地域・日時・介助・費用を確認 → 契約・個別支援計画 → 利用開始。
医療的ケアについて
居宅介護の制度対象と市内事業所一覧は確認しましたが、重症心身障害、重度知的障害、強度行動障害、全面介助、吸引、経管栄養、人工呼吸器等のお子様ごとの対応は確認できませんでした。情報がない項目を『対応なし』とは扱いません。
