結城市 障害福祉サービス（居宅介護）の確認窓口

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
結城市
サービスの種類
家に来るヘルパー
対象年齢
制度案内は障害児も対象に含めています。一方、2026年9月10日更新の市内事業所一覧では、居宅介護の事業所が「障害者（18歳以上）」の欄に掲載されています。各事業所がお子様を受け入れているかは未確認です。
ひとこと
結城市で、お子様の居宅介護を探すときの制度・申請窓口です。市の現在一覧には居宅介護の事業所がありますが、成人向けの掲載条件をお子様へ当てはめず、利用可否は市と各事業所へ確認する必要があります。
利用の条件
障害福祉サービスの利用は市への申請と支給決定が必要です。障害支援区分が不要な場合もありますが、お子様の年齢、受給者証、希望する介助、利用時間、事業所のお子様受け入れを個別に確認してください。
利用までの流れ
結城市社会福祉課へ相談 → お子様が居宅介護の対象になるか、申請・受給者証の手順を確認 → 市内事業所へお子様の受け入れ、訪問地域、希望日時、必要な介助、費用を確認 → 支給決定後に契約。
医療的ケアについて
市の制度案内・事業所一覧だけでは、お子様の医療的ケア、吸引、経管栄養、人工呼吸器への対応を確認できませんでした。
