施設のこと

地域
潮来市
サービスの種類
外出の付きそい
対象年齢
潮来市に住む障がいのあるお子様・成人が対象です。お子様ごとの障がい状況、外出目的、身体介護の有無、必要時間を市が確認して利用を決定します。
ひとこと
潮来市で、社会生活上必要な外出や余暇の外出に付きそう移動支援を事前に申請するための入口です。市役所の住所は支援場所ではなく、登録事業所一覧も現在の担当可否を示しません。
空き・受付について
潮来市の現在の制度ページ・案内と、2026年5月1日現在の事業所一覧を2026年10月29日に確認しました。電話確認はしていません。現在担当できる登録事業所、新規受付・空き、希望日時・外出地域、実費、お子様ごとの介助・個別ケアは未確認です。
利用の条件
利用前に市へ申請し、地域生活支援事業受給者証の交付を受け、登録事業所へ直接相談します。通院、通勤、通学、通所、営業活動、10時間を超える外出、定期的で長期の外出等は対象外と案内されています。
利用までの流れ
潮来市社会福祉課へ事前相談・申請 → 市が対象・身体介護の有無・支給量を確認 → 地域生活支援事業受給者証の交付 → 登録事業所へ希望日時・外出目的・経路・実費・必要な介助を相談 → 利用時に受給者証を提示。
医療的ケアについて
市の制度案内から、重症心身障害、重度知的障害、強度行動障害、全面介助、吸引、経管栄養、人工呼吸器等の個別対応を推測していません。登録事業所へ一つずつ確認してください。
利用できる時間
利用時間や曜日は、支給決定と登録事業所の現在の担当状況によります。利用承認は原則として9月30日までで、10月1日以降も続ける場合は更新申請が必要です。
地域・送迎
潮来市に住む方の制度です。実際に利用できる地域、出発・到着場所、登録事業所の現在の提供地域は、市と事業所へ確認してください。
料金
市民税非課税世帯は無料。課税世帯は30分100円で1日上限2,000円、身体介護を伴う場合は30分200円で1日上限4,000円です。公共交通、通行料、駐車料、送迎等は別に必要です。登録されていない事業所へ支払った費用は市の対象になりません。
住所
申請・相談窓口：潮来市役所 社会福祉課。支援を受ける場所や登録事業所の住所ではありません。
電話
