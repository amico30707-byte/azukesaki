姫路赤十字病院 医療型短期入所（県の輪番事業）

施設のこと

地域
姫路市
サービスの種類
お泊まり（短期入所）
対象年齢
兵庫県の輪番事業では15歳未満のお子様が対象です。寝たきりで呼吸の障害がなく、経管栄養のみ（口から食べられない）のお子様が対象と書かれています。
ひとこと
兵庫県の医療型短期入所の輪番事業で、播磨地域の受け入れ病院です。県の表では5月・6月の担当です。
空き・受付について
県の輪番事業で5月・6月の担当であることは確認しましたが、ほかの月の利用、現在の空き、費用は未確認です。県のページ（2026年7月2日更新）で確認しました。病院の公式ページには、この事業の案内が見つかりませんでした。電話での確認はしていません。ベッドが空いていないときや、お子様の状態によっては利用できないことがあると県のページに書かれています。
利用の条件
県の輪番事業の対象は、県内に住み、医療型短期入所の対象になるお子様です。受給者証がない場合は、まずお住まいの市町に支給決定を相談します。必要に応じて事前診察、かかりつけ医の診療情報提供書、契約、予約があります。呼吸の障害があるお子様は、県の表では対象外です。
利用までの流れ
受給者証がなければ市町に支給決定を相談 → 病院の窓口に電話で申込み → 事前診察の予約（不要な病院もあり） → かかりつけ医の診療情報提供書を提出 → 事前診察（外来） → 利用契約 → 利用日の予約 → 利用。
医療的ケア
あり
医療的ケアについて
県の輪番事業の表に「経管栄養状態のみ（経口摂取不可）」「寝たきり・呼吸障害なし」と書かれています。人工呼吸器や吸引が必要なお子様の受け入れは、この表からは読み取れず、要確認です。
利用できる時間
県の表では5月・6月の担当です。ほかの月の利用、入所・退所の時刻、泊数は未確認です。
地域・送迎
兵庫県内に住む対象のお子様。県の表では播磨地域の担当です。圏域に入る市町は公式ページに書かれていないため、要確認です。
料金
県のページに費用の記載はありません。障害福祉サービスの利用者負担や食費などの実費は、市町と病院へ確認してください。
