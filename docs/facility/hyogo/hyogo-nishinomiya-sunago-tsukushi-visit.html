西宮すなご医療福祉センター 訪問看護ステーションつくし

施設のこと

地域
西宮市
サービスの種類
家に来るヘルパー
対象年齢
小児と重症心身障がい児・者を中心に、知的障がいや身体障がいのある方も対象です。年齢の上限は書かれていません。
ひとこと
西宮すなご医療福祉センターの訪問看護です。お子様と重症心身障がいのある方を中心に、ご自宅での看護、リハビリ、ご家族への支援（日中の見守りや相談）を行います。西宮市の小児慢性特定疾病のお子様のレスパイト事業の登録事業者にものっています。
空き・受付について
公式ページと西宮市のページで、対象、処置の例、時間、市のレスパイト事業の登録を確認しました。新しい受け入れの空き、お子様ごとの受け入れ、訪問看護の費用は未確認で、電話での確認もしていません。
利用の条件
訪問看護は医師の指示のもとで行います。申込みの方法は公式ページに書かれていないため、ステーションへお問い合わせください。西宮市のレスパイト事業を使うときは、市の対象（小児慢性特定疾病医療受給者証を持つ西宮市民のお子様など）と申請が必要です。
利用までの流れ
ステーションへ相談 → 主治医の訪問看護指示書 → 契約 → 訪問開始。西宮市のレスパイト事業は、事業者と内容を相談してから市に申請 → 利用決定通知書兼利用券 → 事業者と日時を調整。
医療的ケア
あり
医療的ケアについて
公式ページに、医師の指示のもとで行う処置として、胃ろうなどのカテーテル管理、気管カニューレ管理、人工呼吸器管理、在宅酸素などがのっています。お子様ごとの受け入れ、レスパイトで伺える時間は要確認です。
利用できる時間
月曜日から土曜日の9時〜17時（相談可）。日曜・祝日・年末年始・お盆は休みです。24時間の連絡体制があり、緊急時の対応もできると書かれています。
地域・送迎
西宮市内のほか、市外の方の利用も順次受け付けていると書かれています。伺える範囲は要確認です。
料金
訪問看護の費用は公式ページに書かれていません。西宮市の小児慢性特定疾病のレスパイト事業は、年間12時間以内で自己負担なし（交通費などは別）と市のページにあります。
