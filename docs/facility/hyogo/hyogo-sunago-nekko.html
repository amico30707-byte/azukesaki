西宮すなご医療福祉センター ねっこ

空きや受け入れは、かならず施設にご確認ください

利用を考えるときは

公式ページを見る西宮すなご医療福祉センター｜児童発達支援事業ねっこ

電話0798-44-3331

確認日：2026年10月15日（あずけさき手帖が公式の情報を確かめた日）

施設のこと

地域
西宮市
サービスの種類
通う療育
対象年齢
児童発達支援は2〜5歳の発達の遅れや偏りがあるお子様、放課後等デイサービスは主に小学1〜3年生（場合により4年生まで）を案内しています。
ひとこと
未就学のお子様は原則親子で個別・集団療育へ通い、小学生はお子様だけで個別・集団療育を受ける通所支援です。
空き・受付について
対象、親子・単独通所、曜日・時間、定員1日10名、利用者負担と実費、受給者証は確認しました。利用希望は随時受付ですが、定員到達時はすぐ利用できない場合があります。現在の空き、電話でのお子様ごとの受け入れ、利用市町村、送迎、個別ケアは未確認です。2026年度4月の新規募集表示や定員を現在の空きとは扱っていません。
利用の条件
登録制で通所受給者証の申請が必要です。児童発達支援と放課後等デイサービスを合わせた定員は1日10名です。利用希望は随時受け付けていますが、定員到達時はすぐ利用できない場合があります。放課後等デイサービスは、基本的に児童発達支援ねっこの卒業児が対象で、一般利用は空き状況により受け付けます。2026年度4月の新規募集表示や定員を、現在の空きとは扱いません。
利用までの流れ
ねっこへ相談 → 年齢、親子・単独通所、利用枠、地域を確認 → 市区町村へ通所受給者証を申請 → 登録 → 利用開始時期を調整。
医療的ケアについて
必要に応じて医療、心理士、リハビリを案内できることは確認しました。児童発達支援・放課後等デイサービスでの医療的ケア一般、吸引、経管栄養、人工呼吸器の対応は未確認です。
利用できる時間
児童発達支援は、2〜5歳の個別療育が月・火・金曜の9時〜10時30分、11時〜12時、金曜13時30分〜14時30分などです。集団療育は4〜5歳が月・火曜14時30分〜15時30分または16時〜17時、2〜3歳が水・木曜9時〜10時30分または11時〜12時です。放課後等デイサービスは水・木曜13時30分〜14時30分の個別療育、水・木・金曜15時〜17時の集団療育です。利用枠は年齢・内容により異なります。
地域・送迎
施設は西宮市にあります。児童発達支援は原則親子通所です。利用できる市町村、送迎の有無・範囲は公式ページで確認できていません。
料金
在住の市区町村が通所受給者証に定めた利用者負担額です。教材等の実費は別に必要です。
住所
兵庫県西宮市武庫川町2番9号
電話
0798-44-3331ねっこ直通。対象年齢、親子・単独通所、利用枠、申請、現在の空きを確認します。
