施設のこと

地域
西宮市
サービスの種類
お泊まり（短期入所）
対象年齢
重症心身障がい児者の短期入所です。対象の年齢は公式ページに書かれていないため、要確認です。
ひとこと
重症心身障がいのあるお子様・大人の方が使える、短い期間のお泊まりのサービスです。登録から利用まで完全予約制で、初回は日帰り利用のみです。
空き・受付について
公式ページに「新規および再開利用受付休止のお知らせ」（2026年2月ごろ掲載のPDF）と、2026年12月〜2027年1月の申込みのお知らせがのっています（PDFの中身は確認できていません）。新しく使えるかどうか、空き、費用は未確認で、電話での確認もしていません。
利用の条件
障害福祉サービスの支給で「障害児医療型（重心医ケア）」または「障害者医療型（療養介護）」の判定がある方、またはセンターの診察で利用に当たると判断された方が対象です。利用できるのは西宮市・尼崎市・芦屋市・宝塚市・伊丹市・川西市・猪名川町にお住まいの方です。主治医の医療情報提供書、フェイスシート、保険証、受給者証、母子手帳、障害者手帳・療育手帳などが必要です。最後の利用から2年以上たったときや体の状態が変わったときは、書類と診察をやり直します。
利用までの流れ
相談支援課に連絡 → 見学・面談 → 医療情報提供書・フェイスシートの確認 → 書類をもとにした診察（予約制） → 契約 → 利用開始（初回は日帰りのみ）。

あり
医療的ケアについて
対象は「障害児医療型（重心医ケア）」などの判定がある方で、医療型の短期入所です。吸引・経管栄養・人工呼吸器など処置ごとの受け入れは公式ページに書かれておらず、要確認です。
利用できる時間
登録から利用まで完全予約制です。初回は日帰り利用のみです。最長の日数や入所・退所の時刻は公式ページで確認できませんでした。

西宮市・尼崎市・芦屋市・宝塚市・伊丹市・川西市・猪名川町。
料金
