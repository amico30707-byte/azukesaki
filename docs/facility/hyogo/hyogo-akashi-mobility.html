明石市 移動支援事業

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
明石市
サービスの種類
外出の付きそい
対象年齢
対象要件を満たす全身性障害、知的障害、精神障害、視覚障害等のお子様を含みます。未成年は原則として保護者同伴を想定し、例外は市の判断が必要です。
ひとこと
社会生活上必要な外出や余暇活動など、社会参加のための外出を支える明石市の移動支援です。お子様の保護者同伴の考え方もガイドラインに示されています。
利用の条件
お子様だけでの利用は、介助するご家族の同行が難しい場合、保護者1人では介助が難しい場合、ご家族の疾病等で一時的に付きそえない場合などに認められることがあります。利用時のお子様の引き渡しは保護者が行います。通園・通学・通院等の通年・長期の外出は対象外です。
利用までの流れ
明石市障害福祉課へ申請書と必要書類を提出 → 生活・身体状況の調査 → 市の支給決定・受給者証 → 2026年1月9日時点の一覧を候補探しに使う → 指定事業所へ現在の地域・日時・実費・支援内容を確認 → 契約・利用。お子様だけで利用する場合も、ガイドヘルパーへの引き渡しは保護者が行います。
医療的ケアについて
市の制度ページと移動支援ガイドラインでは、医療的ケア一般、吸引、経管栄養、人工呼吸器に対応する事業所を確認できませんでした。必要な処置は市と候補事業所へ確認してください。
