岐阜県立多治見病院 医療型短期入所

お知らせ対象は中学3年生までで、住んでいる地域（多治見市・土岐市・瑞浪市・恵那市・中津川市・可児市・御嵩町）の条件があります。利用は3か月に1回です。

空きや受け入れは、かならず施設にご確認ください

利用を考えるときは

公式ページを見る岐阜県立多治見病院｜医療型短期入所について

電話0572-22-5311

確認日：2026年11月11日（あずけさき手帖が公式の情報を確かめた日）

施設のこと

地域
多治見市
サービスの種類
お泊まり（短期入所）
対象年齢
中学3年生までです（公式ページ）。
ひとこと
岐阜県立多治見病院が2025年8月1日から始めた、重症心身障がいのお子様の医療型短期入所です。空いているベッド1床を使い、1泊2日から3泊4日まで泊まれます。人工呼吸器を使っているお子様などが対象です。
空き・受付について
2026年11月11日に、岐阜県立多治見病院の医療型短期入所のページ、しおり（2025年8月版）、お知らせ（2025年8月1日）を確認しました。電話確認はしていません。1床はいまの空きではありません。空き・予約の状況、料金、送迎は未確認です。
利用の条件
公式ページでは、人工呼吸器を使っている方や、気管切開・吸引・胃ろう・経管栄養などの医療的ケアが必要で一人で歩けない方などが対象です。対象の地域に住んでいることも条件です。利用資格確認フォーム、小児科外来での利用前の診察、付きそいありのおためし利用を経て、病院が利用の可否を決めます。
利用までの流れ
利用資格確認フォームを送る → 小児科外来で短期入所の利用前の診察（第2・第4木曜日） → 利用の可否の連絡 → おためし入院1回目（1泊2日・保護者付きそい） → おためし入院2回目（2泊3日・保護者付きそい）、最終日に契約の相談 → 本予約（毎月1日〜7日に翌月から3か月分を受付） → 入所当日の医師の診察で最終判断。
医療的ケア
あり
医療的ケアについて
公式ページでは、人工呼吸器を使っている方や、医療的ケア（気管切開、吸引、胃ろう、経管栄養など）が必要で一人で歩けない方などが対象です。しおりの持ち物の表には、呼吸器、吸引、酸素、導尿、経管栄養の物品があります。お子様ごとの受け入れは、事前の診察とおためし入院で病院が判断します。
利用できる時間
入所は火曜日だけで、13時45分に指定の駐車場に着いたら病棟へ電話します。退所は10時です（9時までに来院）。しおりには、退所を水曜日・木曜日にすることもできると書かれています。土日祝日・年末年始（12月29日〜1月3日）は利用できず、火曜日から金曜日に祝日がある週も利用できません。新しい入所は1週間に1名で、利用の間は最短で3か月です（公式ページと2025年8月版のしおり）。
地域・送迎
多治見市、土岐市、瑞浪市、恵那市、中津川市、可児市、可児郡御嵩町にお住まいの方が対象です（公式ページ）。送迎の記載はありません。
料金
料金は公式ページ・しおりに書かれていないため、病院へご確認ください。
住所
岐阜県多治見市前畑町5丁目161番地（南5階病棟）
電話
0572-22-5311病院の代表番号です。公式ページでは「南5階病棟 0572-22-5311（内線5689）」として、前の週の金曜日正午を過ぎた取り消しの連絡先に案内されています。それより前の取り消しは、病院のお問い合わせフォームからです。
