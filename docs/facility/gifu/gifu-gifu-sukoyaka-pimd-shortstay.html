ひとこと
岐阜県総合医療センターの重症心身障がい児施設で、在宅で重症心身障がい児・者を介護するご家族の負担を軽くするための短期入所（レスパイト）を行っています。運営規程では、空いているベッドを使い、利用は6名までです（空きの人数ではありません）。
空き・受付について
2026年11月11日・12日に、すこやかのページ・しおり・運営規程と、岐阜県の一覧（2022年4月1日現在）を確認しました。電話確認はしていません。6名はいまの空きではありません。空き・新規の受付、お子様の年齢、利用できる地域、料金、処置ごとの対応は未確認です。
利用の条件
お住まいの市町村の障がい福祉の窓口で受給者証を受けたうえで、病院の小児療育内科の外来で診察を受け、利用が認められたら契約します（2024年11月版のしおり）。施設が別に決めた入所の基準があります。はじめは日帰りの「おためし」（木曜日・11時入所）から始めると書かれています。お子様ごとの利用の可否は施設へご確認ください。
利用までの流れ
市町村の窓口で受給者証を申請 → 小児療育内科の外来を予約して診察 → 利用が認められたら短期入所の契約 → 日帰りの「おためし」 → 予約（2024年11月版のしおりでは、利用する月の前の月の最初の平日から。Webは5時、電話は9時から受付。利用の5日前まで）→ 健康チェックの記録を出して入所。予約の受付日は年度ごとにお知らせが出るため、すこやかのページでご確認ください。
医療的ケア
あり
医療的ケアについて
すこやかのしおり（2023年12月改訂）に、看護師による医療的ケアを行うと書かれています。岐阜県の医療機関一覧（2022年4月1日現在）では、医療的ケアが必要な児・者を受け入れる医療型短期入所にのっています。吸引、経管栄養、人工呼吸器など処置ごとの受け入れは、施設へご確認ください。
利用できる時間
2024年11月版のしおりでは、入所は平日の9時または10時（土日祝日・年末年始は入所できません）、退所は14時・15時・16時のいずれか（土日祝日も退所できます）です。利用は1か月に1回・7日以内（最大6泊7日）で、受給者証の日数の範囲内です。窓口の受付は平日8時30分〜17時15分です（運営規程）。
地域・送迎
施設は岐阜市野一色にあります。利用できる市町村や送迎は公式の資料に書かれていないため、要確認です。
料金
障害福祉サービスの利用者負担、食事代、水道光熱費などを後日請求すると書かれています。食事の負担額は2026年6月に変わったとお知らせがあります。金額は確認できなかったため、施設へご確認ください。
