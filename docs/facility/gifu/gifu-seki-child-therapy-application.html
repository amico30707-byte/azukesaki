関市 障がい児通所支援の手続き

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
関市
サービスの種類
通う療育
対象年齢
児童発達支援は通所する障がいのあるお子様、放課後等デイサービスは学校に通う障がいのあるお子様が対象です。詳しい年齢・状態と利用する施設の対象は、福祉政策課と施設へ確認してください。
ひとこと
関市が案内する児童発達支援・放課後等デイサービス等の制度と、相談から申請、利用計画案、支給決定・受給者証、事業所との契約までの手順です。特定の施設の現在の空き案内ではありません。
利用の条件
利用したい施設を確認したうえで、保護者が関市へ障害児通所支援給付費を申請します。市から求められた場合は障害児支援利用計画案を提出し、支給決定後に受給者証を受け取り、事業所と契約します。
利用までの流れ
関市福祉政策課へ相談 → 利用したい施設を確認 → 保護者が障害児通所支援給付費を申請 → 必要な場合は障害児支援利用計画案を依頼・提出 → 支給決定・受給者証の発行 → 事業所へ現在の受付・空き、曜日・時間、送迎、費用、個別の支援を確認 → 契約・利用。
医療的ケアについて
市の制度・手続き案内から、医療的ケア一般、重症心身障害、重度知的障害、強度行動障害、全面介助、吸引、経管栄養、人工呼吸器、看護師配置などを推測していません。利用する事業所と日時ごとに確認してください。
利用できる時間
市は、申請から受給者証の発行までおおむね1か月半〜2か月と案内しています。これは施設の待ち期間や現在の空きではありません。療育の曜日・時間は利用先へ確認してください。
地域・送迎
関市の申請・相談窓口です。掲載ページだけでは市内外の利用施設、送迎範囲、利用できる地域を確認できないため、施設ごとに確認してください。
料金
申請書には利用者負担額の減額・免除申請が含まれます。世帯区分別の月額上限、3〜5歳の無償化、食費・教材費・送迎等の実費は、市と利用先へ確認してください。
住所
申請・相談窓口：岐阜県関市若草通3丁目1番地（関市役所 南庁舎1階 福祉政策課）
