施設のこと

地域
鳴門市
サービスの種類
外出の付きそい
対象年齢
鳴門市が外出時の支援が必要と認める障がい児者が対象です。全身性障がい・知的障がいのお子様の条件や、保護者の疾病等で通学手段がない行動援護受給中のお子様の例外条件があります。
ひとこと
社会生活上必要な外出や余暇活動などの社会参加を支える鳴門市の移動支援です。お子様を含む対象、月の支給量、費用基準、利用者証、事業所契約が要綱に示されています。現行PDF末尾には2025年10月1日施行の附則があります。
空き・受付について
市の対象・支給量・費用基準・1割負担・申請・利用者証・契約と、現行PDF末尾の2025年10月1日施行の附則を2026年10月18日に再確認しました。現在の契約事業所一覧、空き、新規受付、電話でのお子様ごとの受け入れ、地域・曜日・時間・交通費・個別ケアは未確認です。
利用の条件
原則1日で終わる外出が対象で、通勤・営業活動・通年で長く続く外出などは対象外です。市へ申請し、地域生活支援事業利用者証を事業所へ提示して、契約と利用内容を調整します。
利用までの流れ
鳴門市社会福祉課へ対象・外出目的を相談 → 市へ申請 → 支給決定・地域生活支援事業利用者証を確認 → 市と契約する事業所へ提示 → 外出地域・日時・実費・必要な介助を確認 → 契約・利用調整。
医療的ケアについて
市の制度ページ・実施要綱では、医療的ケア一般、吸引、経管栄養、人工呼吸器に対応する移動支援事業所を確認できませんでした。必要な処置は市と事業所へ確認してください。
利用できる時間
通常の支給量は月30時間以内です。保護者の疾病等でほかに通学手段がない場合の例外的な通学支援は月4回以内（片道を1回）です。事業所の提供曜日・時間は別に確認してください。
地域・送迎
鳴門市の制度です。市と契約する事業所の所在地、実際の外出範囲、市外外出の条件は未確認です。
料金
費用基準は30分以内1,500円、30分超1時間以内2,700円、1時間超1時間30分以内4,000円、以後は時間帯ごとの額です。実際の利用者負担は基準額の1割で、要綱では月額上限なしです。生活保護世帯と市民税非課税世帯は徴収しないとされています。料金表は営業時間ではなく、交通費等の実費は候補事業所へ確認してください。
