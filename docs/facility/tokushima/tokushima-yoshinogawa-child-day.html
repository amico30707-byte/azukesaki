吉野川市 日中一時支援

空きや受け入れは、かならず施設にご確認ください

利用を考えるときは

公式ページを見る吉野川市｜子育てガイド（2026年度版）

電話0883-22-2263

確認日：2026年10月9日（あずけさき手帖が公式の情報を確かめた日）

施設のこと

地域
吉野川市
サービスの種類
日中のあずかり
対象年齢
日中に監護する方がいないため、一時的な見守りなどが必要な障がい児を対象に含みます。知的障がいのある方も対象です。お子様ごとの対象判断は市へ確認してください。
ひとこと
障がいのあるお子様の日中の活動の場を確保し、ご家族の就労や一時的な休息を支える、宿泊を伴わない吉野川市の事業です。
空き・受付について
2026年度版の子育てガイドで障がい児の日中一時支援を、地域生活支援事業の案内・規則で申請、支給量、料金区分を確認しました。市の受給者証は希望日時の利用を確約しません。現在の実施事業所、新規受付・空き、曜日・時間、送迎、電話でのお子様ごとの受け入れ、個別ケアは未確認です。
利用の条件
利用前に吉野川市福祉総務課へ申請し、地域生活支援事業受給者証の交付を受けます。市の案内では、原則月7日、8月のみ月14日が支給量の上限です。現在の適用とお子様の決定日数は申請時に確認してください。
利用までの流れ
吉野川市福祉総務課へ相談 → 対象・必要書類・現在の料金を確認 → 障がいの程度を示す手帳等を添えて申請 → 地域生活支援事業受給者証と支給量を確認 → 案内された事業所へ現在の受付、日時、食事・送迎等の実費、支援内容を確認 → 利用。
医療的ケアについて
日中重心医療機関の料金区分があっても、重症心身障害、吸引、経管栄養、人工呼吸器など個別ケアへの対応は推測していません。事業所ごとに確認してください。
利用できる時間
市の案内は4時間以下、4時間超8時間以下、8時間超の区分を示しています。これは事業所の営業時間や希望日時の空きを示すものではありません。
地域・送迎
吉野川市へ申請する地域生活支援事業です。市外事業所の利用、現在利用できる事業所、事業所ごとの対象地域・送迎範囲は未確認です。
料金
市の案内では、日中基本は4時間以下150円、4時間超8時間以下310円、8時間超470円、日中重心医療機関は同480円・970円・1,450円です。市民税非課税世帯は無料で、食事・送迎等は別に自己負担とされています。申請時に現在の額と実費を確認してください。
住所
申請窓口：徳島県吉野川市鴨島町鴨島115番地1（吉野川市福祉総務課）
電話
0883-22-2263吉野川市福祉総務課 障がい福祉係。対象、申請、現在利用できる事業所、料金を確認してください。
確認日
2026年10月9日

サービスごとのこと

日中一時支援（宿泊なし）
日中に一時的な見守りなどが必要な障がい児を対象に含み、ご家族の就労・休息を支えます。市への事前申請と地域生活支援事業受給者証が必要です。
