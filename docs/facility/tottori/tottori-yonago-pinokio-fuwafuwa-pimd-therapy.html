施設のこと

地域
米子市
サービスの種類
通う療育
対象年齢
放課後等デイサービスなので、学校に通うお子様が対象です。主に医療ケアの必要な重症心身障がいのお子様の支援をしています。
ひとこと
NPO法人ぴのきおの重心型の放課後等デイサービスです。米子市の案内では、主に医療ケアの必要な重症心身障がい児の支援を行い、バイタルチェック、吸引、注入（水分補給）、入浴、排せつの介助をしていると案内されています。
空き・受付について
2026年11月13日に米子市の事業所紹介、県の一覧（「多機能型事業所『ぴのきお』」）、米子市の放課後等デイサービス一覧を見なおしました。法人の公式サイトは確認できませんでした。電話番号は一覧によってちがいます。電話確認はしていません。現在の空き、新規受付、処置ごとの受け入れは未確認です。
利用の条件
市町村の通所受給者証が必要です。米子市の案内では定員5名で、これは現在の空きではありません。
利用までの流れ
お住まいの市町村へ通所受給者証を相談 → ぴのきおへ見学・相談（必要な医療的ケアを伝える） → 契約 → 利用日を調整。くわしい手順は事業所へご確認ください。
医療的ケア
あり
医療的ケアについて
米子市の案内に、バイタルチェック、吸引、注入（水分補給）の記載があります。経管栄養の方法ごと、人工呼吸器などの対応は事業所へご確認ください。
利用できる時間
米子市の案内では、開所時間は9時〜18時、サービス提供時間は平日13時〜18時、休日10時〜16時で、日曜・月曜は休みです。
地域・送迎
施設は米子市両三柳にあります。放課後は学校までお迎えに行き、自宅まで送ると案内されています。送迎できる地域は事業所へご確認ください。
料金
利用料は公的制度にもとづく利用者負担額です。実費の金額は事業所へご確認ください。
