伯耆町 お子様の療育・居宅訪問型児童発達支援

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
西伯郡伯耆町
サービスの種類
通う療育
対象年齢
児童発達支援・医療型児童発達支援は未就学のお子様、放課後等デイサービスは就学中のお子様、居宅訪問型児童発達支援は重度の障がい等により外出が著しく難しいお子様を対象に案内しています。保育所等訪問支援もお子様を対象とする制度です。実際の対象は町の支給決定で確認します。
ひとこと
伯耆町が案内する、お子様の通所・訪問型の療育制度です。ご自宅で発達支援を行う居宅訪問型児童発達支援は、入浴・排せつ・食事等を支える居宅介護（ホームヘルプ）とは別のサービスです。
利用の条件
身体障がい・知的障がい・精神障がい（発達障がいを含む）があるお子様、または療育が必要と認められるお子様が対象です。必ずしも障害者手帳や診断が必要とは限りませんが、町が支援の必要性を確認します。利用する事業に応じた町の申請・支給決定と通所受給者証が必要です。
利用までの流れ
伯耆町福祉課へ相談 → 申請 → 障害児支援利用計画案を用意 → 町の支給決定・通所受給者証を確認 → 事業所と契約 → 利用開始。町は受給者証の交付まで約1か月かかる場合があると案内しています。
医療的ケアについて
『医療型児童発達支援』という制度名は確認しましたが、現在利用できる事業所や、医療的ケア一般、重症心身障害、重度知的障害、強度行動障害、全面介助、吸引、経管栄養、人工呼吸器への個別対応は未確認です。制度名から処置別対応を推測していません。
利用できる時間
各事業所の営業日・時間、訪問日時、通所時間、現在の空きは未確認です。
地域・送迎
伯耆町の制度です。町外事業所の利用、居宅訪問型児童発達支援の訪問地域、保育所等訪問支援の訪問先、通所の送迎地域は町と事業所へ確認してください。掲載住所は町の申請・相談窓口で、支援場所ではありません。
料金
利用者負担は原則1割で、町の案内では生活保護・住民税非課税世帯は月額上限0円、一般1は4,600円、一般2は37,200円です。多子軽減の対象となる場合は、第2子の負担が5％、第3子以降が0％になる案内です。実際の世帯区分、食費・教材費・送迎等の実費は町と事業所へ確認してください。
住所
申請・相談窓口：鳥取県西伯郡伯耆町吉長37番地3 伯耆町 福祉課・福祉支援室（支援場所ではありません）
電話
0859-68-5534伯耆町 福祉課・福祉支援室。希望する療育の種類、年齢、通所かご自宅への訪問かを伝えてください。
