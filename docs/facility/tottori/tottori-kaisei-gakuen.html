鳥取県立皆成学園

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
倉吉市
サービスの種類
日中のあずかりお泊まり（短期入所）通う療育
対象年齢
短期入所と日中一時支援は在宅の障害のあるお子様、児童発達支援はお子様とお父様・お母様が一緒に週1回通う案内です。詳しい年齢条件は未確認です。
ひとこと
宿泊する短期入所、宿泊しない日中一時支援、親子で通う児童発達支援を案内しています。
利用の条件
短期入所には障害福祉サービス受給者証、日中一時支援には地域生活支援事業受給者証または給付決定通知書が必要です。どちらも学園との契約が必要です。
利用までの流れ
倉吉市にお住まいの場合は、給付費申請書・計画相談申請書を提出 → 相談支援事業者と契約 → 面接等と利用計画案 → 市の支給決定 → 利用計画作成 → 学園と契約・利用日を相談。皆成学園は、短期入所と日中一時支援それぞれの利用申込書を案内しています。ほかの市町村は申請手順をお住まいの窓口へ確認してください。児童発達支援は別の通所手順です。
医療的ケアについて
短期入所・日中一時支援での医療的ケア、吸引・経管栄養・人工呼吸器の個別対応は未確認です。
利用できる時間
短期入所・日中一時支援・児童発達支援の利用曜日と時間は未確認です。
地域・送迎
施設は倉吉市にあります。日中一時支援は各市町村との契約で実施されるため、お住まいの市町村で対象になるか確認してください。
料金
倉吉市の2022年9月28日更新の案内では、原則1割負担で、所得に応じた月額上限があります。医療費・食費等は別です。現在の負担上限、日中一時支援の食事・送迎費、短期入所の実費は市と学園へ確認してください。
