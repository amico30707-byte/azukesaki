絆～Bande～ 放課後等デイサービス・短期入所

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
倉吉市
サービスの種類
通う療育お泊まり（短期入所）
対象年齢
放課後等デイサービスは6歳〜18歳のお子様が対象です。短期入所は法人が障がい児・者を対象と案内し、倉吉市の18歳未満向け案内にも掲載されています。短期入所の詳しい年齢条件は要確認です。
ひとこと
倉吉市で放課後等デイサービスと宿泊する短期入所を行う事業所です。通所とお泊まりは別の事業なので、対象、利用時間、支給決定、現在の受け入れを分けて確認します。
利用の条件
放課後等デイサービスと短期入所は、市町村の支給決定を受けてから事業所と契約します。短期入所は、ご家族の急用や入院などで介護が難しいときの利用を案内しています。放課後等デイサービスの定員10人、短期入所3床は現在の空きではありません。
利用までの流れ
お住まいの市町村へ放課後等デイサービスまたは短期入所を相談 → 申請・利用計画案・支給決定を確認 → Bandeへ見学、対象、希望日、必要な介助、費用を相談 → 事業所と契約 → 利用日を調整。
医療的ケアについて
法人と市の案内から、短期入所・放課後等デイサービスでの医療的ケア一般、吸引、経管栄養、人工呼吸器の対応は確認できません。必要な処置・全面介助・行動面の支援を項目ごとに相談してください。
