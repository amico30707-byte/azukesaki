米子市 子育て短期支援（ショートステイ・トワイライトステイ）

お知らせ障害福祉の短期入所・日中一時支援とは別の制度です。原則として当日利用と送迎はありません

空きや受け入れは、かならず施設にご確認ください

利用を考えるときは

公式ページを見る米子市｜子育て短期支援事業（2026年4月1日更新）

電話0859-23-5469

確認日：2026年10月7日（あずけさき手帖が公式の情報を確かめた日）

施設のこと

地域
米子市・委託施設等
サービスの種類
お泊まり（短期入所）日中のあずかり
対象年齢
米子市に住む18歳未満のお子様が対象です。初めて利用する場合は、アレルギー等を確認する聞き取りと質問票があります。
ひとこと
保護者の病気・出産・冠婚葬祭・育児疲れなどで家庭での養育が一時的に難しいときのショートステイと、仕事等で平日夕方・休日に養育が難しいときのトワイライトステイです。障害福祉の短期入所・日中一時支援とは別の子育て支援制度です。
空き・受付について
市の2026年4月1日更新ページで、対象、利用理由、時間、料金、実施施設等、申請順、初回手続き、送迎なしを確認しました。現在の空き、新規受付、希望日の受け入れ、施設ごとの対象・定員、個別ケア、電話確認は未確認です。
利用の条件
市へ事前に電話し、利用理由、希望日、お子様の年齢・健康状態・必要な支援を伝えます。治療が必要な場合、安全な受け入れが難しい場合、障害福祉サービスの利用が適切な場合などは利用できないことがあります。
利用までの流れ
米子市こども相談課へ事前に電話 → 市が施設等へ受け入れを確認 → 利用可否の連絡を受ける → 初回は窓口で聞き取り・質問票と申請 → 入退所時刻、持ち物、費用を確認。お子様の送迎は行わないと案内されています。
医療的ケアについて
治療が必要な場合や安全な受け入れが難しい場合は利用できないことがあります。障害・医療的ケアの個別受け入れ、看護職員、吸引、経管栄養、人工呼吸器、全面介助への対応は確認できませんでした。
利用できる時間
ショートステイは原則1か月7日までです。トワイライトステイの目安は平日16時〜22時、休日9時〜22時です。原則として当日利用はできず、市が施設等と調整します。
地域・送迎
米子市に住むお子様の制度です。米子聖園天使園、米子聖園ベビーホーム、光徳子供学園、因伯子供学園、ファミリーホーム・里親等で実施します。施設の所在地と希望日の受け入れは市の調整時に確認してください。
料金
世帯の所得、お子様の年齢、利用内容により1日0円〜5,350円です。食費等を含む現在の負担は申請時に確認してください。
住所
鳥取県米子市錦町一丁目139番地3（申請窓口）
