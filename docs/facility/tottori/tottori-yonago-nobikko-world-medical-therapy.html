鳥取県立総合療育センター 児童発達支援センター のびっこワールド

空きや受け入れは、かならず施設にご確認ください

利用を考えるときは

公式ページを見る鳥取県｜児童発達支援センター：のびっこワールド

電話0859-38-2173

確認日：2026年11月13日（あずけさき手帖が公式の情報を確かめた日）

施設のこと

地域
米子市
サービスの種類
通う療育
対象年齢
未就学（0歳〜6歳）で障がいのあるお子様と、医療的ケアが必要な未就学のお子様が対象です。
ひとこと
鳥取県立総合療育センターの児童発達支援センターです。医療的ケアが必要な未就学のお子様も対象で、食べる・飲みこむ力に合わせた給食があります。
空き・受付について
2026年11月13日に県のページと米子市の事業所紹介を見なおしました。定員と時間は2つの案内でちがいます（県：1日10人・9時30分〜12時、米子市：定員30名・9時30分〜15時30分。どちらも日付の記載なし）。電話確認はしていません。現在の空き、新規受付、処置ごとの受け入れは未確認です。同じセンターの居宅訪問型児童発達支援（のびっこホーム）と短期入所は、別のページでのせています。
利用の条件
市町村の障害福祉の窓口で申請し、支給決定を受けてから契約します。センターを受診したことがない場合は、先に受診が必要です。定員は1日10人で、現在の空きではありません。
利用までの流れ
相談・説明 → 見学・体験 → 市町村の障害福祉の窓口で申請 → 相談支援事業所と契約 → 支給決定 → サービス担当者会議 → 契約 → 利用開始（県のページ）。センターを受診したことがない方は、先に受診が必要です。
医療的ケア
あり
医療的ケアについて
県のページで「医療的ケアが必要な、未就学のお子さま」が対象と明記されています。吸引・経管栄養・人工呼吸器などの処置ごとの対応は、センターへご確認ください。
利用できる時間
県のページでは、月曜日〜金曜日（祝日は除く。年末年始などの休園日あり）で、ふだんは9時30分に来て12時に帰る流れです。午後の活動がある日もあります。米子市の事業所紹介（日付の記載なし）では、サービス提供時間9時30分〜15時30分、土日祝休み、定員30名とされていて、県のページ（1日10人）とちがいます。利用の前にセンターへご確認ください。
地域・送迎
施設は米子市にあります。送迎サービスはありません。
料金
原則としてサービス費用の1割で、世帯の所得に応じた月額の上限があります。給食は実費です。
住所
鳥取県米子市上福原7丁目13-3 鳥取県立総合療育センター
電話
