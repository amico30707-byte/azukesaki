施設のこと

地域

サービスの種類
日中のあずかり
対象年齢
北見市の日中一時支援は、日中に保護が必要な障がいのあるお子様・成人が対象です。とむての森は対象の制限なしと案内していますが、お子様の年齢・障害条件・利用できる市町村は申し込み前に確認してください。
ひとこと
通院、きょうだいとの時間、ご家族の就労・休息などのために、お子様・成人を日中に支援する事業です。北見市の利用決定と、施設への希望日時・支援内容の確認を分けて進めます。
空き・受付について
曜日・時間の案内は現在の空きではありません。現在の空き、新規受付、電話でのお子様ごとの受け入れ、詳しい年齢・利用地域・実費・送迎・個別ケアは未確認です。
利用の条件
北見市障がい福祉課（0157-25-1136）へ申請します。相談支援事業所へ申請代行を頼める案内があり、障害支援区分の認定は不要です。施設へ希望日時、支援内容、実費、受け入れを別に確認してください。
利用までの流れ
北見市障がい福祉課または相談支援事業所へ申請 → 市の利用決定 → とむての森へ連絡 → 希望日時・支援内容・料金・実費を確認 → 利用調整。
医療的ケアについて
公式ページでは医療的ケア一般、吸引、経管栄養、人工呼吸器、全面介助の事業別対応を確認できませんでした。必要なケアは希望日時とともに個別に相談してください。
利用できる時間
月曜日〜日曜日（祝日を含む）8時〜18時。時間は相談できます。施設は24時間電話対応可と案内していますが、電話受付を日中一時支援の利用時間にはしません。希望日の受け入れは別に確認が必要です。
地域・送迎
北見市の地域生活支援事業として利用する場合は北見市へ申請します。北見市以外のお子様が利用できるかは、お住まいの市町村と施設へ確認してください。
料金
施設は原則5％の利用者負担と案内しています。現在の金額、月額上限、食事・送迎等の実費は北見市と施設へ確認してください。
