施設のこと

地域
札幌市白石区
サービスの種類
お泊まり（短期入所）
対象年齢
重症心身障がい児（者）の短期入所です。お子様は、障害児の区分3で、受給者証の短期入所の欄に「重心児」の記載があることが条件と案内されています。受け入れの年齢は施設へご確認ください。
ひとこと
社会福祉法人北翔会の、重症心身障がい児（者）のための医療型障害児入所施設・療養介護の施設です。短期入所の定員は10名で、療養棟ごとに受け入れ枠があります。理由を問わず利用できると案内されています。
空き・受付について
2026年11月11日に施設のページと札幌市の施設一覧を確認しました。電話確認はしていません。定員10名は上限で、現在の空き、予約の受付、入退所時刻、費用、処置ごとの受け入れは未確認です。
利用の条件
ご家族の病気、冠婚葬祭、休息など、理由は問わず利用できると案内されています。お子様は、受給者証の短期入所の欄に「重心児」の記載が必要です。はじめての利用の前に、施設の医師の外来診察があり、かかりつけ医の診療情報提供書が必要です。
利用までの流れ
区役所・市町村で短期入所の支給決定を受ける（お子様は「重心児」の記載を確認） → 施設へ相談し、ふだんの様子と必要なケアを伝える → かかりつけ医の診療情報提供書を持って外来診察 → 病棟の見学 → はじめは日帰りか平日の1泊2日でためす → 予約・利用。
医療的ケアについて
施設のページでは、短期入所の定員のうち第4療養棟にレスパイト入院2床がふくまれ、施設入所の説明に医療的ケアが必要な方への医療・看護があり、日課表には経管栄養も載っています。ただ、短期入所で受けられる処置（吸引、経管栄養、人工呼吸器など）の一覧はありません。必要なケアを一つずつ施設へご確認ください。
利用できる時間
1回の利用は約7日までが目安です。理由や予約の状況によっては相談できます。入退所の時刻は施設へご確認ください。
地域・送迎
施設は札幌市白石区にあります。利用できる地域と送迎は、確認したページにはありませんでした。
料金
利用者負担と食費などの実費は、確認したページにはありませんでした。市区町村と施設でご確認ください。
