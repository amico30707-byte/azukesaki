札幌市 居宅介護（ホームヘルプ）

施設のこと

地域
札幌市
サービスの種類
家に来るヘルパー
対象年齢
18歳未満のお子様用の介護給付費等支給申請書が公開されています。ホームヘルプを希望する18歳以上の方には障害支援区分認定を行うという案内のため、成人向けの手続きをお子様へそのまま当てはめません。
ひとこと
ご自宅で使うホームヘルプなどの障がい福祉サービスについて、お住まいの区への申請、利用計画案、市の調査、支給決定、受給者証、事業者との契約を進めます。
利用の条件
お住まいの区役所保健福祉課へ申請し、利用計画案を作成します。区の職員が心身の状況等を調べ、介護者の状況・居住環境・計画案も考慮して支給決定します。支給決定後に受給者証を事業者へ示して契約します。
利用までの流れ
お住まいの区役所保健福祉課へ申請 → 利用計画案を作成 → 市の調査 → 計画案を提出 → 支給決定・受給者証 → 2026年10月1日現在の事業所一覧などから候補を探す → 契約・利用。
医療的ケアについて
居宅介護で行える医療的ケア一般、吸引、経管栄養、人工呼吸器は未確認です。診断書が必要になる場合があるという案内を、事業者の処置対応の根拠にはしていません。
