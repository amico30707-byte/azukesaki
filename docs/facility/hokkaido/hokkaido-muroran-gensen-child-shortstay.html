室蘭言泉学園 短期入所事業所

空きや受け入れは、かならず施設にご確認ください

施設のこと

地域
室蘭市
サービスの種類
お泊まり（短期入所）
対象年齢
室蘭市は障がい児サービスの短期入所実施施設として室蘭言泉学園を掲載し、法人も障がいのあるお子様・成人を一時的に預かる事業と説明しています。詳しい年齢、受給者証、障害区分等は市と施設へ確認してください。
ひとこと
ご家族の冠婚葬祭、入院・手術等で一時的に家庭での介護が難しいときに、障がいのあるお子様・成人が宿泊する短期入所です。同住所の日中一時支援事業所『にこにこ』とは別に掲載します。
利用の条件
室蘭市障害福祉課または相談支援事業所へ相談し、申請、利用計画案、支給決定を経て受給者証を確認した後、施設へ希望日、泊数、介助、持ち物、体調条件を相談します。
利用までの流れ
室蘭市障害福祉課または相談支援事業所へ相談 → 申請・利用計画案・支給決定 → 受給者証を確認 → 施設へ希望日、泊数、介助、持ち物を相談 → 空き・入退所時刻・費用・体調条件を確認 → 契約・利用。
医療的ケアについて
障がい児入所施設への併設、24時間支援の記載から、重症心身障害、重度知的障害、強度行動障害、全面介助、吸引、経管栄養、人工呼吸器等の受け入れを推測していません。必要な介助・処置を一つずつ確認してください。
利用できる時間
宿泊を伴う短期入所です。入退所時刻、連続泊数、休業日、希望日の受け入れは未確認です。2025年9月1日時点の法人資料は24時間支援あり、定員2人としていますが、現在の空きを示しません。
地域・送迎
施設所在地は室蘭市です。市外からの利用、送迎、保護者による入退所、利用できる地域は公式ページで確認できませんでした。
料金
利用者負担、食費・光熱水費、送迎等の実費は確認したページでは確認できませんでした。市町村の月額上限と施設の実費を分けて確認してください。
