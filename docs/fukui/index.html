医療的ケア児支援センター

福井県医療的ケア児者支援センター

医療的ケア児者とご家族の相談、情報提供、関係機関との調整を行う窓口です。2025年6月2日から嶺南地域の相談拠点も案内されています。来所相談は予約が必要です。

出典：https://www.cfa.go.jp/assets/contents/node/basic_page/field_ref_resources/5218c3a3-610e-4925-8596-a9116889756f/b536f355/20260617_policies_shougaijishien_care-ji-shien_21.pdf　確認日：2026年3月

まとめの記事

  • 福井県の短期入所・障害児のあずけ先まとめ福井県で、重い障害や医療的ケアのあるお子様をあずけられる短期入所・日中一時支援の探し方をまとめました。相談の窓口や受給者証の申しこみ先、見学のポイントもやさしく説明します。
  • 福井市の日中一時支援・移動支援福井市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。放課後や長い休みの日中一時支援や、市独自の重症心身障害児（者）福祉手当も、やさしく説明します。
