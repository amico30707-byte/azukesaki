医療的ケア児支援センター

徳島県医療的ケア児等支援センター

旧ページから現在の専用サイトへの移転を確認しました。医療的ケアが必要なお子様とご家族、支援者の相談を受け、関係機関と調整します。電話は0885-32-0903、平日9時〜17時で、相談フォームもあります。

出典：https://www.cfa.go.jp/assets/contents/node/basic_page/field_ref_resources/5218c3a3-610e-4925-8596-a9116889756f/b536f355/20260617_policies_shougaijishien_care-ji-shien_21.pdf　確認日：2026年3月

まとめの記事

  • 徳島県の短期入所・障害児のあずけ先まとめ徳島県で、重い障害や医療的ケアのあるお子様をあずけられる短期入所・日中一時支援の探し方をまとめました。相談の窓口や受給者証の申しこみ先、見学のポイントもやさしく説明します。
  • 徳島市の短期入所・日中一時支援・移動支援徳島市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。料金のしくみや、前もって登録した介護人にたのめる在宅介護等支援も、やさしく説明します。
  • 鳴門市の短期入所・日中一時支援・移動支援鳴門市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。社会福祉課にまとまった相談先や、県の医療的ケア児等支援センターも、やさしく説明します。
  • 阿南市の短期入所・日中一時支援・移動支援阿南市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。令和8年10月からはじまった「医療的ケア児在宅レスパイト事業」や、社会福祉協議会にたのんでいる基幹相談支援センターも、やさしく説明します。
