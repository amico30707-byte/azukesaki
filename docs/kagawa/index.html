医療的ケア児支援センター

香川県医療的ケア児等支援センターソダテル

出典：https://www.cfa.go.jp/assets/contents/node/basic_page/field_ref_resources/5218c3a3-610e-4925-8596-a9116889756f/b536f355/20260617_policies_shougaijishien_care-ji-shien_21.pdf　確認日：2026年3月

まとめの記事

  • 香川県の短期入所・障害児のあずけ先まとめ香川県で、重い障害や医療的ケアのあるお子様をあずけられる短期入所・日中一時支援の探し方をまとめました。相談の窓口や受給者証の申しこみ先、見学のポイントもやさしく説明します。
  • 高松市の日中一時支援・移動支援高松市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。お子様も使える移動支援や県の支援センター「ソダテル」も、やさしく説明します。
  • 丸亀市の日中一時支援・移動支援丸亀市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。重いお子様に月ごとにお金が出る市の「在宅重度障害児年金」や、急なときにお子様を一時的に保護する「丸亀市障害者等緊急受入事業」も、やさしく説明します。
