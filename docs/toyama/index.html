医療的ケア児支援センター

富山県医療的ケア児等支援センターりあん

医療的ケアの必要なお子様とご家族の相談を受け、医療・保健・福祉・教育などの支援機関へつなぐ窓口です。平日9〜16時の受付を公式ページで確認しました。

出典：https://www.cfa.go.jp/assets/contents/node/basic_page/field_ref_resources/5218c3a3-610e-4925-8596-a9116889756f/b536f355/20260617_policies_shougaijishien_care-ji-shien_21.pdf　確認日：2026-03

まとめの記事

  • 富山県の短期入所・障害児のあずけ先まとめ富山県で、重い障害や医療的ケアのあるお子様をあずけられる短期入所・日中一時支援の探し方をまとめました。相談の窓口や受給者証の申しこみ先、見学のポイントもやさしく説明します。
  • 富山市の日中一時支援・移動支援富山市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。こども健康課の窓口や県の支援センター「りあん」も、やさしく説明します。
  • 高岡市の日中一時支援・移動支援高岡市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。手帳がないお子様も診断書などで使えることがある日中一時支援・移動支援や、市の「きずな子ども発達支援センター」も、やさしく説明します。
