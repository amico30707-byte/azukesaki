医療的ケア児支援センター

山形県医療的ケア児等支援センターにこすく

山形県内の医療的ケア児・者とご家族、支援者からの相談を案内。福祉サービス、保育・就学、退院後の生活準備などを相談できます。

出典：https://www.cfa.go.jp/assets/contents/node/basic_page/field_ref_resources/5218c3a3-610e-4925-8596-a9116889756f/b536f355/20260617_policies_shougaijishien_care-ji-shien_21.pdf　確認日：2026-03

まとめの記事

  • 山形県の短期入所・障害児のあずけ先まとめ山形県で、重い障害や医療的ケアのあるお子様をあずけられる短期入所・日中一時支援の探し方をまとめました。相談の窓口や受給者証の申しこみ先、見学のポイントもやさしく説明します。
  • 山形市の日中一時支援・移動支援山形市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。市内6か所の基幹相談支援センターや、医療的ケア児等支援センター「にこすく」も、やさしく説明します。
  • 鶴岡市の日中一時支援・移動支援鶴岡市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。お子様が使える事業所が対象の年齢といっしょにのっている「子ども版 障害福祉のしおり」や、病院でのレスパイトも、やさしく説明します。
