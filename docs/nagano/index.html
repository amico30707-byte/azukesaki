医療的ケア児支援センター

長野県医療的ケア児等支援センターいきあう

医療的ケア児等とご家族、支援者、学校・保育所・事業所などから相談を受ける県の窓口です。平日8時30分〜17時15分の電話相談を県公式ページで確認しました。

出典：https://www.cfa.go.jp/assets/contents/node/basic_page/field_ref_resources/5218c3a3-610e-4925-8596-a9116889756f/b536f355/20260617_policies_shougaijishien_care-ji-shien_21.pdf　確認日：2026年3月

まとめの記事

  • 長野県の短期入所・障害児のあずけ先まとめ長野県で、重い障害や医療的ケアのあるお子様をあずけられる短期入所・日中一時支援の探し方をまとめました。相談の窓口や受給者証の申しこみ先、見学のポイントもやさしく説明します。
  • 長野市の短期入所・日中一時支援・移動支援長野市で障害のあるお子様をあずけたいときの相談窓口と、障害児自立サポート事業・移動支援・短期入所の市のしくみをまとめました。医療的ケアのあるお子様の使い方や、市独自の手当も、やさしく説明します。
  • 松本市の短期入所・日中一時支援・移動支援松本市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。近所の方などにお世話をたのめる「タイムケア事業」や、医療的ケアの相談窓口も、やさしく説明します。
  • 上田市の短期入所・日中一時支援・移動支援上田市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。時間単位でお子様を見てくれる市独自の「タイムケア」や、費用の5%になっている自己負担も、やさしく説明します。
  • 安曇野市の短期入所・日中一時支援・移動支援安曇野市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。前もって登録した人や団体が代わりにお世話をしてくれる「タイムケア事業」も、やさしく説明します。
  • 佐久市の短期入所・日中一時支援・移動支援佐久市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。近所の方や知り合いなどにお世話をたのめる「タイムケア事業」や、市立の浅間総合病院の医療型の短期入所も、やさしく説明します。

  • 伊那市の短期入所・日中一時支援・移動支援伊那市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。登録した人や団体が時間単位でお世話をしてくれる「タイムケア事業」や、市独自の「重度心身障害福祉年金」も、やさしく説明します。
  • 塩尻市の短期入所・日中一時支援・移動支援塩尻市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。1年360時間まで使える「タイムケア事業」や、相談センター「ボイス」も、やさしく説明します。

    中野市
