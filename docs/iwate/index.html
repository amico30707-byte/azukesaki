医療的ケア児支援センター

岩手県医療的ケア児支援センター

医療的ケアが必要なお子様とご家族の日常生活・就園・就学などの相談窓口です。電話・メール・予約制のオンライン面談と来所相談を、平日9時30分〜16時に受け付けています。

出典：https://www.cfa.go.jp/assets/contents/node/basic_page/field_ref_resources/5218c3a3-610e-4925-8596-a9116889756f/b536f355/20260617_policies_shougaijishien_care-ji-shien_21.pdf　確認日：2026-03

まとめの記事

  • 岩手県の短期入所・障害児のあずけ先まとめ岩手県で、重い障害や医療的ケアのあるお子様をあずけられる短期入所・日中一時支援の探し方をまとめました。相談の窓口や受給者証の申しこみ先、見学のポイントもやさしく説明します。
  • 盛岡市の日中一時支援・移動支援盛岡市で障害のあるお子様をあずけたいときの相談窓口と、日中一時支援・移動支援・短期入所の市のしくみをまとめました。市の専任の医療的ケア児等コーディネーターも、やさしく説明します。
