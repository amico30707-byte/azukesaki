# 医療型短期入所とは？福祉型との違いと使い方

## はじめに

短期入所（ショートステイ）には、「福祉型」と「医療型」があります。重い障害や医療的ケアのあるお子様の場合、医療型を使うことが多いです。

この記事では、医療型短期入所がどんなところか、福祉型とのちがい、はじめて使うまでの流れ、使うときに知っておきたいことをまとめました。

## 福祉型と医療型のちがい

|  | 福祉型 | 医療型 |
| --- | --- | --- |
| 場所 | 障害のある方の施設など | 病院、診療所、介護老人保健施設、介護医療院 |
| 使えるお子様 | 医療的なケアが多くないお子様 | 重症心身障害のお子様や、遷延性意識障害のお子様など（くわしい条件は市区町村で確かめる） |
| いる人 | 生活支援員など | 医師・看護師がいる中で過ごす |

国の資料では、医療型の対象は「遷延性意識障害（いしきがもどりにくい状態が長く続いている）のお子様、重症心身障害のお子様など」とされています。国の調査（2019年度）では、医療型短期入所を行っているところの9割以上（96.3%）が、病院や診療所でした。

お泊まりをしない日中だけの利用は、「医療型特定短期入所」とよばれることがあります。お泊まりなしなら、入院のベッドがない診療所でも行うことができます。

## もう1つの選択肢「福祉型強化」

福祉型の中には、「福祉型強化短期入所」というしくみもあります。看護師などが常勤で1人以上いる福祉型の施設で、医療的ケアが必要なお子様を受け入れるためのものです。

2024年度からは、福祉型強化で日中だけ使える「福祉型強化特定短期入所」もできました。

近くに医療型がないときや、ケアの内容によっては、こちらが合うこともあります。市区町村や相談支援専門員に、両方の候補を聞いてみてください。

## どんなときに使う？

- ご家族が休みたいとき
- ご家族が病気や出産、入院のとき
- 冠婚葬祭や、きょうだいの行事のとき
- 将来の暮らしにそなえて、家以外で過ごす練習をしたいとき

急な入院などで、すぐにあずけ先が必要になったときのことは「[親が急に入院・倒れたときの障害児のあずけ先](/blog/kinkyu-short.html)」にまとめています。

## はじめて使うまでの流れ

1. 市区町村で、医療型短期入所が使える受給者証の手続きをする
2. 使いたい病院・施設に問い合わせる
3. 主治医に、紹介状（診療情報提供書）を書いてもらう
4. 施設で事前の診察や面談を受ける
5. 見学や、日帰り・ご家族付きそいの体験をする
6. 契約して、予約できるようになる

施設によっては、受給者証に「短期入所（医療型）」などと書かれていることが、利用の条件になります。手続きのときに、医療型を使いたいことをはっきり伝えてください（「[受給者証とは？](/blog/jukyushasho.html)」）。

施設によっては、はじめての利用まで数か月かかります。急に必要になってからでは間に合わないことがあるので、早めにじゅんびを始めましょう。

## ある県立の施設の例

愛知県のある県立の施設では、次のように案内しています。施設ごとにちがうので、あくまで一つの例として見てください。

- 相談から本利用まで、おおよそ3〜4か月かかる
- 体験の1回目はご家族付きそい、2回目はご家族なしで泊まる
- 体験のあと、施設が受け入れを決める
- 利用は、原則として月1回、8日以内
- 予約の受付は、利用したい日のおよそ2か月前から
- 1年以上使っていないと、もう一度受診が必要になる

「早めに登録して、ときどき使っておく」ことが大切な理由が、よく分かります。

## 知っておきたいこと

- 入院の方のベッドが空いたときに使うところも多く、希望の日に使えるとは限りません
- 予約の受付が「利用月の前の月の〇日まで」などと決まっていることが多いです
- 体調がすぐれない日や、感染症がはやっている時期は、使えないことがあります
- 利用中に体調をくずすと、むかえに行く必要があることがあります
- 利用中は、治療や訓練、薬の処方などはしないところがあります
- 受給者証の期限が切れていると、費用が全額自己負担になることがあります（「[受給者証の更新はいつ？](/blog/jukyushasho-koshin.html)」）
- 送り迎えはご家族がするところが多いです

## はじめての利用の日

さきほどの県立の施設では、はじめに受付で受給者証を見せ、お子様の体調を確かめます。そのあと、病棟の看護師が、お子様のケアについて1時間ほど聞き取りをします。

ほかの施設でも、はじめての日は、ケアの手順をくわしく聞かれることが多いです。次のものを用意しておくと安心です。

- 受給者証
- お薬と、お薬手帳
- ケアの手順を書いたメモ（吸引の回数、注入の量と時間、体位を変える間かくなど）
- いつも使っている医療機器や、その消耗品
- お子様が安心できるもの（タオル、おもちゃ、音楽など）

持ち物は、施設から一覧表をもらえることが多いです。くわしくは「[ショートステイの持ち物リスト](/blog/mochimono.html)」もご覧ください。

## よくある困りごと

- 予約がなかなか取れない
  →1か所だけでなく、2〜3か所に登録しておくと、使える日がふえます。
- 近くに医療型がない
  →福祉型強化短期入所や、レスパイト入院、訪問看護なども考えてみてください。都道府県の医療的ケア児支援センターに聞くと、地域の情報を教えてもらえることがあります（「[医療的ケア児支援センター一覧](/blog/iryocare-center.html)」）。
- 当日に熱が出て、使えなかった
  →体調が悪い日は使えないのがふつうです。キャンセルの連絡のしかたを、前もって聞いておきましょう。
- 受け入れを断られた
  →理由を聞き、相談支援専門員と次の候補を考えましょう（「[障害児の預け先がない・断られたときにできること](/blog/azukesaki-nai.html)」）。

## 費用のこと

利用料は、受給者証に書かれた「1か月の上限」の中でおさまります。そのほかに、食事代や光熱水費がかかるところがあります。くわしくは「[短期入所の費用はいくら？](/blog/hiyo.html)」や「[子どもの医療費の助成のちがい](/blog/iryohi-josei.html)」をご覧ください。

## 問い合わせで聞いておきたいこと

- お子様の年齢やケアの内容で、受け入れてもらえるか
- 夜の看護師の人数
- 呼吸器や吸引器、ポンプなどは、家から持っていくか
- 予約のしかたと、いつから受け付けるか
- 体験利用の回数と、ご家族の付きそいがいるか

見学のときに見ることは「[短期入所の見学ポイント10こ](/blog/kengaku.html)」、持ち物は「[ショートステイの持ち物リスト](/blog/mochimono.html)」にまとめています。病院が行うレスパイト入院とのちがいは「[レスパイト入院とショートステイの違い](/blog/respite-nyuin.html)」を、対象になる状態は「[重症心身障害児とは？](/blog/jushin.html)」をご覧ください。

## さいごに

医療型短期入所は、数が少なく、すぐには使えないことも多いです。だからこそ、元気なうちに登録しておき、ときどき使っておくことが、いざというときの安心につながります。

医療的ケアのあるお子様のあずけ先ぜんたいについては、「[医療的ケア児の預け先は？](/blog/iryoteki-care.html)」もご覧ください。あずけさき手帖では、たんの吸引・経管栄養・人工呼吸器など、必要なケアから短期入所を探せます。

※対象や手続き、費用は、年度や施設、市区町村によって変わります。くわしくは施設やお住まいの窓口でご確認ください。

# 障害児のヘルパーが見つからないときにできる7つのこと

## はじめに

受給者証にヘルパーの時間が書いてあるのに、来てくれる事業所が見つからない。そんな悩みを、多くのお父様・お母様から聞きます。ヘルパーの人手が足りない地域は少なくありません。

この記事では、ヘルパーが見つからないときに試したいことをまとめました。

## 試したい7つのこと

1. 相談支援専門員に、一緒に探してもらう
2. 市区町村の窓口で、地域の居宅介護・移動支援の事業所一覧をもらい、子どもを受けているところに順に問い合わせる
3. 1つの事業所で全部の時間をまかなおうとせず、2つ以上の事業所に分けて頼む
4. 曜日や時間に少しはばを持たせる（夕方や土日は、人が足りないことが多いです）
5. 社会福祉協議会の事業所にも問い合わせる
6. 医療的ケアがある場合は、訪問看護ステーションにも相談する
7. 家で見てもらうのがむずかしければ、日中一時支援や短期入所など、施設であずける方法も考える

## 問い合わせるときに伝えること

- お子様の年齢と、必要な手助け（食事、トイレ、おふろ、見守りなど）
- 来てほしい曜日と時間（第1希望と第2希望）
- ご自宅の地域
- ご家族が一緒に家にいられるか

お子様の居宅介護は、多くの市区町村で、お父様・お母様の病気やお仕事など、お世話がむずかしい事情があるときに使えるしくみです。使える時間は、市区町村がご家庭の事情を聞いて決めます。また、「ご家族が家にいること」を条件にしている事業所もあります。最初に確かめておくと話が早いです。

## 家で見てもらう？ お出かけについてもらう？

| したいこと | 使うしくみ |
| --- | --- |
| 家での食事・おふろ・トイレの手助け | 居宅介護 |
| 通院の付きそい | 居宅介護（通院のための介助） |
| 買い物や行事へのお出かけ | 移動支援 |
| 強い行動があるお子様のお出かけ | 行動援護 |

しくみがちがうと、頼める事業所もちがいます。「何をしてほしいか」をはっきりさせてから探すと、見つかりやすくなります。

## 親が家にいないときもヘルパーは使える？

お子様の居宅介護（家に来るヘルパー）を、お父様・お母様が家にいない時間に使えるかどうかは、市区町村や事業所によってちがいます。国の事業として行われた調査の報告書（2021年3月）でも、「保護者がいないときの利用を、原則みとめていない自治体がある」と書かれています。

同じ報告書は、ヘルパーが来ている時間だけが、家事や買い物、通院、きょうだいの送り迎えなどをできる時間になっているご家族がいることにもふれています。そのうえで、ご家族の状況に合わせて一つひとつ考えるよう、自治体の運用をよくしていく必要があるとしています。

使いたいときは、次のことを窓口や相談支援専門員に伝えてみてください。

- 家をはなれるあいだに、何をしなければならないか（通院、きょうだいの送り迎えなど）
- 何時間くらい、どのくらいの回数か
- お子様の体の状態や、必要な手助け

事業所によっても考え方がちがうので、問い合わせのときに最初に確かめておきましょう。家での利用がむずかしいときは、日中一時支援や短期入所など、施設であずかってもらう方法もあります。

出典：[厚生労働省 令和2年度障害者総合福祉推進事業「ヘルパーによる長時間の介助が必要とされている障害児等に対する支援の在り方に関する調査研究」報告書](https://www.mhlw.go.jp/content/12200000/000798624.pdf)

## さいごに

ヘルパーが見つからないのは、ご家族のせいではありません。いくつかの方法を組み合わせて、少しずつ支えを増やしていきましょう。

あずけさき手帖では、家に来るヘルパーや、外出の付きそいをしてくれる事業所を、地域から探せます。

# 移動支援は何歳から使える？障害児の条件と申しこみ方

## はじめに

移動支援は、お出かけのときにヘルパーさんが付きそってくれるしくみです。「うちの子は何歳から使えるの？」という質問をよくいただきます。

答えは、「お住まいの市区町村によってちがう」です。移動支援は、国が全国一律で決めている制度ではなく、市区町村ごとに決めている制度だからです。

## 市区町村による年齢のちがい（例）

あずけさき手帖で各市の案内を確かめたところ、次のようなちがいがありました。

| 市区町村 | 年齢についての案内 |
| --- | --- |
| 神戸市 | 小学生以上（障害の種類などの条件あり） |
| 松江市 | 小学生以上 |
| 前橋市 | 小学生以上（障害の種類などの条件あり） |
| 長野市 | 小学生以上。18歳未満は1対1の支援のみ |
| 川崎市 | 原則として学齢以上。中学3年生までは保護者の付きそいが原則。保護者のお仕事や病気などで付きそえないときは、お子様だけで使える場合あり |
| 札幌市 | 年齢だけの制限はないが、未就学のお子様など、本来ご家族が付きそう外出は原則対象外 |
| 世田谷区 | 未就学のお子様の余暇の外出には使えない。小学生も条件あり |

ここにあげた市では、小学生くらいからが目安になっているところが多いです。

## 使えるお出かけ、使えないお出かけ

使えることが多い：買い物、散歩、余暇、地域の行事、役所での手続きなど

使えないことが多い：通学・通所など毎日続く外出、通院（居宅介護の通院のための介助を使う）、通勤や仕事

ただし、お父様・お母様の入院や病気など、特別な事情があるときは、通学に使えることもあります。

## 申しこみの流れ

1. 市区町村の障害福祉の窓口で、移動支援を使いたいと相談する
2. お子様の様子や、使いたいお出かけを伝えて申しこむ
3. 市区町村が使える時間を決める
4. 移動支援の事業所を選んで契約する

## 強い行動があるお子様は「行動援護」も

自分や人を傷つける行動などがあるお子様のお出かけには、専門の研修を受けたヘルパーが付きそう「行動援護」というしくみもあります。こちらは国の制度です。

## 移動支援でできないこと

移動支援は市区町村の制度なので、できないことも地域によって少しずつちがいます。ここでは、高松市の案内（2026年4月版）を例にします。上に書いた通学・通院のほかに、次のような外出は対象になりません。

- 仕事や営業など、お金をかせぐための外出
- ギャンブルなど、社会のきまりに合わない外出
- 政治や宗教の活動のための外出

また、出かけた先でヘルパーがただ「見守る」だけの場合は使えない、とされています。ヘルパーが車を運転するときは、運転している時間は利用時間にふくめないことになっています。

ほかの地域のきまりは、お住まいの市区町村の案内（「移動支援 ガイドライン」などの名前でのっていることがあります）で確かめてください。

出典：[高松市 移動支援事業ガイドライン（令和8年4月版）](https://www.city.takamatsu.kagawa.jp/kurashi/kenkou/shogai_shien/todokede/guru-pusien.files/idousiengaidrainR8.pdf)

## 行動援護とのちがい

移動支援と行動援護は、どちらもお出かけにヘルパーが付きそうしくみです。でも、制度のもとや、使える人がちがいます。

| くらべること | 移動支援 | 行動援護 |
| --- | --- | --- |
| 制度 | 市区町村の事業 | 国の制度（障害福祉サービス） |
| 使える人 | 市区町村が決める | 強い行動があり、行動関連項目の点数などの条件にあてはまる人 |
| 手助けの中身 | お出かけの付きそい | 付きそいに加えて、危険をさける手助け、トイレ・食事の手助け |
| 使える外出や時間 | 市区町村のきまりで決まる | 市区町村が支給決定で決める |

行動援護の条件にあてはまるかどうかは、受給者証の手続きの中で市区町村が決めます。両方使えそうなときは、どちらを使うか窓口で相談してください。行動援護のくわしい条件は、「[強度行動障害でショートステイを使うには？受け入れのコツ](/blog/kyodo-kodo.html)」でまとめています。

## 「2時間ルール」とは

「2時間ルール」は、移動支援ではなく、居宅介護（家に来るヘルパー）の料金の計算についての国のきまりです。1日に何回か居宅介護を使うときは、前の回と次の回のあいだを、おおむね2時間以上あけることになっています。

ただし、体の状態などで、短い間かくで何回も来てもらう必要があるときや、別の事業所のヘルパーとのあいだは、このかぎりではないとされています。

移動支援の時間のきまりは、市区町村ごとに決まっています。「家での手助けのあとにお出かけ」のように、いくつかのサービスを続けて使いたいときは、どう組み合わせられるか、事業所や窓口で確かめておくと安心です。

出典：[宮城県 訪問系サービスの報酬に関する資料](https://www.pref.miyagi.jp/documents/51616/02houmonkei.pdf)

## さいごに

移動支援を使えば、ご家族が行けない日も、お子様がお出かけを楽しめます。使える場面は市区町村によってちがうので、行事などに使いたいときは早めに確かめましょう。

あずけさき手帖では、市区町村ごとの移動支援の案内をまとめています。お住まいの地域のページをご覧ください。

# 日中一時支援と放課後等デイサービスの違い

## はじめに

「放課後等デイサービスのあとも、もう少しあずかってほしい」「土日や長い休みに、あずけられる場所がほしい」。そんなときに名前が出てくるのが「日中一時支援」です。

でも、放課後等デイサービスとなにがちがうのか、いっしょに使えるのか、わかりにくいですよね。この記事では、2つのちがいと、いっしょに使うときの注意点をまとめました。

## 2つのちがい（一覧）

いちばん大きなちがいは、「国の決まりで全国同じしくみか」「市区町村がそれぞれ決めるか」です。

|  | 放課後等デイサービス | 日中一時支援 |
| --- | --- | --- |
| どんな制度 | 国の法律（児童福祉法）のサービス | 市区町村が行う事業（地域生活支援事業） |
| 対象 | 学校に通う障害のあるお子様（小学生〜高校生） | 障害のある方（年齢などの条件は市区町村が決める） |
| 目的 | 生活の力をのばす支援・居場所 | 日中の居場所づくり、ご家族の仕事や休息のため |
| ルール | 全国でだいたい同じ | 市区町村によって大きくちがう |

日中一時支援は、市区町村ごとに対象、料金、時間、使える日数がちがいます。「となりの市ではできたのに、うちの市ではできない」ということもあります。

## 日中一時支援は何歳から？手帳がなくても使える？

何歳から使えるかは、市区町村が決めています。小さなお子様から使える地域もあれば、条件がある地域もあります。

手帳がなくても使えることがあります。たとえば埼玉県戸田市では、手帳のほかに、児童相談所などの知的障害の判定や、難病の方も対象になっています。

申請は、市区町村の障害福祉の窓口です。使う前に「支給決定」を受けておく必要があります。

## 料金と土日の利用

料金も市区町村によってちがいます。戸田市の例では、サービスの1割をはらい、1か月の上限もあります。日中一時支援は、ほかの障害福祉サービスとは別に上限を計算するルールの地域もあります。

土日や夏休みなどの長い休みに使えるかは、事業所の営業日と市区町村のルールによります。土日に開いている事業所は多くないこともあるので、早めにさがしておくと安心です。

## いっしょに使える？同じ日に使える？

「放課後等デイサービスと日中一時支援を、同じ月に両方使う（併用）」ことは、多くの地域でできます。

むずかしいのは「同じ日に両方使う（同日利用）」です。これは市区町村によって答えがちがいます。

- さいたま市：2024年4月から、放課後等デイサービスや児童発達支援と、同じ日に夕方の日中一時支援を使えるようになりました
- 戸田市：放課後等デイサービスなどの前やあとに、日中一時支援を使うことができます。ただし、日中一時支援の時間中に、ほかのサービスを同時に使うことはできません

一方で、同じ日の利用をみとめていない市区町村もあります。「放デイのあと、仕事が終わるまでの時間だけあずけたい」というときは、必ず市区町村の窓口か相談支援専門員に「同じ日に使えますか」と確認してください。

「タイムケア」という言葉を聞くこともあると思います。これは、以前、国が行っていた「障害児タイムケア事業」の名前です。障害のあるお子様を放課後や長い休みにあずかる事業で、2006年に、市区町村が行う事業へまとめられました。

## レスパイト入院とは

レスパイト入院は、ご家族の休息のために、お子様が病院に短いあいだ入院することです。「レスパイト」は「ひと息つく」という意味です。

ただ、「レスパイト入院」という名前の、全国で同じ一つの制度があるわけではありません。じっさいには、次のようにいくつかの形があります。

- 病院が、医療保険を使った短い入院として受け入れる
- 都道府県や市が「レスパイト入院事業」をつくり、決まった病院で受け入れる
- 病院が、福祉の制度である「医療型短期入所」として受け入れる

同じ「レスパイト入院」という言葉でも、病院や地域によって中身がちがう、と考えておくと安心です。

## ショートステイ（医療型短期入所）とのちがい

|  | レスパイト入院 | ショートステイ（医療型短期入所） |
| --- | --- | --- |
| もとになる制度 | 医療保険や、都道府県・市の事業など、病院や地域でちがう | 障害福祉の制度（障害者総合支援法） |
| 受給者証 | いらないことが多い（事業によっては登録が必要） | 市区町村の受給者証が必要 |
| 場所 | 病院の病棟 | 病院や、医療型の施設 |
| 費用の考え方 | 医療保険の自己負担など。子どもの医療費助成などで軽くなることがある | 福祉サービスの利用者負担（所得に応じた上限あり）と食費など |
| 日数 | 病院や事業ごとに決まっている | 市区町村が決めた日数の範囲で使う |

医療型短期入所のくわしい使い方は「[医療型短期入所とは？福祉型との違いと使い方](/blog/iryogata-tanki.html)」、費用のしくみは「[短期入所の費用はいくら？障害児の利用料のしくみ](/blog/hiyo.html)」をご覧ください。

## 期間や費用は、病院や地域でちがいます

いくつか例を見てみます（2026年11月時点の公式ページより）。

- 兵庫県：2026年7月から、兵庫県立こども病院で、医療的ケア児を対象にしたレスパイト入院を始めました。人工呼吸器の装着など高度な医療的管理が必要な15歳未満のお子様が対象で、1回あたり最大6泊7日、年間最大4回までです。受け入れは1名分で、事前の診察が必要です。
- 福岡県：小児慢性特定疾病の認定を受けていて、人工呼吸器を使っている、気管切開をしているなどのお子様を対象に、県の事業としてレスパイト入院を行っています（福岡市・北九州市など、政令市・中核市にお住まいの方は県の事業の対象外です）。使える日数は、承認された期間のなかで14日までです。病院の案内では、事業の利用料はかからず、入院の費用は保険と医療費の助成の受給者証を使う形になっています。移動の費用や個室の差額代などは、ご家族の負担です。

このように、対象の年齢、日数、回数、ご家族が払うお金は、病院や地域によって大きくちがいます。おむつや着替えを持っていく、ご家族付きそいの体験入院が必要、などの決まりも病院ごとにあります。

「保険は使えますか」「1回で何日まで泊まれますか」「自分で払うお金は何がありますか」は、申しこむ前に病院に直接たしかめてください。

## 在宅レスパイトという方法もあります

「お子様を外にあずけるのは、まだ心配」というご家族には、「在宅レスパイト事業」があります。訪問看護の看護師さんがご自宅に来て、そのあいだ医療的ケアを代わってくれるしくみです。お父様・お母様は、ねむる、買い物に行く、きょうだいと出かけるなどの時間にできます。

これも市区町村や都道府県の事業なので、内容はまちまちです。

| 地域の例 | 1回の時間 | 1年に使える時間 |
| --- | --- | --- |
| 東京都文京区 | 2〜4時間（30分単位） | 288時間まで |
| 栃木県 | 1時間以上（30分単位） | 48時間まで |
| 大分市 | 市の案内でご確認ください | 100時間まで（始めた月によって少なくなる） |

多くの場合、ふだんから保険の訪問看護を使っていることが条件になります。お住まいの地域にこの事業があるかは、市区町村の障害福祉の窓口や、医療的ケア児支援センター（「[医療的ケア児支援センター一覧・47都道府県の相談窓口](/blog/iryocare-center.html)」）で聞いてみてください。

## できる病院の見つけ方

- 主治医やかかりつけの病院に「レスパイト入院を受けている病院はありますか」と聞く
- 都道府県の医療的ケア児支援センターに聞く
- 相談支援専門員に、医療型短期入所とあわせて探してもらう
- 都道府県や市のホームページで「レスパイト入院」「在宅レスパイト」と調べる

どれも数が少なく、はじめての利用までに事前の診察や体験入院が必要なことが多いです。困ってから探すと間に合わないことがあるので、元気なうちに一度使っておくと安心です。

## さいごに

レスパイト入院、ショートステイ、在宅レスパイト。名前はむずかしく見えますが、どれも「ご家族が休むため」のしくみです。いくつかを組み合わせて使っているご家族もいます。主治医や相談支援専門員と相談しながら、ご家族に合う形を見つけてください。

あずけさき手帖では、医療型短期入所など、医療的ケアに対応したあずけ先を地域から探せます。

# 小児の訪問看護とは？回数・費用と在宅レスパイト

## はじめに

退院して自宅での暮らしが始まると、たんの吸引や経管栄養、呼吸器の管理など、毎日のケアがご家族の肩にかかります。「このやり方で合っているのかな」「少しでいいから休みたい」と感じるのは、とても自然なことです。

そんなときに力になってくれるのが「訪問看護」です。この記事では、小児の訪問看護で何をしてもらえるのか、回数や費用のしくみ、「在宅レスパイト」について、やさしくまとめました。

## 小児の訪問看護とは

訪問看護は、看護師などが自宅に来て、ケアや体調のチェックをしてくれるサービスです。大人のサービスと思われがちですが、赤ちゃんやお子様も使えます。

小児の訪問看護では、たとえば次のようなことをしてもらえます。

- 体温・呼吸・脈などのチェックと、体調の変化への気づき
- たんの吸引、経管栄養、人工呼吸器や気管切開の管理
- お風呂の手伝いや、体の向きを変えるなどのケア
- リハビリ（ステーションによっては理学療法士なども来る）
- お父様・お母様へのケアのアドバイスや、困りごとの相談

訪問看護を使うには、主治医が書く「訪問看護指示書」が必要です。まずは主治医や病院の相談室、相談支援専門員に「訪問看護を使いたい」と伝えましょう。

## 回数と時間のしくみ

お子様の訪問看護は、ふつう医療保険で使います。医療保険の訪問看護は、原則として週3日までです。

ただし、人工呼吸器を使っているなど国が定めた病気や状態に当てはまる方や、主治医が「特別訪問看護指示書」を出した場合（一時的に体調が悪いときなど）は、週4日以上使えることがあります。条件によっては、1日に2回以上来てもらったり、2か所以上の訪問看護ステーションを組み合わせたりできる場合もあります。

1回の訪問は30分から90分くらいが目安です。15歳未満で重い障害や医療的ケアのあるお子様は、90分をこえる長い訪問が週3回まで認められる場合があります。

どのくらい使えるかは、お子様の状態や主治医の判断によって変わります。くわしくは主治医や訪問看護ステーションに相談してください。

## 費用と医療費の助成

医療保険で訪問看護を使うと、小学校に入る前のお子様は2割、小学生以上は3割が自己負担になります。

でも、実際には多くの方が、ほとんど負担なく使っています。次のような医療費の助成が使えることが多いからです。

- こども医療費の助成（市区町村ごとに、対象年齢や自己負担がちがう）
- 重度心身障害者（児）医療費の助成（自治体によって名前や条件がちがう）
- 小児慢性特定疾病の医療費助成（対象の病気の場合）

どの助成が使えるか、交通費などの実費がかかるかは、お住まいの市区町村や訪問看護ステーションに確認しましょう。手当や助成全体については「[特別児童扶養手当と障害児福祉手当の違い・もらえる条件](/blog/teate.html)」でもまとめています。

## 在宅レスパイト（自宅で休むためのしくみ）

訪問看護は、基本的に「お子様のケア」のためのサービスです。そのため、看護師が来ているあいだにご家族が外出することは、ステーションによって考え方がちがいます。

そこで、ご家族が休むための「在宅レスパイト事業」を行っている自治体が増えています。これは、訪問看護師が自宅に長めにいて、ご家族の代わりにケアをしてくれるしくみです。たとえば横浜市では、1回30分から6時間まで、1年度で合計24時間まで、利用料なしで使えます（2026年11月現在）。

ただし、在宅レスパイト事業は自治体が独自に行っているもので、あるかどうか、時間や費用は地域によって大きくちがいます。お住まいの市区町村の障害福祉の窓口に確認してみてください。

自宅ではなく、病院や施設にあずけて休む方法もあります。医療型短期入所は「[医療型短期入所とは？福祉型との違いと使い方](/blog/iryogata-tanki.html)」、レスパイト入院は「[レスパイト入院とショートステイの違い・どちらを使う？](/blog/respite-nyuin.html)」でくわしく紹介しています。

## 訪問看護ステーションの選び方

小児の訪問看護をしているステーションは、大人中心のところより少なめです。さがすときは、次のことを確認しましょう。

- お子様（とくに医療的ケアのあるお子様）の訪問の経験があるか
- 夜や休みの日に、電話で相談できるか（24時間対応）
- リハビリのスタッフがいるか
- 主治医や病院、相談支援専門員と連携してくれるか

病院の相談室や、都道府県の医療的ケア児支援センター（「[医療的ケア児支援センター一覧・47都道府県の相談窓口](/blog/iryocare-center.html)」）でも、地域のステーションの情報を教えてもらえることがあります。

## さいごに

訪問看護は、お子様の体を守るだけでなく、ケアを続けるお父様・お母様の心強い味方でもあります。「こんなことを相談していいのかな」と思うことでも、遠慮なく話してみてください。

自宅でのケアに加えて、ときどきあずけて休める場所があると、さらに安心です。あずけさき手帖では、お住まいの地域の施設をさがせます。

# 親が急に入院・倒れたときの障害児のあずけ先｜緊急ショートステイ

## はじめに

「もし、わたしが急に入院したら、この子はどうなるんだろう」。重い障害や医療的ケアのあるお子様を育てるお父様・お母様から、いちばんよく聞く心配のひとつです。

ご家族の病気やけがは、前もって決められません。でも、「だれに、どの順番で連絡するか」と「どこが受け入れてくれそうか」を、元気なうちに決めておくことはできます。

この記事では、急なときに使えるしくみと、いまからしておけるじゅんびを、順番にまとめました。

## まず知っておきたい3つのしくみ

急なときの受け入れには、おもに次のようなしくみがあります。

|  | どんなしくみ | 相談するところ |
| --- | --- | --- |
| 短期入所（ショートステイ） | 障害のあるお子様が、施設や病院に短い期間お泊まりする。医療的ケアがあるお子様は医療型が多い | 市区町村の障害福祉の窓口、相談支援専門員 |
| 地域生活支援拠点等 | 地域で、相談や緊急時の受け入れをまとめて受けもつ体制 | 市区町村の障害福祉の窓口 |
| 子育て短期支援事業（ショートステイ） | 保護者の病気などで子育てがむずかしいとき、児童養護施設などで子どもをあずかる。期間や受け入れ先は市区町村によってちがう | 市区町村の子育ての担当の窓口 |

重い障害や医療的ケアのあるお子様の場合、中心になるのは短期入所です。子育て短期支援事業は、障害のあるお子様を受けられるかどうかが地域や施設によってちがうので、お住まいの市区町村でご確認ください。

医療型短期入所のくわしい使い方は、「[医療型短期入所とは？福祉型との違いと使い方](/blog/iryogata-tanki.html)」でまとめています。

## 地域生活支援拠点等とは

地域生活支援拠点等は、障害のある方が地域で安心して暮らせるように、いくつかの事業所や機関が力を合わせて支える「しくみ」です。ひとつの建物のことではなく、地域の事業所が役わりを分けて受けもつ形も多いです。

国の通知では、拠点がになう役わりとして、次のようなことがあげられています。

- 相談：急なときに支えがなくなりそうなご家庭を、前もって知っておき、登録しておく。いつでも連絡がとれる体制をつくる
- 緊急時の受け入れ・対応：短期入所の事業所などを使って、急なときに受け入れられる体制をつくる。受け入れや、病院への連絡などをする
- 体験の機会・場：家以外で過ごす体験の場をつくる
- 専門的な人の確保・養成：医療的ケアや強い行動のある方に対応できる人をそだてる

ここでいう「緊急」には、介護をしているご家族の病気などで、支えが受けられなくなる場合もふくまれています。

障害者総合支援法の改正で、市町村は拠点を整えるよう努めることになりました。ただ、どこに拠点があるか、事前の登録があるか、夜や休日にどう動いてくれるかは、市区町村によって大きくちがいます。お住まいの市区町村でご確認ください。

## 急に入院が決まったときの順番

いざというときは、あわてて当然です。次の順番を、メモにして冷蔵庫などにはっておくと安心です。

1. お子様の安全をまもる。体調が悪そうなら、まず主治医や救急に連絡する
2. 相談支援専門員に連絡する（夜や休日は、事業所の決まりによります）
3. ふだん使っている短期入所の事業所に、空きがあるか聞く
4. つながらないときは、市区町村の障害福祉の窓口に「緊急で受け入れ先をさがしています」と伝える。地域生活支援拠点等があれば、そこにつないでもらう
5. 医療的ケアのあるお子様は、主治医や、ふだんの病院の相談室にも相談する
6. 受け入れ先が決まったら、サポートブック、お薬、医療的ケアの物品、受給者証などを持っていく

国の通知では、拠点のコーディネーターが、短期入所の事業所が見つからないときに相談にのり、いっしょに受け入れ先をさがすなど、相談支援事業所を後ろから支える役わりも書かれています。「どこに電話しても見つからない」ときは、拠点があるかどうか、窓口で聞いてみてください。

## 元気なうちにしておきたい5つのこと

急なときに受け入れてもらえるかどうかは、ふだんのじゅんびで大きく変わります。

1. 受給者証に短期入所をつけておく：使う予定がなくても、つけておくと話が早くなります（「[受給者証とは？障害児の取り方と流れをやさしく解説](/blog/jukyushasho.html)」）
2. 短期入所の事業所に登録して、一度使っておく：はじめての施設は、事前の面談や診察が必要なことが多く、急には使えないことがあります
3. 地域生活支援拠点等に、事前の登録があるか聞いておく：登録のしくみがある市区町村もあります
4. サポートブックを作り、すぐ出せる場所においておく：食事、ねむり方、医療的ケアのやり方、好きなことを書いておきます（「[サポートブックの作り方・あずけ先に伝わる書き方](/blog/support-book.html)」）
5. 連絡先の一覧を作る：主治医、病院の相談室、相談支援専門員、短期入所の事業所、市区町村の窓口、親せきなど

相談支援専門員がまだいない場合は、「[相談支援事業所とは？障害児の探し方と選び方](/blog/sodan-shien.html)」を読んで、早めにさがしておくと心強いです。

## 医療的ケアのあるお子様の場合

人工呼吸器やたんの吸引、経管栄養などがあるお子様は、看護師がいる医療型短期入所や、病院のレスパイト入院などが受け入れ先になることが多いです。どちらも数が少なく、急にはベッドが空いていないこともあります。

だからこそ、ふだんから主治医に「わたしが入院したら、この子はどこで受け入れてもらえますか」と聞いておくことが大切です。どこが受け入れてくれるかは、病院や地域によってちがいます。お住まいの市区町村や主治医にご確認ください。

医療的ケアのあるお子様の相談先として、都道府県の医療的ケア児支援センターもあります（「[医療的ケア児支援センター一覧・47都道府県の相談窓口](/blog/iryocare-center.html)」）。レスパイト入院については「[レスパイト入院とショートステイの違い・どちらを使う？](/blog/respite-nyuin.html)」でまとめています。

## 見つからないときは

それでも受け入れ先が見つからないことはあります。そのときは、ひとりでかかえこまずに、市区町村の窓口に「見つからない」とはっきり伝えてください。となりの市や、県の施設を紹介してもらえることもあります。

断られたときの考え方は、「[障害児の預け先がない・断られたときにできること](/blog/azukesaki-nai.html)」にまとめています。また、急なときのそなえは、将来の「親なきあと」のじゅんびにもつながります（「[親なきあとの準備は何から？今からできること](/blog/oyanaki.html)」）。

## あずけ先に伝えることのメモ

急なときは、受け入れてくれる人もお子様のことをよく知りません。次のことを1まいの紙にまとめておくと、電話でも、持っていくときにも役立ちます。

| 書いておくこと | 例 |
| --- | --- |
| お子様のこと | 名前、年れい、体重、病名、障害の様子 |
| 医療的ケア | 吸引の回数、経管栄養の量と時間、呼吸器の設定など |
| お薬 | 名前、量、のむ時間 |
| 体調のサイン | 熱が出やすいとき、ほっさの様子、「いつもとちがう」と気づくポイント |
| 連絡先 | 主治医、ご家族、親せき、相談支援専門員 |
| すきなこと・苦手なこと | 安心できる声かけ、すきな音楽、こわがるもの |

紙は、すぐ出せるところに置き、スマートフォンでも写真にとっておくと安心です。お父様・お母様が話せないときに、ほかのご家族が代わりに伝えることもできます。

きょうだいがいるご家庭は、きょうだいのあずけ先も同じように考えておきましょう。子育て短期支援事業や、親せき、学校の先生など、だれに頼めるかを書き出しておくと、いざというときに少し落ち着いて動けます。

## さいごに

急な入院は、だれにでも起こりえます。「そのときにどうするか」を一度紙に書いておくだけでも、お父様・お母様の不安は少し軽くなります。

あずけさき手帖では、短期入所や医療型短期入所を、地域や必要なケアからさがせます。お住まいの市区町村のページもあわせてご覧ください。

※制度のしくみや受け入れの体制は、市区町村や年度によって変わります。くわしくはお住まいの窓口でご確認ください。

# 重症心身障害児の児童発達支援・放課後等デイサービス（重心型）とは？ちがい・さがし方

## はじめに

「ねたきりで、たんの吸引もあるうちの子を、うけ入れてくれる通い先はあるのかな」。重い障害のあるお子様を育てるお父様・お母様から、よく聞く心配です。

お子様が通う場所には、小学校に入る前の「児童発達支援」と、学校に通うお子様の「放課後等デイサービス」があります。そのなかに、重い障害のあるお子様をおもにうけ入れる事業所があり、「重心型（じゅうしんがた）」とよばれることがあります。

この記事では、2つのサービスのちがい、重心型の事業所のとくちょう、さがす順番を、やさしくまとめました。「重症心身障害」という言葉の意味は、「[重症心身障害児とは？医療的ケア児との違い](/blog/jushin.html)」でくわしく書いています。

## 児童発達支援と放課後等デイサービスのちがい

どちらも、児童福祉法という国の法律で決められたサービスです。全国で、だいたい同じしくみで行われています。

|  | 児童発達支援 | 放課後等デイサービス |
| --- | --- | --- |
| 使うお子様 | おもに小学校に入る前のお子様 | 学校（幼稚園と大学をのぞく）に通っているお子様 |
| 使う時間 | 平日の日中など | 学校がおわったあと、土曜日や長いお休みの日 |
| していること | 毎日の生活の動きの練習、集団になれる練習など | 生活の力をのばす練習、まわりの人との交流など |
| 使える期間 | 小学校に入るまで | 学校に通っているあいだ。ひつようとみとめられれば、20歳になるまで使えることがある |

小学校に入るときに、児童発達支援から放課後等デイサービスに切りかわります。受給者証（サービスを使うための証明書）の中身も変わるので、入学の前の年の秋ごろから、相談支援専門員や市区町村の窓口と話しておくと安心です（「[受給者証とは？障害児の取り方と流れをやさしく解説](/blog/jukyushasho.html)」）。

放課後等デイサービスと、市区町村の日中一時支援のちがいは、「[日中一時支援と放課後等デイサービスの違い](/blog/houkago-day.html)」をご覧ください。

## 「重心型」の事業所とは

国の基準では、「おもに重症心身障害のお子様を通わせる事業所」には、次の人をそれぞれ1人以上おくことになっています。児童発達支援でも、放課後等デイサービスでも同じです。

- 嘱託医（その事業所とけいやくしている医師）
- 看護職員（看護師など）
- 児童指導員または保育士
- 機能訓練担当職員（理学療法士など、体の動きの練習を見る人）
- 児童発達支援管理責任者（お子様ごとの支援の計画をつくる人）

じっさいに、いつ、だれが何人いるかは事業所によってちがうので、見学のときに聞いてみてください。

また、国の基準をもとにした都道府県の条例（たとえば京都府）では、事業所の定員は、ふつうは10人以上です。でも、重心型の事業所は5人以上でもよいとされています。そのため、重心型は少人数の事業所が多いのが、とくちょうです。

## 児童発達支援センターとのちがい

小学校に入る前のお子様の通い先には、「児童発達支援センター」という名前のところもあります。以前は、センターに「福祉型」と「医療型（体の障害のあるお子様が対象）」の2つがありました。2024年4月からは法律が変わり、この2つが1つにまとめられました。あわせて、センターが地域の障害のあるお子様の支援の中心になる役わりも、はっきり決められました。

「近くに重心型の事業所がない」というときは、地域のセンターに相談してみるのも1つの方法です。

## ふつうの事業所でも、うけ入れてくれることがある

重心型でなくても、看護師がいて、医療的ケアのあるお子様をうけ入れている事業所もあります。歩けるお子様や、ほかのお子様と遊ぶのが好きなお子様には、そちらが合うこともあります。

- 重心型：少人数で、ねたきりのお子様や体の動きがとてもすくないお子様にあわせたすごし方が多い
- 看護師がいるふつうの事業所：歩ける医療的ケア児など、動きのあるお子様も多い

どちらがよいかは、お子様の体のようすと、ケアの中身によります。「重心型しかだめ」ときめつけず、両方の候補を相談支援専門員に聞いてみてください。医療的ケアのあるお子様のあずけ先全体は、「[医療的ケア児の預け先は？](/blog/iryoteki-care.html)」にまとめています。

## 送迎のこと

国の資料では、放課後等デイサービスのしくみの中に「学校と事業所のあいだの送迎」が入っています。じっさいに送迎があるか、どこまで来てくれるか、車に看護師がいっしょに乗るかは、事業所ごとにちがいます。

医療的ケアのあるお子様の送迎は、事業所の人手が足りず、「送迎はご家族で」と言われることもあります。そこで2024年4月からは、国の報酬（事業所に入るお金）のしくみが見直されました。重症心身障害のあるお子様や医療的ケアのあるお子様を送迎するとき、運転する人のほかに職員や看護師などが車に乗ると、ふつうより多く加算されるようになっています（杉並区の説明資料より）。

見学のときは、次のことをかならず聞いておきましょう。

- 家まで、または学校まで送迎があるか
- 車いすのまま乗れる車か
- 車の中で吸引などがひつようなとき、看護師が乗るか
- 送迎がない日や、ご家族が送るときの時間

学校から事業所までの送り迎えにこまったときは、「[障害児の通学支援・送り迎えに使えるサービス](/blog/tsugaku.html)」も読んでみてください。

## さがす順番

1. 相談支援専門員に「重心型、または看護師がいる事業所をさがしたい」と伝える（まだいない方は「[相談支援事業所とは？](/blog/sodan-shien.html)」）
2. 市区町村の障害福祉の窓口で、地域の事業所の一覧をもらう
3. 主治医や病院の相談室にも、通っているお子様が多い事業所を聞く
4. 医療的ケアがあるお子様は、都道府県の医療的ケア児支援センターにも聞く（「[医療的ケア児支援センター一覧](/blog/iryocare-center.html)」）
5. 2〜3か所を見学して、体験の利用をする
6. 市区町村で受給者証の手続きをして、事業所とけいやくする

重心型の事業所は数がすくなく、空きを待つことがあります。1か所にきめる前に、いくつか見学しておくと安心です。

## 見学で聞きたいこと

- 看護師が、いつも何人いるか（お休みの日の体制も）
- 吸引、経管栄養、人工呼吸器など、うけ入れられるケア
- 体調が悪くなったときの連絡と、むかえのきまり
- 1日のすごし方（体の動きの練習、ねる時間、食事）
- 長いお休みの日の、開いている時間
- 高校を卒業したあとの行き先について、相談にのってくれるか

見学のくわしいポイントは、「[短期入所の見学ポイント10こ](/blog/kengaku.html)」も参考になります。

## よくある困りごと

- 空きがなく、待つことになった
  →ほかの事業所にも登録して、使える日を少しずつふやしましょう。待っているあいだは、日中一時支援や訪問のサービスを組み合わせる方法もあります。
- 体調をくずしやすく、休みがちになる
  →休みが多くても通いつづけられるか、キャンセルのきまりはどうか、先に聞いておくと安心です。
- 近くに事業所がない
  →となりの市の事業所を使えることもあります。家に来てもらう居宅訪問型児童発達支援もかんがえてみてください（「[外に出にくい子の家で受けられるサービス](/blog/houmon-service.html)」）。

## 費用のこと

利用料は、原則としてサービスの1割です。世帯の所得にあわせて、1か月の上限がきまっています。また、満3歳になってはじめての4月1日から小学校に入るまでの3年間は、児童発達支援などの利用料がかかりません（おやつ代などは別）。くわしくは「[短期入所の費用はいくら？](/blog/hiyo.html)」をご覧ください。

## さいごに

重心型の事業所は、お子様にとっては楽しくすごせる場所、お父様・お母様にとっては少し体を休められる時間になります。高校を卒業すると、通う場所は大人の「生活介護」などに変わるので、早めにかんがえておきましょう（「[障害児の「18歳の壁」とは？](/blog/18sai-kabe.html)」）。

あずけさき手帖では、医療的ケアや重症心身障害に対応したあずけ先を、地域からさがせます。お住まいの市区町村のページもあわせてご覧ください。

※事業所の体制や送迎、利用できる日数は、事業所や市区町村、年度によって変わります。くわしくは事業所やお住まいの窓口でご確認ください。

# 外に出にくい子の家で受けられるサービス｜訪問入浴・居宅訪問型児童発達支援・訪問看護のちがい

## はじめに

「人工呼吸器をつけていて、出かけるだけで半日がかり」「かぜをひくと重くなりやすいので、人の多いところには行きにくい」。そんなお子様を育てるお父様・お母様も、すくなくありません。

外に出にくいお子様でも、家に来てもらって受けられるサービスがあります。この記事では、その中から「訪問入浴」「居宅訪問型児童発達支援」「訪問看護」の3つを中心に、ちがいと申しこむ順番をまとめました。

## 3つのサービスのちがい

|  | 訪問入浴 | 居宅訪問型児童発達支援 | 訪問看護 |
| --- | --- | --- | --- |
| していること | 家に浴そうを持ってきて、おふろに入れる | 家で、生活の動きの練習や遊びなどの支援をする | 体調のチェック、医療的ケア、リハビリなど |
| もとになる制度 | 市区町村の事業（地域生活支援事業） | 国の法律（児童福祉法）のサービス | おもに医療保険 |
| 申しこみ先 | 市区町村の障害福祉の窓口 | 市区町村の障害福祉の窓口 | 主治医（訪問看護指示書がひつよう） |
| 子どもが使えるか | 市区町村によってちがう | 外に出るのがとてもむずかしいお子様が対象 | 赤ちゃんから使える |

同じ「家に来てくれるサービス」でも、制度も申しこみ先もばらばらです。1つずつ見ていきましょう。

## 訪問入浴とは

訪問入浴は、浴そうを積んだ車で家に来て、おふろに入れてくれるサービスです。家のおふろ場がせまい、だきかかえて入れるのがむずかしい、というときに助けになります。

国の要綱では、訪問入浴は市区町村が行う「地域生活支援事業」の1つで、体の障害のある方が家でおふろに入れるようにする事業です。行うかどうかは、市区町村がえらぶ事業（任意事業）とされています。

市区町村の事業なので、あるかどうか、だれが、何回、いくらで使えるかは、地域で大きくちがいます。ここからは1つの例として、神奈川県厚木市の要綱を見てみます（ほかの市区町村ではきまりがちがいます）。

- 身体障害者手帳の1級か2級で、ねたきりの状態が続き、医師がおふろに入ってよいと証明した、65歳未満の方
- 回数はおおむね週1回（7月〜9月は、ほかの方法で入れないときは週2回まで）
- 来るのは、看護師1人以上と介護の人2人以上の体制の事業者
- 費用は、原則として市が9割を助成（生活保護の世帯や市民税がかからない世帯は10割）

この要綱には、お子様だけの書き方はありません。お子様が使えるかどうか、年れいのきまりがあるかは、お住まいの市区町村でご確認ください。身体障害者手帳の取り方は「[身体障害者手帳とは？](/blog/shintai-techo.html)」にまとめています。

## 居宅訪問型児童発達支援とは

居宅訪問型児童発達支援は、2018年度にできた、国の法律のサービスです。重い障害などで、児童発達支援などに通うために外に出ることがとてもむずかしいお子様の家に、支援する人が来てくれます。

家では、毎日の生活の動きの練習や、知ることやかんがえることをのばす支援などをします。国の資料では、人工呼吸器をつけているお子様や、感染症にかかりやすいお子様などが例にあげられています。ただし、「送迎する人がいない」など、お子様の体のようすとは別の理由では使えません。「通いたいけれど、まだ通えない」お子様の、はじめての療育の場になることもあります。

使える日数は、市区町村が決めます。例として福岡市の案内では、原則として月10日（週2日）までとされています。

使うまでの流れも、例として福岡市の案内を見てみます。

1. 相談する
2. サービスの利用計画をつくる
3. 市区町村に申請する
4. 受給者証を受けとる
5. 事業所とけいやくする
6. 利用をはじめる

費用は、原則としてサービスの1割で、世帯の所得にあわせた1か月の上限があります。満3歳になってはじめての4月1日から小学校に入るまでは、利用料がかかりません（神戸市の案内より。このきまりは全国で同じです）。

この事業所は数がとてもすくない地域もあります。近くにあるかは、相談支援専門員や市区町村の窓口に聞いてみてください。体調が安定してきて通えるようになったら、通う事業所に切りかえることもできます（「[重症心身障害児の児童発達支援・放課後等デイサービス（重心型）とは？](/blog/jushin-day.html)」）。

## 訪問看護とは

訪問看護は、看護師などが家に来て、体調のチェックや医療的ケア、リハビリなどをしてくれるサービスです。お子様のばあいは、ふつう医療保険で使います。使うには、主治医が書く「訪問看護指示書」がひつようです。

回数や費用、ご家族が休むための「在宅レスパイト事業」のことは、「[小児の訪問看護とは？回数・費用と在宅レスパイト](/blog/houmon-kango.html)」でくわしくまとめています。

## ヘルパーに来てもらう方法も

おふろや食事、着がえなどの手助けは、家に来るヘルパー（居宅介護）にたのめることもあります。お子様が使えるかどうかや、その条件は、お住まいの市区町村でご確認ください。ヘルパーさがしでこまったときは、「[障害児のヘルパーが見つからないときにできる7つのこと](/blog/helper.html)」を読んでみてください。

## こんなときは、どれ？

| こまっていること | まずかんがえたいサービス |
| --- | --- |
| おふろに入れるのが体力的にきびしい | 訪問入浴、ヘルパー、訪問看護（おふろの手伝い） |
| 吸引や呼吸器の管理を、だれかに見てほしい | 訪問看護 |
| 通えないけれど、療育を受けさせたい | 居宅訪問型児童発達支援 |
| 体の動きのリハビリをしたい | 訪問看護（リハビリのスタッフがいるステーション） |
| ご家族が少し休みたい | 在宅レスパイト事業、ヘルパー |

1つのこまりごとに、いくつかの方法があることも多いです。どれを組み合わせられるか、同じ日に使えるかは、市区町村や事業所によってかんがえ方がちがいます。お住まいの市区町村でご確認ください。

## 申しこむ順番

どれからはじめればよいかまよったら、次の順番がおすすめです。

1. 主治医に「家で受けられるサービスを使いたい」と相談する。訪問看護を使っていなければ、まず訪問看護からはじめることが多い
2. 相談支援専門員に、こまっていること（おふろ、療育、ご家族の休み）を伝える（まだいない方は「[相談支援事業所とは？](/blog/sodan-shien.html)」）
3. 市区町村の障害福祉の窓口で、訪問入浴と居宅訪問型児童発達支援があるか、お子様が使えるかを聞く
4. 使えそうなものから、受給者証の手続きをする
5. 事業所に来てもらい、家の中の動き方や、ケアのやり方をいっしょに確かめる

窓口では、「何にいちばんこまっているか」を先に伝えると、話が早く進みます。たとえば「週に1回、おふろに入れるのが体力的にきびしい」「同じ年の子とふれあう時間がない」などです。

## 家に人が来るときのじゅんび

- ケアのやり方や、体調が悪いときのサインをメモにしておく（「[サポートブックの作り方](/blog/support-book.html)」）
- 車をとめる場所や、浴そうを運び入れる通り道を、事業所と確かめておく
- 来てもらう曜日と時間を、カレンダーに書きこんでおく

家に人が来ることになれるまでは、お父様・お母様も気をつかうものです。少しずつで大丈夫です。

## さいごに

外に出にくいお子様でも、家で受けられる支えはあります。1つのサービスでぜんぶをまかなおうとせず、いくつかを組みあわせて、お子様とご家族の毎日を少しずつ楽にしていきましょう。家での支えになれてきたら、病院や施設であずかってもらう方法もかんがえてみてください（「[レスパイト入院とショートステイの違い](/blog/respite-nyuin.html)」）。

あずけさき手帖では、お住まいの地域のあずけ先をさがせます。お住まいの市区町村のページもあわせてご覧ください。

# 子どもの短期入所とは？お年寄りのショートステイとのちがい・見分け方

## はじめに

「〇〇市 ショートステイ」と調べたら、お年寄りの施設ばかりが出てきた。そんな経験はありませんか。

「短期入所（ショートステイ）」という言葉は、お年寄りの介護でも、障害のある方の福祉でも、子育ての支援でも使われています。同じ言葉でも、使うための手つづきも、受け入れてくれる場所も、まったくちがいます。

この記事では、障害のあるお子様の短期入所が、どんなしくみなのか、お年寄りのショートステイとどこがちがうのか、そして市の一覧や検索で「お子様が使えるところ」を見分けるコツを、やさしくまとめました。

## 「ショートステイ」は3つある

まず、よく出てくる3つを、ならべてみます。

|  | 障害のある方の短期入所 | お年寄りのショートステイ | 子育てのショートステイ |
| --- | --- | --- | --- |
| もとになる制度 | 障害者総合支援法（障害福祉サービス） | 介護保険 | 子育て短期支援事業（こども家庭庁の事業） |
| 使える人 | 障害のある方。お子様もふくむ | おもに65歳以上で、要介護・要支援の認定を受けた方 | お父様・お母様が病気などで、お子様のお世話ができないご家庭 |
| 手つづき | 市区町村で受給者証をもらう | 市区町村で要介護認定を受ける | 市区町村の子育ての窓口に申しこむ |
| 場所の例 | 障害のある方の施設、病院など | 特別養護老人ホームなど | 児童養護施設など |

障害のあるお子様のご家族が使うのは、ふつうは左はしの「障害のある方の短期入所」です。

## 障害のある方の短期入所とは

国の説明では、短期入所は、家でお世話をしているご家族が、病気などでお世話ができないときに、施設に短いあいだ泊まって、入浴・トイレ・食事などのお世話を受けるサービスです。ご家族がひと息つくため（レスパイト）にも使われています。

障害のあるお子様も使えます。お子様のばあいは、国が決めた「障害児の区分」で、区分1以上にあたることが条件です。この区分は、市区町村が受給者証の手つづきの中でたしかめます（「[受給者証とは？障害児の取り方と流れをやさしく解説](/blog/jukyushasho.html)」）。

短期入所には、大きく分けて次の3つの形があります。

- 福祉型：障害のある方の施設などで行う
- 福祉型強化：福祉型の中で、看護師がいて、医療的ケアのある方を受け入れる形
- 医療型：病院・診療所・介護老人保健施設などで行う。重症心身障害のお子様や、いしきがもどりにくい状態が長く続いているお子様などが対象

重い障害や医療的ケアのあるお子様は、医療型や福祉型強化を使うことが多いです。くわしくは「[医療型短期入所とは？福祉型との違いと使い方](/blog/iryogata-tanki.html)」をご覧ください。日帰りのあずかりや、ヘルパーとのちがいは「[短期入所と日中一時支援の違い・ヘルパーとの使い分け](/blog/chigai.html)」にまとめています。

## お年寄りのショートステイとのちがい

お年寄りのショートステイは、介護保険のサービスです。介護保険を使えるのは、65歳以上の方と、40歳から64歳で、年をとることに関係する決められた病気（特定疾病）のある方です。ですから、お子様は使えません。

検索の結果に出てくる「特別養護老人ホーム」「介護老人福祉施設」「短期入所生活介護」「短期入所療養介護」「要介護」といった言葉は、お年寄りのショートステイのしるしです。

ただし、1つだけ注意があります。介護老人保健施設（老健）は、医療型短期入所を行える場所の1つにもなっています。お年寄りの施設の名前でも、障害のある方の短期入所をあわせて行っているところが、たまにあります。名前だけで決めつけず、「障害福祉の短期入所の指定がありますか」「お子様も受け入れていますか」と聞いてみてください。

## 子育てのショートステイとのちがい

市区町村の子育ての窓口には、「子育て短期支援事業」という別のショートステイもあります。お父様・お母様が病気やつかれなどで、お子様のお世話がむずかしいときに、児童養護施設などでお子様をあずかるしくみです。1回に使える日数には市区町村の決まりがあり、たとえば箕面市（大阪府）では「原則7日以内」です。日数や、のばせるかどうかは、お住まいの市区町村でご確認ください。

こちらは障害のないお子様もふくめた、子育てぜんたいのための事業です。重い障害や医療的ケアのあるお子様を受け入れられるかは、施設や市区町村によってちがいます。お住まいの市区町村でご確認ください。

「出産で入院するあいだ、きょうだいをあずけたい」というときは、障害のないきょうだいは子育て短期支援事業、障害のあるお子様は障害福祉の短期入所、と分けてかんがえることもあります。

## 市の一覧や検索で、お子様むけを見分けるコツ

市の「事業所一覧」や検索の結果を見るときは、次のことばに注目してください。

- 「障害福祉サービス」「障害児」「重症心身障害」「医療的ケア」と書いてある
- 「医療型短期入所」「福祉型強化」「空床型」「併設型」「単独型」など、障害福祉の短期入所の言葉がある
- 「対象：児童」「18歳未満」「小学生から」など、年齢が書いてある
- 「主たる対象：知的障害」「身体障害」などの書き方がある

反対に、「要介護」「要支援」「ケアマネジャー」「介護保険」と書いてあれば、お年寄りむけです。

検索するときは、「〇〇市 短期入所 障害児」「〇〇市 医療型短期入所」「〇〇市 重症心身障害 短期入所」のように、お子様むけの言葉を足すと、見つかりやすくなります。

国の「障害福祉サービス等情報公表システム」（WAM NETの中にあります）では、地図や住所から、障害福祉の事業所をさがせます。サービスをえらんでしぼりこめるので、「短期入所」をえらぶと、障害福祉の短期入所の事業所だけを見られます。ただ、「お子様を受け入れているか」「どんな医療的ケアができるか」は、のっていないこともあるので、事業所に聞いてたしかめてください。

## 使いはじめるまでの順番

1. 市区町村の障害福祉の窓口で、「短期入所を使いたい」と伝え、受給者証の手つづきをする
2. 相談支援専門員に、お子様に合う短期入所をいっしょにさがしてもらう（まだいない方は「[相談支援事業所とは？障害児の探し方と選び方](/blog/sodan-shien.html)」）
3. 候補の事業所に電話して、お子様の年齢やケアで受け入れてもらえるか聞く
4. 見学して、日帰りや短い時間の体験をする（「[短期入所（ショートステイ）の見学ポイント10こ](/blog/kengaku.html)」）
5. けいやくして、予約できるようにする

重い障害や医療的ケアのあるお子様の短期入所は、数が少なく、はじめて使うまでに時間がかかることが多いです。急に必要になる前に、元気なうちから登録しておくと安心です。急なときのことは「[親が急に入院・倒れたときの障害児のあずけ先](/blog/kinkyu-short.html)」にまとめています。

費用は、原則としてサービスの1割で、世帯の所得におうじて1か月の上限があります。食事代などは別です（「[短期入所の費用はいくら？障害児の利用料のしくみ](/blog/hiyo.html)」）。

## さいごに

「ショートステイ」とひとことで言っても、お年寄りのもの、子育てのもの、障害のある方のもの、と3つあります。検索でお年寄りの施設ばかり出てきても、お子様が使えるところがないとは限りません。言葉を足して調べたり、窓口や相談支援専門員に聞いたりしてみてください。

市ごとのくわしい窓口や事業所は、「金沢市の短期入所・日中一時支援｜障害児・医療的ケア児のあずけ先」（[金沢市](/blog/city-kanazawa.html)）や、「[松山市](/blog/city-matsuyama.html)」「[郡山市](/blog/city-koriyama.html)」「[八王子市](/blog/city-hachioji.html)」「[姫路市](/blog/city-himeji.html)」など、市の記事にまとめています。あずけさき手帖では、お子様を受け入れている短期入所を、地域や必要なケアからさがせます。

※制度の中身や対象は、年度や市区町村、事業所によって変わります。くわしくはお住まいの窓口でご確認ください。

# 重心・医療的ケアのショートステイの「空き」の調べ方

## はじめに

「来月、どうしても泊まりであずけたい日がある。でも、どこが空いているのか分からない」。重い障害や医療的ケアのあるお子様のお父様・お母様から、よく聞くなやみです。

インターネットで「ショートステイ 空き」と調べても、お年寄りの施設の空き情報ばかり出てくることが多いです（ちがいは「[子どもの短期入所とは？お年寄りのショートステイとのちがい](/blog/kodomo-short.html)」）。お子様の短期入所は、空きがいつでも見られるページは、まだ多くありません。

この記事では、重症心身障害（重心）や医療的ケアのあるお子様の短期入所の「空き」を調べるときに、どこを見て、だれに聞けばよいかを、順番にまとめました。

## まず知っておきたいこと

重心や医療的ケアのお子様を受け入れる短期入所は、もともと数が少ないです。また、医療型短期入所は、病院の入院のベッドが空いたときに使う形のところも多く、空きは毎日のように変わります（「[医療型短期入所とは？福祉型との違いと使い方](/blog/iryogata-tanki.html)」）。

そのため、「空き情報のページを見れば、すぐ予約できる」とは限りません。空きを調べるのは、次の3つを組み合わせることだとかんがえておくと、気もちがすこし楽になります。

- 市や県が出している空き情報や一覧を見る
- 登録している病院・施設に、予約のきまりにそって申しこむ
- 相談支援専門員などに、いっしょに調整してもらう

## 市や県の「空き情報」のページ（例）

いくつかの市や県では、重心や医療的ケアのある方の短期入所について、空き情報や当番のしくみを公開しています。ここでは、公式ページでたしかめられた例を2つ紹介します。お住まいの地域に同じしくみがあるかは、お住まいの市区町村でご確認ください。

例1：千葉市（2026年3月の更新）

千葉市は、「重症心身障害児者等受け入れ短期入所空き状況」というページで、重症心身障害の方や、それと同じくらい濃い医療的ケアがいる方を受け入れる、市内の短期入所8か所の情報をまとめています。空きの情報は日々変わるので、くわしくは各事業所にたしかめるように、と書かれています。使うときは、ご家族と事業所のけいやくなので、事業所にちょくせつ問い合わせる形です。前もって、区の窓口で、短期入所の支給決定を受けておく必要があります。

例2：兵庫県の「輪番制（りんばんせい）」（2026年度）

兵庫県は、病院が順番に（輪番で）医療型短期入所のベッドを空けておくしくみを行っています。2026年度は、神戸・阪神地域で1床、播磨地域で1床です。地域ごとに当番の病院と、受け入れられる年齢やケアの条件が決まっています。たとえば播磨地域では、月によって当番の病院がかわり、人工呼吸器のあるお子様を受け入れられる病院と、受け入れられない病院があります。使う前に、受給者証の手つづき、かかりつけ医の紹介状、登録のための事前の診察（いらない病院もあります）、けいやくが必要です。予約制で、空きがないときや、お子様の状態によっては使えないことがあります。

兵庫県の市の記事（「[神戸市](/blog/city-kobe.html)」「[姫路市](/blog/city-himeji.html)」）、千葉市の記事（「[千葉市](/blog/city-chiba.html)」）にも、この情報をのせています。

## 病院・施設の「予約のしくみ」を知る

重心や医療的ケアのお子様の短期入所は、「空いていたら、いつでも使える」のではなく、予約のきまりがあることが多いです。たとえば、次のような形です。

例：東京都立府中療育センター

- 使いたい月の2か月前の1日から15日までに申しこむ
- 申しこみを調整して、月末に結果を電話で知らせる
- 希望する人が多く、希望どおりにならないことがある
- はじめての方は、前もって短期入所の医師の診察を受ける
- 18歳未満のお子様は、受給者証に「医療型」または「重心」と書かれていることが条件

このように、「申しこみの期間」「結果が出る日」「受給者証に書かれていること」が決まっていることがあります。登録している施設ごとに、次のことをメモしておくと、空きを逃しにくくなります。

- 何か月前の、何日から何日までに申しこむか
- 電話・FAX・ウェブなど、申しこみの方法
- キャンセルが出たとき、れんらくをもらえるか
- 1か月に使える日数のめやす

## 空きを調べる順番

1. 受給者証に、短期入所（必要なら医療型）が入っているかたしかめる（「[受給者証とは？](/blog/jukyushasho.html)」）
2. 市や県に、空き情報のページや、受け入れ施設の一覧があるか調べる。なければ、市区町村の障害福祉の窓口で「重心・医療的ケアの短期入所の一覧はありますか」と聞く
3. 候補の施設に電話して、受け入れの条件と予約のきまりを聞く
4. 2〜3か所に登録しておく。1か所だけだと、空きがないときに困ります
5. 使いたい日が決まったら、それぞれの予約のきまりにそって、早めに申しこむ
6. 空きがないときは、相談支援専門員に相談する

## 相談支援専門員にたのめること

相談支援専門員は、お子様のサービスの計画をつくり、事業所との調整をしてくれる人です（「[相談支援事業所とは？](/blog/sodan-shien.html)」）。空きさがしでは、次のことをたのんでみてください。

- お子様のケアに合う短期入所の候補を、地域の中から教えてもらう
- 施設に、お子様の状態を伝えて、受け入れられるか聞いてもらう
- 「この日に使いたい」という希望を、いくつかの施設に問い合わせてもらう
- 空きがないときに、日中一時支援や在宅レスパイトなど、ほかの方法をかんがえてもらう

医療的ケアのあるお子様は、医療的ケア児等コーディネーターや、都道府県の医療的ケア児支援センターも、地域の受け入れ先にくわしいことがあります（「[医療的ケア児等コーディネーターとは？](/blog/ikea-coordinator.html)」「[医療的ケア児支援センター一覧](/blog/iryocare-center.html)」）。

## 空きがないときにかんがえること

- 日にちをずらせるか、半日や日帰りならあるか聞く
- 病院のレスパイト入院をかんがえる（「[レスパイト入院とショートステイの違い](/blog/respite-nyuin.html)」）
- となりの市や、県の中の別の地域の施設も候補に入れる
- 急な入院など、どうしても必要なときは、緊急の受け入れのしくみがないか、市区町村に聞く（「[親が急に入院・倒れたときの障害児のあずけ先](/blog/kinkyu-short.html)」）

断られてしまったときのことは「[障害児の預け先がない・断られたときにできること](/blog/azukesaki-nai.html)」にまとめています。

## 空きを逃さないための、ふだんの工夫

- 使いたい日が決まっている行事（きょうだいの行事、冠婚葬祭、ご家族の通院など）は、カレンダーに書き出して、予約の受付が始まる日もいっしょに書いておく
- ときどき使っておく。施設によっては、長く使っていないと、もういちど受診や面談が必要になることがあります
- 使ったあとに、施設の方に「次はいつごろ空きそうですか」と聞いておく
- お子様のケアの手順や、ふだんのようすを紙にまとめておくと、はじめての施設でも話が早く進みます（「[サポートブックの作り方](/blog/support-book.html)」）
- キャンセルが出たときにれんらくをもらえる施設なら、電話に出られる時間を伝えておく

空きは、お父様・お母様の努力だけで、ふやせるものではありません。それでも、予約のきまりを知り、登録先をすこしずつふやしていくと、「どこも空いていない」という月がへっていきます。

## さいごに

重心や医療的ケアのお子様の短期入所は、空きを見つけるだけでも大変です。でも、ふだんから2〜3か所に登録して、予約のきまりを知っておくと、使える日がすこしずつふえていきます。ひとりでさがさず、相談支援専門員にもたよってください。

あずけさき手帖では、重症心身障害や医療的ケアに対応した短期入所を、地域や必要なケアからさがせます。施設ごとに、出典と確認日ものせています。

※空き情報のページや予約のきまりは、年度や施設、市区町村によって変わります。くわしくは施設やお住まいの窓口でご確認ください。

# 障害のあるお子様も使える？一時預かり・ファミリーサポート・ベビーシッター補助

## はじめに

「数時間だけ、だれかに見ていてほしい」。病院の受診、きょうだいの行事、すこし休みたいとき。そんなとき、子育て中のご家庭には「一時預かり」や「ファミリーサポート」「ベビーシッター」などのしくみがあります。

では、障害や医療的ケアのあるお子様は、これらを使えるのでしょうか。答えは「しくみによる」「市区町村や事業所による」です。

この記事では、子育てのための一時あずかりのしくみと、障害のあるお子様のために区や市が用意しているしくみの例、申しこむ前に聞いておきたいことをまとめました。

## 子育てのしくみと、障害福祉のしくみはちがう

お子様を短い時間あずけるしくみは、大きく2つに分かれます。

|  | 子育てのしくみ | 障害福祉のしくみ |
| --- | --- | --- |
| 例 | 一時預かり、こども誰でも通園制度、ファミリー・サポート・センター、ベビーシッターの補助 | 日中一時支援、短期入所、放課後等デイサービスなど |
| 窓口 | 市区町村の子育て・保育の窓口 | 市区町村の障害福祉の窓口 |
| 使う人 | 子育て中のご家庭ぜんたい | 障害のあるお子様（受給者証などがいる） |
| 障害のあるお子様 | 受け入れは施設や市区町村による | お子様に合わせた支援が前提 |

重い障害や医療的ケアのあるお子様は、障害福祉のしくみのほうが、受け入れの体制がととのっていることが多いです（「[短期入所と日中一時支援の違い](/blog/chigai.html)」「[日中一時支援と放課後等デイサービスの違い](/blog/houkago-day.html)」）。でも、子育てのしくみも、うまく使えば、選べるあずけ先がふえます。

## 一時預かり

一時預かりは、家での保育が一時的にむずかしくなった小さなお子様を、保育所や認定こども園、幼稚園、地域子育て支援拠点などで、おもに昼間にあずかるしくみです。たとえば兵庫県の案内では、冠婚葬祭や、お父様・お母様のリフレッシュ、一時的なお仕事、お父様・お母様のけがや病気での入院などのときに使えるとされています。対象は小学校に入る前のお子様で、料金や時間は市町によってちがいます。

障害や医療的ケアのあるお子様を受け入れるかどうかは、施設や市区町村によってちがいます。看護師がいる施設は多くありません。お住まいの市区町村でご確認ください。

また、国の「居宅訪問型保育」という保育のしくみでは、障害や病気などの程度から、集団での保育がとてもむずかしいと市区町村が認めたばあいなどに、保育者がお子様の家に来て保育をする形があります。対象は原則3歳未満です。お住まいの市区町村に、このしくみがあるか聞いてみてください。保育園や幼稚園での受け入れは「[医療的ケア児は保育園・幼稚園に入れる？](/blog/hoikuen.html)」にまとめています。

## こども誰でも通園制度

2026年4月から、「こども誰でも通園制度」が本格的にはじまりました。0歳6か月から満3歳未満のお子様が、お父様・お母様がはたらいているかどうかにかかわらず、月10時間まで、保育所などに通えるしくみです。

障害や医療的ケアのあるお子様を、どの施設が受け入れるかは、市区町村や施設によってちがいます。お住まいの市区町村の子育ての窓口でご確認ください。

## ファミリー・サポート・センター

ファミリー・サポート・センター（ファミサポ）は、「あずけたい人（依頼会員）」と「あずかりたい人（提供会員）」が会員になり、地域の中で助けあうしくみです。国の説明では、保育施設までの送りむかえや、学校の放課後、冠婚葬祭、買い物などの外出のときに、お子様をあずかることが例にあげられています。

提供会員は、看護師などの専門家とは限らない、地域の方です。そのため、障害のあるお子様を受け入れるか、どこまでのお世話をお願いできるかは、センターによってちがいます。たんの吸引や経管栄養などの医療的ケアは、お願いできないとかんがえておいたほうが安心です。くわしくは、お住まいの市区町村のセンターでご確認ください。

医療的ケアのないお子様や、きょうだいの送りむかえなどには、心強い助けになることがあります（「[障害児のきょうだいの行事の日、預け先はどうする？](/blog/kyodai-gyoji.html)」）。

## ベビーシッターの補助

ベビーシッターの料金を、区や市が助成しているところがあります。東京都の区では、「ベビーシッター利用支援事業（一時預かり利用支援）」という形で、障害のあるお子様は使える時間や年齢がふえるしくみの区があります。

例：目黒区（2025年度の区のページ。今の年度の中身は区でご確認ください）

- 障害のあるお子様は、12歳になる年度の終わり（小学6年生）まで使える
- 1年度に288時間まで（ふつうは144時間）
- 補助は1時間2,500円まで（22時から7時は3,500円まで）
- 障害者手帳か受給者証の写しが必要

ほかの区の例では、港区と荒川区は、障害のあるお子様は1年に288時間まで使えます（ふつうは144時間。どちらも2026年度の区のページ。荒川区は小学校に入る前のお子様が対象）。北区は、障害のあるお子様なら小学6年生まで使えます。くわしくは各区の記事（「[目黒区](/blog/city-meguro.html)」「[港区](/blog/city-minato.html)」「[北区](/blog/city-kita.html)」「[荒川区](/blog/city-arakawa.html)」）をご覧ください。

ベビーシッターは、会社やシッターによって、障害のあるお子様や医療的ケアに対応できるかがちがいます。たのむ前に、お子様のようすを伝えて、受けられるかをたしかめてください。

## 障害のあるお子様むけの一時あずかりがある区や市も

子育てのしくみとは別に、区や市が、障害や医療的ケアのあるお子様のための一時あずかりを用意していることもあります。

例：練馬区「障害児一時預かり事業 なないろ」

- 区内に住む1歳6か月から小学6年生までのお子様
- お父様・お母様の病気や休養、きょうだいの行事、冠婚葬祭などのときに使える
- 手帳や受給者証がなくても、こども発達支援センターなどで相談したことがあれば対象になることがある

例：江東区「医療的ケア児緊急一時預かり事業」（2026年10月から）

- 区内に住み、人工呼吸器・たんの吸引・経管栄養など、区が決めた医療的ケアが毎日必要なお子様
- ご家族の病気や入院、学校行事、冠婚葬祭などで、ほかにお世話をする人がいないときに、日中にあずかる
- 1年度に24時間まで。通所の受給者証と、主治医の書類がいる。前もって区に申請する

くわしくは「[練馬区](/blog/city-nerima.html)」「[江東区](/blog/city-koto.html)」の記事をご覧ください。川崎市の「障害児・者一時預かり」のように、日中一時支援を「一時預かり」とよんでいる市もあります（「[川崎市](/blog/city-kawasaki.html)」）。名前だけで判断せず、窓口で中身を聞いてみてください。

医療的ケアのあるお子様は、家に看護師が来て、ご家族が休む時間をつくる「在宅レスパイト」がある市もあります（「[小児の訪問看護とは？回数・費用と在宅レスパイト](/blog/houmon-kango.html)」）。

## 申しこむ前に聞いておきたいこと

- 障害や医療的ケアのあるお子様を受け入れているか
- 看護師や、障害のあるお子様になれた職員がいるか
- 薬をのませる、吸引をするなど、お願いできることと、できないこと
- 発作や体調の変化があったときのれんらくのしかた
- 事前の面談や、ならし保育がいるか
- 料金と、補助を使うときの手つづき

お子様のようすは、紙にまとめて渡すと伝わりやすくなります（「[サポートブックの作り方](/blog/support-book.html)」）。どのしくみが合うか迷ったら、相談支援専門員に「子育てのしくみも合わせてかんがえたい」と伝えてみてください（「[相談支援事業所とは？](/blog/sodan-shien.html)」）。

## さいごに

子育ての一時あずかりは、障害のあるお子様が使えるかどうか、地域や施設でちがいます。「うちの子は無理かも」と決める前に、子育ての窓口と障害福祉の窓口の両方に聞いてみてください。区や市が、障害のあるお子様のために、別のしくみを用意していることもあります。

あずけさき手帖では、市区町村ごとの記事で、障害のあるお子様が使える一時あずかりや補助をまとめています。

※しくみの中身や対象、料金は、年度や市区町村によって変わります。くわしくはお住まいの窓口でご確認ください。
